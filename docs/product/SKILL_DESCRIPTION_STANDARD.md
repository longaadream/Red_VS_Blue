# 棋子技能描述语言标准

更新：2026-09-14。采用用户确认的紧凑描述格式，保留RED-209位移语义。
本轮已核对144项清单，更新142份技能JSON及78份预览；弃用的凛冬咆哮与已符合要求的率先出阵保持原样。见[逐项落地记录](../qa/RED-209-skill-text-applied.json)。图鉴、选棋详情和战斗详情已按技能keywords加粗正文关键词，保持主题文字颜色；新手首次查看说明已接入这三个入口。

## 1. 基本原则

用简洁中文短句写清触发条件、目标、效果和数值。不强制统一长句，不堆同义词、示例或不适用情况。参数可以简写，决定机制的条件必须保留。

- 参数栏展示类型、费用、CD和次数。常规CD不在正文重复；重置/增加冷却、新技能可立即使用仍是效果，必须写明。
- 正文保留角色特有条件、秘密选择、可选效果、数量、距离基准与特殊时间。
- 通用状态、取整、生命周期及衍生手牌效果放词典或关联手牌；关键限制尚无其他可见位置时，先保留正文。
- 关键词加粗，强调状态、机制及特殊伤害类型，不整句加粗。文档的 `**关键词**` 是排版示意；客户端须正式支持渲染，不直接显示星号。

## 2. 目标与距离

| 写法 | 含义 |
| --- | --- |
| 选择空地格（5） | 最远5格内的1个空地格 |
| 选择地格（5） | 最远5格内的1个地格，不额外限定为空地格 |
| 选择敌人（5） | 最远5格内的1名敌人 |
| 选择敌人（>6） | 超过6格，不包含第6格 |
| 选择敌人（≥6） | 至少6格，包含第6格 |
| 选择敌人（3–6） | 3至6格，包含两端 |
| 选择其他友军（7） | 7格内友军，排除自身 |
| 选择全图敌人 | 无局部射程限制，不用未验证的固定99格冒充全图 |

单目标可省“1名/1个”，多目标保留数量。选择、随机、所有、生命最低是不同选取方式，不能互换。
普通距离按目标选择器定义；方形区域保留N×N。例如闪现写“选择自身周围5×5内空地格”，不能改成普通距离（5）或（2）。

“自身”指持有/施放技能的棋子，“你”指所属玩家。第二步相对目标计算时写“目标周围空地格（2）”，不能省掉距离基准。区域中心、左上角与路径范围也必须明确。

统一写“正方向”，代替“同行同列”“同一行或同一列”“行或列”，指上下左右，不包含斜向。
玩家文案中的“可行走格/可行走地格”统一写“空地格”；允许掩体时明确写“空地或掩体”。此措辞不改变walkable、占用、地形类型或落点校验；含义不等价时应在目标说明或词典中明确，不能偷偷改规则。

## 3. 数值、时长与资源

| 内容 | 写法 |
| --- | --- |
| 普通伤害 | 造成2点伤害 |
| 特殊伤害 | 造成2点**真实伤害** |
| 倍率 | 2x攻击力、1.5x攻击力、0.75x攻击力；1x省为攻击力 |
| 自身回复 | 回复自身5点 |
| 目标回复 | 回复目标5点；多对象时写明选定友军等具体对象 |
| 状态持续 | **定身**[1]、**减伤**[2]，单位为回合 |
| 强度层数 | **天照** x 2；可组合为“**状态** x 2 [3]” |
| 玩家资源 | 行动点、充能点、临时行动点；不用AP/CP代替可见名称 |

普通伤害不写“物理/魔法/法术”前缀。内部 `physical`、`magical`、`true` 可以保留，显示名称统一不要求迁移机制。
倍率在属性前，层数在状态后；固定属性加值与百分比仍区分，攻击力+2不等于攻击力+50%。
同时存在intensity与stacks时不能机械合并；x n对应该状态定义的强度或层数，单位效果由词典说明。

生命回复可省“生命值”，行动点等资源回复必须写名称。实际伤害、施放时攻击力、目标最大生命等计算基准不能删。例如“回复自身0.5x实际伤害点”，不能省“实际”。取整、最低伤害和叠加统一引用词典。

## 4. 时间、触发与效果关系

写“游戏开始时”，不写“开局”。回合触发注明所属方与阶段，例如“你的回合开始时”“目标下回合结束时”。不能以“每回合”掩盖归属，也不能用[N]替代延迟触发。

- [N]只表示状态持续回合，按词典计时；准备进度6不是[6]，行动次数也不是时长。
- 延迟一次仍写明确时点，如“目标下回合结束时再次受到等量伤害”。
- 双尾飞行保留“此后的第2个己方回合结束时”落地，不只用[2]代替落地时点。
- 不写时长不代表永久；永久性与每局次数须来自定义，必要时保持可见。

**句号分隔的效果按顺序独立执行，前项失败不阻止后项；逗号或“并”连接的效果依赖前项成功，前项失败则后续不执行。**
该约定适用于效果之间的连接；条件中的逗号、单个效果的参数及对象列举不是执行节点。

> 造成2点伤害。回复自身1点。
>
> 造成2点伤害，并回复自身1点。

第一例的回复不依赖伤害成功，第二例依赖。不得为缩短文字随意拆句或合句。
运行时必须显式保存和判断依赖，不能仅凭标点自动改变旧代码。“成功命中”“成功结算”“实际扣血”可能不同，需核对效果契约，不能把success自动视作伤害大于0。

“同时”只用于引擎已支持的同批效果，遵守[ADR-0022](../decisions/ADR-0022-deterministic-effect-batch-queues.md)。逗号和“并”不表示同时；图中的顺序、依赖和批次须显式保存。

## 5. 位移动词与框架约束

主动走格、冲刺、传送、推拉、换位分别使用对应动词。“正方向”只压缩方向表述，不混同位移种类。

- 走格/冲刺/推拉有实际路径，传送/换位只有落点接触。
- “经过”包含实际路径和终点，不含起点；“落在”只表示终点。取消或原地不拾取。
- 非法落点默认取消，整组一起提交或取消。公共保障放词典，特殊碰撞伤害或替代方案仍写正文。
- 双尾飞行标记不阻挡进入；到期按实际占位整组提交或取消，不写成“预留格不可进入”。
- 定身限制主动走格；禁锢限制棋盘位移，不阻止死亡或强制离场。

实现严格走[统一位置入口](../technical/ENGINE_CORE.md#5-空间与战斗事实)，禁止直接写棋子坐标。通行/停止规则来自真实路径查询和提交参数，不能凭动词猜测，也不能靠文案隐藏坐标直写。

## 6. 关键词与可省略信息

**打坐**作为独立关键词：无法主动走格或使用技能。正文保留准备进度、推进条件与奖励。本轮已新增词条及仙人模式引用，界面仍使用现有关键词展示。

按用户确认省略：

- 非核心棋子死亡不提供普通死亡充能收益是公共规则，影分身不另写“不提供充能点”。
- 诅咒效果由衍生手牌展示，诅咒结界只写生成条件与手牌，不重复该牌的伤害和弃置说明。
- 骑射横扫不额外写“可穿透棋子”；不能推广为所有弹射物具有相同穿透规则。
- 凛冬咆哮已弃用，不作为现役描述迁移阻塞。

圣盾不叠加、默认计时、实际伤害口径和复活清理引用词典。角色特有限制、数量、秘密选择、距离基准、延期时点和每局限用仍须可见。关联手牌或词典不能查看时，应先补齐展示再删必要信息。

## 7. 新手提示与展示一致性

首次打开技能详情时展示一次符号提示，确认后保存已读状态，不再自动弹出。提示解释：

- 目标后（5）是最远5格；（>6）不含6，（≥6）包含6，（3–6）包含两端。
- [3]是持续3回合，x 2是状态定义的强度/层数，2x攻击力是倍率。
- 正方向指上下左右；句号、逗号和“并”按效果依赖约定阅读。

已实现：首次查看时弹出说明，点击“知道了”后通过本机localStorage保存，三个入口共用已读状态。存储不可用时仅在当前页面记住确认；换设备或清除存储后会再次显示。正文、targetText、预览、参数栏、关键词和衍生手牌应共用定义，不能各自维护不一致数值。

## 8. 写法示例与检查

以下为语言示例，不证明对应资源已经改动：

| 技能 | 建议短句 |
| --- | --- |
| 致命视线 | 选择敌人（>6），造成2x攻击力的伤害。 |
| 圣光闪耀 | 选择友军（7），回复目标5点。 |
| 神威·转移 | 选择其他友军（7），将其传送至自身周围空地格（7）。 |
| 仙人模式 | 进入**打坐**，准备进度6。你的回合开始时进度−1，每个存活友方影分身额外−1。归零时结束打坐，获得3点行动点和1点充能点。 |
| 诅咒结界 | 每回合1次：你的回合自身受伤时免疫该次伤害，并交给对手1张【诅咒】。 |

“率先出阵”保留：“当阵容中有本棋子时，本棋子首先上场。”
“裂魂”保留游戏开始时授予本局玩家规则的语义，不能改成持有者登场或存活时才触发。

1. 目标、数量、边界、基准与选择器一致，方形没有误写成距离。
2. 时点、回合归属、时长、准备进度和次数没有混用。
3. 倍率、伤害类型、实际伤害及属性计算基准准确。
4. 标点依赖与执行分支一致，成功语义有依据。
5. 位移经统一入口，正文与路径、接触和失败行为一致。
6. 省略的信息在词典、参数栏或衍生手牌确实可见。
7. 描述与代码冲突先确认机制，不靠文字偷偷改玩法；纯规范PR不携带旧资源覆盖最新main。

技能详情的技能标题旁常驻 Tips · 描述说明入口，已确认的玩家仍可随时主动打开同一份说明。
