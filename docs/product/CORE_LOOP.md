# Demo v0.1 核心循环

状态：有效
权威规则：[核心对局合同](./DEMO_V0_1_CORE_MATCH_CONTRACT.md)

```text
选择内容阵营与 8 枚不同核心棋子
  → 服务端以 seed 生成双方不重叠出生点
  → 双方查看全部站位，各自最多重投 1 枚并锁定
  → 同时确认部署结果
  → 交替进行自己的回合（恢复行动点、移动/使用技能）
  → 终局检查
  → 未结束则进入下一完整轮次
```

1. 座位决定先后手；内容阵营不决定先后手。后手取得幸运币。
2. 部署重投阶段限时 45 秒；双方均可查看全部站位，各自锁定后同时确认部署结果。
3. 每位玩家的第 1 个自己回合基础行动点为 1，此后每个自己回合加 1，最高为 10。
4. 对局在核心棋子全灭、40 个完整轮次结算后未分胜负，或投降时结束。

阶段细则、时间表和例外均以合同为准，尤其是[回合与行动点](./DEMO_V0_1_CORE_MATCH_CONTRACT.md#6-回合行动点与时限)和[终局](./DEMO_V0_1_CORE_MATCH_CONTRACT.md#10-终局)。
