# Demo v0.1 核心循环

状态：有效
权威规则：[核心对局合同](./DEMO_V0_1_CORE_MATCH_CONTRACT.md)

```text
选择内容阵营与 8 枚不同核心棋子
  → 基尔加丹移入仪式扩展；双方各确定性随机召唤 1 枚先锋并随机落到空格
  → 自己的回合从预备区至多三选一，免费召唤到与所有存活场上棋子曼哈顿距离严格大于 5 的安全空格；无安全格时确定性随机落到空格
  → 完整结算召唤触发与场上核心终局检查，然后直接进入正常行动阶段（恢复行动点、移动/使用技能）
  → 该部署核心在放置当回合第一次成功普通移动消耗 0 AP 并消费公开 statusTag；未使用则在本回合结束、行动权交接前清除
  → 终局检查
  → 未结束则进入下一完整轮次
```

1. 座位决定先后手；内容阵营不决定先后手。后手取得幸运币。
2. 初始化完成时双方场上各有 1 枚随机先锋；每个自己的回合若普通预备区非空，必须先免费部署 1 枚，再进入正常行动阶段。候选与合法落点只向当前输入玩家公开；部署完成后没有独立免费移动或跳过窗口，新棋子的当回合免费首移 statusTag 随普通场上状态公开显示。
3. 每位玩家的第 1 个自己回合基础行动点为 1，此后每个自己回合加 1，最高为 10。
4. 双先锋初始化完成后，只计算场上存活核心；一方场上核心为 0 时立即败北，普通预备区与仪式暂存的基尔加丹都不能阻止终局。第 40 个完整轮次结算后仍未分胜负时平局，投降立即结束。

阶段细则、时间表和例外均以合同为准，尤其是[回合与行动点](./DEMO_V0_1_CORE_MATCH_CONTRACT.md#6-回合行动点与时限)和[终局](./DEMO_V0_1_CORE_MATCH_CONTRACT.md#10-终局)。
