# Demo v0.1 术语

状态：有效
权威规则：[核心对局合同](./DEMO_V0_1_CORE_MATCH_CONTRACT.md)

| 术语 | 定义 |
| --- | --- |
| 座位（red / blue） | 对局中的玩家位置，用于确定先后手；不代表内容阵营。 |
| 内容阵营（light / dark；亦可称 good / evil） | 玩家选择棋子时所属的内容池；与座位和先后手无关。 |
| 玩家所有权 | 某玩家对其选择、控制的棋子及由其效果产生实体的控制关系。 |
| 核心棋子 | 每名玩家开局所选的 8 枚棋子；用于判定存活条件。 |
| 召唤物 | 技能产生但不属于初始 8 枚核心棋子的实体；默认不计入核心存活条件。 |
| 完整轮次 | 双方各完成一个自己的回合后完成的一轮。 |
| 终局 | 由核心全灭、40 个完整轮次结算或投降触发的对局结束状态。 |
| 基础行动点 | 在自己回合开始时恢复至的行动点上限，随自己的回合数增长，最高 10。 |
| 临时行动点 | 不受基础上限限制、但不跨回合保留的行动点。 |
