# Demo v0.1 范围

状态：有效
权威规则：[核心对局合同](./DEMO_V0_1_CORE_MATCH_CONTRACT.md)

## 目标

Demo v0.1 提供一局可测试的 1v1 核心对战：玩家完成阵营棋子选择、随机部署重投、交替回合行动，并能以核心棋子全灭、轮次上限或投降结束对局。

## 包含

- 单一固定地图 `large-trap-arena`。
- 光方或暗方内容阵营的独立选择，以及任意阵营组合的 1v1 对局。
- 每名玩家选择 8 枚不同核心棋子、随机出生、双方可见站位、一次可选重投与同时确认。
- 行动点、移动、技能、弹道、伤害、召唤/复活、终局及成长回合时限。

## 明确排除

- 其他地图、正式发行规则和未来棋子设计。
- 扩充当前光方 13 枚、暗方 12 枚候选池；该变更必须走独立准入任务。
- 通用普通攻击、跨回合保留未使用基础行动点、召唤物计入核心存活条件。
- 将旧实现、旧数值或旧文档自动认定为正确设计。

## 验收入口

每项可观察验收场景与规则编号见[核心对局合同的验收场景](./DEMO_V0_1_CORE_MATCH_CONTRACT.md#12-可观察验收场景)。
