# 固定路线 PVE

任务：RED-235。2026-10-03 用户要求从已讨论的章节内容和 A/B/C/D 界面实现可玩流程。本任务的固定路线取代新入口的同图探索方向；RED-181 的旧探索模式保留为独立入口，历史资料不能覆盖本次要求。

## 内容与操作

三章分别为旧城边境、灰烬封锁区和王座要塞。每章固定七节点：战斗 → 事件 → 战斗 → 商店 → 事件 → 战斗 → 首领。普通战斗从本章四个遭遇中无放回抽取三场；章节首领固定为憎恶、死神和阿尔萨斯。抽取由冒险种子决定，打开背包、查看角色或返回关卡页不重新抽取。

关卡间界面使用现有 tabletop 深色木桌、平整棕黄色面板、深棕描边、简洁按钮和现有角色头像。A 为 D 顶部的悬浮进度栏，不占独立布局空间；收起时只显示小下拉箭头，悬停箭头展开，移出整个进度栏 1 秒后收起。每次进入关卡间界面（含新节点、战后返回和重开）自动展示 5 秒，期间悬停保持展开。箭头支持点击和键盘访问。D 向上填满原进度栏空间，展开/收起不改变 D/C/B 位置。B 为右下背包；C 为左下各角色独立资料。技能和数据来自当前资源与实际队伍状态，不能用示意图数值代替。

战斗节点点击“进入战斗”后使用原生 `battle.html` 和 PVP 的同一套操作与呈现。PVE 的敌人行动预告、免费队员部署与卡牌补给沿用现有冒险机制。普通战斗以全部初始敌方核心为目标，首领战只有首领为敌方核心，护卫和召唤物不计核心。胜利结算后返回流程页，继续进入下一节点；战败或平局不能推进。第三章首领胜利且奖励处理完后通关。

事件和商店具体内容仍待定，本版保留节点并提供继续操作，不提供商品、交易、免费治疗或额外奖励。已有战斗补给与奖励仍按现有定义处理。队伍伤势、未使用的冒险牌、遗物和卡牌成长按现有冒险清理与保留语义传递，临时战斗效果清理。

## 交付边界

本次是单人固定路线内容；不修改 PVP 的核心规则、地图语义、敌人基础数值或已有随机算法。新流程不迁移旧探索存档，不实现多人和待定事件/商店经济。刷新或关闭页面不保留本次进度，界面应明确提示。章节阵容属于待试玩校准的内容，不能据此宣称平衡验收完成。

人工体验重点：检查 A/C 尺寸和角色资料可读性；打开背包后返回当前节点；进入战斗连续移动、使用技能、结束回合；观察敌方真实行动；胜利后处理奖励并返回流程；依次打完章节首领，核对伤势与可保留内容。
