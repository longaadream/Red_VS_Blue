# 基础规则词典

本文件记录 RED-192 中逐项确认的规则。角色描述只写效果和例外；通用含义放在词典中。

## 回合与时间

每名玩家的回合依次执行：

1. 刷新基础行动点，己方棋子技能冷却减少1。
2. 完成本回合部署及登场效果。
3. 结算己方回合开始效果及连锁。
4. 正常行动。
5. 结算回合结束效果及连锁。
6. 扣除状态持续时间，清理到期状态。
7. 切换玩家。

“持续N回合”在持有者接下来的N个回合结束时计数。施加时已经开始的那个回合不计入。回合结束效果先结算，状态后到期，因此最后一次持续伤害仍受尚未到期的减伤影响。玩家级状态由该玩家持有，同样计时。

“冷却1”表示下一个自己的回合可再次使用。冷却与状态持续时间是不同的计时器。

延迟效果必须写明“你的回合开始时”或“目标的下一个回合结束时”等时点，不用“几回合后”代替。准备进度、每回合次数和持续时间也分别记录。

鸣人的打坐初始准备进度为6；你的回合开始时减少1，每个存活影分身额外减少1，归零同阶段结束打坐并获得3行动点、1充能。血誓按持有者三个回合结束计时。

## 状态

每个状态类型声明自己的策略，不从图标、显示顺序或技能入口推断。

| 策略 | 含义 | 示例 |
| --- | --- | --- |
| 不叠加 | 不增加第二份效果 | 圣盾、已激活的仙人模式 |
| 时长相加 | 相同效果延长持续时间 | 沉默、冰冻、定身 |
| 强度相加 | 相同实际到期时刻的同类效果合计强度 | 强化、纳米激素 |
| 独立实例 | 保留来源与载荷，分别处理 | 飞雷神来源标记、黑棺延迟伤害 |

强度与到期时刻都不同的实例同时存在，分别到期。“相同到期”指实际时刻相同，不是技能原本写的时长相同。强度之外的效果载荷不同也不能合并。永久与限时效果分别保存。

解除整个状态，与撤销某个来源，是两种操作。撤销来源保留其他来源和仍被引用的规则。唯一进度标记的数值更新由其规则负责，不能靠重复添加标记代替。

纳米激素的防御、移动力与增伤都按份数相加：两份为防御+6、移动力+2、伤害+2。

## 位移与离场

定身只限制主动走格；技能冲刺、传送以及外来推拉仍允许。禁锢禁止棋盘上的位置改变，包括走格、冲刺、传送、推拉与换位。死亡、强制离场和召唤落位属于生命周期，不由禁锢阻止。

蓝染黑棺施加定身；延迟伤害单独记录，避免不同来源的伤害被状态合并吞掉。

## 伤害与数值

- 真实伤害只无视防御，仍受减伤、数值护盾、圣盾和免伤影响。
- 伤害、治疗、属性增量每一步向下取整。不同百分比减伤按规则结算顺序分别相乘；两个50%减伤最终为25%。
- 有效正伤害经防御和数值减伤后最低为1；完全抵挡或免伤为0，原始0伤害仍为0。
- 实际伤害指真正扣掉的生命值，不含过量伤害。目标剩2生命、结算伤害10，50%吸血恢复1生命。
- 寒冰坚忍在扣血前减伤；实际扣血后才反冻造成伤害的敌方棋子。玩家规则和环境没有棋子反冻目标。
- 百分比属性增加以生效前当前属性为基准。
- 无限刃的自损表述为“受到1点真实伤害”，适用相同防御结算和事件规则。

## 死亡与复活

巫妖誓约先完成死亡事件、死亡计数和符合条件的充能结晶掉落，再复活。复活清除死前获得的状态，恢复初始能力，再施加复活效果明确给予的加攻与冷却重置；本局限定技能的已用次数保留。

复活不等于免疫致命伤害。前者发生死亡，后者不发生。
