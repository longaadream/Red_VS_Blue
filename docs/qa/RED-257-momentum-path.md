# RED-257 动能路径长度回归

实现候选，等待人工验收。任务：https://linear.app/redvsblue/issue/RED-257

风险 Medium。基线 `main@00df31f8bd35b34200d507fd83853bf5ac99ba94`。

普通移动与免费普通移动日志保存成功提交器返回的实际路径，规则按路径格数累加动能。
旋转冲刺和骑射横扫也按成功位移返回的路径积累；保留既有动能消耗/保留、伤害、距离、CD 和传送例外。
不新增普通移动重复格能力，不从 UI 草稿或计划路径计算。

## 人工验证

1. 拥有动能的棋子绕障碍走 4 格、端点仅距 2 格，动能增加 4；免费普通移动同样计算。
2. 走格被拒绝或取消不增加动能；实际传送不增加动能。
3. 旋转冲刺或骑射横扫的落点被前置反应改变时，动能只增加实际走过的格数。
4. 动能保留效果开启时保留原有层数再加实际路径，正常动能技能仍按原规则消耗。
