# RED-240：普通移动路径实验与动画衔接

用户要求试做可选路径的普通移动，并加快动画衔接。随后明确 PVE 暂不处理，等待独立重做。

- base_branch: main
- base_sha: 9d1b0c30801cd733ec4cede37ce1ef0889a2313a（fetch 后与远端核对）
- 风险：High。用户已批准最小集成 PR #226 的公开隔离规则预演与隐私回归；不引入教程、AI 或 PVE 改动。
- 新规则替代 RED-30 的“单次普通移动只能直线”：每一步仍为上下左右，可在一次移动内转弯，路径长度不超过 moveRange。
- AP 仍为一次普通移动 1 点；部署免费首移保持。不可行走地形、存活棋子阻挡，原地、非相邻、重复或失效路径拒绝。
- 不包含斜向、路线效果等价归类、教程/AI、PVE 重做、技能位移、经济/随机/存档/依赖升级、合并或发布。

## 交互与权威边界

2026-10-08 试用后修订：选中棋子后沿棋盘拖动绘制实际路线，拖回已经过的格子就截断后续草稿，松手直接提交，不再显示独立确认/途经点面板。返回起点松手、取消或非法落点不移动。绕行掉头允许，原路回拖属于编辑撤销，不是实际重复经过。

普通点击终点沿公开最短路线直接移动；自定义拖动不自动改路，也不使用隐藏效果为路线评分。路径不尝试判断两条路线效果是否相同。动画恢复原来 200ms 普通/状态节拍和原移动速度，保留整条路径的连续插值，不整体加快技能/卡牌/资源。

普通移动命令携带逐格路径，排除起点、包含终点。规则入口和统一位置提交器重新检查同一路径；不能在确认后静默寻找另一条路线。实际接触与动画来自已提交的 positionChanged 路径。冲刺和传送继续使用原有语义。

## 人工验证

1. 在本分支候选页面新开普通练习对局，选择完整 8 枚棋子的棋组。
2. 部署并选中己方棋子，按住拖动经过右、下、左，画出绕行掉头路线；拖动中尚未结算/扣点，路线明确可见。
3. 不松手，拖回先前经过的格子；后面的路线应撤销，再从该处向另一方向继续画。
4. 松手，检查沿最终草稿路线移动，行动点只扣一次，免费首移不扣，无第二次确认。
5. 拖回起点再松手、Esc、指针取消/多指缩放、切换棋子/回合/状态后，旧路线应清空，不提交动作。
6. 拖到棋盘外、超出移动长度或经过阻挡地格后松手，应拒绝，不按旧路径或自动替代路径移动。
7. 连续动作、多段伤害、2×、跳过与减少动态下，检查顺序和最终位置/血量一致；原动画速度恢复，转弯没有逐格停顿。
