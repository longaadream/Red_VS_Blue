# 官方客户端与资源自动更新

- 用户明确要求加入自动获取官方更新，授权本次客户端更新接口改动；实际玩家验收由用户手动完成。
- base_branch main；fetch 后 base_sha 895834297e3e49ebbf10b12074c08979931b6e01，main-baseline 通过。继续同一编辑器/发布交付候选以保留当前未提交依赖。
- 风险 High：复用已批准的签名资源安装、候选激活、占用阻断和回滚；不改玩法规则和存档语义。
- 允许：electron-client 更新模块/main/preload、菜单更新 UI、客户端构建/独立 updater 依赖、发布清单兼容标识、相关测试文档。核验现有占用接口后发现 Next 不统计真实 Colyseus 玩家房间，因此本次更新接口也接入 Colyseus 启动器的父进程 IPC 和房间创建/释放包装层；只加更新互斥，不改 battle-room 技能、回合、存档或其它玩法引擎逻辑。
- 方案：固定官方 GitHub 公共仓库；资源按 content-test 标签和清单独立发现，校验网络文件摘要后由原安装接口验证签名/ABI；补丁仅在 parent 匹配时使用，否则完整包。自动下载，在主菜单且无房间占用时激活；失败保留稳定版本。客户端使用 electron-updater NSIS 正式版本流，资源预发布不作为客户端更新。更新下载完成由用户确认重启安装，不自动中断对局。
- 版本与信任：不携带 GitHub 令牌；不跟随任意 URL；下载大小/超时有界；禁止资源版本自动降级；客户端与资源各记版本；首次旧客户端需安装一次新版。
- 验收：混合 Release 识别、相同版本不重复安装、补丁匹配/回退完整包、文件损坏和不可信地址拒绝、活动对局推迟、不兼容版本提示、重启恢复本地记录、客户端 updater 流独立、单次检查互斥。
- 检查：定向单测、构建/类型/lint、真实公共 Release 只读下载与哈希验证、界面隔离 smoke、独立审查；不创建/发布真实 Release，不替用户安装重启当前游戏。
- 回退：保留既有 stable 与 previousStable；可关闭自动检查。代码撤销本次更新模块即可，不改已有 Profile。
