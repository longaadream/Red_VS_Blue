## 实现

- Electron ready 后立即创建同一个游戏窗口，先加载本地启动页面，再初始化协议、缓存、资源配置、数据库与对局服务。
- 展示真实阶段完成数和实际耗时；阶段计数不代表耗时百分比。
- 服务启动完成后在同一个窗口加载主菜单。服务失败仍保留主菜单既有的手动重试入口，协议失败显示启动错误。
- 启动窗口关闭会取消后续启动；异步服务检查取消标记和生命周期代数，避免关闭后重新打开窗口。协议页不属于可信游戏 IPC 来源。
- 更新入口遗漏的根因是前一份 RED-204 验收包仅从 main 与主机分支构建。新验收候选明确整合既有 RED-202/RED-203 更新功能及 RED-204 主机功能，各源分支保持不变。

## 人工验收

1. 双击新候选 EXE，观察初始化完成前已显示窗口、当前阶段和计时。
2. 再次启动时于加载阶段关闭，确认没有迟到的游戏窗口。
3. 正常进入主菜单后，打开官方更新面板；核对客户端与资源分别列出。
