- 任务：https://linear.app/redvsblue/issue/RED-227
- 风险：Medium；实现者不能代替人工体验验收。
- 基线：`main`，`bc76ce78e9014f50e5ef1ea445895de8979b0ea1`；依赖 RED-225、RED-226，候选分支 `codex/RED-227-preview-revisions`。
- 范围：公共技能卡/选择交互、公开预演、生成的 Windows 浏览器引擎；指定 Sonic/Kenshin 落点代码及 Edgar 两段攻击。未修改其他角色规则、费用、随机算法、依赖或存档。

## 根因与修复边界

影分身的初始定义含隐藏状态和关联消散规则，原预演将初始规则全部当作公开基准，导致假设棋盘暴露受击消散。修复排除隐藏初始状态关联规则，并按棋盘显示的来源生命与状态建立假设。权威结算仍保留秘密机制。

地格效果原本在假设快照输出时被整个 extensions 删除。候选仅保留公开投影后显示所需的地格字段与 marker 字段；原有公开 marker 也保留，私有记录和未知扩展不进入显示。取消恢复真实状态。

用户将“不加载预演”的疑似技能补充为普里莫「愤怒铁拳」。当前最小引擎场景、原浏览器 bundle 与候选真实训练页面均能加载该预演，尚未稳定复现旧报告；不能据此宣称找到了镜花水月不加载的根因。新增等价性回归，验证有无秘密状态不改变公开预演，且正式镜花水月仍触发。

Electron 原生鼠标回归复现了整卡取消后立即重新进入悬停预演：取消改变本地 pending，角色信息被强制重建，新卡片在静止鼠标下触发 pointerenter。改为复用技能行，仅刷新动作按钮状态；实际内容变化仍重绘。回归检查取消前后 DOM nodeId 相同，鼠标静止后 pending 仍为空。

## 真实训练页面证据

独立页面 `http://127.0.0.1:38727/battle.html?mode=training`，未重置用户原验收局。通过正式训练入口选择光方普里莫、暗方蓝染，再用普通移动将普里莫移动至蓝染相邻格。

1. 普里莫位于 (11,4)，蓝染位于 (12,4)。愤怒铁拳目标悬停预演显示四次 −1，蓝染生命 9→5，AP 不扣；取消后生命恢复 9。
2. 蓝染在自己回合通过正式技能按钮和目标点击，对自己施加镜花水月，再结束回合。普里莫同样悬停蓝染，仍显示四次 −1、生命 9→5，AP 不扣。
3. 正式点击蓝染后进入「镜花水月：选择替代目标」，蓝染真实生命仍为 9，AP 尚未扣。选择普里莫作为替代目标，普里莫生命 17→13，蓝染保持 9，AP 10→9，愤怒铁拳进入冷却。

这验证候选预演不会消耗真实秘密反应，也不会把秘密目标转移展示在预演中。

## 建议人工验收

在原先出现问题的入口，用愤怒铁拳分别悬停普通蓝染和施加镜花水月的蓝染，确认均可预演；正式点击后仍应按真实秘密规则处理。再用影分身检查预演中未揭露一击消散，正式结算仍消散。

选择一个技能后把鼠标移动到另一张技能卡正文，确认旧选择被替换、没有扣费；点击进入正式选择，再点击正文或空白取消。无目标流星腰带从技能按钮拖到棋盘，松手前不扣费，松手后只扣一次。反应 pending 和提交中不允许悬停中断。触屏使用点击流程。
