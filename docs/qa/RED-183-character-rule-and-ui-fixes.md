## 验收要点

1. 塔尔斯双尾飞行的免疫与不可操作均保持 2 回合，预留也以 2 回合结算。
2. 手牌击杀己方棋子的充能规则已由后续“掉落充能结晶”事项接管，本 PR 不再把旧的直接加充能行为作为人工验收门槛。
3. 选棋详情显示充能点消耗。
4. 大厅提供“我的棋组”入口，可在开战前切换光/暗阵营，新建、命名、保存/编辑和删除棋组；进入房间后既可一键载入，也可继续在当前选将页构筑或调整。每套仅接受同阵营 8 枚不重复棋子。持久化解析会过滤损坏条目，并对无版本、未来版本或不可解析资料安全回退；写入失败会保留当前选择并提示用户。不包含推荐或自动构筑。
5. 点击行动记录后，3D 渲染器继续显示来源/目标；HTML 棋盘降级路径同样高亮对应格子。
6. 玩家状态规则的表现事件使用 `targetPlayerIds`，不携带行动棋子主语。
7. 鸣人影分身的声明候选和执行复核均使用曼哈顿距离 5；描述明确空地格与“秘密选择”分支。
8. 格力姆乔使用统一文案“每当一名敌人行动后，若其在格力姆乔4格内，……”，移动和技能后规则均保持敌人/曼哈顿 4 格限制。
9. 利亚德琳按手牌 `instanceId` 丢弃，同名副本不会被一并删除。
10. 教程只允许当前步骤规定的动作；选择乌瑟尔的圣光盾后进入正常目标选择，提前或非法操作会被拒绝且不会卡死。
11. 局内棋子详情的相关/衍生卡和真实手牌共用 `renderHandCardFace()`，包含行动点费用宝石。
12. 技能元信息使用 `·` 分隔，不再出现“路”；图鉴充能仅显示消耗，不显示 `/3`。
13. 索尼克技能列表包含“音速”被动，关联 `rule-sonic-free-move`。
14. 猎空回溯的描述明确“秘密选择”；成功文案不包含数值，回溯条目通过通用的 owner-only 扩展投影约定，仅对选择者公开。
