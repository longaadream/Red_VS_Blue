## 已复现的原因

正式 tails-armor-assembly 多选两个模块后，在 customCards 中留下组合护甲定义。原 hasUnprovenExecutableState 将任意非空 customCards 视为整局不可预演，因此其他确定性技能及普通移动一起返回 unavailable。真实 applyBattleAction 生成护甲后的回归修复前失败；首阶段修复的三个预演/隐私测试文件共 56 项通过。该阶段结果不能代表新增手牌预演已完成。

原预演只接受 move/useBasicSkill/useChargeSkill，页面手牌路径也没有调用预演，故手牌预演属于新增接入。

## 执行边界

正式卡定义从 canonical 资源解析。组合护甲的动态定义从正式生成逻辑重新生成并核对，不能仅凭 ID 或名称认可快照代码。未知动态卡的存在不应关闭其他操作预演，但未经核验的代码不能执行。复用正式规则，不在 UI 重写效果。

目标候选来自隔离规则准备或现有权威准备；预演只更新表现，确认时仍走原提交入口。隐藏手牌/牌堆不暴露，随机结局不猜测，取消及切换不改变真实资源、状态、手牌和 RNG。
