# RED-181：探索供牌与同名卡成长框架

2026-09-10，本地实现与验证记录。用户批准稳定供给成长牌的遗物，要求先搭框架、不做平衡。该范围不等于完整 PVE 已完成。

## 当前接入

| 遗物 | 每场战斗开始供给 |
| --- | --- |
| 血契之书 | 2 张临时血咒 |
| 星火灯盏 | 2 张临时星火 |
| 校准弹匣 | 2 张临时校准射击 + 1 张临时掩护射击 |

初始持有校准弹匣。非最终据点胜利后，独立选择一件未持有遗物和两张同名保留牌，两项均可跳过。新遗物从下场战斗供牌。

卡牌使用后消耗，没有抽牌机制。血咒、星火、校准射击的成长记录归本次冒险、玩家和卡牌 ID，后续副本继承；遗物生成的临时牌战后清除，没使用的奖励牌保留。最多10张手牌，溢出时选择替换旧牌或放弃新牌，未处理前不能推进战斗/探索。

四张卡位于共享 `data/cards`，标为 PVE ready；其余56张仍为 PVE draft，不会生成不可执行的占位卡。遗物与供牌、奖励配置位于 `data/pve/roguelike/supplies.json`，随现有 Base/Patch 包一起导出、导入和校验。v1 使用固定资源路径。原有节点模式解析器只识别并跳过新的探索文档，不转换旧存档。
