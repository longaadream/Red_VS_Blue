## 实现与范围

- 一个 `flow.effects.move` 接口提交单体或整组位置变更。整组先校验后提交，占用、预留、禁锢或路径失效正常取消，重复 ID/非整数等契约错误抛错。
- 连续位移：走格、冲刺、推拉。路径查询统一提供格子、碰撞和最后合法落点；地形策略只有可行走、弹射物通行、任意穿越三种，另保留技能特有禁入地形。传送和换位只接触落点。
- `beforeMove/afterMove` 保留普通走格动作语义；全部位移有 `beforePiecePositionChange`、`afterPiecePathContact`、`afterPiecePositionChange`。定身只阻止走格，禁锢阻止棋盘位移；死亡/召唤保持生命周期。
- 实际经过格和终点拾取，排除起点和重复接触。整组先提交位置、统一拾取记账，再执行反应。鸣人和回溯的必要复合效果可由宿主延后反应，但不能丢失已发生的拾取。
- 33 个现役技能/规则文件迁移，逐文件代码及文案前后记录见 [迁移清单](RED-209-position-migration.json)。可信脚本不能经别名或对象替换直接写坐标，新召唤棋子也立即受保护。该保护不是恶意 JavaScript 安全沙箱。
- 天照使用实际路径接触；燃地和致命毒素保留落点触发。一护不再自行重复执行一套落点伤害。位移失败不自动回滚已经发生的施法费用或其他独立效果。
- 词典、描述标准和作者接口说明同步；战斗记录显示走格/冲刺/传送/推拉/换位，表现读取引擎标记。传送紫色、换位青色提示并直接落位；冲刺沿路径运动并有橙色提示。保留减弱动画设置。
