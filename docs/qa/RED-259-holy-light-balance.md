## 本轮规则

- 卍解·天锁斩月：消耗 2 CP，保留每局一次、属性提升及技能替换。
- 月神赐福（用户所称月光赐福）：CD 2，下一张圣光手牌效果提升 50%，仍仅强化一张；沿用各圣光牌向下取整。
- 维伦新增征讨号令：与图拉扬共享技能定义，1 AP、CD 2，选择圣光惩击、圣光治疗或圣光充能并获得一张，保留其他技能。
- 圣铸进军：每成功使用一张普通圣光手牌，可选一名友军进行一次免费普通移动。按该棋子当前移动力和合法路径寻路，可拐弯；移除原每回合首次、移动力额外 +2 和穿过友军的远征规则。
- 免费移动沿用普通移动的地形、占用、定身、禁锢、移动前后反应及路径接触；不扣额外 AP，不消耗回合普通移动次数。取消仅放弃本次移动，卡牌效果完成一次；无合法候选时略过移动。

## 验收场景

1. 一护 1 CP 时拒绝卍解且状态不变；2 CP 时成功扣费，变身和技能替换仍正确。
2. 泰兰德施放后，圣光惩击 5 → 7、圣光治疗 8 → 12、圣光充能 2 → 3；第二张牌不再受该次赐福强化。检查 CD 2。
3. 从维伦真实角色定义加载征讨号令，三种选项均只获得所选的一张牌，费用和冷却与图拉扬相同。
4. 同一回合连续两张圣光牌分别出现独立移动机会；第一次取消也不吞掉第二次。
5. 选择需要拐弯绕障的合法落点，实际路径长度不超过移动力；移动前后资源与普通移动标志不变。
6. 错误玩家、过期选择和非法落点拒绝且不污染状态；无合法友军或路径时卡牌照常完成，无空选择死锁。
7. 取消两个选择阶段后，卡牌费用、弃牌和伤害/治疗都只结算一次；不产生补偿治疗撤销伤害。
