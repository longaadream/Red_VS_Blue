# RED-224：技能假设棋盘预演

本任务只修改公共引擎与战场交互，不修改角色、技能内容、随机算法或存档格式。不构建安装包，不部署、不发布。2026-10-02 用户批准扩展公共预演执行边界，风险升为 High。

## 验收操作

1. 选择可用的指定目标技能，将鼠标停在合法目标上。棋盘应显示标有“预演”的假设结果及伤害、治疗或效果浮字。
2. 移到非法格或离开棋盘。真实棋盘立即恢复，技能选择仍然保留。
3. 更换合法目标。旧目标的预演不能覆盖新目标。
4. 主动取消。预演消失，遵循原取消规则。
5. 点击目标或从技能按钮拖到目标后松手。只有此时提交一次真实操作。
6. 随机效果不显示确定结局；隐藏效果和反应触发的额外选择忽略，只显示公开效果。技能自身尚需后续选择时继续正常选择，不猜测答案。
7. 预演期间行动点、充能点、冷却、真实生命、随机游标及行动历史均不变化。

## 性能口径

10ms 是规则计算的目标，不包括显示假设棋盘的渲染时间。必须分别记录计算与显示耗时，提供样本数、P50、P95、最慢值；未测量前不能宣称达标。
