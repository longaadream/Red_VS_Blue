# RED-225：技能阅读与释放操作区

风险 Medium。任务合同：https://linear.app/redvsblue/issue/RED-225 。基准为刷新后的 `origin/main`：`bc76ce78e9014f50e5ef1ea445895de8979b0ea1`；集成会话依赖 RED-224 `820d13cd3784f8a6fc4416902266fe92c65f702a`。

## 范围

所有技能的原始完整描述在同一列表中阅读。主动技能标题行提供点击与拖动入口，说明和关键词用于阅读。顶部一行黄色黑描边文字显示真实目标要求，没有独立提示卡、重复技能名或范围图例。当前技能标题再次点击即可取消，费用位置显示大号明显粗体“再次点击取消”，技能名保留，不再新增独立取消按钮占用空间。不可取消及提交等待显示对应状态并禁用；卡牌和无对应技能行保留公共取消入口，必要确认与摘要仍保留。提示读取真实引擎 hint，非法目标反馈暂时使用同一文字行，保留原提示音和选择重试。沿用现有材质、颜色、字体、头像和棋盘资源，不修改角色数据、规则或取消语义。

路径核对后，合同补充公共 `data/pages/tabletop-battle/character-dock.js`：它原本负责动态小按钮和手机关闭面板，直接协调该适配器避免新增覆盖层。原材质 CSS 保持不变。

## 人工体验步骤

1. 选择自己的棋子，比较多个技能描述；被动技能仍可阅读。
2. 点击可用技能标题，确认其他描述仍在。阅读说明及关键词不应换技能或提交命令。
3. 点击非法目标，再点击合法目标；非法输入后仍保留同一次选择。
4. 从标题拖到合法目标，查看预演后松手；应只提交一次。描述区滚动不应启动拖动释放。
5. 再次点击当前技能标题或按 Esc 取消，确认提示明显、取消后费用恢复，再点可重新释放。多步选择仍能取消当前释放；不可取消及提交等待不允许取消。拖动释放结束不能被合成点击误取消。
6. 在桌面、手机横屏及竖屏查看长技能列表，确认顶部文字与当前技能标题可达、棋盘仍可操作。手机瞄准时收起角色统计区给说明留空间；横屏预留侧栏空间，竖屏使用下方阅读区， renderer 复用既有 ResizeObserver 适应棋盘尺寸。
7. 普通刷新及等待权威结果时核对焦点、选择内容和单次提交。
8. 顶部提示使用黄色填充和 2px 黑色字形描边；只有字形有描边，文字区域没有边框或底色。在明亮棋盘与深色背景上检查可读性。

失败定位记录：早期 Electron 隐藏且未聚焦的测试窗口收到 wheel 事件但不执行 Chromium 默认滚动，显示/聚焦测试窗口后同一输入成功；取消后统计区恢复会使技能行移出视口，测试先 `scrollIntoView` 并核对实际命中再输入。candidate13 因测试再次隐藏窗口而超时；candidate16 的空地输入改变选中棋子，改用棋子对应地格打开信息。均未为测试修改生产滚动规则或通过注入选中状态绕过操作。最终候选由明确修正后的输入流程通过，未靠无改动重复运行掩盖失败。

该测试使用训练设置和确定性引擎 fixture 注入准备状态，操作使用 Electron 鼠标输入及 CDP touch 输入；不是远端正式服务器验收。100 次确定性预演采样 p50 5.4ms、p95 6.7ms、最大 8.3ms，状态未污染；不代表所有技能或设备性能承诺。独立代码审查无剩余阻断，人工体验验收仍由负责人完成。
