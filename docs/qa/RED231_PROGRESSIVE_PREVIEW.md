## 复现与根因

用户在新教程实战中反馈点击技能、停在目标上均无预演。真实固定种子 `18707` 标准对局第一次合法部署后：`phase=action`、`deployment.status=turn-ready`、当前玩家拥有输入、双方预备区数量 6/7；合法技能的 `previewBattleAction` 返回 `unavailable / preview-unavailable`，权威状态哈希未变。

`publicViewerExecutionSnapshot` 先执行公开投影，保留渐进部署状态，移除私有预备棋子。预演入口与清理器却同时拒绝任何非 `complete` 部署；当前仍有预备棋子，但本轮增援已完成的合法普通行动因此也被拒绝。

UI 的公开准备返回 unavailable 后，会进入权威挂起目标选择。悬停预演本身拒绝该挂起流程，所以玩家看见可选目标，仍然没有假设结果。不是没有将鼠标停在目标上，也不是教程 AI 没有执行。

## 修复边界

只允许 `progressive-reserve-v1 / turn-ready / action` 且没有未完成部署候选的已有公开技能准备和预演。隔离执行前删掉已公开化的 deployment，不把私有预备身份或部署候选带入技能模拟。保留原先 `complete` 部署支持；其他未完成部署、未知模式、开始/结束阶段、未完成选择、非法动作和不支持效果继续拒绝。

没有改变公开来源证明、隐私过滤、隔离执行器、角色效果、随机算法、存档或公开接口。实际结算仍由权威规则决定；预演只承诺公开的确定性结果。
