投降确认 → 失败结果「PVP 练习结束 · 不计入战绩」 → 再来一局返回准备页正常。准备页截图人工检查：木纹背景、米色纸张、手写字体、红蓝边框、现有角色立绘，与当前 tabletop 风格一致。未做 Android 或窄屏设备实测。

## 首次失败与修复

1. 首次 esbuild 因沙箱父目录读取限制失败；批准构建后正常。VFS 缺少引擎静态导入的文件操作符号，补齐只读拒绝实现后构建通过。
2. 首次 Worker 烟测 2 项失败：测试驱动遇到真实 human pending 时主动抛错；改为按公开候选及 selection 凭据提交，未修改游戏规则。同期日志暴露幸运币单例不在规则 manifest；练习补载当前 Profile 的现有文件，并增加强校验。
3. 独立审查发现选组异步覆盖、AI 私有选择回执、连续 pending 被旧变量清空、重复投影漏计时：分别用选择期间禁用控件、公开动作白名单、渲染前清旧状态、单次投影及页面请求累计计时修复。
4. 复审发现失败遮罩阻挡退出、补载相对路径可能混入 IDB 资源：隐藏失败遮罩、改用同源 URL 对象，并增加回归测试。
