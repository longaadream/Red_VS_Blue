# RED-252 原子作者接口与嵌套编辑

本记录覆盖 2026-10-12 的原子接口、extension 自定义访问、四个样本、自然语言词槽和嵌套编辑纠正。不是全部旧资源完成新版原子作者迁移的声明。合同见 [任务合同](../RED-252-studio-v1/task-contract.md)。

## 用户确认的边界

- 新增语句与表达式只提供通用原子操作和流程结构；默认与高级目录均不提供回溯、飞雷神等专用适配器。旧内容仍可读、诊断。
- extension 建议只来自当前作用域的前序声明；允许自定义对象、变量、字段路径与类型，包括当前未声明的字段。
- 访问缺失或类型不符的 extension 时，当前语句及依赖结果的语句无效；独立后续继续，不自动建值，不要求作者填写 fallback。引擎保留有上下文的诊断。
- 保留当前整体界面；嵌套支持横向滚动、折叠与键盘操作，不改动图数据。
- 语句显示为中文句子；点击一个词槽只编辑该参数，支持逐项引导和自由返回。前置参数决定后续字段及类型；兼容内容保留，不兼容内容提示修正，不能静默替换。

## 当前限制与验收状态

自然语言单参数、前置参数依赖、结构语句和表达式已通过本批定向 Electron 验证；独立只读审查发现的问题均已关闭，未遗留本批 P1/P2。验证使用隔离的临时项目，没有覆盖用户未保存的项目。单参数测试使用真实编辑器与实际注册表，但文件往返不经过保存 IPC；上述两份复杂内容测试另外覆盖了实际保存 IPC。两份复杂内容本次均跳过“试用技能”，不算游戏内视觉验收。

本批修正包括：组合表达式保持单参数编辑；记录字段及返回值写入规范字段名；结构语句的“更多字段”入口；集合处理方式变化保留累计初值；句子、面板和下一项共用依赖判断，递归隐藏前置未完成的字段，不删除草稿；类型不兼容提示修正；可选路径仍可补充。

当前运行 extension 宿主覆盖玩家、棋子、全局变量及玩家映射；其他实例类型不能据此宣称全部已实现。

本次未重跑整个 game suite。此前全量验证的 47 个基线失败仍属历史记录，不由本批定向通过改写为全量绿色。

## 建议人工体验

1. 打开能力组的效果区，点击句子中的数值，只修改这一项，再选择“组合表达式”。目标、来源等其他参数应保持不变。
2. 编辑扩展变量，先填写名称和类型，再填写值；把数值类型改为布尔，原数字应保留并显示类型提示。清空前置名称，下游槽应隐藏；恢复名称后原值应重新出现。
3. 用“下一项”继续填写，也可直接点击别的参数；折叠分支、横向滚动，并保存重开确认结果。
