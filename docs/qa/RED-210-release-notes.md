# RED vs BLUE 0.1.4

Windows 与 Android 同步更新。

- 新增 GitHub / COS 香港下载源选择并记住设置，游戏和官方资源更新统一使用所选源。COS 接入 updates.redvsblue.top；安卓支持 APK 差量下载，补丁失败时完整下载，安装前继续校验摘要与签名。
- 统一走格、冲刺、推拉、传送、换位等位置变更与沿途接触结算，修复连续位移、嵌套动作和相关触发的一致性问题。
- 飞行预留标记允许进入；实际降落时目标被占用或无法落脚则取消本次搬运。
- 修复手牌实例保留、观战服务器上下文及相关显示问题。
- 精简技能说明，统一距离、回合、强度和倍率表达；技能关键词加粗，新增首次阅读指南与常驻 Tips。
- 暴风雪施法范围调整为全图。

升级说明：0.1.3 用户首次升级仍通过 GitHub 或手动安装 0.1.4，安装新版后可选择 COS。Windows 下载 Setup.exe，Android 下载 Android.apk；blockmap、rvbdelta 和更新清单由客户端使用。

香港镜像需在对应产物与清单上传后才能使用。差量更新要求本机保有匹配的旧安装包或已安装 APK，否则使用完整下载。资源包通过独立频道分发，兼容要求以资源清单为准。
