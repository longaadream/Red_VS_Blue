## 验收方法

- 使用独立临时项目与独立编辑器用户目录，动态分配调试端口。不连接用户的预览页面，不覆盖用户草稿。
- 从新建文档开始，通过中文句子目录、参数编辑、结构字段和返回变量完成程序；不得把完整作者图写入文件或通过调试接口注入后冒充从零编写。
- 保存无效草稿后重启恢复，检查有效内容文件保持原版本；修复后正式保存、重开并编译。
- 训练营使用实际战斗页面和权威引擎；核对选择、伤害、召唤、规则与资源。应用新有效草稿后以相同初始场景和种子重试。
- 说明书截图只选最终通过的新句子路径。历史失败截图用于问题定位，不算完成证据。

## 本轮定位并修复的问题

- 新建技能／卡牌曾写入空的召唤声明，导致有效空程序无法编译。新建模板省略未声明字段，编译器不可用时明确报错，不退回未受作者图管理的旧代码。
- 保存草稿期间切换后重新打开文档，异步返回可能只更新旧会话的版本；现同时更新当前会话版本，并保持保存期间的新输入未保存。草稿与有效内容均保留冲突检测。
- 新建草稿正式创建后可能重复插入列表；按引用身份去重。
- 安装器重命名重试在模块加载时创建共享内存，导致浏览器引擎加载失败；改为实际文件重试才创建等待缓冲区。有限重试次数和其他安装语义不变。
- 完整棋子副本中的增益、减益、规则、护盾、技能实例扩展与任意合法数据曾不符合封闭模板类型；显式类型补全并校验，未知字段不会隐式放开。
- 跨所属玩家召唤时先解析目标玩家阵营，再解析模板，避免复制来源阵营。
- 显示消费者合并多条局部显示覆盖，消费护盾、核心标识与创建时技能快照；实际所属与操作权限不被显示值替换。
- 从零编写消散规则暴露出正式“消灭”操作缺口。新增通用消灭原语，使用正式死亡前后事件、墓地与结算链；不通过伪造伤害或直接改生命值实现。补充结算中消灭其他待受伤／治疗棋子的测试，避免后续批次再次写入尸体生命值。
- 训练营容器宽度曾收缩到不足以使用的尺寸；修复伸展布局，实际内嵌画布测得 862×706 与重试后的 916×706。
- 训练快照保留动态图像并正常提供图片类型；未纳入当前权威资源类型表的展示素材仍参与完整快照哈希，素材内容变化会改变训练版本身份。
- 编译器完整类型目录与生成代码所需类型分离，避免新增内置结构改变旧技能的生成文本。独立审查又发现作者自定义根结构引用内置子结构时漏掉子结构；新增失败复现后修复递归依赖收集，保持原有结构顺序。
- 实际影分身编写暴露了映射常量、内置结构中文字段访问、完整结构输入表达式、记录结果命名及字段表达式重填问题。已支持类型化映射常量与唯一中文字段标签；结构参数可直接引用前面保存的对象，重填只替换该字段拥有的计算节点。独立审查发现并关闭了更新记录时源槽与名为 `record` 的字段冲突及旧元数据歧义问题。
- 新建文档的旧默认棋子目标配置与实际地格选择冲突：编辑器保存与重开通过后，正式引擎仍拒绝影分身落点。该失败由原样 UI 产出驱动的运行测试发现，修复位于通用目标绑定与新建默认配置，不能通过测试中改写文档绕过。
- 新内容已使用通用召唤语句，但没有旧内部能力声明，导致召唤未进入权威队列。现在从已校验的实际执行作者图推导通用召唤能力，显式声明和禁止仍优先；位移被阻止后的占用落点由引擎正常拒绝，作者代码不增加成功检查。
- 棋子模板中的规则列表曾直接显示内部编号；通过结构类型及当前内容目录显示实际名称，保留序列化引用。独立审查发现并关闭状态目录别名被空集合遮蔽的边界问题。
- 玩家规则图标曾在权威实例创建时丢失；加载器与转换器现保留图标和可见性。新规则默认隐藏，旧规则保留原显示策略；显式关闭不会被旧注册表再次显示。隐藏只影响界面，规则依然执行。素材控件使用中文名称与真实图片预览。

## 人工验收与说明书

编辑器左侧“使用说明”提供图文指南：[开发者工作台使用说明](../../../electron-editor/ui/developer-guide.html)。包括中文句子参数、结构字段、火球、影分身、被动规则、局内说明与图标、草稿、训练重试和资源包。配图来自实际隔离 Electron 验证。说明书完成本地图片/目录锚点检查和图片检查；浏览器打开本地说明页的渲染检查被自动审批拒绝，未绕过，也不记为页面排版验收通过。

1. 打开能力组中的火球示例，只修改伤害参数；保存草稿、重开，确认其他参数不变。
2. 打开影分身模板，确认初始规则显示中文名称；进入显示对象，逐字段修改与引用变量。
3. 进入规则属性，更改描述、素材和“局内可见”，在训练营检查实际显示；关闭显示后规则仍能触发。
4. 训练中运行技能，修改有效草稿后点击“应用并重试”，确认初始场景一致且使用新效果。
5. 生成资源包并查看内容检查结果。最终易用性由项目负责人判断。
