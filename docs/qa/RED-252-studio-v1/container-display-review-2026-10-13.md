# 显示选项、能力组和容器函数审阅补充

关联 RED-252。本文记录独立 HTML 作者预览的接口方案，不表示正式运行引擎已实现这些新接口。

## 显示选项

显示选项与棋子使用同一份字段定义，字段名、字段类型一致；所有显示项均可省略。当前包括名称、模板、当前生命值、生命上限、攻击力、防御力、移动速度、所属玩家、阵营、位置、核心、能力组、技能、规则、状态、extension。

构建 HTML 时从棋子字段生成显示选项清单和字段联想，避免两份清单分别扩充。填写内容只覆盖显示，不改变真实数值、棋盘位置或实际能力。省略项使用正常显示，召唤时可一次传入完整选项。

```text
新建【显示选项】变量【分身显示】 = {
  名称: 当前棋子.名称,
  当前生命值: 当前棋子.当前生命值,
  生命上限: 当前棋子.生命上限,
  攻击力: 当前棋子.攻击力,
  能力组: 当前棋子.能力组
}
```

这些表达式用于提供显示值；影分身仍沿用此前确认的创建时取值约定。填写能力组、技能、规则或状态的显示项不会在真实棋子上部署它们。

## 棋子的能力组

`棋子.能力组：元组<能力组实例>`，可以查看当前棋子持有的各组及其成员，例如 `当前棋子.能力组[1].技能列表`。

获得能力组时，将组实例加入该字段，并部署该组定义的 Skill、Rule 和初始化声明；移除组时同步卸下该组带入的成员。无需作者另外修改棋子.技能、棋子.规则。共享 Rule 仍有其他能力组或独立挂载需要时保留，不误删其他来源；引用 StatusTag 或 Card 定义不代表自动施加状态或加入手牌。以上沿用既有实例归属规则，不在本轮发明重复获得策略。

## 容器函数

函数用于产生值；修改变量继续使用赋值，读取元素继续使用 `元组[1]`、`映射[键]`，删除继续使用已有“删除容器项”。没有为每种容器增设一套读写语句。

本轮新增函数为审阅提案，其空容器等边界列明供进一步确认：

| 函数及中文参数 | 返回 | 示例或用途 |
| --- | --- | --- |
| 包含（容器，元素） | 布尔 | `包含(目标列表, 目标)`；空容器为假 |
| 首项序号（元组，元素） | 数值／空 | `首项序号({3, 5, 3}, 3)` 得到 1；未找到为空 |
| 截取（元组，起始序号，数量） | 元组<T> | `截取({10, 20, 30}, 2, 2)` 得到 `{20, 30}` |
| 拼接（元组，追加元组） | 元组<T> | `目标列表 = 拼接(目标列表, {目标})` |
| 反转（元组） | 元组<T> | 反转顺序，不修改原元组 |
| 去重（元组） | 元组<T> | 保留第一次出现的位置和原顺序 |
| 任意满足（容器，条件） | 布尔 | `任意满足(目标列表, 每项.阵营 == 当前棋子.阵营)`；空容器为假 |
| 全部满足（容器，条件） | 布尔 | 检查每一项；空容器为真 |
| 包含键（映射，键） | 布尔 | 检查键是否存在，不将 0、假、空值误认为键缺失 |
| 键列表（映射） | 元组<K> | 按键插入顺序返回键，空映射返回空元组 |
| 值列表（映射） | 元组<V> | 与键列表对应，保留重复值 |

数值、文本等按值比较；实例按身份比较，不按显示名称比较。元组索引从 1 开始。截取数量为 0 或起点超过末尾时返回空元组；范围越过末尾时取到末项；负数量或小于 1 的起点为无效参数，由运行引擎负责语句无效处理。

既有函数继续提供数量、筛选、查找首项、逐项变换、累计集合、排序、随机项目、组合集合。数量兼容元组、集合和映射，不另造判空函数。组合集合明确并集、交集、差集；依赖先后顺序时使用元组。筛选保持输入容器种类；逐项变换产生元组并保留重复结果。新增函数不执行游戏，不改变实际对局或消耗随机数。

按“容器查询、容器条件、元组处理、集合运算、映射查询”分类。已有随机函数仍沿用对局种子要求。旧拼接/反转草稿不重写，目录的新编写入口采用明确函数名。
