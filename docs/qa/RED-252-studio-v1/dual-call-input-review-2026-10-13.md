# 独立作者预览：两种调用写法与中文输入

此说明对应 RED-252 的独立 HTML 交互原型。页面用于审核语法与编写体验，不执行游戏结算，也不代表正式工作台或运行引擎已支持全部接口。

## 两种调用写法

同一个容器函数允许两种形式，使用同一份参数和返回类型定义：

| 普通调用 | 成员调用 | 返回 |
| --- | --- | --- |
| `包含(名单, 目标)` | `名单.包含(目标)` | 布尔 |
| `截取(名单, 1, 2)` | `名单.截取(1, 2)` | 与原元素类型一致的元组 |
| `数量(名单)` | `名单.数量()` | 数值 |
| `值列表(分组)` | `分组.值列表()` | 映射中值的元组 |
| `排序(名单, 每项.生命上限, "升序")` | `名单.排序(每项.生命上限, "升序")` | 有序元组 |
| `组合集合("交集", 集合甲, 集合乙)` | `集合甲.组合集合("交集", 集合乙)` | 集合 |

成员写法省略已经放在点号前的容器参数，其他参数的相对顺序保持一致。支持中文命名参数，例如 `名单.截取(起始序号: 1, 数量: 2)`。在变量后输入点号，联想该类型的字段和函数；未输入变量时不铺开所有子字段。作者仍可手动输入自定义 extension 路径。

## 当前参数提示

输入 `名单.包含(` 时，空参数处显示灰色提示“元素 · 棋子”。`名单` 若为元组<数值>，提示随之变为数值。嵌套调用以最内层当前参数为准。正文和右侧展开编辑遵循相同规则；提示不进入表达式正文、保存数据或导出内容。

只有少量合法值的参数列出可选值，例如伤害类型的普通/真实、排序方向的升序/降序/随机。候选按接口要求插入对应值，文本枚举保留引号。

## 全角与半角

`名单.包含(目标)` 与 `名单．包含（目标）` 均可识别。逗号、冒号、运算符、数字、字母及容器括号同样支持混合输入。识别使用影子文本，作者原文不会自动转换；引号内的文字和标点保持原样。

例如 `＂Ａ＋Ｂ＂＋１` 的引号内仍是 `Ａ＋Ｂ`。坐标可写 `坐标（１，－２）`，范围形状可写 `｛坐标（０，１），坐标（１，０）｝`。旧中括号容器兼容迁移仍保留。

## “定义引用”的含义

定义引用指向一份可复用的效果配置，例如天照这份配置；实例是实际附着在某个地格上的那一个天照。多个实例可以源于同一配置，同时各自保存来源、强度、持续时间等数据。

实例的“包含”判断比较是否为同一实例，不按名称比较。“是否存在任意一个天照效果”与“是否包含刚才那个具体效果”是两个不同问题。作者界面宜解释为“效果类型/配置引用”和“具体实例”，不要求用字符串名称代替类型引用。本轮只解释概念，不擅自给正式 TileEffect 加字段或改变相等语义。
