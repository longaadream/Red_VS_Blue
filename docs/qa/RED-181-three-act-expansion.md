# RED-181 三幕探索扩充验证

日期：2026-09-10。范围以用户本轮要求为准：特殊格交互与移动并存、明显战区边界、扩大地图及战区、三幕内容、战斗奖励与追击小怪。

## 实现与验证

- 三幕各 64×64，每幕 5 个固定 16×16 战区；地图使用种子生成，保留地标布局约束。每幕提供营地、招募、补给与出口。
- 棋子占据特殊格时保留原生选择与连续移动；独立交互按钮打开地点弹窗。
- 激活战区显示橙色地面边线、矮墙与立柱。进入战斗从 1 行动点起步，探索固定 3 点。
- 强化专用 IP 敌人；程序行动按路径寻路，召唤数量限制只计算当前敌方战区，避免其他区域的食尸鬼阻断召唤。
- 追击怪在探索中移动，接近后形成局部战区；避开固定战区并检查区域内连通性。每只击杀奖励 8 金币，重复结算不重复发放。
- 固定战斗结算金币和供牌选择；最终战也先处理奖励，再显示通关。中间幕通过出口进入下一幕，保留成长、货币、队伍和伤势，清理临时战斗牌与临时减费。
