# 新角色验收修复

依据：本任务用户验收反馈。风险 Medium。范围为普里莫被动、莫提斯衍生技能展示、柯尔特技能与随动区域、麦克斯相位偏移器再次释放、超级霰弹与破墙地形刷新。不修改无关角色数值或存档格式。

验收要求：

- 普里莫的受伤计数被动在技能列表可见，说明与规则一致。
- 莫提斯展示可解锁的蝙蝠增援。
- 柯尔特技能可通过实际选择与行动入口执行，区域跟随施法者且两种射击区域互斥，多个柯尔特互不覆盖。
- 相位偏移器首次释放后本回合可花费1行动点再次释放，第三次不可释放，过期窗口不能延续到之后回合。
- 超级霰弹不再使用弹射物形式，破除射程内连续墙壁和掩体，正确伤害墙后敌人，射程外地形不变。
- 同地图地形变化刷新3D地形，保持摄像机与棋子表现。

破墙复现：同一方向第1、2、4格设置墙或掩体，第3格放敌人，第5格放墙。超级霰弹选择第4格，前3处地形变地板，第3格目标受到1.5倍伤害，第5格墙保留。另验证飞身肘击合法落点与落地周围破墙。

资源继承以先前已签名的1.0.10候选为基础，仅合入本次明确修复的文件，并检查最终归档中的历史继承与技能行为。不能用整份旧资源覆盖后续修改。

本轮代码验证：6个测试文件、70项通过，覆盖新角色技能实际行动入口、受伤计数、连续破墙、地形刷新、图鉴资源引用。柯尔特补充正方向选择，区域按施法者保存，首个敌人按距离确定，避免另一柯尔特重复结算；相位偏移器使用权威资源接口扣除行动点，位移跳过路径地格，未再次释放时在回合结束恢复冷却。上述验证针对工作区源码，尚不代表旧安装包或旧资源包已经更新。
