## 原因与最小回归状态

圣光充能为多个存活友军添加伤害增益。根动作携带多个 areaCells，随后逐目标播放 statusAdded。小剧场每次重写 HTML 都重新创建全层遮光蒙版，120ms 淡入反复变暗；范围地格填充另有发光强度从 0 到 1.15 再到 0.38 的动画。两者共同产生亮暗变化；不是提交动作或局部界面更新必须产生的效果。

最小回归使用一个根动作与三个友军状态事件，检查每阶段仍有技能横幅、没有蒙版，并保留三个目标共十二个阶段的顺序。渲染器回归检查多个地格、全图地格、连续帧、减少动态效果及瞬时提示：填充 opacity/emissiveIntensity 始终为 0，边框与斜线仍有独立可见材质，不启动范围发光动画，不改变权威模型或地形材质。650ms 瞬时清理与正式演出优先级保留。

## 改动

- 小剧场不生成遮光蒙版；移除对应 CSS、淡入动画及历史/减少动态效果引用。
- 范围填充透明，取消发光强度动画；保留静态地格边框和斜线。
- 保留横幅、逐目标提示、浮字、局部状态/治疗圆环，以及播放时序、输入锁定和清理入口。
