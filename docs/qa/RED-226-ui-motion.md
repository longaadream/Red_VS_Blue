## 范围与体验验收

保留现有材质、字体、布局与角色代码。新增公共鼠标联动层及红蓝箭头光标，全页面接入。

1. 主菜单、图鉴、选择棋子、房间及战场移动鼠标，交互卡片/工具图标轻微向鼠标倾斜；移开后回正。连续划过多个对象不出现动画排队。
2. 按下或开始拖动立即执行原操作，不等待回正动画；手牌原扇形排布、棋盘坐标和技能点击/再次取消不回归。
3. 关键词、被动说明、文字选择和滚动保留原操作，不因装饰动效误触命令。
4. 红蓝箭头尖端与点击位置一致，浅黄卡片和深色背景上均清楚；文本输入保留文本光标，禁止操作保留不可用语义。
5. 桌面1280×720、手机844×390与390×844没有新增溢出；触屏无鼠标hover，减少动态效果模式无新增倾斜。
6. 移开鼠标、切换窗口、页面隐藏/销毁后表现停止，没有空闲RAF循环。
