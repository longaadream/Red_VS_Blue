## 作者编辑与运行

效果编辑器支持嵌套表达式、记录创建/读取/更新、有序列表、映射/筛选/汇总、条件/遍历/有限循环、组合与续接声明及内部语句。输入输出、记录结构及可空值使用类型控件，复杂内容不需要靠 JSON 或节点连线编辑。效果区的“编辑内容”可直接切换执行、预览及已有续接入口；执行和预览分别校验；不完整草稿可继续修复，但保存和打包仍需全部有效。

说明文字可以绑定同一模块的编辑期参数。真实工作台已验证“范围 5 → 6”同步到说明、保存、重开及最终包。运行期值不会被伪装成固定文案参数。

编译器 v2 为普通语句错误提供结构化诊断、无效输出传播和独立语句继续执行。嵌套循环共享预算；部分集合结果在中断后失效。card、rule、triggerSkill、skill、preview、规则续接和主动技能续接均安装诊断宿主。正常 pending、事务致命错误和回放不一致保留控制信号。v1 仍按独立的旧编译器进行精确校验，不把版本不匹配当作可接受内容。

相对旧版有三项明确的故障路径差异：黑棺缺失来源、阿方索非法斜向投射、观者填手牌循环永久受阻，均改按用户确认的 v2 语句隔离规则结算。测试保留 v1 原行为，并分别核对诊断、生命/位置、清理、循环上限和资源结果；未更新冻结源来掩盖差异。

## 人工操作复核

从本工作树执行 `npm.cmd run dev:electron:editor` 启动当前版本，在测试内容项目中复核：

1. 进入“棋子 → 漩涡鸣人 → 影分身之术”，检查能力组的主动技能、规则及状态成员能够切换并编辑；率先出阵的旧入口显示“被动入口（兼容）”。
2. 在测试能力组添加条件、循环和嵌套计算，选择前序输出作为输入；组合及续接在效果区展开，不必切到流程图。保留一个无效入口时应阻止保存，修复全部入口后才能保存。
3. 在说明区绑定一个实际模块参数，修改值，保存并重开，确认效果参数、说明及未知字段都保留。可视状态从现有素材中选择图标，重开后预览应一致。
4. 编辑后直接生成资源包应提示先保存；保存全部后生成，查看校验与产物路径。该操作生成本地作者包，不是发布。
