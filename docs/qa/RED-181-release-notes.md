# RED vs BLUE 0.1.5

Windows、Android 与配套资源同步更新。请先完成客户端更新，再应用要求新客户端的资源包。

## 联机与冒险

- LAN 房间与官方/非官方服务器大厅分开，明确区分 1v1、2v2 和 PVE。单人冒险可直接进入。
- 修复主动退房后再次加入被旧连接占用的问题，以及 Relay 房间能显示却加入失败的跨域请求问题。
- 安卓主机增加局域网广播；LAN 房间展示可复制的 IP 和端口，便于手动直连。
- PVE 队员可离开队伍，房主可保存并解散，关闭房间后保留冒险存档。
- 历史存档支持逐条删除。删除前确认，不影响正在运行的冒险，也不会将同一记录重新显示为自动存档。
- 修复圣光手牌选取战区外目标导致结算失败的问题，以及图拉扬移动候选包含战区外非法落点的问题。友方技能按团队识别，棋子的普通控制权保持不变。
- 修复部分 PVE 头像缺失，减少重复进度校验带来的操作等待。

## 战斗界面与教程

- 调整移动端房间列表的滚动和布局，减少行动点/充能点对部署区域的遮挡。
- 日志按卡牌、技能及其后续选择组织效果，减少无意义的触发、资源消耗等条目；可查看对方已使用卡牌的详情。
- 批量增益同时播放，缩短等待；候选目标提示贴合棋盘，移除棋子上的白点。
- 新手教程采用对话框和顶部任务提示，新增单页规则总览；训练营不再提供 PVE 专用棋子。

## 更新与管理

- 保留默认自动检查和下载更新；资源在退出房间、返回主菜单后应用，客户端安装仍需确认重启。
- 修复旧资源覆盖较新内置资源的降级问题，以及恢复内置资源后使用旧联机身份缓存的问题。
- 增加本机 SSH 运维界面，支持服务器状态、日志、备份、候选上传和版本切换。

## 安装说明与已知限制

- Windows 使用 Setup.exe；Android 使用 Android.apk。更新清单、blockmap 和差量文件由客户端读取，无需手动打开。
- 资源包不能替代原生客户端升级；新资源的最低客户端要求见资源更新清单。不要向旧客户端强制导入不兼容资源。
- 手机局域网自动发现受 Wi-Fi/AP 隔离影响；搜索不到时可尝试同一网络下按 IP 和端口直连。
- 安卓双设备发现、长局性能和部分 2v2 反馈仍需更多实机验证；本次不宣称全部联机问题已彻底解决。
- PVE 关闭房间请使用离开/保存并解散；独立战区投降规则仍待完善。
