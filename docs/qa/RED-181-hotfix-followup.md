# RED-181 0.1.8 Android 与联机热修补充合同

- base_branch: `main`
- base_sha: `daa53b4014e326b1f9d32774a729434db6ffd55f`
- risk: High（更新信任配置）；Medium（断线交互与运维脚本）

## 目标与范围

修复 0.1.8 安卓公开包遗漏官方资源发布者公钥、终止断线后界面仍显示等待重连，以及 Windows 运维面板把 CRLF/BOM 脚本直接交给 Linux Bash 的问题。

允许修改 Android 构建与发布校验脚本、战斗页断线反馈、服务器运维面板及其直接测试。本次不改资源包内容、匹配规则、账号数据、数据库格式或服务器网络架构。

## 验收标准

1. 公开 Android 候选包内 `android-distribution.json` 至少包含配置中的全部官方资源发布者公钥；空列表必须在构建或发布校验阶段失败。
2. 收到终止断线事件后清除挂起的技能和卡牌选择，关闭目标交互，并明确提示退出后重进；可恢复断线仍保留原来的重连流程。
3. 运维面板发送远程脚本前移除 UTF-8 BOM 并统一为 LF，Windows 工作区文件可被 Linux Bash 解析。
4. 保留现有用户数据和官方资源包，不需要重新上传 COS 资源包。

## 验证与回退

- 运行 Android 发布制品测试、运维面板测试、断线状态契约测试和相关静态检查。
- 构建签名候选 APK，核验包名、版本号、签名、源码回执和官方发布者公钥。
- 回退时恢复上一版本 APK；服务器运维脚本和战斗页可随提交整体回滚。旧 0.1.8 APK 的空信任列表无法由远端资源包修复，必须由新 APK 替换。
