## 行为

技能/手牌横幅由 1200ms 延长至 3000ms（1 倍速）；2 倍速沿用现有规则，为 1500ms。回合横幅与操作反馈气泡约 3000ms。浮字由约 550–650ms 延长至至少 2000ms，显式时长最多 3000ms，计时器额外留 80ms 清理余量。减少动态效果只缩短进入动画，不缩短可读时间。

自然演出结束通过 settlePresentation 的可选 preserveFloaters 保留尚未到期的浮字；默认清理、历史切换和销毁规则保持原有处理。跳过仍使用原有 60ms 节奏；移动和子动作时长未增加。浮字不拦截输入，权威结算及选择权限未改变。

## 验证记录

真实 Electron 页面回放通过：鼠标及 CDP 模拟触屏的非法目标后合法重试、主动取消、模拟权威拒绝后保留选择。新增可读性检查：1100ms 时回合横幅 opacity=1、浮字可见；3200ms 时横幅隐藏且浮字移除。证据：output/RED-222/browser/results.json 及 desktop-feedback-after-1100ms.png。

公共表现与选择的 4 个测试文件：88 项通过，1 项既有失败。失败为 battle-action-vignette.test.ts 的 “allows battlefield input during path without changing commands, logs, payloads, or hash”，期望 path，实际 result；修改前已经复现，未修改该阶段测试或生产阶段逻辑。长队列测试按配置的阅读时长推进，验证队列与计时器释放；原先硬编码 180000ms 不足以完成原有 160 个 1200ms 动作，已改为按配置计算。

渲染器回归覆盖正常及减少动态效果下 1900ms 仍存在、自然收尾保留、2080ms 清理及默认 settle 清理。`npm.cmd run lint`、`npx.cmd tsc --noEmit`、`git diff --check` 均通过。主线基线检查直接连接 GitHub 失败，随后通过本机配置代理执行同一检查通过（behind=0）。独立 AI 审查未发现阻断问题。
