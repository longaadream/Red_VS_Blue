# 0.1.14

- 新增统一官方服务器管理面板：可查看服务器状态、执行维护与赛季操作，并管理排位地图池、公告和社区内容审核。
- 资源地图目录新增四张可用地图：双桥裂谷、四通广场、群垒庭院与宽环回廊。排位地图池由管理员明确选择并确认，资源更新不会自动扩大匹配范围。
- 修复目标选择、技能与卡牌预演、续选和取消流程中的操作问题；保留服务端校验、原子拒绝和原有费用/伤害规则。
- 更新 Windows、Android、官方服务器和引擎至同一发行版本，并配套资源包 1.0.13。

Windows、Android、官方服务器和引擎来自同一发行源码。安装最新版客户端并使用配套资源包；本地官网构建已使用 RED-251 签名资源快照完成验证。
