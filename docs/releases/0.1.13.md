# 0.1.13

- 移动支持拖动规划多段转弯路径，途中局面预演、撤回路径与完整行走表现。
- 补齐技能、手牌及地格预演，修复目标选择和训练营移动后的操作问题。
- 更新战斗提示、状态名称与图标、部署候选、资源展示和回合沙漏。
- 新增好友、公告板、约桌帖子与在线社区入口。

- 新增好友房间邀请与当前资源包的棋子选择率、胜率统计。

Windows、Android、官方服务器和引擎来自同一发行源码。安装最新版客户端并使用配套资源包；旧战绩未保存的阵容与回放不会补造。
