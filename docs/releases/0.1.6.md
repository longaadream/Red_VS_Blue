# RED vs BLUE 0.1.6 热修版

适用于 Windows 和 Android，继续使用已发布的资源包 1.0.1。此次修复需要更新客户端，单独重新下载资源包不能替代客户端升级。

## 启动与资源准备

- 修复安装签名资源包后“准备游戏失败”、重启或重新准备仍然失败的问题。资源校验完成后，本机对局服务才报告就绪。
- 启动时按实际校验进度等待，可显示已完成文件数和当前阶段；重复状态不会延长等待。长时间无进展、进程退出或资源响应中断时显示失败原因，重新准备可以重新尝试。
- 保留资源完整性、发布者签名和版本兼容检查。

## 手机横屏教程

- 缩小并移动教学提示，减少对棋盘中央和移动落点的遮挡，隐藏重复的顶部提示。
- 增援移动步骤明确提示选中新棋子、再点击可移动格。

## 安装与验证范围

- Windows 安装 Setup.exe；Android 安装 Android.apk。沿用既有 Android 签名，可覆盖安装。
- 自动化启动、故障恢复和重复准备检查已通过；Windows 预览版首次启动已由玩家确认。
- 手机尺寸预览已验证增援部署和移动流程，安卓实体设备仍需后续验证；本次不宣称已解决所有设备的高亮或联机问题。
- 本次未改变服务器规则数据，官方服务器无需因这些客户端修复同步更新。
