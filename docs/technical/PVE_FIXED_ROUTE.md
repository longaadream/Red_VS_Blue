## 权威边界

新固定路线运行时持有 route 与当前原生战斗，界面只提交带 revision 的操作，不提交胜负、伤亡或构造的战斗状态。路线在新局创建时固定；重复、过期、错误阶段的操作不能重抽、重复开战或重复推进。原生核心终局决定战斗结果。

关卡页持有独立 Worker。战斗使用同源 iframe 加载原 `battle.html?mode=adventure&fixedRoute=1`，通过只在固定路线分支启用的桥接接口访问同一个运行时，避免新开另一份冒险。原探索入口的 Worker 和默认 PVP 代码路径保持不变。

原生 PVE 的初始化、动作执行、敌方计划、部署、卡牌补给和战斗清理由既有 `AdventureSession`/游戏引擎复用。离散遭遇只有一个覆盖战斗地图的战区。四张现有正式地图的地板、墙、掩体、洞穴语义必须保留，不能以旧探索地图的图例覆盖。

允许路径、验收和检查以 Linear 合同为准。禁止依赖更新、PVP 核心规则变更、经济默认值变更、旧存档迁移和假战斗结算。若需要共享规则层修改，先报告并修订合同。
