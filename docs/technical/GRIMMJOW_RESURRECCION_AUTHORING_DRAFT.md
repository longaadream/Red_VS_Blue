# 归刃·豹王作者代码

核对origin/main的grimmjow-resurreccion、rule-grimmjow-resurreccion和preparePostDeathSummon。死亡位置和复制副本作为召唤创建输入均已获用户确认。此为完整作者草案，尚未修改运行引擎。

## 完整组合

归刃是被动Skill，不增加主动按钮；Cluster包含归刃Skill与死亡后Rule。死亡后事件保留可读的死亡棋子记录，可查询死亡时的状态、复制其数据和读取所属玩家；这不允许已死亡棋子继续移动/释放技能。普通在场作用与只读死亡记录访问分别处理。

```text
Cluster：归刃·豹王
成员：归刃·豹王被动Skill、归刃·豹王Rule

Rule：归刃·豹王
触发器：当前棋子.死亡后

code：
    如果 获取长度(容器：获取状态(目标：当前事件.棋子，类型：归刃)) > 0：
        结束

    新建【棋子】变量【副本】 = 复制实例(实例：当前事件.棋子)
    新建【棋子模板】变量【归刃模板】 = {
        基础副本：副本，
        最大生命值：10，当前生命值：10，
        攻击力：5，防御力：0，移动力：5，
        初始技能：{破坏本能Skill，狩猎本能Skill，归刃·豹王Skill，豹王之爪Skill}，
        初始状态：{{类型：归刃，强度：1，持续时间：永久}}，
        护盾：0，增益：{}，减益：{}，规则标签：{}
    }
    召唤(
        模板：归刃模板，位置：当前事件.死亡位置，
        所属玩家：当前事件.棋子.所属玩家
    )
```

归刃StatusTag定义为可见，按既有规则可驱散；不自动挂Rule。模板中的四个Skill名称是类型化定义引用，不是字符串标记，也不是四个已在场Skill实例。初始技能创建新运行实例并清零冷却；初始状态整体替换复制来的临时状态，首次出现前已是归刃状态。模板覆盖数据不派发移除旧状态等场上玩法事件，不先召唤再变身。

基础副本保留死亡实例的名称、模板身份、所属玩家、阵营、extension、当时附加的Rule和其他未覆盖数据；不能把当时Rule列表偷偷换回静态初始模板。召唤生成新棋子身份和独立Skill/Rule成员，Rule挂载到新实例并重建相关Cluster归属，原被动Rule不重复安装。外部来源引用不深复制成另一玩家/棋子，也不自动改成新召唤物来源。内部成员身份及外部引用重建是实施验证事项。

不写核心字段，按召唤默认创建召唤物；原棋子的死亡、墓地、掉落和判负完整发生，不取消死亡，不把新召唤物用于保住原核心身份。此区别与巫妖誓约显式保留核心/召唤物身份相同接口、不同内容配置。

基线固定生命10/攻击5/防御0/移动5，牌面+1只对应原生基础攻击/移动4。本代码不读取死亡前强化后攻击再+1。额外被附加的Rule仍保留，技能列表按原基线换为这四项。召唤位置用通用历史死亡地格，不加执行时机参数，不额外建立死亡前位置记录Rule。

## 状态门槛与边界

基线以死亡时是否有归刃状态来拒绝再召唤，没有独立次数标记。新代码保留这一门槛：归刃状态被驱散后再死亡可能再次触发；不擅自增加extension终身一次。召唤失败不取消原死亡，后续独立效果仍按通用失效规则处理；没有技能fallback复活失败改回HP。
