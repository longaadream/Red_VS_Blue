# 安娜：纳米激素完整作者草案

核查origin/main:nano-boost及nano-boost-damage。AP2、CP2、CD2、每局不限。选10格内其他友军，防御直接+3、移动直接+1，附加永久可见纳米激素状态；状态每份强度给所有伤害+1，可叠加。直接加的防御/移动不会因状态驱散而撤销，不能把它们改成跟随状态的临时属性。敌友按阵营，排除自己。

旧nano-boost-damage在beforeDamageDealt读取所有nano-boost状态强度之和并加到context.damage。基线addRuleById在同棋子已有同Rule定义时不再附一份，故两次状态各1的总增伤为+2，不是两份Rule各读取总强度2造成+4。

## 完整作者代码

```text

触发器：使用技能

    新建【棋子】变量【目标】 = 目标选择器(

    )
    目标.防御力 = 目标.防御力 + 3
    目标.移动力 = 目标.移动力 + 1
    附加状态(目标：目标，类型：纳米激素，强度：1，持续时间：永久)
    附加规则(挂载对象：目标，规则：纳米激素增伤)

    新建【元组<StatusTag>】变量【状态列表】 = 获取状态(
```

读取状态实例逐个求和，避免依赖尚未定稿的获取状态强度多实例聚合。来源省略为无来源，普通叠加使永久状态强度增长；不同来源若其他内容明确标记，仍各自保留且上述求和仍可表达。无正伤害不派发造成伤害前，由引擎保证，不写冗余<=0条件。

## Rule天生去重：已确认

用户明确Rule天生去重，就像天照共用Rule；撤回可重复附加字段提议，不要求技能code检测。相同挂载对象、相同Rule定义重复附加复用已有实例，不重复注册监听，不清空extension或覆写来源；不同挂载对象仍各有自己的实例。Rule没有状态的强度/持续时间，不把状态与Rule绑定。

纳米两次施加防御累计+6、移动累计+2；状态普通叠加，增伤Rule只执行一次并合计全部纳米状态强度，所以伤害+2而非+4。状态被驱散只撤销状态增伤，直接属性增量保留。Rule在状态为空时加成为0，不自动删除其他技能或Rule。
