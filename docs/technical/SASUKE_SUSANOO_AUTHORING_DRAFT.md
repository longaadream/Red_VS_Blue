# 须佐能乎作者代码

基线sasuke-susanoo：AP0、CP2（chargeCost）、CD10、maxCharges=0表示每局不限。此文是作者组合草案，不是引擎迁移完成。继续核对带土时确认本技能也有万花筒死亡记录费用减免，下面CP2仅为基础值，动态费用表达式与按需UI更新已确认；来源数据由对局初始配置声明，并由玩家级常驻万花筒Rule累计。形态只使用StatusTag，不新增形态系统。基线没有禁止重复发动的状态判断，本草案不擅自改成每局一次。

```text
技能：须佐能乎
触发器：使用技能
行动点消耗：0
充能点消耗：最大值(0, 2 - 当前棋子.所属玩家.extension.万花筒减免)
冷却：10
每局使用次数：不限

code：
    当前棋子.防御力 = 当前棋子.防御力 + 1

    新建【元组<Skill>】变量【原技能】 = 筛选(
        容器：当前棋子.技能列表，条件：(技能) => 技能.定义引用 == 千鸟
    )
    遍历【原技能】中的每一项【技能】：
        移除技能(技能：技能.所属Cluster)

    新建【元组<Skill>】变量【已有加具土命】 = 筛选(
        容器：当前棋子.技能列表，条件：(技能) => 技能.定义引用 == 加具土命
    )
    如果 获取长度(容器：已有加具土命) == 0：
        新建【Cluster】变量【加具土命组合】 = 获得技能(
            目标：当前棋子，技能：加具土命
        )
        遍历【加具土命组合.技能列表】中的每一项【技能】：
            技能.当前冷却 = 0

    新建【元组<Skill>】变量【已有因陀罗之矢】 = 筛选(
        容器：当前棋子.技能列表，条件：(技能) => 技能.定义引用 == 因陀罗之矢
    )
    如果 获取长度(容器：已有因陀罗之矢) == 0：
        新建【Cluster】变量【因陀罗之矢组合】 = 获得技能(
            目标：当前棋子，技能：因陀罗之矢
        )
        遍历【因陀罗之矢组合.技能列表】中的每一项【技能】：
            技能.当前冷却 = 0

    附加状态(
        目标：当前棋子，类型：须佐能乎，
        强度：1，持续时间：永久，来源：当前棋子
    )
```

获得/移除作用于Cluster实例，设置冷却只作用于Skill实例。此组合把千鸟视为独立入口Cluster；加具土命和因陀罗之矢各自独立Cluster，汇聚自己的Skill及依赖定义。目标棋子身上已经施加的定身和独立定身Rule不会因佐助移除千鸟入口而自动删除；天照的共用玩家Rule也不因替换入口被再次无条件安装。

再次使用本Skill，按基线继续防御+1，保留自己的须佐能乎入口；千鸟不存在时遍历空元组不做操作。两个已拥有技能不重复获得，不重置其冷却或extension；这是作者显式条件分支，未把通用获得技能接口默认重复策略偷偷定稿。第一次替换获得新实例，当前冷却为0、每局次数从定义初始化，本例两个技能本身次数不限，不需要额外次数写入接口。用户早前的替换重置规则作用于真正新替换的实例，不用再次发动同一个强化入口清空已有技能。

基线susanoo-active永久状态的旧重复写入行为须按通用StatusTag叠加规则对齐，状态为形态标记，不凭空给强度添加额外防御效果；防御增量只由上面的属性语句产生一次。驱散标记不自动回退防御或技能，Rule与StatusTag仍独立，不新增“变回去”操作。两个获得技能由自己明确的作者code实现，没有隐藏的执行须佐能乎原子节点。

当前Skill仍参与正常CP扣费与CD10提交，不因为其入口保留而免费重放。没有新增复杂条件或释放失败反馈。获得Cluster中的依赖引用与自动挂载成员的边界、同定义多实例如何代表同一技能入口、佐助失效后的后续语句按通用契约在实施时验证；这不是所有复制/偷取Cluster边界的最终答案。

## 万花筒动态费用：已确认补齐

基础CP2，玩家万花筒减免后最低0；充能点消耗正文已改为动态表达式。玩家选定的技能/Cluster声明万花筒玩家规则依赖时，初始配置为该玩家安装一份常驻计数Rule；可后续授予/复制/偷取的所选内容也可声明依赖，引擎不硬编码万花筒，完整规则见MANGEKYO_AUTHORING_DRAFT.md。无佐助在场也累计，中途获得须佐能乎使用本玩家此前死亡计数；获得/复制Cluster不重复安装玩家Rule、不清计数。技能转移后读取新所属玩家计数，不复制原玩家extension。费用UI按需要与变化通知更新，确认释放时同一引擎重新校验，无定时轮询；不表示运行引擎已接入。
