# 致命毒素作者草案

基线blackwidow-lethal-toxin及rule-blackwidow-toxin-player。用户确认区域显示对接tileEffect；此文为作者代码，未实施。伤害类型是真实，毒素仅是区域显示类型。保留先放置、后传送及来源离场后陷阱继续生效。

```text
技能：致命毒素
触发器：使用技能
行动点消耗：1
充能点消耗：0
冷却：2
每局使用次数：不限

code：
    新建【地格】变量【落点】 = 目标选择器(
        类型：地格，范围：5，
        筛选条件：{可行走：true，被占用：false}
    )
    新建【玩家】变量【玩家】 = 当前棋子.所属玩家
    新建【元组<区域>】变量【玩家.extension.毒素区域】 = {}
    新建【映射<区域,玩家>】变量【玩家.extension.毒素来源】 = {}
    新建【映射<区域,数值>】变量【玩家.extension.毒素伤害】 = {}
    新建【布尔】变量【玩家.extension.毒素规则已安装】 = false

    新建【区域】变量【陷阱】 = 创建区域(地格：{当前棋子.位置})
    追加元组(元组：玩家.extension.毒素区域，元素：陷阱)
    玩家.extension.毒素来源[陷阱] = 玩家
    玩家.extension.毒素伤害[陷阱] = 4
    设置区域显示(
        区域：陷阱，显示配置：{类型：致命毒素，所属玩家：玩家}
    )
    如果 玩家.extension.毒素规则已安装 == false：
        附加规则(挂载对象：玩家，规则：毒素陷阱，来源：玩家)
        玩家.extension.毒素规则已安装 = true

    位移(
        棋子：当前棋子，起点：当前棋子.位置，终点：落点，
        敌军可通过性：false，友军可通过性：false，
        不可通行地格可通过性：false，中间地格是否经过：false
    )
```

```text
Rule：毒素陷阱
触发器：全场.位置改变后

code：
    新建【玩家】变量【玩家】 = 来源
    新建【元组<棋子>】变量【敌军】 = 目标选择器(
        类型：元组<棋子>，方式：自动，
        中心：当前事件.棋子.位置，范围：0，筛选条件：{关系：敌方}
    )
    新建【棋子】变量【目标】 = 敌军[1]
    新建【元组<区域>】变量【匹配陷阱】 = 筛选(
        容器：玩家.extension.毒素区域，
        条件：(区域) => 获取长度(容器：筛选(
            容器：区域.地格，条件：(地格) => 地格 == 目标.位置
        )) > 0
    )
    新建【区域】变量【陷阱】 = 匹配陷阱[1]
    造成伤害(
        目标：目标，类型：真实，
        伤害量：玩家.extension.毒素伤害[陷阱]，
        伤害来源：玩家.extension.毒素来源[陷阱]
    )
    玩家.extension.毒素区域 = 筛选(
        容器：玩家.extension.毒素区域，条件：(区域) => 区域 != 陷阱
    )
    删除映射项(映射：玩家.extension.毒素来源，键：陷阱)
    删除映射项(映射：玩家.extension.毒素伤害，键：陷阱)
    移除区域(区域：陷阱)
    如果 获取长度(容器：玩家.extension.毒素区域) == 0：
        玩家.extension.毒素规则已安装 = false
        移除规则(规则：当前规则)
```

自动选择器在玩家Rule内以来源玩家的阵营解释敌方，不能以最近一个死亡黑寡妇的存活位置为关系参照。敌军为空或无匹配区域时，依赖无效引用的语句跳过；已有非空陷阱列表不会因此清空。先清理玩家列表和映射，再移除区域；后续不读取失效区域，不要求移除后仍可读取其身份。

同玩家同格多个陷阱按存入元组顺序，只取[1]；没有按地格去重。玩家extension首次声明初始化、重复声明复用；共享玩家Rule仅在安装标记为false时附加，最后一个陷阱消耗后清标记并移除自身。不在每次施放时叠加同定义Rule，也不将通用附加规则偷偷规定为去重。

伤害后消耗陷阱，保留基线先后，圣盾挡住伤害仍消耗。作为独立留下的延迟陷阱，创建时保存玩家伤害来源；原棋子存活时也由该玩家出伤，离场后无需来源回退。不在结算时读取原棋子归属。独立传送效果失败不撤销已放置陷阱。位置改变是逐格还是落点，按既有位置事件事实派发，不另用技能发动来源判断。

显示沿用基线tileType=lethal-toxin，没有显式图标与颜色；不把技能图标自动用作地格图标。基线另有玩家StatusTag条目承载陷阱：本草案将实际数据移至玩家extension和区域，但玩家状态栏、日志、AI查询对旧条目的依赖尚须核对，不能宣称UI与旧版本完全一致。区域创建/移除、区域地格视图为规范化草案，公共接口文档明确标记，未声称已运行支持。

待工程验证：同格重叠只消耗一个、己方不触发、被挡伤害仍消耗、源棋子死亡后触发、传送被阻止仍留陷阱、伤害反应中嵌套位置改变的重入顺序、存读后区域引用和安装标记一致、tileEffect增删动画与日志，以及原玩家状态展示。当前只做文档格式检查，未运行游戏测试。
