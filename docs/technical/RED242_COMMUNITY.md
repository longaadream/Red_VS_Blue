# RED-242：好友与公告板

任务：[RED-242](https://linear.app/redvsblue/issue/RED-242)。方案及首次登录提示已获用户批准。基线 main `9d1b0c30801cd733ec4cede37ce1ef0889a2313a`，继承 RED-241 `ce6310ba882e06502bb9abe98d65af48b85491c9`，保留旧候选所有移动、技能、手牌预演和界面修复。

## 用户入口

首页显眼的在线社区入口打开社区页。官方会话复用 `RvBUtils` 的按服务器隔离存储；已有会话自动验证并连接社区，失败给出重试或重新登录入口。未登录时按 Electron 本进程启动标记提示一次，可关闭继续离线，不在返回首页、刷新或网络错误时循环弹窗。账号对话框不能与启动更新对话框抢占焦点。

好友包含申请、接受、拒绝、撤回、删除、屏蔽及解除屏蔽。在线标记仅向已接受好友展示，认证心跳 20 秒一次，90 秒过期。搜索结果不公开邮箱，也不向陌生人公开在线状态。

共享 server-utils 在页面启动及原官方登录保存会话后接续心跳；同页避免并发重复请求，离开页面停止。网络失败保留会话并显示失败，首页账号窗口或社区刷新可重试。请求只允许HTTPS或本机HTTP，不复用一般联机的HTTP降级；旧请求401不能清理更新后的会话。切换账号/服务器时清除旧好友、帖子、回复及编辑内容。

公告板包含官方置顶公告、约桌/交流帖、分页回复及作者删除。房间码只供复制，仍需通过原大厅入房校验。帖子、昵称和回复按纯文本展示，不支持 HTML、脚本和图片上传。

## 服务接口

所有玩家接口位于 `/official/community`，服务端从官方 Bearer 会话解析操作者。成功返回 JSON，失败返回 `{ error }`，采用既有官方 HTTP 接口设施，不恢复旧房间 REST。

| 方法 | 相对路径 | 用途 |
| --- | --- | --- |
| GET | `/accounts?q=…` | 有界昵称/UID搜索，仅id/name |
| GET | `/friends` | friends、incoming、outgoing、blocked |
| POST | `/heartbeat` | 更新当前账号在线期限 |
| POST | `/friends/request`、`accept`、`reject`、`withdraw`、`remove`、`block`、`unblock` | targetAccountId，身份以会话为准 |
| GET | `/board?limit=…&cursor=…` | 官方公告、分页帖子、nextCursor |
| POST | `/posts` | kind、title、body、可选roomCode |
| GET/POST | `/posts/:id/replies` | 分页回复/发布回复 |
| POST | `/posts/:id/delete`、`/replies/:id/delete` | 作者删除 |

官方置顶公告沿用 `official_settings.announcement` 及本机管理面板。帖子/回复隐藏仅由本机受认证管理面板执行，不创建客户端可声明的管理员角色。

审核列表按 offset 翻页，每页最多100条帖子和100条回复；上一页/下一页可到达历史内容。服务端只接受0至1000000的整数offset，作者删除及隐藏记录继续保留以供审核。

## 持久化和边界

社交表独立于权威对局表。好友关系采用有序账号对及事务锁，防止重复/交叉申请与屏蔽竞态。帖子与回复有长度限制、分页、限频和软删除/隐藏。认证与数据库错误不能伪装成成功；离线入口保持可用。

本版本不包含私聊、群组、外部推送、自动入房、匹配或玩法调整。详见 [ADR-0036](../decisions/ADR-0036-official-community.md)。

## 回退

撤销本任务客户端入口和服务器接口接入；保留新增社交表，不删除原账号、战斗或社交数据。保留继承的 RED-241 修复。部署服务端候选后客户端才可调用新接口，旧服务端不支持时明确显示不可用。
