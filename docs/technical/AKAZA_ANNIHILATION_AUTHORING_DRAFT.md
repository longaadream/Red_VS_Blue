# 破坏杀·灭式作者代码

基线akaza-annihilation：行动点2、充能点0、冷却2、每局不限。正方向4格内敌军，距离1/2/3/4倍率1.25/1/0.5/0.5，按近到远逐个结算，不改为同时伤害。采用已有方向选择、射线目标查询、排序、距离、映射、循环及伤害接口。作者草案，未实施。

```text
技能：破坏杀·灭式
触发器：使用技能
行动点消耗：2
充能点消耗：0
冷却：2
每局使用次数：不限

code：
    新建【方向】变量【方向】 = 目标选择器(
        类型：方向，中心：当前棋子.位置，方向范围：正方向
    )
    新建【地格】变量【起点】 = 当前棋子.位置

    新建【元组<棋子>】变量【敌军】 = 目标选择器(
        类型：元组<棋子>，方式：自动，
        中心：起点，方向：方向，形状：射线，范围：4，
        筛选条件：{关系：敌方}，
        阻挡条件：{友军：false，敌军：false，阻挡弹射物地形：false}
    )
    新建【元组<棋子>】变量【有序敌军】 = 排序(
        容器：敌军，依据：(棋子) => 距离(棋子, 起点)，顺序：升序
    )

    新建【映射<数值,数值>】变量【距离倍率】 = {
        1：1.25，2：1，3：0.5，4：0.5
    }
    新建【映射<棋子,数值>】变量【原距离】 = {}

    遍历【有序敌军】中的每一项【目标】：
        原距离[目标] = 距离(目标, 起点)

    遍历【有序敌军】中的每一项【目标】：
        造成伤害(
            目标：目标，类型：普通，
            伤害量：当前棋子.攻击力 × 距离倍率[原距离[目标]]，
            伤害来源：当前棋子
        )
```

先保存目标距离，再开始伤害，防止前一个目标的反应位移改变后一个目标的距离倍率。攻击力按每段伤害读取，沿用基线循环中的读取方式；不擅自冻结全部攻击力。无目标仍默认成功，失效目标依赖语句跳过，整数取整由引擎负责。

目标枚举、稳定排序与每段事件顺序须在实施中对照固定状态回放；本文件不表示运行迁移或伤害日志已验证。
