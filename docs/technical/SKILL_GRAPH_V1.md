# 技能流程图首版

RED-192 在 PR161 的公共规则与 PR162 的内容编辑器之上提供主动技能图编程。现有技能和规则现在会自动展示源码流程，并可编辑代码节点；全清单、公共 flow 接口与 extension 见[现有内容流程与接口](CONTENT_FLOW_RUNTIME.md)。本文以下节点表仍特指纯参数的类型化主动技能图。133项文案/预览/提示修改的完整144项清单见[审计](../qa/RED-192-skill-language-audit.json)。

## 作者操作

1. 在内容编辑器打开技能，选择“流程图”，先显示现有源码流程。展开“类型化节点编程”并明确创建空图后，生成器才接管描述、预览、执行代码与目标声明；保留技能名称、费用、冷却和其他扩展字段。
2. 从“主动使用”开始，先添加全部目标选择，再连接效果或条件，最后连接“完成”。点击节点，在参数区选择对象、数值来源和后继；条件节点分别填写“是/否”。节点可拖动或自动排列。
3. 编译通过后，正文、代码和完整 JSON 同步更新。新增未连接节点、循环、错误引用、未知版本或手工改动生成字段会阻止保存。
4. 保存沿用原子写盘与外部修改冲突检测；关闭再打开保留节点和位置。要自行修改生成代码，明确“解除图关联，保留代码”。源码流程与类型化图不是同一格式，不会自动把任意脚本改写成纯参数图。

## 已支持能力

| 节点 | 参数及行为 |
| --- | --- |
| 主动使用 / 完成 | 唯一入口、有界执行；主动技能费用和冷却仍由权威引擎负责 |
| 选择棋子 | 相对本棋子的曼哈顿距离，敌方/友方/全部，是否包含本棋子 |
| 选择地格 | 本棋子范围内可行走且未占用的地格，排除飞行预留格 |
| 造成伤害 | 固定值、当前攻击力百分比、先前伤害结果百分比；物理/法术/真实；使用公共伤害管线 |
| 恢复生命 | 同类数值来源；实际伤害是实际扣血，不含过量伤害；使用公共治疗管线 |
| 获得状态 | 定身或圣盾，公共计时、叠加与来源清理；圣盾同时安装必要规则 |
| 传送 | 棋子与地格引用；公共传送校验；所有后续路径必然传送时，选择器也排除禁锢/不可操作目标 |
| 条件 | 生命低于最大生命百分比，或目标是否为本棋子；真假分支必须完整 |

例：主动使用 → 选择5格内敌方棋子 → 造成10点真实伤害 → 本棋子恢复本次实际伤害50%的生命 → 完成。目标仅剩2生命时治疗请求为1；圣盾完全挡住时为0。附带吸血的主动技能并不等于“收割”事件被动，后者仍走既有规则。

神威·转移可表达为：主动使用 → 选择7格内其他友方棋子 → 选择7格内空地格 → 传送选定棋子 → 完成。棋子选择与落点选择共用本棋子为中心。

## 数据与运行边界

- `electron-editor/skill-graph.ts` 是共享编译源；`scripts/build-skill-graph.mjs` 生成浏览器包，打包钩子自动执行。宿主写盘也验证产物一致性，不能绕过画布校验保存失配产物。
- `skillGraph.version = rvb-skill-graph/v1`，`graphCompilerVersion = rvb-skill-graph-compiler/v1`。节点目录含参数类型；最多64节点，不允许循环、不可达节点或读取未在所有前驱路径上生成的结果。
- 选择必须连续置于所有效果和条件之前，与现役 `targeting.steps` 协议一致。取消准备不提交效果；真正提交重验候选与版本。编译代码在现有 SkillCode 和 BattleRunner 内执行，不新增第二套战斗状态。
- `graphTrace` 目前只是执行函数返回的节点诊断数据，尚未接到权威回放或编辑器逐步播放界面。画布的描述预览不等同于运行战斗。
- 类型化纯参数图仍未覆盖全部机制；回合事件、召唤、冲刺路径、随机集合、跨回合进度、玩家资源与任意状态可在现有技能/规则的源码流程中查看和编辑，通过新增 `flow` 接口与 extension 编写。具体可调用接口及入口限制见[运行时说明](CONTENT_FLOW_RUNTIME.md)。
- 图生成的代码不获得额外准入权限。外部可执行内容仍受现有资源包策略限制；编辑器能保存不表示任意外部包可以自动执行。

## 共享被动与回退

“率先出阵”描述为“当阵容中有本棋子时，本棋子首先上场。”其他棋子可在技能列表引用 `naruto-vanguard`，或引用带 `passiveTraits: ["opening-vanguard"]` 的被动定义。保留旧ID兼容既有引用；不要复制鸣人专属判断。多个候选通过既有种子随机选择一名，各玩家独立选择。兼容旧棋子上的优先部署标志。

回退图功能时恢复本次图编译与 UI 提交；已保存内容仍带有生成 SkillCode，可先在新编辑器明确解除图关联后使用旧作者模式。保留项目备份，旧编辑器不会验证图与代码一致性。回退公共规则必须遵守 PR161 的规则版本边界，不支持静默降级正在进行的对局。

验证步骤与限制见[QA](../qa/RED-192-graph/README.md)。
