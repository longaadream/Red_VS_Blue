```text
技能：暗影箭
触发器：使用技能
行动点消耗：4
充能点消耗：1
冷却：1
每局使用次数：不限

code：
    新建【方向类型】变量【方向】 =
        目标选择器(
            类型：方向，
            中心：当前棋子.位置，
            方向范围：正方向
        )

    新建【元组<手牌>】变量【残片】 =
        目标选择器(
            类型：元组<手牌>，
            区域：当前棋子.所属玩家.手牌区，
            筛选条件：{具有标签：灵魂残片}，
            方式：自动
        )

    新建【数值类型】变量【伤害量】 =
        当前棋子.攻击力 + 获取长度(容器：残片)

    遍历【残片】中的每一项【牌】：
        弃置手牌(手牌：牌)

    新建【元组<棋子>】变量【敌军】 =
        目标选择器(
            类型：元组<棋子>，
            中心：当前棋子.位置，
            形状：射线，
            方向：方向，
            范围：全图，
            筛选条件：{敌方：true}，
            方式：自动
        )

    造成伤害(
        目标：敌军，
        类型：普通，
        伤害量：伤害量，
        伤害来源：当前棋子
    )
```
