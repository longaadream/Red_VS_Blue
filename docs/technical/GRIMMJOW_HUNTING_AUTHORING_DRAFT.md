# 狩猎本能作者代码

核对origin/main的grimmjow-hunting-instinct及移动/技能两个Rule。此为作者草案，不是运行迁移。被动Skill只负责显示，Cluster包含狩猎本能Rule；同一Rule的两个触发入口共用下述code，不保留两份复制逻辑。

## 基线行为

敌人普通移动后或成功使用技能后，若结算时仍存活且与格里姆乔距离不超过4，可选择自身2格内非原位、可行走且未占用的落点。基线实际调用teleport，不经过中间地格，不是普通移动；不扣额外AP/CP，没有冷却或每局次数限制。被动选择入口允许取消，无候选时引擎结束本次响应，不阻塞原动作。普通移动触发与位置改变触发不混用。

位移被阻止则结束本次响应，不攻击；实际位移成功后，若与原行动敌人相邻，逐次造成两次攻击力×0.75普通伤害。每次重新读取当前攻击力，不预先缓存；每次伤害的反应结算后再继续下一次。释放者或敌人死亡时结束，以死亡棋子为来源的后续伤害语句失效，不回退玩家继续即时攻击链。

## 完整作者草案

```text
Cluster：狩猎本能
成员：狩猎本能被动Skill、狩猎本能Rule

Rule：狩猎本能
触发器：全场.移动后、全场.使用技能后

code：
    新建【棋子】变量【敌人】 = 当前事件.棋子
    如果 敌人.阵营 == 当前棋子.阵营：
        结束
    如果 当前棋子.当前生命值 <= 0 或 敌人.当前生命值 <= 0：
        结束
    如果 距离(当前棋子, 敌人) > 4：
        结束

    新建【地格】变量【落点】 = 目标选择器(
        类型：地格，范围：2，允许取消：true，
        筛选条件：{可行走：true，被占用：false，排除：当前棋子.位置}
    )
    新建【位移结果】变量【结果】 = 位移(
        棋子：当前棋子，起点：当前棋子.位置，终点：落点，
        敌军可通过性：false，友军可通过性：false，
        不可通行地格可通过性：false，中间地格是否经过：false
    )
    如果 结果.成功 == false：
        结束
    如果 距离(当前棋子, 敌人) != 1：
        结束

    新建【数值】变量【次数】 = 0
    当【次数 < 2】成立时循环：
        如果 当前棋子.当前生命值 <= 0 或 敌人.当前生命值 <= 0：
            结束
        造成伤害(
            目标：敌人，类型：普通，
            伤害量：当前棋子.攻击力 × 0.75，伤害来源：当前棋子
        )
        次数 = 次数 + 1
```

允许取消仅显式写在本次被动落点选择入口；不是为所有主动目标选择器打开取消，也不继承整条Rule隐式权限。取消由引擎结束这一响应，不回滚已完成的敌方动作，不执行后续位移/攻击。原位被排除。筛选字段使用已确认选择器能力，具体编辑器字段呈现仍待实施。

事件棋子为本次移动/使用技能的执行者，不是技能目标或Rule持有者。敌友按阵营。选择等待/恢复时引擎复核规则持有者和原事件棋子的有效性；候选落点需服从权威占用/预留检查，不能在UI再次独立实现规则。被动位移为传送，只产生相应位置改变事实，不凭空再派发普通移动后事件。动作失败不会当成成功使用技能后。

两次伤害分别产生事件，也各自可能触发破坏本能；破坏本能自伤不会再次触发本能。即时连续攻击需要子伤害及反应的公共结算边界，不能把两次改成同时，不能先计算一次攻击力给后续共用。当前运行代码与新队列的调度对齐仍须工程验证。
