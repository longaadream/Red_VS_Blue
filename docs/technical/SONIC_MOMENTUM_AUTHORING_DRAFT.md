## 公共依赖初始化与Rule

每个依赖动能的Cluster在初始化声明区展开下列普通声明/部署语句。不会按角色名自动启用，也不需要零强度常驻状态。多个Cluster在同一棋子声明相同字段保留已有值、附加同Rule去重；因此多技能不会重复获得动能。Skill登记用具体运行实例。

```text
初始化声明区（各动能Cluster复用此组语句）：
    在【当前棋子.extension】中新建【数值】变量【动能】 = 0
    在【当前棋子.extension】中新建【集合<Skill>】变量【消费动能技能】 = {}
    在【当前棋子.extension】中新建【集合<Skill>】变量【更新动能技能】 = {}
    附加规则(挂载对象：当前棋子，规则：动能积累)
    附加规则(挂载对象：当前棋子，规则：动能消费)

Rule：动能积累
挂载对象：棋子
触发器：当前棋子.普通移动后
code：
    当前棋子.extension.动能 = 当前棋子.extension.动能 + 获取长度(容器：当前事件.实际路径)

Rule：动能消费
挂载对象：棋子
触发器：当前棋子.使用技能后
code：
    如果 容器包含元素(容器：当前棋子.extension.消费动能技能，元素：当前事件.技能) == false：
        结束
    如果 获取长度(容器：获取状态(目标：当前棋子，类型：保留动能)) > 0：
        结束
    如果 容器包含元素(容器：当前棋子.extension.更新动能技能，元素：当前事件.技能)：
        结束
    当前棋子.extension.动能 = 0
```

主动主体和后续交互执行完，才进入使用技能后。准备拒绝/取消不消费；效果未命中或传送被阻止但释放成功，仍进入消费。其他未登记技能不影响计数。更新动能技能由自身按实际路径写入，消费Rule不再清空结果；本文件不冒充已完成这些冲刺的主体。移除后的旧Skill引用无法匹配另一实例，重新获得须登记新实例；共享Rule不随单个Cluster移除而卸载。

计数只保存一份，UI应绑定同一extension数值并按变化更新；零动能仍可显示。具体棋子显示插槽映射待表现实现，不伪造0强度状态，也不在渲染时累加。基线所读Rule没有普通回合末清零代码，不增加未经依据的清零规则。

## 追踪攻击：sonic-homing-attack

AP1/CP0/CD0/每局不限。选4格内同行或同列敌人，相邻四格必须有可行走空位，自己的当前格不豁免占用。用种子随机选择一格传送；失败结束效果，仍按成功释放消费动能。

```text
Cluster：追踪攻击
初始化声明区：
    展开上述公共依赖初始化语句
    加入集合(集合：当前棋子.extension.消费动能技能，元素：本Cluster.追踪攻击)

Skill：追踪攻击
触发器：使用技能
行动点消耗：1
充能点消耗：0
冷却：0
每局使用次数：不限
code：
    新建【棋子】变量【目标】 = 目标选择器(
        类型：棋子，范围：4，筛选条件：{
            关系：敌方，与当前棋子同行或同列：true,
            条件：(候选) => 获取长度(容器：目标选择器(
                类型：元组<地格>，方式：自动，中心：候选.所在地格，
                范围：1，最小距离：1，距离算法：曼哈顿，
                筛选条件：{可行走：true，被占用：false}
            )) > 0
        }
    )
    新建【元组<地格>】变量【落点们】 = 目标选择器(
        类型：元组<地格>，方式：自动，中心：目标.所在地格，
        范围：1，最小距离：1，距离算法：曼哈顿，
        筛选条件：{可行走：true，被占用：false}
    )
    如果 获取长度(容器：落点们) == 0：
        返回技能释放失败(原因："目标相邻地格没有合法落点")
    新建【地格】变量【落点】 = 随机排序(容器：落点们)[1]
    新建【位移结果】变量【位移结果】 = 位移(
        棋子：当前棋子，起点：当前棋子.所在地格，终点：落点，
        友军可通过性：true，敌军可通过性：true，
        不可通行地格可通过性：true，中间地格是否经过：false
    )
    如果 位移结果.成功 == false：
        结束
    新建【数值】变量【余量】 = 当前棋子.extension.动能
    新建【数值】变量【加成】 = 0
    当 余量 >= 4 时循环：
        余量 = 余量 - 4
        加成 = 加成 + 1
    造成伤害(目标：目标，类型：普通，
        伤害量：当前棋子.攻击力 × 0.5 + 加成，伤害来源：当前棋子)
```

`展开`是文档省略重复初始化段的记法，编辑器实际保存普通声明/附加Rule语句，不新增执行节点。目标初选与改写沿已有规则；改写后不再拿原同行/同列条件否定合法替代目标。目标附近无合法格属于准备失败；选完落点后被反应占据属于位移失败，不回滚费用。随机在本次选择确认后只消费一次种子，挂起恢复不重抽。

加成先算每4动能的整数份，再与0.5倍攻击相加；不将两项小数合并后才取整。实际伤害读传送后当前攻击与动能，保持基线读取时点。目标失效则伤害语句跳过，后事件仍正常消费有效施法者的动能；施法者已失效不继续行动。

## 超级形态：sonic-super-form

AP0/CP3/CD3/每局不限。增加2行动点允许超过上限；本回合不消费动能。形态仅为StatusTag，不引入形态引擎，也不在结束时扣除已有动能。

```text
StatusTag：保留动能
可见：true
允许叠加：false

Cluster：超级形态
初始化声明区：
    展开上述公共依赖初始化语句
    附加规则(挂载对象：当前棋子，规则：超级形态回合清理)

Skill：超级形态
触发器：使用技能
行动点消耗：0
充能点消耗：3
冷却：3
每局使用次数：不限
code：
    调整资源(玩家：当前棋子.所属玩家，资源：行动点，变化量：2，允许超过上限：true)
    附加状态(目标：当前棋子，类型：保留动能，强度：1，持续时间：永久)

Rule：超级形态回合清理
挂载对象：棋子
触发器：全场.回合结束
code：
    遍历【获取状态(目标：当前棋子，类型：保留动能)】中的每一项【状态】：
        状态.强度 = 0
```

重复释放仍获得2行动点；同回合重复附加不可叠加标记不产生额外层数或多回合保护。全场回合结束显式耗尽，包含创建当回合，不套持续时间1的“创建回合不递减”。本技能未登记为消费动能技能；标记消失只结束保留资格，不清空计数。可见标记被驱散后，后续动能技能恢复普通消费。回合末其他Rule与本清理仍按既定优先级，不新增角色专属时序。
