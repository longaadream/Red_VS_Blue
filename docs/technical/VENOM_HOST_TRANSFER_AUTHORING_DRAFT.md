普通选择默认最小距离1，不能初选自己；被指定为目标前改写成自己时，合法同格语义允许成功结束，不重新用初始候选排除规则拒绝。友军和敌军均可选择，不限定核心。目标失效使依赖语句失效，不把目标换成其他棋子。

移动列表先保存双方起点和终点，再一次提交给同一位移模块。两项彼此依赖对方离开原格；一项被位移规则阻止时，另一项终点仍被占用，所以也不能落地，双方不动。不先移动第一人造成重叠，不通过临时出局/删除棋子或事后回滚坐标模拟换位；校验期间的占用假设不是提前发布空格状态。权威提交前复核位置、实例和落点，先完成相关位置更新，再对实际移动派发位置改变后事件，观察者不会看到两棋子同格的中间状态。

批量入口用有序元组配对，结果按输入顺序一一对应，每项保留既有成功/发生位移字段。此为通用数据形状整理，不引入必须全部成功、原子模式或角色专属换位节点。本次明确的是相互占用依赖导致双方失效，不把它推广为任意互不相关位移也必须全成全败。双尾飞行仍按已经确认的两个独立调用分别结算。

完全失败仅取消位移效果，技能使用仍成功、正常消耗和冷却，不附加定身。成功后按当时阵营判断敌友，敌方获得定身1；同阵营玩家之间仍算友方。定身限制普通移动，不自动禁止传送；这里只说明若其他合法位移拦截Rule阻止一方时如何处理，不把普通定身误当传送免疫。
