# 惊鸿掠水作者代码

基线alfonso-water-dash；采用通用查询路径、容器、循环、伤害和位移接口组合。Set用于去重，元组用于路径顺序与种子随机。作者草案，未实施；保留基线最多10次连跳尝试与伤害/位移先后，不引入技能专用节点。

```text
技能：惊鸿掠水
触发器：使用技能
行动点消耗：2
充能点消耗：2
冷却：1
每局使用次数：不限

code：
    新建【方向】变量【方向】 = 目标选择器(
        类型：方向，中心：当前棋子.位置，方向范围：正方向
    )
    新建【地格】变量【起点】 = 当前棋子.位置
    新建【集合<棋子>】变量【已处理】 = {}
    新建【路径查询结果】变量【路径】 = 查询路径(
        棋子：当前棋子，起点：起点，方向：方向，范围：全图，
        敌军可通过性：false，友军可通过性：false，
        不可通行地格可通过性：false
    )

    如果 路径.首个阻挡棋子.阵营 != 当前棋子.阵营：
        造成伤害(
            目标：路径.首个阻挡棋子，类型：普通，
            伤害量：当前棋子.攻击力 × 2，伤害来源：当前棋子
        )
        加入集合(集合：已处理，元素：路径.首个阻挡棋子)

    位移(
        棋子：当前棋子，起点：起点，终点：路径.最后合法落点，
        敌军可通过性：false，友军可通过性：false，
        不可通行地格可通过性：false，中间地格是否经过：true
    )

    新建【数值】变量【尝试次数】 = 0
    当【尝试次数 < 10】成立时循环：
        新建【元组<棋子>】变量【附近敌军】 = 目标选择器(
            类型：元组<棋子>，方式：自动，中心：当前棋子.位置，
            范围：4，筛选条件：{关系：敌方}
        )
        新建【元组<棋子>】变量【候选敌军】 = 筛选(
            容器：附近敌军，
            条件：(棋子) => 集合包含元素(集合：已处理，元素：棋子) == false
        )
        如果 获取长度(容器：候选敌军) == 0：
            跳出循环

        新建【元组<棋子>】变量【随机敌军】 = 随机排序(容器：候选敌军)
        新建【棋子】变量【目标】 = 随机敌军[1]
        新建【元组<地格>】变量【候选落点】 = 目标选择器(
            类型：元组<地格>，方式：自动，中心：目标.位置，
            范围：{最小：1，最大：1}，
            筛选条件：{可行走：true，被占用：false}
        )
        如果 距离(当前棋子, 目标) == 1 且 当前棋子.位置.可行走：
            追加元组(元组：候选落点，元素：当前棋子.位置)

        加入集合(集合：已处理，元素：目标)
        尝试次数 = 尝试次数 + 1
        如果 获取长度(容器：候选落点) == 0：
            继续下一次

        新建【元组<地格>】变量【随机落点】 = 随机排序(容器：候选落点)
        位移(
            棋子：当前棋子，起点：当前棋子.位置，终点：随机落点[1]，
            敌军可通过性：false，友军可通过性：false，
            不可通行地格可通过性：false，中间地格是否经过：false
        )
        造成伤害(
            目标：目标，类型：普通，
            伤害量：当前棋子.攻击力 × 2，伤害来源：当前棋子
        )
```

首段路径是伤害前的只读预查询，非实际经过结果；最后落点在伤害前确定，再经权威位移复核。不可行走地形与任何棋子都截住初段查询；友军不受首段伤害。原地位移失败不阻止独立的后续连跳流程。

基线连跳允许本人所在格作为目标邻格候选，并且传送效果失败后仍执行目标伤害；以上保留这种独立语句语义，不擅自加“传送成功才伤害”。没有合法邻格也会消耗一次尝试并标记该目标，但不造成伤害，因此集合命名为已处理而非已伤害。

随机来源按此前确认改为种子随机；具体候选枚举次序、shuffle随机消耗与基线Math.random替换的回放结果需要实施验收，不据作者代码擅改运行随机算法。范围全图对应基线tracePath的100步上限被地图边界进一步截断；若未来地图允许超过100格，需另明确边界，不能宣称无限地图等价。

查询路径从起点相邻格开始，以棋子确定敌友阵营；首个阻挡棋子允许为空，依赖它的条件与语句跳过。查询不触发额外移动/伤害事件。本草案不表示类型检查、UI、动画或日志已通过。
