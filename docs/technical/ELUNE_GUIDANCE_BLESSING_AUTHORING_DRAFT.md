```text

Rule：月华积累
挂载对象：棋子
触发器：本玩家.使用手牌后
code：
    如果 当前事件.手牌.标签 不包含 圣光：
        结束
    新建【元组<StatusTag>】变量【月华们】 = 获取状态(目标：当前棋子，类型：月华)
    新建【数值】变量【月华值】 = 1

        月华值 = 月华值 + 月华.强度
    如果 月华值 >= 2：
        遍历【月华们】中的每一项【月华】：
            移除状态(状态：月华)
        新建【元组<棋子>】变量【友军】 = 目标选择器(
            类型：元组<棋子>，方式：自动，范围：全图，筛选条件：{关系：友方}
        )
        新建【元组<棋子>】变量【排序后友军】 = 排序(
            容器：友军，依据：(棋子) => 棋子.当前生命值，顺序：升序
        )
        恢复生命(目标：排序后友军[1]，数值：5，来源：当前棋子)
    否则：
        附加状态(目标：当前棋子，类型：月华，强度：1，持续时间：永久，来源：当前棋子)

宿主须在场有效；不查找某个角色名字替代实际Cluster持有者。每个宿主独立积累，只有其所属玩家用牌触发；可治疗全阵营友军包括自己。标签包含圣光即匹配，不限普通；三种普通圣光及已标记强化牌按数据定义归类。

月华可见可驱散，强度表示层数；无状态时循环零次即从1开始，等价于已确认的无状态强度0。显式逐实例求和用于本内容，不擅自规定公共获取状态强度的多实例返回。达到阈值后清空而不是扣2留余量；先清后治疗沿已确认作者方案，普通治疗触发正常反应。同生命值排序稳定保留输入元组次序，不消耗随机数；空元组[1]无效则只跳过治疗。

成员：月神赐福Skill

触发器：使用技能
行动点消耗：1
充能点消耗：0
冷却：2
每局使用次数：不限
code：
    新建【元组<手牌定义>】变量【牌池】 = 元组<手牌定义>{圣光惩击，圣光治疗，圣光充能}
    新建【元组<手牌定义>】变量【随机牌池】 = 随机排序(容器：牌池)
    获得手牌(玩家：当前棋子.所属玩家，手牌：随机牌池[1])
    在【当前棋子.所属玩家.extension】中新建【数值】变量【Multiplier】 = 1.5
    当前棋子.所属玩家.extension.Multiplier = 1.5
    附加状态(目标：当前棋子.所属玩家，类型：月神赐福，强度：1，持续时间：永久)
    附加规则(挂载对象：当前棋子.所属玩家，规则：赐福强化Rule)
    附加规则(挂载对象：当前棋子.所属玩家，规则：赐福消费Rule)

Rule：赐福强化
挂载对象：玩家
触发器：本玩家.使用手牌前
code：
    如果 当前事件.手牌.标签 不包含 圣光：
        结束
    如果 获取长度(容器：获取状态(目标：当前玩家，类型：月神赐福)) == 0：
        结束
    当前事件.局部变量.伤害量 = 当前事件.局部变量.伤害量 × 当前玩家.extension.Multiplier

    当前事件.局部变量.强化强度 = 当前事件.局部变量.强化强度 × 当前玩家.extension.Multiplier

挂载对象：玩家

    如果 当前事件.手牌.标签 不包含 圣光：
        结束
    新建【元组<StatusTag>】变量【赐福们】 = 获取状态(目标：当前玩家，类型：月神赐福)
    如果 获取长度(容器：赐福们) == 0：
        结束
    遍历【赐福们】中的每一项【赐福】：
        移除状态(状态：赐福)
    删除变量(位置：当前玩家.extension，名称：Multiplier)
```

月神赐福可见、永久、不叠加，已有时忽略新状态；再次使用仍取得一张牌，倍率覆盖1.5，次数仍只有下一张，不累积。持久声明不重置已存在字段，所以随后显式赋值；删除后再次使用重新声明。Rule独立去重，不与状态自动挂卸。宿主泰兰德离场不取消玩家赐福。

牌池严格三张定义引用，不从所有圣光牌自动扩大；随机排序使用种子流，取[1]，不新增随机返回类型。满手仍成功创建到弃牌区、正常获得赐福，不拒绝技能或退款；真正新牌创建失败只使该效果失败，独立赐福语句继续。

使用前局部变量由引擎在已声明初始化的上下文开放，各句独立；不存在的变量跳过，不新增变量、不从玩家extension读临时伤害量。只乘伤害/治疗/强化强度，不乘费用、数量或范围；不改定义或其他手牌实例。多目标多段读取本次已改变量，不逐次再乘。数值在统一结算/写入整数属性时取整，基础5→7、8→12、2→3。

成功使用后的消费每张牌只一次。准备取消/拒绝不消费；按最新已确认无目标正常成功的圣光牌仍消费，即使效果空或被blocked，不沿旧历史段落改成拒绝。手牌默认进入弃牌区，实例身份仍可由事件读取。挂起恢复不得重复使用前改写或重复发牌。

现阶段现有三种圣光牌没有嵌套使用/执行期间重新授予赐福；这类未来内容的预占与重入版本边界须另核对，不擅自加入保留次数事务模块。UI值变化依赖通知，不轮询；状态消失使Rule不再改写，即使extension残留也不生效。
