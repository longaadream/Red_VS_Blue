# 天照铺设与结算作者代码

关联sasuke-amaterasu、sasuke-indra-arrow及三个天照Rule。当前阶段只写作者组合与接口规格，不修改引擎。铺设、接触、站立与伤害Rule作者正文已整理；用户已确认获取状态返回具体实例元组。来源分组已确认，共享调度生命周期与表现适配仍需工程对齐，不表示运行迁移完成。

## 天照之炎

```text
技能：天照之炎
触发器：使用技能
行动点消耗：2
充能点消耗：0
冷却：3
每局使用次数：不限

code：
    新建【玩家】变量【伤害玩家】 = 当前棋子.所属玩家
    新建【地格】变量【中心】 = 目标选择器(
        类型：地格，范围：5，筛选条件：{}
    )
    新建【元组<地格>】变量【候选地格】 = 目标选择器(
        类型：元组<地格>，方式：自动，中心：中心，
        形状：正方形，边长：3，筛选条件：{}
    )
    新建【集合<地格>】变量【全局.extension.天照地格】 = {}
    新建【映射<地格,区域>】变量【全局.extension.天照区域】 = {}
    新建【映射<地格,棋子>】变量【全局.extension.天照来源】 = {}
    新建【映射<地格,玩家>】变量【全局.extension.天照伤害玩家】 = {}
    新建【布尔】变量【全局.extension.天照规则已安装】 = false
    新建【数值】变量【新增数量】 = 0

    遍历【候选地格】中的每一项【地格】：
        如果 集合包含元素(集合：全局.extension.天照地格，元素：地格) == false：
            新建【区域】变量【区域】 = 创建区域(地格：{地格})
            加入集合(集合：全局.extension.天照地格，元素：地格)
            全局.extension.天照区域[地格] = 区域
            全局.extension.天照来源[地格] = 当前棋子
            全局.extension.天照伤害玩家[地格] = 伤害玩家
            设置区域显示(
                区域：区域，显示配置：{
                    类型：天照，图标：🌑，图标位置：右下
                }
            )
            新增数量 = 新增数量 + 1
    如果 全局.extension.天照规则已安装 == false：
        附加规则(挂载对象：当前棋子.所属玩家，规则：天照接触灼烧，来源：当前棋子.所属玩家)
        附加规则(挂载对象：当前棋子.所属玩家，规则：天照站立叠层，来源：当前棋子.所属玩家)
        附加规则(挂载对象：当前棋子.所属玩家，规则：天照灼烧伤害，来源：当前棋子.所属玩家)
        全局.extension.天照规则已安装 = true
```

## 因陀罗之矢

```text
技能：因陀罗之矢
触发器：使用技能
行动点消耗：2
充能点消耗：0
冷却：1
每局使用次数：不限

code：
    新建【玩家】变量【伤害玩家】 = 当前棋子.所属玩家
    新建【方向】变量【方向】 = 目标选择器(
        类型：方向，中心：当前棋子.位置，方向范围：正方向
    )
    新建【元组<地格>】变量【候选地格】 = 目标选择器(
        类型：元组<地格>，方式：自动，中心：当前棋子.位置，
        方向：方向，形状：射线，范围：全图，筛选条件：{}
    )
    新建【集合<地格>】变量【全局.extension.天照地格】 = {}
    新建【映射<地格,区域>】变量【全局.extension.天照区域】 = {}
    新建【映射<地格,棋子>】变量【全局.extension.天照来源】 = {}
    新建【映射<地格,玩家>】变量【全局.extension.天照伤害玩家】 = {}
    新建【布尔】变量【全局.extension.天照规则已安装】 = false
    新建【数值】变量【新增数量】 = 0

    遍历【候选地格】中的每一项【地格】：
        如果 集合包含元素(集合：全局.extension.天照地格，元素：地格) == false：
            新建【区域】变量【区域】 = 创建区域(地格：{地格})
            加入集合(集合：全局.extension.天照地格，元素：地格)
            全局.extension.天照区域[地格] = 区域

            新增数量 = 新增数量 + 1
    如果 新增数量 > 0：
        如果 全局.extension.天照规则已安装 == false：
```

正方形只取地图存在的3×3地格；射线从起点相邻格到地图边缘，不被墙、敌军或友军截断。这两种选择不筛可行走/占用属性，不改变原地形，仅创建单格区域及tileEffect。正方形3×3复用已讨论形状；偶数边长等通用形状边界不在本例定稿。

首次声明后全局字段保持值，不重复清空。每格Set唯一登记，三个Map与它一致；重复铺设不覆盖区域或来源。候选查询保留元组枚举次序，Set不承担Gameplay排序。字段与加具土命消费段共用同一批全局extension数据。

现役两个铺设技能都安装三个玩家Rule，但只允许最初登记玩家调度。作者用全局布尔标记保证只安装一组，挂到首次实际安装者的玩家，显式来源也是该玩家。此为保留基线一次调度的组合，不把通用附加规则默认改成去重，也不新建全局Rule挂载对象。三个Rule无需原佐助在场，天照地格全部消耗后不移除灼烧伤害Rule。管理玩家淘汰、复制得到相关Skill却未铺设、存档引用恢复与标记一致性仍须后续案例核对；本草案不扩大成所有模式的最终生命周期政策。

## 路径接触Rule

```text
Rule：天照接触灼烧
触发器：全场.路径接触后

code：
    如果 集合包含元素(
        集合：全局.extension.天照地格，元素：当前事件.地格
    )：
        新建【StatusTag】变量【灼烧】 = 附加状态(
            目标：当前事件.棋子，类型：天照灼烧，
            强度：1，持续时间：永久，
            来源：全局.extension.天照来源[当前事件.地格]
        )
        在【灼烧.extension】中新建【玩家】变量【伤害玩家】 = 全局.extension.天照伤害玩家[当前事件.地格]
```

每次只处理当前实际接触的一格，响应结束后再继续路径；不另外监听位置改变再给终点重复加层。不区分阵营。没有接触天照，不加状态；地格原施法者引用仅用于历史身份和叠加分组；伤害玩家已在铺设时另存，无需原棋子继续在场，也不读取其现时归属。

## 站立叠层Rule

```text
Rule：天照站立叠层
触发器：全场.回合结束

code：
    新建【元组<棋子>】变量【棋子列表】 = 目标选择器(
        类型：元组<棋子>，方式：自动，范围：全图，筛选条件：{}
    )
    遍历【棋子列表】中的每一项【棋子】：
        如果 集合包含元素(
            集合：全局.extension.天照地格，元素：棋子.位置
        )：
            新建【StatusTag】变量【灼烧】 = 附加状态(
                目标：棋子，类型：天照灼烧，
                强度：1，持续时间：永久，
                来源：全局.extension.天照来源[棋子.位置]
            )
            在【灼烧.extension】中新建【玩家】变量【伤害玩家】 = 全局.extension.天照伤害玩家[棋子.位置]
```

每位玩家回合结束都查询全场当前存活棋子，不只处理该回合玩家。挂载玩家仅负责唯一调度，不能把选择器范围隐式限制成其棋子或同阵营；范围全图按全场实例查询，不依赖来源棋子的位置。反应导致目标失效时依赖语句跳过。

## 灼烧伤害Rule

```text
Rule：天照灼烧伤害
触发器：全场.回合结束

code：
    新建【元组<棋子>】变量【棋子列表】 = 目标选择器(
        类型：元组<棋子>，方式：自动，范围：全图，筛选条件：{}
    )
    遍历【棋子列表】中的每一项【棋子】：
        如果 棋子.所属玩家 == 当前事件.玩家：
            新建【元组<StatusTag>】变量【灼烧状态】 = 获取状态(
                目标：棋子，类型：天照灼烧
            )
            遍历【灼烧状态】中的每一项【状态】：
                造成伤害(
                    目标：棋子，类型：真实，
                    伤害量：状态.强度 × 2，伤害来源：状态.extension.伤害玩家
                )
```

用户已确认获取状态返回具体StatusTag实例元组，没有则为空；各棋子自己的状态独立，共用Rule不共享状态数据。只有当前结束回合玩家的棋子结算伤害；逐个读取状态强度和extension中的伤害玩家。多实例逐个结算，目标在先前伤害反应中失效，后续依赖该目标的语句跳过。

不把获取状态强度擅自规定成多实例求和，不通过额外缓存状态引用绕开查询契约。用户确认同来源才允许合并，不同来源灼烧分别存在；天照显式传入来源，所以不能因同属玩家将两名佐助的状态合并。共用Rule逐个结算状态，不把不同施法者强度合计后只出一次伤害；各次伤害直接归保存的玩家，不触发原棋子的造成伤害/击杀被动。来源字段可省略，但天照保留显式叠加分组来源，伤害参数独立读取extension.伤害玩家；缺少该字段是内容/迁移不变量错误，不能临时补原棋子所属玩家。无天照地格也继续处理已有灼烧，因此Rule不以地格Set为空为退出条件。

## 基线顺序与验证边界

基线三个Rule都未声明priority，玩家Rule按priority从大到小稳定排序，铺设注册顺序为接触、站立叠层、灼烧伤害，因此本组同优先级站立叠层先于伤害。作者保持注册顺序，不给它们虚构新优先级而改变与其他Rule的相对顺序。状态计时与其他全场Rule的组合仍须实施回放，稳定相同优先级调度须正式记录在公共引擎契约，不以文档代码冒充已验证。

显示沿用天照图标🌑与右下位置。原天照之炎expand及presentationStep动画参数的兼容仍由统一表现队列适配，不能把没有编排参数的单格新增直接声称与旧动画一模一样。原来源、旧intensity/stacks展示映射、加具土命原无sourcePieceId的创建路径与新显式来源参数也须核对，不静默改变来源/击杀统计。

待验证：地图裁切、正方向射线、重复铺设唯一地格、跨佐助来源分成独立状态并各自出伤、同来源叠加、三个Rule只运行一组、逐格实际接触、传送只接触落点、墙体可经过时的接触事实、回合末先叠层后伤害、双方站立但只当前玩家受伤、无天照地格仍保留旧灼烧伤害、消耗重新铺设、可驱散状态与独立Rule、玩家来源不随原棋子死亡/控制权变化改变、统一日志与动画。当前只执行文档格式检查，无游戏测试。

## 延迟伤害玩家归属：最新修改

玩家引用在铺设/直接附加灼烧时保存，不在原棋子死亡后再访问其所属玩家。状态.来源仍是历史施法者身份用于来源分组，状态.extension.伤害玩家是实际伤害归属。地格消费删除三个映射，但已经附加的灼烧保留自身玩家引用；原棋子存活或死亡都不改变此来源类型。

同名同类型extension重复声明不覆盖已有值：附加状态合并到已有实例时保留该实例已保存的伤害玩家。控制权改变后再施加并与旧状态合并的跨归属归因，需要未来专门核对；不借本轮更改普通叠加规则，也不宣称该边界已定稿。缺少玩家字段不能用死亡棋子补值，更不能静默改为管理Rule玩家。旧存档/旧状态迁移与首次状态通知的初始化顺序仍需运行实现验证。
