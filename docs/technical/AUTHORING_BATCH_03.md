## 已确认接口：普通移动后的实际路径

固定基线动能积累Rule通过逆查battle.actions最后一条move记录取得path.length。作者框架提议在`当前棋子.普通移动后`的只读事件提供`当前事件.实际路径：元组<地格>`，包含本次实际进入的格子，不含起点；中途停止仅返回已经走过部分，同格重复经过保留重复项。点按自动路径与拖动路径用同一结果，冲刺/传送不触发此普通移动入口。用户已确认该字段；下列片段展示累计方式，完整共享Rule与两项主动见[动能与索尼克](SONIC_MOMENTUM_AUTHORING_DRAFT.md)：

```text
当前棋子.extension.动能 = 当前棋子.extension.动能 + 获取长度(容器：当前事件.实际路径)
```

这样绕路走4格即加4，计划走4格但被中断只走2格即加2；不得用起终点距离或预测路径代替。初始化声明区已可以解决公共计数与Rule依赖，不继续把初始化列为新缺口；消费前快照、实际Skill引用登记及超级形态保留仍需补连续正文。
