# 千鸟作者草案

核对origin/main中的sasuke-chidori与rule-chidori-immobile。用户要求统一为定身，不再使用千鸟专属状态名或专属限制Rule；状态与Rule仍独立。此文是作者代码设计，未实施。位移参数、实际路径返回、集合伤害、普通状态叠加和独立Rule使用已确认接口；用户已选择普通叠加，撤回本技能的状态时间刷新分支。

```text
技能：千鸟
触发器：使用技能
行动点消耗：1
充能点消耗：0
冷却：1
每局使用次数：不限

code：
    新建【地格】变量【终点】 = 目标选择器(
        类型：地格，范围：6，
        筛选条件：{
            可行走：true，被占用：false，
            同行或同列：true，排除当前位置：true
        }
    )
    新建【位移结果】变量【路径】 = 位移(
        棋子：当前棋子，起点：当前棋子.位置，终点：终点，
        敌军可通过性：true，友军可通过性：true，
        不可通行地格可通过性：true，中间地格是否经过：true
    )
    如果 路径.成功：
        新建【元组<棋子>】变量【敌军】 = 筛选(
            容器：路径.经过棋子，
            条件：(棋子) => 棋子.阵营 != 当前棋子.阵营
        )
        造成伤害(
            目标：敌军，类型：普通，
            伤害量：当前棋子.攻击力，伤害来源：当前棋子
        )
        遍历【敌军】中的每一项【目标】：
            如果 目标具有【定身】状态 == false：
                附加规则(挂载对象：目标，规则：定身，来源：当前棋子)
            附加状态(
                目标：目标，类型：定身，
                强度：1，持续时间：1，来源：当前棋子
            )
```

```text
Rule：定身
触发器：当前棋子.移动前

code：
    如果 当前棋子具有【定身】状态：
        阻止当前事件
    否则：
        移除规则(规则：当前规则)
```

定身状态与通用定身Rule分别引用外部定义，不用relatedRules自动安装。规则的当前棋子上下文是挂载棋子，不是来源佐助。基线只阻止普通移动，不凭“定身”名称扩大为禁止所有传送或技能。

基线同行同列、距离1至6、终点可行走且不占用的限制留在选择器；可经过友军、敌军与不可通行地格，但这些参数不豁免终点落脚条件。基线先查询目标再位移，位移成功后集合出伤，伤害后给存活对象附加状态；已有状态的处理按用户最新决定改为普通叠加，不保留基线刷新为1。新草案采用已批准的实际经过事实与遇阻停最后合法落点政策；反应导致路径变化时，不以旧预测路径造成额外伤害。若部分位移成功，伤害只覆盖实际经过敌军，属于统一位移政策的结果，实施须列回归。路径失败仅跳过此依赖分支，主动技能仍按默认成功结算，未擅自免除其费用。

死亡目标引用失效，状态判断、附加及其依赖的条件分支跳过，不生成状态或Rule。圣盾等阻挡伤害但目标仍在场时，仍施加定身；不以实际伤害量作为附加条件。攻击力在位移完成之后读取，保留基线读取时点。

## 定身使用普通叠加：已确认

用户先要求统一通用定身，再明确按普通叠加规则处理已有状态，覆盖旧chidori-immobile刷新为1的行为。每次均调用附加状态，不查询具体状态实例，不设置持续时间，不重建状态来规避叠加。新附加参数为强度1、持续时间1：持续时间相同则加强度，强度相同则加时间，两者相同则两者都加，两者都不同则保留独立实例；不增加千鸟专属叠加规则。定身Rule只看状态是否存在，强度增加不凭空增加限制种类。

已有定身时不再因本次叠加安装额外限制Rule；第一次附加时显式安装，不建立StatusTag与Rule的自动关联。前次状态已消失但旧Rule尚未清理的再次附加、同定义Rule重复安装策略须按公共接口统一，在实施时避免重复监听和日志；本草案不擅自宣布所有附加规则默认去重。状态的所属玩家回合结束计时和新附加本回合不计按公共约定实现。

本次属于用户明确批准的基线差异：千鸟专属状态/Rule改为通用定身，旧的刷新时间改为普通叠加。原专属状态名和限制提示也须在将来迁移时同步改为通用文案，不能宣称文字与旧版本完全一致。获取状态完整返回类型仍属一般未决接口，不因撤回本例刷新提议而视为获批。

当前未修改运行引擎、技能数据、UI或动画。待验证：穿过友敌及墙体、合法落脚、实际经过敌军、位移被阻止、圣盾挡伤害仍定身、击杀不加状态、同强度同时间叠加、与其他技能的定身叠加、不同参数形成独立状态、普通移动限制及所属玩家回合结束计时。仅执行文档格式检查，未运行游戏测试。
