# 黑棺：共享Rule与多任务完整作者草案

基线aizen-black-coffin：AP2、CP2、CD2、每局不限，灵压，敌军5，先普通伤害攻击×1.5，存活目标定身1，下一个目标所属玩家回合末再受创建时同量伤害。延迟量为创建时数值，不是实际扣血；小数由引擎自动向下取整。用户确认定身与延迟任务分开，数据放玩家extension，Rule天生去重，任务结构体与动态遍历已确认。这里只补作者草案，未修改运行代码。

## 完整作者代码

```text
类型【延迟伤害任务】 = {
    目标：棋子,
    来源：玩家,
    伤害量：数值,
    创建回合：数值

Cluster：黑棺
成员：黑棺主动Skill
引用Rule定义：黑棺延迟伤害、定身限制

技能：黑棺
触发器：使用技能
行动点消耗：2
充能点消耗：2
冷却：2
每局使用次数：不限

code：
    新建【棋子】变量【目标】 = 目标选择器(
        类型：棋子，范围：5，筛选条件：{关系：敌方}
    )
    如果 目标.攻击力 >= 当前棋子.攻击力：
        返回 技能释放失败
    新建【玩家】变量【伤害玩家】 = 当前棋子.所属玩家
    新建【数值】变量【数值】 = 当前棋子.攻击力 × 1.5
    造成伤害(目标：目标，类型：普通，伤害量：数值，伤害来源：当前棋子)

    新建【玩家】变量【玩家】 = 当前规则.挂载对象
    在【玩家.extension】中新建【元组<延迟伤害任务>】变量【黑棺任务】 = {}

        新建【集合<棋子>】变量【在场棋子】 = 目标选择器(
            类型：集合<棋子>，方式：自动，范围：全图，筛选条件：{}
        )
        如果 集合包含元素(集合：在场棋子，元素：任务.目标) == false：
            删除元组项(元组：玩家.extension.黑棺任务，元素：任务)
            继续下一次
        如果 当前回合.编号 <= 任务.创建回合：
            继续下一次

            继续下一次

        造成伤害(
            目标：任务.目标，类型：普通，
            伤害量：任务.伤害量，伤害来源：任务.来源
        )
```

## 运行语义与验收边界

任务及保存数值在创建时确定，来源/目标为实例引用，不向Rule传额外参数。延迟段从创建时就保存玩家来源，不要求原蓝染存活；首段仍是棋子造成的伤害。已撤回死亡来源自动回退；不得等到结算时再读取蓝染.所属玩家。首段目标已经失效时，新建任务中直接依赖目标的构造语句无效，后续依赖未产生任务的追加也跳过；初始资源/伤害已完成不倒回。共享玩家Rule存在但任务为空无伤害。实际失效引用构造与结构体字段的工程适配必须验证，不靠文档假设已经支持。

到期跟随目标当前所属玩家回合末，创建回合不计；目标死亡/离场的记录清理按实例身份与在场集合比较，不读失效棋子的属性，不产生额外伤害。该集合查询用于任务清理，不是技能里对伤害目标写存活fallback。目标若后来以原实例复活，已被清理的任务不会自动恢复。

到期记录在产生伤害前移出待处理队列，避免伤害反应再次进入该Rule时重复处理同任务；局部任务记录仍可用于本次伤害。其他任务保留，删除当前项后继续下一原项，伤害反应新增任务也继续检查，但创建回合判断使新任务仍不会提前结算。不能任务一完成就删除共享Rule；它继续处理后续追加任务。共享Rule的直接执行来源引用与玩家伤害归属分开；原蓝染即使存活，延迟段也不算其造成伤害或击杀。

定身StatusTag与延迟任务互不取消，驱散定身不删除延迟伤害，不创建额外黑棺状态或隐藏关联。原可见黑棺状态被撤去是此前用户指定变更，不能宣称UI/驱散与旧基线完全不变。各任务逐个造成伤害，不自动改成同时伤害。

元组删除需定位当前独立记录，一条同值任务完成不移除其他同值记录。动态游标、删除其他项、递归响应/挂起恢复的实现与执行预算尚未验证，不报告引擎完成或死循环问题已修复。共享Rule按每个玩家挂载对象去重，不跨玩家合并。
