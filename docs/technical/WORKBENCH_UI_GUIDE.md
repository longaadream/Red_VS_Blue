# 内容工作台：作者操作说明

新版开发者工作台的逐步操作说明位于 [编辑器内置用户手册](../../electron-editor/ui/developer-guide.html)，也可从左侧“使用说明”打开。本轮从空白创建、保存重开和真实训练营验证的结果单独记录；不能用历史迁移数量替代这条作者操作流程的验收。

## 开发者工作台新增约定（2026-10-14）

- 内部模块、参数、类型、枚举和诊断以中文说明；用户自行命名的变量保留原名。显示名称与稳定引用身份分离。
- 多字段对象按类型逐字段编辑，嵌套对象与容器继续使用相同规则。未填写、空值、空容器、0 和“否”互不等同；不以重新填默认值掩盖不兼容输入。
- “保存草稿”写入项目独立 `.author-drafts` 目录，保留未完成语句和未应用表达式；不覆盖有效内容，不参与资源包。正式保存仍要求作者图与编译产物有效，草稿与正式文件均有版本冲突检查。
- 内嵌训练营复用隔离的正式战斗页面与引擎。当前有效草稿经校验生成独立内容快照；“应用并重试”建立新战局，保持初始场景和随机种子，不热修改旧战局。
- 第一次用户动作之前的训练场景调整纳入重试初始场景；之后的临时调整只属于当前试玩。切换目录隐藏训练视图，关闭试玩释放视图和隔离资源。训练日志通过实际动作通知更新，不用重复轮询。
- 召唤模板与显示选项分别决定实际能力和看到的字段。默认召唤非核心棋子；省略显示字段不改变正常显示。分身没有实际技能时保留创建时显示技能；真实技能的冷却仍随其实际实例变化。视觉伪装不等于通信身份匿名化，本轮不改通信投影与持久化身份。

本文说明 RED-252 工作台的作者模型。目录重做的历史验证见 [UI 初版记录](../qa/RED-252-studio-v2/README.md)，兼容补全与最终验证见 [兼容补全记录](../qa/RED-252-studio-v2/authoring-completion.md)。语句本身的接口、类型与示例见 [语句手册](AUTHOR_STATEMENT_MANUAL.md) 和 [接口索引](AUTHOR_STATEMENT_REFERENCE.md)。手册中已经商定的接口，不等于当前运行引擎和编辑器已经全部实现。

工作台当前可调用的模块、完整输入输出、参数默认值、允许入口及副作用，见从实际注册表生成的[已实现接口目录](GAMEPLAY_MODULE_API.md)。它与设计讨论手册分开记录，避免把尚未落地的设计承诺显示成现有能力。

## 棋子、能力组与成员

### 局内说明与图标

主动技能的名称和说明沿用同一内容定义，不增加技能图标要求。规则可以选择项目素材库图片作为玩家规则图标；只有该规则实际授予玩家后，局内玩家状态栏才展示其名称、描述和图标。可见状态的图标同样从项目素材库选择，保存后由局内状态标签和详情消费。清除图片保留既有默认表现；引用不可用时保留原值并明确提示。

图标不是只存在于编辑器的预览值：保存的资源路径随内容进入资源包和训练快照，再保留到权威规则实例及显示模型。测试应覆盖编辑、保存、重开、打包、运行和真实图片加载，不能仅断言 HTML 中出现一个图片标签。变更描述或图标不改变规则效果、优先级与状态数值。

Rule 的可选 `visible` 字段表示“局内可见”。新建规则明确保存 false；旧定义未声明时保持原有玩家界面显示策略。true 使用定义自身的名称、说明和图标，false 隐藏规则显示，但不取消规则、不影响触发。无图标仍可使用默认表现；隐藏规则仍可编辑并保存描述和图标。

棋子是配置角色内容的入口。技能目录以 **Cluster（能力组）** 为组织单位：

| 成员 | 用途 |
| --- | --- |
| Skill | 主动技能的入口、消耗与效果。 |
| Rule | 监听事件并执行效果，可以独立构成被动能力。 |
| StatusTag | 棋子或其他内容使用的状态定义；可视状态可选择图标。 |
| Card | 该能力创建、修改或引用的卡牌内容。 |
| extension | 实际所属对象的扩展字段，用于保存作者声明的数据。 |

一个 Cluster 可以包含零个、一个或多个主动 Skill。不能因为没有主动 Skill，就把被动能力排除在技能目录之外。状态没有独立的顶层目录，应从使用它的能力组进入。

旧资源中少数被动入口仍存放在 `kind: passive` 的 Skill 文档，工作台将它们标为“被动入口（兼容）”，不误标为主动技能，也不暗中改写资源类型。新建被动能力使用 Rule；同组包含不同类别的历史 Skill 时，各成员分别显示真实类别。

Cluster 组织现有定义和引用，不是另一份运行状态。共同引用的 Rule 仍然是同一个定义；在编辑器中显示它，不会自动给棋子添加 Rule，也不会把 Rule 与某个 StatusTag 的生命周期绑定起来。跨文档修改必须保存到真正所属的文档。

能力组名称和说明独立保存于根文档的 `cluster.name`、`cluster.description`，不会改写根成员自身的名称和说明。首次编辑分组信息时会初始化版本、标识及空引用列表。构建器返回的 `metadata` 是可选视图信息，不是另一层必须写入的存储结构。

## 效果与表达式

### 句子与逐项填写

效果编辑的交互规范是完整中文句式，例如“对【目标】造成【伤害量】点【普通】伤害，来源为【当前棋子】”。点击哪一个蓝色参数，就只编辑该参数；不应为了修改伤害量而重新填写整条语句。数值位置允许由多个原子表达式组合。

填写顺序提供引导而不强制锁定。前置参数决定后续需要的参数、候选、格式和类型。例如先选择记录结构，才知道可选字段；选定字段后，写入值使用该字段的类型。先选择常量、已有输出或组合表达式，再显示对应的编辑控件。当前不相关的项不展示，修改前置项时保留兼容的已填内容，不兼容的内容保留在草稿并提示修正，不能静默替换为默认值。

以“写入扩展变量”为例，先确定所属对象和变量名称，再选择预期类型。选择“数值”后，值槽可以填写数字、引用数值输出或组合运算；改成“布尔”后，候选与编辑控件改为布尔值。如果原来已填数字，编辑器会保留并标明类型不兼容，等待作者修正。无需访问子字段时不必填写字段路径，需要时再补充。

修改伤害量时，只点击句中的伤害量参数，输入如 `当前棋子.攻击力 * 1.5` 的表达式，并通过光标旁联想插入变量、字段与函数。多字段结构既能逐字段填写，也能通过“输入表达式”直接引用前面保存的整个对象。目标、伤害类型和来源保持原值。嵌套内容可以折叠，长句和深层嵌套可以横向滚动。

这些句式是同一份类型化语句的显示方式，保存和执行仍使用原模块定义；不会把自然语言另行解析成一份不同的游戏逻辑。实现与具体操作验证见[本批交互记录](../qa/RED-252-atomic-authoring/README.md)。

效果区按执行顺序排列语句。先选取语句，再通过输入槽选择常量、上下文、已有输出或计算表达式。分支和循环在当前编辑区域内展开，不能要求作者为了完成常规效果而切换到流程图。

表达式允许嵌套。例如，一个数值输入可以由加法、乘法、属性读取和条件计算组合而成。局部变量和前序输出只能引用当前作用域内的值。extension 的候选列表只建议当前作用域已声明的变量，同时允许自定义指定对象、变量名称、字段路径与类型，即使该字段当前并未声明。随机、目标选择和会修改游戏状态的模块，应作为有顺序的语句执行，其返回值再供后续语句引用。

新增语句和表达式目录只提供通用原子操作与流程结构，不提供“回溯”“飞雷神触发目标”等专用模块，也不在高级选项中提供它们。已有资源的内部兼容适配器可以被读取和诊断，不能作为新内容的积木。复杂能力由原子操作组合，例如复制实例、声明/读写 extension、计数、位移、应用实例信息。

### extension 的选择与自定义访问

选择当前已有变量可以减少填写；需要访问其他入口创建的数据时，使用自定义访问。只填写访问位置和预期类型，不必先复制一份声明，也不会因此自动创建数据。变量、字段或所属对象不存在，以及值不符合类型时，该语句无效；依赖结果的语句跳过，独立后续继续。作者不需要再写存在性判断或 fallback。

例如，读取“当前玩家”的 `content.延迟任务.伤害量`，指定数值类型。运行时有该字段就取得数值；没有该字段就跳过依赖它的伤害语句，后面的独立日志或其他效果仍可执行。自定义字段路径使用点号分隔；元组第一项写 `列表.1`。读写不能通过缺失路径创建字段；需要创建数据时明确使用声明语句。

当前运行接口覆盖玩家、棋子和全局扩展变量，以及玩家扩展映射。其他实例类型的完整 extension 宿主支持仍须分别验证，不能由这个编辑入口推定已经全部实现。

类型、引用、extension、复杂表达式和结构声明都使用同一套编辑界面，不能把复杂配置转交给旧表单或流程图。诊断菜单中的旧格式、代码和完整数据仅用于检查兼容内容。无法结构化编辑的旧内容应明确提示能力边界，不能仅因为能显示源码就标记为已经完成可视化迁移。

### 长句与右侧配置

默认效果区显示中文句子，点击句中一个蓝色参数，在右侧修改这个参数。选中项变为实蓝色；关闭配置后回到原参数。其余句子的位置不会被插入的表单推开。移动、复制、删除等操作收在每行的“更多”菜单；变量、返回值和类型声明可按需打开，并使用同一配置区编辑。

当前棋子等纯引用，以及可安全内联的单次使用计算，可以直接在句中读成“当前棋子.攻击力 × 1.5”。这只是显示投影，原始语句和求值顺序仍保留。随机、选择、状态更改及需保存历史值的计算不应为了页面简短而被移动。

选择器的取消不能与编辑器关闭混为一谈：关闭参数配置只结束本次界面编辑，不改变游戏执行；新作者选择器收到取消时中止当前入口，旧续接选择还需查看“取消后继续”的配置。“返回上一步”“不选而继续”“取消整次释放”是不同动作，后续统一接口不能只用一个含糊的取消开关代替。

### 结构语句与数据声明

| 语句或声明 | 用途与例子 |
| --- | --- |
| 记录结构 | 声明字段名称和类型，例如一份延迟效果记录包含“伤害量：数值”和“释放者：棋子引用”。字段只能按声明类型连接。 |
| 创建记录 | 把当前伤害量与释放者的输出装入同一份记录，供后续模块或续接使用。 |
| 读取记录字段 | 从前序记录选择“伤害量”，将它连接到造成伤害的数值输入。无需输入对象路径。 |
| 更新记录字段 | 产生修改后的记录，例如保留释放者并替换伤害量；后续语句应引用更新后的输出。 |
| 映射 | 对元组里的每一项执行子语句并返回一个值。例如把棋子元组变成距离元组。 |
| 筛选 | 对每一项返回布尔值，只保留满足条件的项。例如保留仍在场的棋子。 |
| 汇总 | 声明初始值，每次把本项和累计值交给子语句，返回新的累计值。例如累计数值元组的总量。 |
| 遍历 | 按顺序对每项执行效果。例如对选出的每名棋子施加同一种状态。 |
| 条件循环 | 声明条件子语句、循环体和次数上限。条件不成立或预算耗尽就离开循环。 |
| 组合模块 | 声明输入、输出及参数，把多条语句整理为可复用模块；使用“进入组合”在同一个效果区修改内部语句。 |
| 选择后续接 | 声明续接流程与载荷类型，在选择语句中连接载荷；玩家完成选择后运行对应续接。使用“进入续接”编辑内部效果。 |
| 返回 | 按当前入口或组合的输出声明填写返回值，并结束当前流程。它与一个模块执行失败后跳过语句不同。 |

声明区可编辑输入输出、记录字段及组合和续接定义。常量控件支持嵌套记录、可空值与有序列表；列表表示元组语义，允许重复且保留顺序，不等同于去重集合。模块目录的搜索不截断为前几十项，仍按入口权限与输入类型筛选。

内容同时有执行和预览入口时，应分别编辑对应入口。预览受独立的副作用校验约束，不允许通过预览修改战斗状态。编写过程中可以暂存不完整的语句、字段或引用，错误留在当前草稿中显示；修好所有入口与说明关联后才能保存。一个入口暂时有错误，不应阻止继续修复另一个入口。

### 运行失败与等待

新版编译器为语句设置错误边界。普通语句错误会记录模块、语句及可用的内容、玩家、回合、阶段、随机种子和行动链上下文，将失败输出标为无效，再继续独立后续语句。引用该无效输出的语句跳过；已经完成的效果不会因后续语句失败而自动重放。

嵌套循环共享运行预算，避免每一层单独合法却组合成巨量循环。预算耗尽后离开循环，部分集合结果失效，独立后续仍可执行。单次执行诊断有数量上限并记录抑制摘要，避免错误循环刷满日志。

玩家尚未完成选择是正常等待，不能按普通错误跳过。事务回滚、致命错误及回放不一致也保留原有控制信号，由权威引擎处理。编辑器的无效定义会在保存前拒绝，不会为了“继续运行”而放行未通过校验的代码。

## 保存与资源包

### 说明文字与效果参数

在成员效果区展开“说明文字 · 关联效果参数”，可以编辑内容说明和目标提示。选择一个实际参数，点击“插入参数”，该位置会成为与效果共用的占位值。例如选择目标模块的范围为 5，说明模板“选择范围：{{value1}}”显示为“选择范围：5”；把同一个模块的范围改成 6 后，说明同步变为“选择范围：6”。

文字编辑直接加入当前文档草稿，使用顶部保存即可。无需另存一份说明配置。“检查说明”用于检查关联是否有效；删除了被引用的语句或留下没有绑定的占位值时会显示错误，保存和打包也会拒绝该无效文档。修复关联后可以继续保存，未涉及的字段保留。

可关联的是编辑时已确定的数值、文本或布尔值，包括声明输入、模块参数和直接输入的常量。运行时才知道的目标生命值、伤害结果等不能伪装成固定说明数值。已有文字不会被猜测性改写，未建立关联的文字仍是普通静态说明。

编辑器显示草稿与保存状态。成员可能来自不同文档，因此打包前需要处理所有未保存草稿，不能默默使用旧文件生成资源包。

资源包操作分为内容检查、包信息设置、生成和查看结果。生成成功必须以实际输出文件和管线结果为准；生成本地 `.rvbpack` 不代表上传或发布。素材预览、状态图标和打包都使用工作区中的实际资源。

顶部“保存全部”会保存当前工作区中已修改的文档，包括从能力组内修改的其他所属文档。所有草稿先校验，再逐个进行版本检查和写入；这不是跨文件原子事务。如果后面的文件发生版本冲突，已经保存的文件不会回滚，剩余草稿继续保留并提示失败。

## 初版操作入口

| 要做的事 | 操作 |
| --- | --- |
| 新建主动或被动能力组 | 能力组 → 新建 → 选择“主动技能 · Skill”或“被动规则 · Rule”。 |
| 编辑已有成员 | 打开能力组，选择主动技能、规则、状态、卡牌或扩展标签；在同一页面编辑。 |
| 查看共享定义的位置 | 成员编辑区 → 定义来源 → 打开所属文档。 |
| 配置可视状态图标 | 能力组 → 状态 → 选择状态 → 图标资源。素材来自当前工作区。 |
| 修改 extension | 扩展 → 选择所属对象 → 增加字段，选择类型；对象和列表可继续添加子项。 |
| 组合计算 | 点击语句输入槽 → 新建表达式 → 选择兼容模块 → 继续组合它的输入。 |
| 编辑预览或续接入口 | 效果区的“编辑内容”直接切换执行、预览及已有续接入口，各入口保留独立草稿；全部有效后才能保存。 |
| 调整控制结构 | 添加条件、遍历或循环，在对应分支内部插入语句；可移动、复制或删除。 |
| 打包 | 保存全部 → 资源包 → 内容 → 设置 → 生成 → 查看结果和输出位置。 |

普通对局的语义覆盖与操作证据以兼容补全记录为准；冒险专用内容及设计手册中尚未落地的新玩法不计入这次普通对局迁移。表达式只允许纯计算，有副作用的操作作为有执行顺序的语句添加。技能试用现在打开工作台内嵌训练营，使用正式战斗引擎；修改后通过“应用并重试”重建同场景、同种子的战局。

### 组合多层表达式

每个输入槽都能继续使用子表达式。一次乘法虽然有两个输入，但这两个输入都能是完整的计算结果，因此不会限制为一层 `a × b`。例如：`（当前棋子.攻击力 × 1.5 + 10）×（状态强度 + 1）`。

点击伤害量，直接输入 `(当前棋子.攻击力 * 1.5 + 10) * (强度 + 1)`，其中“强度”是前面已声明的数值变量。编辑器校验类型和作用范围，保存原表达式及其原子计算节点；再次修改会替换这一参数自己的计算节点，不堆积旧节点。保存并重新打开后仍可按字符编辑。结构字段使用同样的表达式入口，内置字段显示中文名，实际存储仍保持稳定字段身份。

验收也应打开影分身的选项记录、回溯的实例记录和飞雷神的条件分支。它们分别覆盖多选项、不同类型字段、嵌套条件及来源引用，不能用一个简单伤害公式代替全部作者能力的验证。

## 检查一项修改

1. 在效果区修改一个数值或引用，确认说明与输入槽反映当前草稿。
2. 保存，离开再重新打开，确认修改仍然存在。
3. 对涉及多个成员的能力，检查每个受影响成员的保存状态。
4. 用训练窗口检查已有试用入口能够覆盖的行为；界面预览不能代替规则回归测试。
5. 生成资源包并查看输出结果，再使用该包进行游戏验证。
