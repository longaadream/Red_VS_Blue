# 破坏本能作者核对草案

基线grimmjow-destruction-instinct与rule-grimmjow-destruction-instinct。被动Skill只负责展示，不是可点击主动入口；Cluster包含对应Rule。实际正伤害事件由引擎过滤，不重复写伤害量>0。当前只更新作者文档。

基线每次格里姆乔实际造成伤害后，自身受到1点真实伤害。排除破坏本能自身产生的伤害，原实现通过context.skillId=grimmjow-destruction-instinct区分，并将自伤送入damageQueue，不能仅以伤害目标等于自身排除所有其他自伤。

## 当前模块代码核查

当前工作树已将此Rule生成为模块代码，但防递归仍沿用context.skillId的字符串比较。自伤请求通过context.damageQueue.push显式写入skillId: grimmjow-destruction-instinct；引擎在队列和后续afterDamageDealt事件中保留该字段。因此现有实现没有自动的Skill/Rule实例执行来源引用。队列/事件派发通用，具体标记和过滤位于内容Rule，不是引擎专门判断格里姆乔。此为静态核查，未运行游戏验证。

## 已确认接口：伤害执行来源实例

伤害来源表示归属棋子/玩家/具体卡牌实例，无法区分同一棋子的主动伤害与破坏本能自伤。用户确认引擎在伤害事件自动提供只读当前事件.执行来源，类型为Skill实例或Rule实例（系统直接效果可无入口）。它表示直接调用造成伤害的入口，不是最外层最初Skill；某反应Rule追加伤害应记该Rule。无需给每次造成伤害手动加文本标记。

```text
Cluster：破坏本能
成员：破坏本能被动Skill、破坏本能Rule

Rule：破坏本能
触发器：当前棋子.造成伤害后

code：
    如果 当前事件.执行来源.定义引用 == 当前规则.定义引用：
        结束
    造成伤害(
        目标：当前棋子，类型：真实，
        伤害量：1，伤害来源：当前棋子
    )
```

执行来源实例字段已获用户确认，尚未修改运行接口。字段本身保存Skill/Rule实例，可直接比较实例身份；本例进一步读取双方定义引用排除同定义各实例。比较类型化定义引用，不用字符串skillId。按Rule定义排除本能的同定义各实例，不仅排除当前规则的单个实例，避免未来同棋子重复获得该Rule导致互相触发。拥有者不同仍由当前棋子触发范围过滤；来源棋子死亡则新的伤害语句失效；显式玩家来源也不能让已死亡格里姆乔行动。

本例不用全局/棋子extension的临时布尔开关防重入，因为原自伤排队，布尔恢复时点未必覆盖队列伤害结算；不能在没有调度证明时把它当等价。也不使用状态标记来源来代替执行入口，StatusTag可选来源与此事件事实是不同含义。

被挡伤害不派发造成伤害后，无实际伤害不触发。自伤仍走真实伤害正常管线，可触发其他合法Rule，只有本能跳过自身伤害，不能全局关闭自伤事件。原damageQueue与作者造成伤害的子事件顺序在实施时按公共调度对齐，不悄悄改为先于同阶段其他Rule立刻伤害。

验证待办：正常攻击触发一次自伤、每个独立伤害结果触发、被挡不触发、自伤不递归、其他技能自伤仍触发、同定义Rule多实例、反应伤害直接执行入口、队列调度与原顺序、其他受伤Rule仍触发、自伤致死后状态清理与归刃。本轮仍只补作者代码，不修改运行实现，无游戏测试。
