# 月牙天冲作者代码

基线ichigo-getsuga-tensho，采用已确认正方向选择、射线阻挡、独立排序与元组索引。设计草案，尚未实施。未命中不属于释放失败；沿用失效目标使依赖语句跳过的引擎规则。

```text
技能：月牙天冲
触发器：使用技能
行动点消耗：2
充能点消耗：0
冷却：2
每局使用次数：不限

code：
    新建【方向】变量【方向】 = 目标选择器(
        类型：方向，中心：当前棋子.位置，方向范围：正方向
    )

    新建【元组<棋子>】变量【敌军】 = 目标选择器(
        类型：元组<棋子>，方式：自动，
        中心：当前棋子.位置，方向：方向，形状：射线，范围：全图，
        筛选条件：{关系：敌方}，
        阻挡条件：{友军：true，敌军：false，阻挡弹射物地形：true}
    )

    新建【元组<棋子>】变量【有序敌军】 = 排序(
        容器：敌军，依据：(棋子) => 距离(棋子, 当前棋子)，顺序：升序
    )

    新建【棋子】变量【目标】 = 有序敌军[1]

    造成伤害(
        目标：目标，类型：普通，
        伤害量：当前棋子.攻击力 × 1.5，伤害来源：当前棋子
    )
```

射线查询排除起点的释放者，从其相邻格开始。友军仍参与阻挡，不因敌方候选筛选而被忽略。只查询方向目标，不移动棋子。首个目标、地形阻挡/友军阻挡/未命中的区别须由公共查询结果与执行日志保留；不把本草案简化成只显示泛化未命中信息，不宣称动画与日志已验证。

容器规范更新：此前按列表使用的目标查询、排序和洗牌均使用元组（vector）；不隐式去重。用户已确认元组下标从1开始，代码[1]表示第一项。
