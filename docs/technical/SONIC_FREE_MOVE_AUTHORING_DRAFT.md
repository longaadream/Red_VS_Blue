# 音速：本玩家回合开始刷新一次免费移动

基线`082166c6b803b2e838bce5f0f6824c5bbc714dd6`，已核对sonic-free-move-passive和rule-sonic-free-move。被动，无主动费用、冷却或每局使用次数。仅作者草案。

```text
StatusTag：部署首次免费移动
可见：true
允许叠加：false

Cluster：音速
初始化声明区：
    附加规则(挂载对象：当前棋子，规则：每回合首次移动免费)
    附加规则(挂载对象：当前棋子，规则：首次免费移动费用)
    附加规则(挂载对象：当前棋子，规则：首次免费移动消费)
    附加规则(挂载对象：当前棋子，规则：首次免费移动回合清理)

Rule：每回合首次移动免费
挂载对象：棋子
触发器：本玩家.回合开始

    新建【元组<StatusTag>】变量【状态们】 = 获取状态(目标：当前棋子，类型：部署首次免费移动)

    否则：
        附加状态(目标：当前棋子，类型：部署首次免费移动，强度：1，持续时间：永久)
```

与基线共用部署首次免费移动状态，不新增音速专属次数。已有资格刷新为1，不能叠成2次；无状态直接附加。状态不填来源，持有不同被动来源不会产生独立免费次数。Rule同宿主同定义去重，高速护甲也应复用同一刷新/费用/消费Rule。护甲获得时的主动效果与长期模块配置在护甲正文另行定义。

本玩家按所属玩家判断，不因同阵营队友回合开始刷新。获得Cluster只部署，下一次本玩家回合开始才赠送，不把获得当作回合开始。被动Skill不重复注册同一触发器。移除Cluster专属成员与共享依赖继续沿Cluster合同，不可删除其他来源仍需要的Rule。

开始移动前锁定费用，再在首次普通移动提交消费；取消、零步、被拦截未开始不消费，实际开始后中断不退款。移动途中获得的新资格不会在移动后被重新查找消费。冲刺/传送不消费本资格。强度0自然耗尽，回合结束显式清理包含当回合新状态。

与迅捷同在时，沿已记录的迅捷规则：一次实际普通移动会各消费一份，并非引擎自动挑一个免费来源。本文没有创建额外费用来源仲裁接口。如以后改为只消耗一个减免来源，应统一调整所有相关消费Rule。
