# 猗窝座伤害记录、乱式与瞬步

作者草案，未实施。采用用户确认的只读当前回合上下文、玩家extension、泛型映射、实例身份、选择器、筛选、位移与伤害模块，不创建伤害记录专用状态。

## 玩家extension数据

先声明 `伤害历史：映射<棋子,映射<棋子,数值>>` 并初始化为空映射：外层键为造成伤害的猗窝座实例，内层键为受伤实例，值为最后实际伤害回合号。死亡或出局身份不会被同名新棋子冒用。

用户已确认持久字段同名同类型重复声明复用已有值、不重新初始化，类型不一致报错。以下Rule和主动技能均显式声明字段，首次初始化，后续保留整局历史；不由引擎预留未声明变量。

## 公共记录Rule

```text
Rule：猗窝座伤害记录
触发器：全场.造成伤害后

code：
    如果 当前事件.伤害来源 != 来源：
        结束
    如果 当前事件.目标.阵营 == 来源.阵营：
        结束

    在【来源.所属玩家.extension】中新建【映射<棋子,映射<棋子,数值>>】变量【伤害历史】 = {}

    如果 当前事件.目标.当前生命值 > 0：
        如果 映射包含键(映射：来源.所属玩家.extension.伤害历史，键：来源) == false：
            来源.所属玩家.extension.伤害历史[来源] = {}

        来源.所属玩家.extension.伤害历史[来源][当前事件.目标] = 当前回合.编号
```

本记录只对引擎确认的实际正伤害事件生效，不在Rule重复写非正伤害检查。基线标记仅对结算后仍在场的目标保存；失效目标读取阵营/记录语句由统一失效机制处理。技能的整局记忆不因标记不可见而变成可驱散状态。

## 破坏杀·乱式

```text
技能：破坏杀·乱式
触发器：使用技能
行动点消耗：1
充能点消耗：0
冷却：1
每局使用次数：不限

code：
    在【当前棋子.所属玩家.extension】中新建【映射<棋子,映射<棋子,数值>>】变量【伤害历史】 = {}

    新建【棋子】变量【目标】 = 目标选择器(
        类型：棋子，范围：1，筛选条件：{关系：敌方}
    )
    新建【数值】变量【倍率】 = 1

    如果 映射包含键(映射：当前棋子.所属玩家.extension.伤害历史，键：当前棋子)：
        如果 映射包含键(映射：当前棋子.所属玩家.extension.伤害历史[当前棋子]，键：目标)：
            如果 当前棋子.所属玩家.extension.伤害历史[当前棋子][目标] == 当前回合.编号：
                倍率 = 1.5

    造成伤害(
        目标：目标，类型：普通，
        伤害量：当前棋子.攻击力 × 倍率，伤害来源：当前棋子
    )
```

## 猗窝座·瞬步

```text
技能：瞬步
触发器：使用技能
行动点消耗：0
充能点消耗：0
冷却：3
每局使用次数：不限

code：
    在【当前棋子.所属玩家.extension】中新建【映射<棋子,映射<棋子,数值>>】变量【伤害历史】 = {}

    新建【元组<棋子>】变量【候选】 = 目标选择器(
        类型：元组<棋子>，方式：自动，
        中心：当前棋子.位置，形状：正方形，边长：7，
        筛选条件：{关系：敌方}
    )
    新建【元组<棋子>】变量【已伤害敌军】 = {}

    如果 映射包含键(映射：当前棋子.所属玩家.extension.伤害历史，键：当前棋子)：
        已伤害敌军 = 筛选(
            容器：候选，
            条件：(棋子) => 映射包含键(
                映射：当前棋子.所属玩家.extension.伤害历史[当前棋子]，键：棋子
            )
        )

    如果 获取长度(容器：已伤害敌军) == 0：
        返回 构造行动结果(成功：false，提示：范围内没有本局曾被自身伤害的敌军)

    新建【棋子】变量【目标】 = 目标选择器(
        类型：棋子，候选集合：已伤害敌军
    )
    新建【地格】变量【落点】 = 目标选择器(
        类型：地格，中心：目标.位置，范围：{最小：1，最大：1}，
        筛选条件：{可行走：true，被占用：false}
    )
    新建【位移结果】变量【结果】 = 位移(
        棋子：当前棋子，起点：当前棋子.位置，终点：落点，
        敌军可通过性：false，友军可通过性：false，
        不可通行地格可通过性：false，中间地格是否经过：false
    )

    如果 结果.发生位移：
        当前棋子.攻击力 = 当前棋子.攻击力 + 1
```

失败返回用于前置复杂条件，不消耗资源。落点选择与位移经过统一准备/合法性验证；接触后释放者失效时属性语句不生效。最新约定区分指令成功与实际发生位移；本技能奖励仍要求实际移动，因此改判断结果.发生位移，不能因合法原地指令成功而获得攻击奖励。已完成作者条件对齐，权威提交及接触反应仍须实施验证。
