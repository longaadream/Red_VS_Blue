# 豹王之爪作者代码

基线origin/main:grimmjow-panther-claw，归刃后获得的附加Skill，不计入140个初始Skill定义。AP2、CP0、CD2、每局不限。此文为完整作者草案，未修改引擎/数据/UI。

Cluster包含豹王之爪主动Skill。灵压是通用攻击力比较条件，本例按已确认复杂条件在主动code中前置返回失败，不需要在引擎识别豹王之爪或灵压字符串。规则实现效果与旧targetValidation相同，不将这种内容约束升级为引擎专属功能。

```text
技能：豹王之爪
触发器：使用技能
行动点消耗：2
充能点消耗：0
冷却：2
每局使用次数：不限

code：
    如果 获取长度(容器：获取状态(目标：当前棋子，类型：归刃)) == 0：
        返回 构造行动结果(成功：false，提示：尚未归刃)

    新建【棋子】变量【目标】 = 目标选择器(
        类型：棋子，范围：4，筛选条件：{关系：敌方}
    )
    如果 目标.攻击力 >= 当前棋子.攻击力：
        返回 构造行动结果(成功：false，提示：目标攻击力必须低于施法者)

    新建【数值】变量【次数】 = 0
    当【次数 < 5】成立时循环：
        如果 当前棋子.当前生命值 <= 0 或 目标.当前生命值 <= 0：
            结束
        造成伤害(
            目标：目标，类型：普通，
            伤害量：当前棋子.攻击力 × 0.75，伤害来源：当前棋子
        )
        次数 = 次数 + 1
```

归刃存在与灵压检查都在效果提交前，失败提示不支付AP/CP、不进入冷却、不产生任何一段伤害。选择与使用准备由公共流程处理；初始目标合法性与复杂条件均由权威引擎复核，不靠UI自行判定。归刃驱散后不能凭按钮缓存发动。没有新增普通攻击概念。

五段逐次结算，每段重新读取当前攻击力；小数效果由引擎向下取整，不在技能显式floor。首段击杀则结束，未击杀继续；被挡的一段无伤害后事件，但不自动结束后续段。仅首段前验证灵压，后续反应改变双方攻击不擅自重新拒绝已提交技能。目标移动但仍存活时仍引用同一目标，不每段重选或重新验证原范围。

各段伤害均可能触发破坏本能的1真实自伤；公共调度在下一段执行前完成该段及其反应，自身致死后停止。即时技能释放者失效后，后续以其为来源的伤害语句无效；独立延迟效果须预先显式保存玩家来源，不存在死亡来源自动回退。已产生效果后结束仍是正常成功，不返回失败去回滚已经发生的伤害/支付。

原消息累计命中段数与实际伤害总量。作者没有为日志另算一套规则：实际伤害由伤害结果/权威事件汇总，执行次数与真实提交段数对应；自动日志描述及UI格式适配留实施检查。每段实际伤害不等于固定未取整攻击倍率。
