# 黑色月牙天冲作者代码

卍解获得的额外Cluster：主动Skill与传送Rule一起获得/移除。基线ichigo-black-getsuga-tensho及rule-ichigo-black-getsuga-teleport。设计草案，未实施；用现有已确认接口表达，不新增传送时机参数。

```text
技能：黑色月牙天冲
触发器：使用技能
行动点消耗：2
充能点消耗：0
冷却：2
每局使用次数：不限

code：
    在【当前棋子.所属玩家.extension】中新建【映射<棋子,元组<地格>>】变量【黑色月牙落点】 = {}
    删除映射项(映射：当前棋子.所属玩家.extension.黑色月牙落点，键：当前棋子)

    新建【方向】变量【方向】 = 目标选择器(
        类型：方向，中心：当前棋子.位置，方向范围：正方向
    )
    新建【元组<棋子>】变量【敌军】 = 目标选择器(
        类型：元组<棋子>，方式：自动，
        中心：当前棋子.位置，方向：方向，形状：射线，范围：全图，
        筛选条件：{关系：敌方}，
        阻挡条件：{友军：true，敌军：false，阻挡弹射物地形：true}
    )
    新建【元组<棋子>】变量【有序敌军】 = 排序(
        容器：敌军，依据：(棋子) => 距离(棋子, 当前棋子)，顺序：升序
    )
    新建【地格】变量【首个位置】 = 有序敌军[1].位置

    造成伤害(
        目标：敌军，类型：普通，
        伤害量：当前棋子.攻击力 × 2，伤害来源：当前棋子
    )

    新建【元组<地格>】变量【候选落点】 = 目标选择器(
        类型：元组<地格>，方式：自动，
        中心：首个位置，范围：{最小：1，最大：1}，
        筛选条件：{可行走：true，被占用：false}
    )
    如果 获取长度(容器：候选落点) > 0：
        当前棋子.所属玩家.extension.黑色月牙落点[当前棋子] = 候选落点
```

```text
Rule：黑色月牙天冲·传送
触发器：全场.使用技能后

code：
    如果 当前事件.棋子 != 来源：
        结束
    如果 当前事件.技能.定义引用 != 黑色月牙天冲：
        结束

    新建【玩家】变量【玩家】 = 来源.所属玩家
    如果 映射包含键(映射：玩家.extension.黑色月牙落点，键：来源) == false：
        结束

    新建【元组<地格>】变量【候选落点】 = 玩家.extension.黑色月牙落点[来源]
    新建【地格】变量【落点】 = 目标选择器(
        类型：地格，候选集合：候选落点，
        筛选条件：{可行走：true，被占用：false}，允许取消：true
    )

    位移(
        棋子：来源，起点：来源.位置，终点：落点，
        敌军可通过性：false，友军可通过性：false，
        不可通行地格可通过性：false，中间地格是否经过：false
    )
    删除映射项(映射：玩家.extension.黑色月牙落点，键：来源)
```

持久字段重复声明同类型保留旧值；本技能只显式删除本释放者键，不清空整个映射。首个敌军位置在伤害前取值，即使目标死亡仍能查询历史位置四邻格。候选列表在伤害后形成，实际选择/位移仍复核合法性。没有敌军时首个位置无效，依赖它的候选准备不生效，不创造传送机会。
