# 骑射横扫：路径伤害、冲刺与可选侧射

固定基线`082166c6b803b2e838bce5f0f6824c5bbc714dd6`，已核对shadow-ride-sweep与rule-momentum-consume。正文复用地格选择、相对坐标范围、方向值、逐项查询/伤害、位移及共享动能，不增加专属模块。AP1/CP0/CD1/每局不限。

## 完整作者正文

```text
Cluster：骑射横扫
初始化声明区：
    展开动能公共依赖初始化语句
    加入集合(集合：当前棋子.extension.消费动能技能，元素：本Cluster.骑射横扫)
    加入集合(集合：当前棋子.extension.更新动能技能，元素：本Cluster.骑射横扫)

行动点消耗：1
充能点消耗：0

每局使用次数：不限

    新建【地格】变量【终点】 = 目标选择器(
        类型：地格，范围：7，筛选条件：{
            可行走：true，被占用：false，与当前棋子同行或同列：true
        }
    )
    新建【地格】变量【起点】 = 当前棋子.位置
    新建【数值】变量【原动能】 = 当前棋子.extension.动能

    新建【数值】变量【dy】 = (终点.y - 起点.y) / 步数
    新建【方向】变量【冲刺方向】 =
        如果 dx == 1 则 右 否则 如果 dx == -1 则 左 否则 如果 dy == 1 则 下 否则 上
    新建【路径查询结果】变量【预测路径】 = 查询路径(
        棋子：当前棋子，起点：起点，方向：冲刺方向，范围：步数，
        友军可通过性：true，敌军可通过性：true，不可通行地格可通过性：false
    )
    遍历【预测路径.经过地格】中的每一项【地格】：
        新建【元组<棋子>】变量【敌军】 = 目标选择器(
            类型：元组<棋子>，方式：自动，中心：地格，范围：0，最小距离：0，
            筛选条件：{关系：敌方}
        )
        遍历【敌军】中的每一项【敌人】：
            造成伤害(目标：敌人，类型：普通，
                伤害量：当前棋子.攻击力 + 加成，伤害来源：当前棋子)

    新建【布尔】变量【保留动能】 = 获取长度(容器：获取状态(目标：当前棋子，类型：保留动能)) > 0
    新建【位移结果】变量【结果】 = 位移(
        棋子：当前棋子，起点：起点，终点：预测路径.最后合法落点，
        友军可通过性：true，敌军可通过性：true，
        不可通行地格可通过性：false，中间地格是否经过：true

        新建【数值】变量【本次动能】 = 获取长度(容器：结果.经过地格)
        当前棋子.extension.动能 = 如果 保留动能 则 原动能 + 本次动能 否则 本次动能

                如果 所选侧格.x > 终点.x 则 右

                否则 如果 所选侧格.y > 终点.y 则 下 否则 上

                    阻挡条件：{友军：false，敌军：false，阻挡弹道地形：true}

                )
                遍历【由近到远】中的每一项【敌人】：
                    造成伤害(目标：敌人，类型：普通，伤害量：5 + 加成，伤害来源：当前棋子)
```

初始化的展开记法对应[共享动能](SONIC_MOMENTUM_AUTHORING_DRAFT.md)中现有普通语句，不是新模块。dx/dy只会是-1、0、1，同行/同列非自身目标避免除0；方向计算由普通比较和条件表达式组合。相对坐标使用现有地图坐标系，x右为正、y下为正。左右候选仅排除地图外格子，不要求可行走或未占用，选它是决定方向，不会移动到它。

## 顺序与基线取舍

路径普通伤害在位移前逐格、逐目标发生，每击读取当时攻击力；反伤/击杀/位置变化可能影响后续执行。这里不能改成先移动再按实际路径批量伤害。位移后只用实际经过格数计算动能，路径伤害与侧射起点仍保留基线预测路径记录。反应中实际移动变短，不反过来撤销已发生的路径伤害，也不悄悄把侧射改为仅实际路径。

动能范围阈值与+2在施放时记录，保留标记在位移前记录，保持基线读取顺序。合法位移失败不更新动能，但仍可进入已获得的侧射机会，匹配基线提前设置侧射任务、使用后响应仍能侧射的流程；失效棋子的伤害仍按无效引用规则跳过。成功后更新动能，公共使用后消费Rule不再次清空。取消侧射只跳过射击，不退款、不撤销路径伤害、位移或动能更新。

原基线对途中墙/洞直接返回释放失败；用户后续已明确位移一律停在最后合法落点，因此不保留该路径前置拒绝。地形只用walkable通行布尔，不重加floor/cover白名单；初选仍要求可行走空地。此处是已批准政策覆盖旧代码，不声称逐项与旧行为相同。

侧射候选中心保持原选择终点，与固定基线left/right一致；从预测路径每个格子分别射出，不是只从终点射一条。侧射逐条、每条由近到远结算；不同射线间若敌人因反应换位置，后续射线重新查询，可再次命中。不增加整次技能去重Set。伤害规则更改阵营/位置的细节依查询快照与实例有效性处理。

侧射选择在冲刺之后，恢复从该选择点继续；之前的伤害和动能更新不得重放。无侧格直接结束侧射，取消返回无效引用时侧射方向及依赖它的查询失效，不误用最后一个else得到上方向。仍只派发一次使用技能后。
