# 飞段：血誓仪式与狂信者献祭

基线：`082166c6b803b2e838bce5f0f6824c5bbc714dd6`。本文件按用户最新确认替代批次04的目标数量待定段：搜索所有符合条件的血誓目标，每个都造成伤害；不再只取第一个。仅作者规范，未修改运行引擎。

## 血誓仪式

```text
Skill：血誓仪式
触发器：使用技能
行动点消耗：0
充能点消耗：0
冷却：3
每局使用次数：不限
code：
    新建【棋子】变量【目标】 = 目标选择器(
        类型：棋子，范围：4，筛选条件：{关系：敌方}
    )
    如果 获取长度(容器：获取状态(目标：目标，类型：血誓诅咒)) > 0：
        返回 使用失败("目标已处于血誓诅咒中")
    新建【StatusTag】变量【血誓】 = 附加状态(
        目标：目标，类型：血誓诅咒，强度：1，持续时间：3，可见：true
    )
    在【血誓.extension】中新建【棋子】变量【施法者】 = 当前棋子
    附加规则(挂载对象：当前棋子，规则：血誓共同受伤)

Rule：血誓共同受伤
触发器：当前棋子.受到伤害前
上下文：挂载棋子
优先级：200
code：
    新建【棋子】变量【释放者】 = 当前棋子
    新建【数值】变量【共同伤害量】 = 当前事件.伤害量
    新建【元组<棋子>】变量【敌人们】 = 目标选择器(
        类型：元组<棋子>，方式：自动，范围：全图，筛选条件：{关系：敌方}
    )
    对每个 敌人 属于 敌人们：
        新建【元组<StatusTag>】变量【匹配血誓】 = 筛选(
            容器：获取状态(目标：敌人，类型：血誓诅咒)，
            条件：(状态) => 状态.extension.施法者 == 释放者
        )
        如果 获取长度(容器：匹配血誓) > 0：
            造成伤害(目标：敌人，类型：真实，伤害量：共同伤害量，伤害来源：释放者)
```

每个敌人只执行一次伤害，不按匹配状态条数重复出伤。敌人查询按稳定战场顺序逐个处理；不会把同一玩家的其他飞段绑定也混进来。后续实例失效时相关语句自动跳过，不补另一个目标，不阻止遍历其他仍有效的敌人。遍历时重新读取该敌人的状态；之前反应已移除其血誓，则不再受本次共同伤害。过程中新增棋子不进入本次查询快照。

共同伤害取本Rule进入时的伤害前事件量，并在遍历前保存，避免嵌套伤害事件改变读值。它是追加给被诅咒目标的真实伤害，不是反弹给攻击者，也不阻止或改写飞段原伤害的承受者。原伤害之后被濒死免疫或圣盾阻止，不撤销已经发生的共同伤害。非正伤害由引擎停止，无需作者再写判断；目标自身防御Rule可阻止这份真实伤害。

优先级200保留基线，高于濒死免疫的100；免疫Rule只负责飞段自身免伤，不查询血誓、不再追加第二份。Rule按宿主+定义去重；暂时没有血誓目标时自然无效果，不删除Rule。血誓绑定使用状态extension中显式声明的棋子实例引用；不强制使用通用来源字段，也不按字符串、角色名称或玩家身份代替实例。

## 狂信者献祭

```text
Skill：狂信者献祭
触发器：使用技能
行动点消耗：2
充能点消耗：0
冷却：0
每局使用次数：不限
code：
    新建【棋子】变量【释放者】 = 当前棋子
    新建【数值】变量【施放前已损生命】 = 当前棋子.最大生命值 - 当前棋子.当前生命值
    造成伤害(目标：当前棋子，类型：真实，伤害量：4，伤害来源：释放者)
    如果 施放前已损生命 < 3：
        结束
    新建【数值】变量【额外伤害量】 = 施放前已损生命 / 3
    新建【元组<棋子>】变量【敌人们】 = 目标选择器(
        类型：元组<棋子>，方式：自动，范围：全图，筛选条件：{关系：敌方}
    )
    对每个 敌人 属于 敌人们：
        新建【元组<StatusTag>】变量【匹配血誓】 = 筛选(
            容器：获取状态(目标：敌人，类型：血誓诅咒)，
            条件：(状态) => 状态.extension.施法者 == 释放者
        )
        如果 获取长度(容器：匹配血誓) > 0：
            造成伤害(目标：敌人，类型：真实，伤害量：额外伤害量，伤害来源：释放者)
```

4点自伤走正常伤害模块，其共同受伤由独立血誓Rule触发；技能正文只另加施放前已损生命/3，不再次把4加上。全部自己的有效血誓目标都收到额外部分；自伤后重新查询，不能拿自伤前目标列表冒充仍然有效。小于3时成功结束，照常消耗，不调用小于1的伤害被最低伤害抬到1。数值整数提交由引擎向下取整，不增加取整积木。

自伤被阻止并不终止后续额外伤害；自伤导致释放者死亡，则其作为伤害来源的后续语句失效，不自动归因给玩家。没有目标仍可正常使用并自伤，不返回失败。预览和日志不能硬写敌人必定受到4+额外量，须按实际各次伤害结果展示。

## 不死神体：完整作者主体

```text
Skill：不死神体
类型：被动
描述：每局1次：受到致命伤害时保留1点生命，并进入濒死[2]。期间免疫致命伤害，持续时间结束时被消灭。
Cluster成员：不死保命、濒死免疫、濒死到期

StatusTag定义：不死已触发
可见：false
叠加：不叠加

Rule：不死保命
触发器：当前棋子.受到伤害应用前
上下文：挂载棋子
优先级：-101
code：
    如果 获取长度(容器：获取状态(目标：当前棋子，类型：濒死)) > 0：
        结束
    如果 获取长度(容器：获取状态(目标：当前棋子，类型：不死已触发)) > 0：
        结束
    如果 当前事件.伤害量 < 当前棋子.当前生命值：
        结束
    阻止当前事件
    当前棋子.当前生命值 = 1
    附加状态(目标：当前棋子，类型：不死已触发，强度：1，持续时间：永久)
    附加状态(目标：当前棋子，类型：濒死，强度：1，持续时间：2)

Rule：濒死免疫
触发器：当前棋子.受到伤害应用前
上下文：挂载棋子
优先级：100
code：
    如果 获取长度(容器：获取状态(目标：当前棋子，类型：濒死)) == 0：
        结束
    如果 当前事件.伤害量 >= 当前棋子.当前生命值：
        阻止当前事件

Rule：濒死到期
触发器：当前棋子.状态移除后
上下文：挂载棋子
code：
    如果 当前事件.状态类型 != 濒死：
        结束
    如果 当前事件.移除原因 != 持续时间耗尽：
        结束
    消灭(目标：当前棋子)
```

濒死免疫从旧受到伤害前移至伤害应用前，读取经过防御、护盾等处理后的待扣血量。5血受2伤扣至3；5血受5伤或更多整次阻止，仍为5。它不回血至1，不调用伤害，不负责共同受伤。首次不死保命仍是阻止致命伤害并直接保留1血，不冒充治疗；只有第一次激活才写1血。已用标记记录在棋子上，移除并重新授予Cluster不能凭空恢复每局资格；新局实例初始化不继承旧局标记。被动定义maxCharges=0不改为主动技能次数按钮。

持续时间使用统一状态生命周期：所属玩家回合结束递减，创建当回合不计；不再由Rule另减remainingTurns。转移所属玩家后跟随新玩家结束阶段。自然到期移除具体状态，再由独立Rule消灭棋子，不额外扣第二次持续时间。普通驱散不当作自然到期，沿基线没有状态就不继续倒计时的行为，不暗中改成驱散即死。状态不可见与否属于内容定义；这里仅将已用标记明确为不可见、防止普通驱散刷新每局资格。

`状态移除后.移除原因`是为表达自然到期补齐的通用只读事件字段，`持续时间耗尽`是引擎提供的枚举值，不用字符串猜测原因。状态移除事件须保留类型/原因快照，不能要求读取已失效状态实例的字段。强度耗尽、主动移除、驱散不能伪装为持续时间耗尽。此字段为作者接口补充，尚未实现运行派发；它不会把Rule自动关联到StatusTag。

消灭绕过伤害、防御、圣盾与免伤，进入已确定的正常死亡前/死亡后流程；不是出局，不再产生血誓共同伤害或伤害击杀返回值。已死亡、正在死亡或不存在的目标不重复进入死亡结算。正常死亡规则仍区分核心/召唤物的掉落和胜负作用。

用户已确认消灭来源可选，有来源则死亡归属该来源；不填来源仍有正常死亡事件，但不授予任何人的击杀奖励。本例到期不填来源，明确撤销旧实现把死亡归给下一位敌方玩家的处理。无来源不代表忽略全场死亡计数、墓地、核心判负等正常死亡规则；也不制造伤害结果或回填上一次攻击者。
