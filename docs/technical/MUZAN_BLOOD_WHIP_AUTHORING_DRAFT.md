# 血之鞭击作者代码

基线muzan-blood-whip：AP1、CP0、CD1、每局不限，无交互选择，四个正方向各3格内全部敌军。此为完整作者草案，未修改引擎/数据/UI。

```text
技能：血之鞭击
触发器：使用技能
行动点消耗：1
充能点消耗：0
冷却：1
每局使用次数：不限

code：
    新建【元组<方向>】变量【方向列表】 = {右，左，下，上}
    新建【元组<棋子>】变量【目标列表】 = {}
    新建【集合<棋子>】变量【已记录】 = {}
    遍历【方向列表】中的每一项【方向】：
        新建【元组<棋子>】变量【射线敌军】 = 目标选择器(
            类型：元组<棋子>，方式：自动，
            中心：当前棋子.位置，方向：方向，形状：射线，范围：3，
            筛选条件：{关系：敌方}，
            阻挡条件：{友军：false，敌军：false，阻挡弹射物地形：false}
        )
        射线敌军 = 排序(
            容器：射线敌军，依据：(棋子) => 距离(棋子, 当前棋子)，顺序：升序
        )
        遍历【射线敌军】中的每一项【目标】：
            如果 集合包含元素(集合：已记录，元素：目标) == false：
                加入集合(集合：已记录，元素：目标)
                追加元组(元组：目标列表，元素：目标)

    新建【数值】变量【伤害量】 = 当前棋子.攻击力
    遍历【目标列表】中的每一项【目标】：
        造成伤害(
            目标：目标，类型：普通，伤害量：伤害量，伤害来源：当前棋子
        )
```

方向按基线右/左/下/上，方向内由近到远。显式元组保序，Set仅去重；不能把Set无序遍历当结算顺序。方向是类型化方向值，不要求玩家逐次选择，不使用字符串来识别棋子实例。友军、敌军及地形均不截断范围查询。

目标在伤害前整体确定，攻击力只计算一次。按原单目标循环逐次提交伤害，不改成同时伤害；先前反应导致后续目标失效，该目标伤害语句跳过。范围内无敌军时空元组无操作，默认成功，仍按元数据支付AP/CD。目标移动后仍引用同一已记录目标，不重新查询范围；阵营变化后的合法性按效果公共契约处理，不为该技能擅自新加筛选。
