## 共用规则与基线差异

- 每个初始技能为一个可编辑Cluster；被动Skill与其Rule分别列出。StatusTag不隐式安装Rule。
- 普通/真实伤害按已确认规范，不再使用旧物理类别。正方向交互用已确认方向选择器，不自行实现拖动选点推方向。
- 自动范围查询保留基线棋子枚举顺序供同时伤害使用，不因坐标元组顺序随意改变同批Rule处理顺序。射击首个目标则显式按距离排序。
- 字段写入与地形变更经过权威入口；坐标只由位移提交。每次事件上下文数值按引擎事实读取，不能用伤害后生命差反算。
- 3×3采用相对格子元组，地图边缘裁切。本文重复列出形状值是为了完整展示作者正文；编辑器可复用相同的数据常量。

## 愤怒铁拳

基线每击读取当前攻击力×0.25，四次独立伤害；不能先缓存攻击力或把四段合为一次攻击力伤害。目标失效后依赖它的伤害语句失效，次数循环仍有固定上限。

```text

触发器：使用技能
行动点消耗：1
充能点消耗：0
冷却：1
每局使用次数：不限

    新建【棋子】变量【目标】 = 目标选择器(
        类型：棋子，范围：1，筛选条件：{关系：敌方}
    )
    新建【数值】变量【次数】 = 0
    当 次数 < 4：
        次数 = 次数 + 1
        造成伤害(
            目标：目标，类型：普通，伤害量：当前棋子.攻击力 × 0.25，
            伤害来源：当前棋子
        )
```

## 收割

Cluster包含被动Skill与收割Rule。基线逐个实际伤害目标派发造成伤害后，分别治疗，不先汇总再取一半。例如两个目标各受1点伤害：两次0.5分别整数化为0，不变成合计治疗1。基线治疗队列进入统一治疗结算，作者恢复生命也必须遵守反应队列顺序，不能因直接模块调用而把队列执行提前。

```text
Skill：收割
类型：被动

Rule：收割
触发器：当前棋子.造成伤害后
code：
    如果 当前事件.伤害量 >= 2：
        恢复生命(
            目标：当前棋子，数值：当前事件.伤害量 × 0.5，来源：当前棋子
        )
```

这里伤害后事件的伤害量是实际生命扣减，只读；>=2保留基线不发起0治疗的行为，不是重复检查已由引擎排除的非正伤害。自伤不被此Rule额外排除。宿主失效则治疗无效，不用直接增加生命替代治疗模块。
