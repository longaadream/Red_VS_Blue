# 乌尔奇奥拉：超速再生与归刃作者代码

核查origin/main三个Rule：rule-ulquiorra-damage-dealt、rule-ulquiorra-damage-taken、rule-ulquiorra-resurreccion。两个旧伤害Rule同时回血及计数；新作者结构按两个Cluster分开责任，不给两个Cluster各复制整条旧Rule。以下是完整作者草案，未修改运行引擎。

## 已确认行为与基线差异

超速再生：实际造成或受到伤害后恢复1。被挡/无正生命损失不触发，当前棋子生命已为0不能通过此恢复取消死亡。归刃：实际造成或受到伤害一次进度+1，最多3，累计事件次数而不是伤害量。进度是可见永久状态，可驱散；已归刃停止累计。所属玩家回合开始，进度达到3则攻击+1、移动+1、移除进度、获得黑虚闪、附加可见永久归刃。标记被驱散后的原再累积行为保留，不改成永久一次。

用户明确自伤可以算两次，覆盖基线受到伤害分支排除自伤的行为。因此造成伤害后、受到伤害后各处理一次，不写伤害来源等于当前棋子时结束；超速再生最多产生两次恢复1的尝试，归刃进度两次各加1但总强度仍不超过3。实际恢复量受剩余生命/治疗阻挡等规则约束，不保证每次实加1。

统一伤害事件字段已确认：当前事件.伤害来源是棋子/玩家/卡牌实例，当前事件.目标是受伤棋子；各伤害阶段含义一致。旧afterDamageTaken的sourcePiece/targetPiece交换只能作为适配材料，不能照搬到作者语义。执行来源仍单独表示直接调用伤害的Skill/Rule/卡牌入口。

## 超速再生完整作者代码

```text
Cluster：超速再生
成员：超速再生被动Skill、超速再生Rule

Rule：超速再生
触发器：当前棋子.造成伤害后、当前棋子.受到伤害后

code：
    如果 当前棋子.当前生命值 <= 0：
        结束
    恢复生命(目标：当前棋子，数值：1，来源：当前棋子)
```

两个事件入口共用code，但各事件正常执行，不按同一伤害身份去重；没有实际正伤害不派发由引擎保证。回复产生治疗事件，不再发伤害事件，不能误造回血递归。每个入口只尝试一次，避免Cluster安装同一入口多份。

## 归刃完整作者代码

```text
Cluster：归刃·黑翼大魔
成员：归刃·黑翼大魔被动Skill、归刃进度Rule、归刃结算Rule

Rule：归刃进度
触发器：当前棋子.造成伤害后、当前棋子.受到伤害后

code：
    如果 获取状态强度(目标：当前棋子，类型：归刃) > 0：
        结束
    如果 获取状态强度(目标：当前棋子，类型：归刃进度) >= 3：
        结束
    附加状态(
        目标：当前棋子，类型：归刃进度，强度：1，持续时间：永久
    )

Rule：归刃结算
触发器：本玩家.回合开始

code：
    如果 当前棋子.当前生命值 <= 0：
        结束
    如果 获取状态强度(目标：当前棋子，类型：归刃) > 0：
        结束
    如果 获取状态强度(目标：当前棋子，类型：归刃进度) < 3：
        结束

    当前棋子.攻击力 = 当前棋子.攻击力 + 1
    当前棋子.移动力 = 当前棋子.移动力 + 1
    移除状态(目标：当前棋子，类型：归刃进度)
    新建【元组<Skill>】变量【已有黑虚闪】 = 筛选(
        容器：当前棋子.技能列表，条件：(技能) => 技能.定义引用 == 黑虚闪
    )
    如果 获取长度(容器：已有黑虚闪) == 0：
        获得技能(目标：当前棋子，技能：黑虚闪)
    附加状态(
        目标：当前棋子，类型：归刃，强度：1，持续时间：永久
    )
```

本玩家只指挂载棋子当前所属玩家，不监听同阵营其他玩家的回合开始。进度及归刃定义声明可见，即可驱散，来源省略为无来源，永久状态通过普通叠加加层，先判断3再附加，不增加直接设置强度接口。永久加永久仍为永久。本例预期同一无来源进度实例，不借此定稿任意多来源强度聚合。

普通伤害事件、子治疗队列、被动优先级与UI刷新统一由公共引擎承担。旧healQueue的实际结算顺序与新伤害/恢复管线需要工程验证，不凭草案声称已经逐项等价。两个事件均应各派发一次，挂起/恢复不能额外重复，但不能把用户允许的双入口误当重复Bug。

AP0/CP0/CD0、不限次数的被动展示元数据，不产生额外费用。归刃进度展示采用状态变化通知，不靠轮询。黑虚闪代码见ULQUIORRA_CERO_AUTHORING_DRAFT.md。

验证待办：正常造成/受到伤害各回血与进度一次；自伤两个事件各一次、进度在2时自伤仍只到3；满血/治疗被挡时实际恢复受限；致死不回血取消死亡；归刃未达3不发动、所属玩家回合开始才变更、敌人/同阵营队友回合不发动；进度驱散后归零、归刃标记驱散后可重新累计；黑虚闪已有时不重置；技能复制/移除后两个Cluster各自负责规则、不丢另一技能功能；事件来源/目标一致。仅文档检查，未执行游戏测试。
