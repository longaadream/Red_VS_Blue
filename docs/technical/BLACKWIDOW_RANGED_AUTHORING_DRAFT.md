# 黑寡妇：致命打击与致命视线

作者草案，未实施。致命打击可用已有接口直接组合；致命视线的普通选择及目标改写后的候选验证政策已确认。

```text
技能：致命打击
触发器：使用技能
行动点消耗：2
充能点消耗：0
冷却：1
每局使用次数：不限

code：
    新建【方向】变量【方向】 = 目标选择器(
        类型：方向，中心：当前棋子.位置，方向范围：正方向
    )
    新建【元组<棋子>】变量【敌军】 = 目标选择器(
        类型：元组<棋子>，方式：自动，
        中心：当前棋子.位置，方向：方向，形状：射线，范围：全图，
        筛选条件：{关系：敌方}，
        阻挡条件：{友军：true，敌军：false，阻挡弹射物地形：true}
    )
    新建【元组<棋子>】变量【有序敌军】 = 排序(
        容器：敌军，依据：(棋子) => 距离(棋子, 当前棋子)，顺序：升序
    )
    新建【棋子】变量【目标】 = 有序敌军[1]
    新建【数值】变量【倍率】 = 1 + 距离(目标, 当前棋子) × 0.1

    造成伤害(
        目标：目标，类型：普通，
        伤害量：当前棋子.攻击力 × 倍率，伤害来源：当前棋子
    )
```

方向上未命中仍成功，依赖无效目标的伤害语句跳过。原友军阻挡、地形阻挡、未命中日志区别须由通用查询日志保留，不增加无目标释放失败条件。

```text
技能：致命视线
触发器：使用技能
行动点消耗：1
充能点消耗：2
冷却：2
每局使用次数：3

code：
    新建【棋子】变量【目标】 = 目标选择器(
        类型：棋子，范围：{最小：7，最大：99}，
        筛选条件：{关系：敌方}
    )
    造成伤害(
        目标：目标，类型：普通，
        伤害量：当前棋子.攻击力 × 2，伤害来源：当前棋子
    )
```

费用与冷却按origin/main定义，次数3按用户确认maxCharges代表每局次数表达。范围最大99保留基线参数，不直接换成无限地图查询。基线code对普通目标检查距离>6，但对ruleRewrittenPrimaryTargetPieceId跳过距离检查。新作者代码把原范围约束放选择器，不写技能专用mirrorRewrite分支；用户已确认转移后按新候选规则验证，不重新套用原选择器的范围/关系限制；仍验证在场和效果合法性。不能把此技能特殊例外藏进共用伤害模块，也不能擅自改成镜花水月重定向近距离后拒绝释放。
