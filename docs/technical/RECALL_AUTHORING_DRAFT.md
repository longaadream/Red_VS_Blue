Cluster汇聚Skill、两Rule及共用代码块。敌方事件上下文以挂载玩家阵营判断；同阵营队友行动不计数。一次完成的普通移动计一次，不按经过格数累计；技能计成功使用一次，不按伤害段数累计，取消/拒绝不计。冲刺/传送仅有位置改变时不冒充普通移动。基线按敌方行动/回合末判定，不能任意扩大为手牌使用也计数。

重复发动覆盖当前实例自己的旧记录，其他释放者不受影响。计数与到期共用一次消费路径，先删除记录再恢复，防止位置事件或快照重新挂载Rule重入导致重复执行。秘密数字仅对创建玩家显示，不向队友或公共日志泄露。

副本位于玩家 extension，避免把本次回溯记录保存进被复制棋子自身再递归复制。复制保存可变属性/状态/技能/Rule/extension 的独立数据；具体 Skill、Rule、Status、Card、Cluster 等外部实体引用在快照中保留稳定身份，不复制整个战斗图。信息应用保留场上棋子身份、经权威入口同步内部成员/归属，不覆盖 `instanceId`，不直接写坐标；已删除或失效的持久引用不会按数组位置或同名实例重定位。

位置与信息恢复是两项独立效果；位置占用/阻挡失败不跳过信息应用。位置结果使用普通权威位移返回值，记录格式不增加宿主专用的位移失败字段，信息应用也不依赖隐藏的宿主状态。与影分身的位移依赖召唤不同，本例明确无成功依赖。死亡或其他场上目标失效时依赖恢复语句无效，记录仍清除，不额外复活。原地不移动也不阻止信息恢复。

全部信息包含攻击、防御、技能、冷却和状态等已确认范围，显示与规则挂载须同步，但不伪造治疗/增删状态/获得技能事件。位置恢复仍产生真实位置事件。正常费用与冷却已在Skill效果前提交，副本记录该时刻数值，不能在执行完后再次覆盖技能默认冷却。恢复自身不把已经消费的玩家回溯任务从副本中复活。
