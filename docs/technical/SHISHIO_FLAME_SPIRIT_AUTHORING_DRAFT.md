## 燃地Rule

```text
Rule：炎灵燃地·踏入
挂载对象：玩家
触发器：全场.位置改变后
code：
    新建【棋子】变量【目标】 = 当前事件.棋子
    如果 映射包含键(映射：全局.extension.炎灵燃地，键：目标.位置) == false：
        结束
    新建【燃地记录】变量【记录】 = 全局.extension.炎灵燃地[目标.位置]
    新建【集合<棋子>】变量【在场棋子】 = 目标选择器(
        类型：集合<棋子>，方式：自动，范围：全图，筛选条件：{}
    )
    如果 集合包含元素(集合：在场棋子，元素：记录.来源棋子) == false：
        结束
    如果 记录.来源棋子.所属玩家 != 来源：
        结束
    造成伤害(
        目标：目标，类型：真实，伤害量：目标.当前生命值 × 0.5，伤害来源：记录.来源棋子
    )

Rule：炎灵燃地·回合结算
挂载对象：玩家
触发器：全场.回合结束时
code：
    新建【元组<棋子>】变量【目标列表】 = 目标选择器(
        类型：元组<棋子>，方式：自动，范围：全图，筛选条件：{}
    )
    新建【集合<棋子>】变量【在场来源】 = 目标选择器(
        类型：集合<棋子>，方式：自动，范围：全图，筛选条件：{}
    )
    遍历【目标列表】中的每一项【目标】：
        如果 映射包含键(映射：全局.extension.炎灵燃地，键：目标.位置) == false：
            继续下一次
        新建【燃地记录】变量【记录】 = 全局.extension.炎灵燃地[目标.位置]
        如果 集合包含元素(集合：在场来源，元素：记录.来源棋子) == false：
            继续下一次
        如果 记录.来源棋子.所属玩家 != 来源：
            继续下一次
        造成伤害(
            目标：目标，类型：真实，伤害量：目标.当前生命值 × 0.5，伤害来源：记录.来源棋子
        )
```

两个玩家Rule的来源是挂载玩家，用当前归属筛选来源棋子，避免每玩家监听都对同格触发一次。规则自然去重，不额外声明已安装开关。永久是登记/显示不自动到期，基线开始该响应时来源须仍存活在场；保留此依赖，不擅自使死亡来源的燃地跨未来回合继续伤害。回合末目标顺序为棋盘实例查询顺序，逐个按执行时当前生命计算，包含自己/友方/敌方，不批量同时计算。

回合末来源在进入Rule时的在场查询为成员快照，子反应若使其死亡，后续以其为来源的伤害语句按失效引用跳过；其余独立语句继续，不能把整体程序默认静默中断。本例明确依赖存活棋子，保留棋子来源，不自动改为玩家延迟伤害。多个来源、来源中途死亡、控制权改变和查询有效性需运行阶段对齐基线/统一生命周期，不能把作者草案当证明。重复位置变化依据引擎实际事件派发，不另按技能种类判断。
