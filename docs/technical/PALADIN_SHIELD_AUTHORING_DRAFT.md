# 圣盾公共规则与提里奥、乌瑟尔技能

固定基线：`082166c6b803b2e838bce5f0f6824c5bbc714dd6`。仅整理作者代码；基线定位包括shield-of-light、ashbringer、tirion-holy-recall、tirion-divine-glory、divine-blessing及其独立Rule。后续用户决定优先于旧实现：荣耀在召唤后触发，Rule与StatusTag分离，伤害类型仅普通/真实，友方按阵营判断。

## 公共圣盾规则

```text
Rule：圣盾抵挡
触发器：当前棋子.受到伤害前
上下文：挂载棋子
code：
    新建【元组<StatusTag>】变量【圣盾列表】 = 获取状态(目标：当前棋子，类型：圣盾)
    如果 获取长度(容器：圣盾列表) == 0：
        结束
    新建【StatusTag】变量【本次圣盾】 = 圣盾列表[1]
    移除状态(状态：本次圣盾)
    阻止当前事件
```

圣盾是可见、可驱散的普通StatusTag；免伤行为来自独立Rule，不是引擎内置圣盾分支。Rule按挂载对象+定义去重，消耗后保留Rule，无状态时自行结束；重复获得盾不会安装第二份响应，也不同时安装旧divine-shield-defense隐藏Skill。

保持基线find后移除一个完整状态实例的行为：按稳定创建顺序取第一份，整份消耗，不擅自改成强度减1，也不清空其他来源的盾。普通叠加规则仍决定添加时是否合并；一次消耗是一次真实状态移除，可触发荣耀与血色回响。查询选择盾的顺序不替代多个伤害Rule之间的优先级/同优先级种子随机规则。

非正伤害由引擎停止，不重复写伤害量判断。真实伤害只忽略防御，仍可被此Rule阻止；blocked不派发受到伤害后事件。此前造成伤害前已经消费的强化不会退回。

## 圣光盾

```text
Skill：圣光盾
触发器：使用技能
行动点消耗：2
充能点消耗：0
冷却：1
每局使用次数：不限
code：
    新建【棋子】变量【目标】 = 目标选择器(
        类型：棋子，范围：7，最小距离：0，筛选条件：{关系：友方}
    )
    新建【玩家】变量【释放玩家】 = 当前棋子.所属玩家
    新建【布尔】变量【对自身使用】 = 目标 == 当前棋子
    附加状态(目标：目标，类型：圣盾，强度：1，持续时间：永久)
    附加规则(挂载对象：目标，规则：圣盾抵挡)
    如果 对自身使用：
        调整资源(玩家：释放玩家，资源：行动点，变化量：1)
```

描述明确允许对自身使用，因此显式最小距离0；这不是改变其他技能默认最小距离1。准备时仍按完整2行动点检查和提交，随后回1且不超过上限，不能把费用改成1让只有1行动点时也能发动。已有盾不额外拒绝使用，普通叠加处理；附加未产生新实例也不取消自身退款。此处沿基线不标记状态来源，不把施法者或受益者自动填成来源。

```text
触发器：使用技能

充能点消耗：0
冷却：1
每局使用次数：不限
code：
    新建【棋子】变量【目标】 = 目标选择器(
        类型：棋子，范围：1，筛选条件：{关系：敌方}
    )
    新建【数值】变量【伤害量】 = 当前棋子.攻击力

```

```text
行动点消耗：1
充能点消耗：0
冷却：2

code：
    如果 获取长度(容器：获取状态(目标：当前棋子，类型：圣盾)) > 0：
        返回 使用失败("已经拥有圣盾")
    附加状态(目标：当前棋子，类型：圣盾，强度：1，持续时间：永久，来源：当前棋子)
```

沿用户已确认草案保留来源字段；前置判断接受任何来源的圣盾，不只查自己施加的。拒绝发生在费用、冷却和效果提交之前，不另建一个脱离code的使用条件系统。

## 圣骑士的荣耀

```text
Skill：圣骑士的荣耀
类型：被动
描述：召唤后获得圣盾。失去圣盾时攻击力+1。
Cluster成员：荣耀召唤护佑、荣耀失盾成长

Rule：荣耀召唤护佑
触发器：当前棋子.召唤后
上下文：挂载棋子
code：
    如果 获取长度(容器：获取状态(目标：当前棋子，类型：圣盾)) > 0：
        结束
    附加状态(目标：当前棋子，类型：圣盾，强度：1，持续时间：永久)
    附加规则(挂载对象：当前棋子，规则：圣盾抵挡)

Rule：荣耀失盾成长
触发器：当前棋子.状态移除后
上下文：挂载棋子
code：
    如果 当前事件.状态类型 != 圣盾：
        结束
    当前棋子.攻击力 = 当前棋子.攻击力 + 1
```

两个Rule随同一被动Cluster安装，给其他棋子也有效，不按提里奥字符串识别。召唤后沿已经确认的入口，不能改回游戏开始时。已有圣盾则整条召唤响应结束；安装Cluster本身不伪造一次召唤事件。状态类型比较使用定义引用。

消耗、驱散与圣光汲取的真实移除可加攻；合并不凭空制造移除事件，纯快照恢复不派发状态生命周期事件。离场失效棋子的字段写入跳过，不给死亡棋子增长。一次移除加1，不按被移除盾的强度加攻。

## 赐福

```text
Skill：赐福
触发器：使用技能
行动点消耗：0
充能点消耗：1
冷却：0
每局使用次数：4
code：
    新建【元组<棋子>】变量【持盾棋子】 = 目标选择器(
        类型：元组<棋子>，方式：自动，范围：全图，筛选条件：{具有状态：圣盾}
    )
    新建【数值】变量【强化量】 = 2 + 获取长度(容器：持盾棋子)
    新建【元组<棋子>】变量【友军】 = 目标选择器(
        类型：元组<棋子>，方式：自动，范围：全图，筛选条件：{关系：友方}
    )
    对每个 目标 属于 友军：
        附加状态(目标：目标，类型：强化，强度：强化量，持续时间：永久)
        附加规则(挂载对象：目标，规则：强化出伤)

Rule：强化出伤
触发器：当前棋子.造成伤害前
上下文：挂载棋子
code：
    新建【元组<StatusTag>】变量【强化列表】 = 获取状态(目标：当前棋子，类型：强化)
    如果 获取长度(容器：强化列表) == 0：
        结束
    新建【StatusTag】变量【本次强化】 = 强化列表[1]
    当前事件.伤害量 = 当前事件.伤害量 + 本次强化.强度
    移除状态(状态：本次强化)
```

持盾数统计全场存活棋子，包含敌方及自身；同一棋子即使有多份盾也只计1。强化量在本次使用中只计算一次，后续盾数量变化不重新计算；只赋予当时友方，包含同阵营不同玩家。保持maxCharges=4就是每局4次，不误写无限次。

强化是可见状态，来源沿基线省略，按普通叠加；Rule取第一份当前实例、加其全部强度并移除整份，与基线保持一致。不同来源其他强化若未来存在，不无条件合并或一并消费。一次伤害前只处理一份；批量伤害的逐目标前事件沿公共调度，不承诺给每个目标重复同一份增伤。Rule保留且天然去重，不使用隐藏Skill和Rule双重执行。伤害前事件非正则引擎不进入本响应；增伤已消费而目标后续免伤时不返还。

## 核验与待实施

五个初始Skill已有完整主体，从B转A；共享圣光盾按定义只计一次。参数对照固定基线；召唤后、来源可选、独立Rule等差异来自此前用户决定。A只表示作者主体齐全，不表示引擎/可视化界面完成。

后续运行验证：圣光盾必须先付2再返1、已有盾仍可施放、圣光重召失败无消耗、一次消费一实例、不同来源盾共存、普通/真实伤害阻挡、荣耀召唤与状态移除触发一次、移除后来源死亡不写字段、赐福敌我盾计数按棋子去重且释放时快照、强化先消费再被圣盾挡下、共享Rule重复安装不双触发。旧隐藏入口去重与事件重入时序须在运行迁移时验证。
