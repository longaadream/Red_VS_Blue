# 暗影步：标记、刷新与单次传送作者草案

固定核验基线：`082166c6b803b2e838bce5f0f6824c5bbc714dd6`。核对shadow-step、shadow-step-teleport、rule-shadow-step。仅作者规格，未修改运行代码。

AP0、CP0、CD3、每局不限次数。选择7格内可行走空地；下个所属玩家回合开始尝试一次，失败也清理。落点被自身占据也取消，保持该技能基线要求。状态强度固定为1，坐标不再塞进强度字段。

## 数据与结算边界

地格可行走/占用沿目标选择器同一权威属性读取，不能由UI另算。预检查保留本技能“包括自己在内任何占用均取消”的规则；位移执行仍由引擎再次保证不重叠。不是为所有传送额外增加占用fallback。结算失败正常结束，不退已经提交的技能资源，不保留下一次重试。

每棋子只保留一个标记任务，与原基线重标记替换行为一致；不同棋子使用实例作为Map键，互不覆盖。全局extension仅保存记录，没有全场监听或角色硬编码。版本是作者extension中的普通数值，防止传送反应中重新标记后，旧结算末尾误删已刷新的同一个状态。旧任务先出Map，旧区域先清；反应中新建的任务与区域继续保留。若原状态已失效，末尾条件按缺失引用跳过，不访问移除后的extension。

驱散/自然耗尽通过状态移除后清理；离场使用已经确认的棋子级生命周期收尾入口，仅用历史棋子身份作为Map键，不读取死者位置。两种清理重复到达时Map无键即无效果。Rule与StatusTag仍独立，清理标记不卸载共享Rule。已移除区域不影响局部记录的落点、版本等其他字段读取。

正值刷新不重置状态创建身份；另存标记回合确保创建/重标记当回合不会立刻传送。所属玩家变化后，入口跟随棋子当前所属玩家。额外瞬时反应、保存恢复及宿主离场状态存储的工程顺序需后续测试，不因作者主体完整而宣称实现完成。
