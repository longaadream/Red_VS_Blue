# 鬼舞辻无惨（RED-216）

暗方，生命 15、攻击 4、防御 1、移动 4。内容 ID 为 `dark-muzan`。

## 已确认规则

| 技能 | 消耗与冷却 | 规则 |
| --- | --- | --- |
| 血肉再生 | 被动 | 每个全局回合结束时，若该回合未受到实际生命伤害且当前生命未满，恢复 2；每局最多成功恢复 3 次。 |
| 血之鞭击 | AP 1，CD 1 | 对全部正方向3格内的敌人造成1倍伤害。 |
| 无惨之躯 | AP 1，CD 3 | 冲刺至正方向 6 格内的合法地格，可穿过友军；实际路径中的敌人受到 0.75 倍伤害并定身 1 回合，自身获得 50% 减伤[1]。 |
| 寄生 | 被动，CP 2 | 濒死时可花费 2 点充能点，选择中心 5×5 内另一存活棋子，传送到其相邻地格并注入血液：宿主成为己方棋子，获得血肉再生，随后无惨死亡。 |

“全局回合”指任一玩家的单个回合。护盾完全吸收或完全抵挡不算受伤；伤害实际扣除生命后，即使稍后回复，也算该回合受伤。未满血检查在结算时进行；满血或治疗被阻止不消耗再生次数。

获得再生之前在该回合受到的伤害也计入判断。回合结束规则同时检查持有者的受伤标记和当回合实际伤害日志，防止刚获得被动的宿主绕过受伤条件。

临时减伤和定身使用统一状态计时：只在持有者自己的回合结束扣减，施加当回合不扣减。每局再生次数是独立的永久进度，不使用限时状态计时。

冲刺途中因地格接触死亡时，尚未开始的路径伤害、定身和自身减伤取消。鞭击或冲刺已经开始范围伤害结算后，即使首个目标的反伤击杀无惨，其余已确定目标仍完成本次范围命中；死亡不重复结算，尸体不获得自身减伤。

寄生可选择友方、敌方及召唤物，不能选择自身。没有合法宿主、没有合法相邻地格、充能不足或取消时，不扣除充能。

注入血液后，宿主归属无惨方，获得血肉再生，无惨死亡。新增被动需同时安装伤害记录和回合结束规则；已有再生被动不刷新其每局次数。

寄生不免疫伤害，也没有容器分支。宿主保留原有技能、属性和当前生命，只增加再生能力；无惨正常完成死亡结算和充能结晶掉落。

结晶遵守既有核心规则：只有 `isCore: true` 的棋子死亡掉落，位置是寄生传送后的实际死亡格。训练工具临时放置的无惨为非核心，不掉结晶；验收结晶应通过开局设置选无惨为核心。无惨四技能的显式关键词仅保留无惨之躯的「定身」；血肉再生不在描述正文重复「被动：」。

## 实现边界

位移必须通过统一位置接口；伤害和治疗通过统一结算管线。寄生不得通过技能脚本直接改写濒死棋子的生命、坐标或战场数组来绕过死亡结算。

寄生使用可选的技能声明 `deathParasitism`（version 1，范围半径、充能消耗、授予技能及规则 ID）。这是引擎内部的封闭能力，不改变现有 SkillCode 编写规范。引擎在死亡批次提交前，通过现有可暂停动作事务收集宿主与落点选择；选择权属于濒死棋子的玩家。取消走原死亡流程，成功后同样执行正常死亡触发、墓地和结晶结算。

`changeDyingPiecePosition` 只供原生死亡处理调用，不暴露到脚本 API。它只接受当前战场上生命为 0 的指定棋子，复用合法落点、位置反应和接触流程；位置反应之后再次检查宿主、落点及充能，再提交扣费和转阵营。普通位移接口仍拒绝死亡棋子。没有可暂停事务的底层独立伤害调用不会代替玩家选择，直接执行普通死亡。

宿主技能与规则使用当前对局的资源加载器授予，避免绕过资源版本固定。已经存在的再生能力去重安装，保留其次数状态。同批多个濒死棋子可依次选择同一个仍存活宿主，每次成功各付自身费用。宿主恰为攻击者时，已发生攻击的伤害归属保持原玩家；只允许本次寄生引起的真实宿主归属变化，不放宽其他伤害源冻结检查。

无惨内容依赖上述引擎能力；旧客户端或旧服务端仅更新角色 JSON 不足以支持寄生。主浏览器、训练 AI、冒险引擎与服务端引擎均需从同一源码生成。

本任务不包含其他角色平衡、依赖更新、存档格式变更、完整客户端发布或远程部署。
