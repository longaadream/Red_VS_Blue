# 卍解·天锁斩月作者代码

基线ichigo-bankai-tensa-zangetsu：行动点0、充能点2、冷却0；不把maxCharges=0误写成有限次数。基线使用永久卍解状态拒绝重复发动，并移除自己的技能入口。采用已确认的Skill/Cluster实例、筛选、属性读写、资源上限、状态及冷却接口，不新建形态系统。设计草案，未实施。

```text
技能：卍解·天锁斩月
触发器：使用技能
行动点消耗：0
充能点消耗：2
冷却：0
每局使用次数：不限

code：
    如果 当前棋子具有【卍解·天锁斩月】状态：
        返回 构造行动结果(
            成功：false，提示：卍解·天锁斩月每局只能使用一次
        )

    新建【元组<Skill>】变量【原技能】 = 筛选(
        容器：当前棋子.技能列表，
        条件：(技能) => 技能.定义引用 == 月牙天冲
    )
    新建【Cluster】变量【原月牙】 = 原技能[1].所属Cluster
    新建【Cluster】变量【卍解入口】 = 当前技能.所属Cluster

    当前棋子.攻击力 = 当前棋子.攻击力 + 1
    当前棋子.移动力 = 当前棋子.移动力 + 2

    调整资源(
        玩家：当前棋子.所属玩家，资源：行动点，
        变化量：1，允许超过上限：true
    )

    移除技能(技能：原月牙)
    移除技能(技能：卍解入口)

    新建【Cluster】变量【黑色月牙】 = 获得技能(
        目标：当前棋子，技能：黑色月牙天冲
    )

    遍历【黑色月牙.技能列表】中的每一项【技能】：
        技能.当前冷却 = 0

    附加状态(
        目标：当前棋子，类型：卍解·天锁斩月，
        强度：1，持续时间：永久，来源：当前棋子
    )
```

技能列表为只读元组<Skill>，定义引用按统一中文定义引用比较，不把字符串ID当成实例。当前技能表示本次使用的Skill实例；先保存Cluster引用再移除入口，本次已启动的执行不因此中途停止。上述视图及正在执行技能的移除提交顺序须在实施中对齐权威入口，不直接改动棋子技能数组。

本例月牙天冲与卍解入口各为独立Cluster；黑色月牙天冲Cluster包含其传送Rule，获得时一并挂载。重置冷却作用于获得的Skill实例，不修改共享定义。卍解持续标记不隐式绑定技能/Rule生命周期；驱散后的增量回退政策不在本次凭空增加。
