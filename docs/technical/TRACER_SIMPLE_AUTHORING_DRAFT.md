# 猎空：闪现与脉冲手枪作者草案

自动整理的作者伪代码，未实施。基线为blink与pulse-pistol；敌友按战斗阵营判断，不按所属玩家判断。移动事件粒度沿用权威事件，不在此新增一次动作/逐格事件政策。

```text
技能：闪现
触发器：使用技能
行动点消耗：1
充能点消耗：0
冷却：0
每局使用次数：不限

code：
    新建【地格类型】变量【落点】 =
        目标选择器(
            类型：地格，
            中心：当前棋子.位置，
            形状：正方形，
            边长：5，
            筛选条件：{可行走：true，被占用：false}
        )
    位移(
        棋子：当前棋子，起点：当前棋子.位置，终点：落点，
        敌军可通过性：false，友军可通过性：false，
        不可通行地格可通过性：false，中间地格是否经过：false
    )
```

```text
被动技能：脉冲手枪

Rule：
    触发器：全场.移动后、全场.使用技能后

    如果 当前事件.棋子.阵营 == 来源.阵营：
        结束

    新建【元组<棋子>】变量【敌军】 =
        目标选择器(
            类型：元组<棋子>，
            中心：来源.位置，
            形状：正方形，
            边长：5，
            筛选条件：{敌方：true}，
            方式：自动
        )
    新建【元组<棋子>】变量【随机敌军】 = 随机排序(容器：敌军)
    新建【棋子类型】变量【目标】 = 随机敌军[1]
    新建【数值类型】变量【伤害量】 = 来源.攻击力
    造成伤害(目标：目标，类型：普通，伤害量：伤害量，伤害来源：来源)
```

空元组索引无效，依赖目标的伤害语句自动跳过；随机排序必须使用种子。基线Math.random不属于可沿用的新随机契约。没有命中候选不提示被动“释放失败”。

容器规范更新：此前按列表使用的目标查询、排序和洗牌均使用元组（vector）；不隐式去重。用户已确认元组下标从1开始，代码[1]表示第一项。
