## 共用约定

- 每个初始技能对应一个 Cluster，包含该 Skill 及本节列出的被动 Rule、所引用的状态定义。Rule 与状态分别安装，不靠 relatedRules 隐式绑定。
- 以下正文统一普通/真实伤害，不沿用旧描述的“物理”分类；该修改来自先前用户决定。
- 数值向下取整交给引擎。显式选定目标后不因后续死亡重新选人。
- 自动查询只取得有效场上棋子；实例身份比较和 Set 成员比较不读取旧实例属性。以此查询源是否仍在场，无需增加专用“艾德加是否存活”模块。
- 正常治疗统一调用恢复生命；结果为0不等于非法目标。伤害/位移结果不能被界面预览反复执行。
- 属性增量仍通过权威字段写入口；沿既有草案写“移动力”，映射 moveRange，不创建另一套 speed 数据。

## 艾德加：近身搏击

基线：AP1、CP0、CD0、不限次数，1格敌人，先缓存攻击力×0.5，再依次打两次。每次有实际伤害后治疗1；宿主中途死亡/离场则不继续攻击或治疗。伤害来源自动回退玩家的旧约定已撤回，不能让死亡棋子继续主动连击。

```text
Skill：近身搏击
触发器：使用技能
行动点消耗：1
充能点消耗：0
冷却：0
每局使用次数：不限

code：
    新建【棋子】变量【目标】 = 目标选择器(
        类型：棋子，范围：1，筛选条件：{关系：敌方}
    )
    新建【数值】变量【每次伤害】 = 当前棋子.攻击力 × 0.5
    新建【数值】变量【次数】 = 0
    当 次数 < 2：
        次数 = 次数 + 1
        新建【集合<棋子>】变量【在场棋子】 = 目标选择器(
            类型：集合<棋子>，方式：自动，范围：全图，筛选条件：{}
        )
        如果 集合包含元素(集合：在场棋子，元素：当前棋子) == false：
            结束
        如果 集合包含元素(集合：在场棋子，元素：目标) == false：
            结束
        新建【伤害结果】变量【结果】 = 造成伤害(
            目标：目标，类型：普通，伤害量：每次伤害，伤害来源：当前棋子
        )
        如果 结果.实际伤害量 > 0：
            恢复生命(目标：当前棋子，数值：1，来源：当前棋子)
```

治疗时目标若已离场，由统一目标有效性检查失效；不把死亡棋子复活。循环体局部结果每次新建，不复用上一击的结果。屏障挡住第一击但目标仍在场，第二击仍会执行。

## 艾德加：撑“杆”跳跃

基线：AP0、CP1、CD3、每局1次，5格合法空地。位移被阻止则结束后续效果，但技能已经使用；正常成功后以实际当前位置为中心3×3，敌人同时普通3伤害，再永久移速+1。

```text
Skill：撑“杆”跳跃
触发器：使用技能
行动点消耗：0
充能点消耗：1
冷却：3
每局使用次数：1

code：
    新建【地格】变量【落点】 = 目标选择器(
        类型：地格，范围：5，筛选条件：{可行走：true，被占用：false}
    )
    新建【位移结果】变量【位移结果】 = 位移(
        棋子：当前棋子，起点：当前棋子.位置，终点：落点，
        敌军可通过性：true，友军可通过性：true，
        不可通行地格可通过性：true，中间地格是否经过：false
    )
    如果 位移结果.成功 == false：
        结束
    新建【元组<坐标>】变量【范围形状】 = {
        {x:-1,y:-1},{x:0,y:-1},{x:1,y:-1},
        {x:-1,y:0},{x:0,y:0},{x:1,y:0},
        {x:-1,y:1},{x:0,y:1},{x:1,y:1}
    }
    新建【元组<棋子>】变量【敌军】 = 目标选择器(
        类型：元组<棋子>，方式：自动，中心：当前棋子.位置，
        相对格子：范围形状，筛选条件：{关系：敌方}
    )
    造成伤害(目标：敌军，类型：普通，伤害量：3，伤害来源：当前棋子)
    当前棋子.移动力 = 当前棋子.移动力 + 1
```

采用已确认的相对坐标元组；准确参数名称以通用相对范围接口为准。没有敌人也增加移速；伤害后宿主失效则属性写入失效，不恢复已死亡对象。传送只校验终点，不把沿途不可通行误当终点可落脚。

## 剑心：龙巢闪

基线：AP2、CP0、CD1、不限次数，1格敌人，连续3次攻击力×0.75普通伤害。基线每击重新读取攻击力，与近身搏击缓存伤害不同。目标提前死亡后依赖它的语句失效，不重新选敌人。

```text
Skill：龙巢闪
触发器：使用技能
行动点消耗：2
充能点消耗：0
冷却：1
每局使用次数：不限

code：
    新建【棋子】变量【目标】 = 目标选择器(
        类型：棋子，范围：1，筛选条件：{关系：敌方}
    )
    新建【数值】变量【次数】 = 0
    当 次数 < 3：
        次数 = 次数 + 1
        造成伤害(
            目标：目标，类型：普通，
            伤害量：当前棋子.攻击力 × 0.75，伤害来源：当前棋子

```

宿主失效后攻击力字段无效，整条伤害语句失效，不读取历史攻击力继续行动。三击不合并，以保留圣盾、反伤、击杀和每次伤害后的触发。日志汇总可用统一事件结果，不要求作者重新实现日志模块。

## 剑心：飞天御剑流·剑速

Cluster 包含被动 Skill、蓄势 Rule、增伤 Rule，引用“飞天御剑流”状态定义。状态可见、永久、不叠加；新状态被忽略，保证连续普通移动仍只保留一次机会。采用强度1代表一次机会，1.5作为增伤表达式，不混用强度和倍率。显示描述明确“下次造成伤害增加50%”；基线旧状态 intensity=1.5 的数字呈现需要迁移 UI 对照，不宣称逐像素一致。

```text
Skill：飞天御剑流·剑速
类型：被动

Rule：飞天御剑流·蓄势
触发器：当前棋子.移动后
code：
    附加状态(
        目标：当前棋子，类型：飞天御剑流，强度：1，持续时间：永久
    )

Rule：飞天御剑流·增伤
触发器：当前棋子.造成伤害前
code：
    新建【元组<StatusTag>】变量【状态们】 = 获取状态(
        目标：当前棋子，类型：飞天御剑流
    )
    如果 获取长度(容器：状态们) == 0：
        结束
    移除状态(状态：状态们[1])
    当前事件.伤害量 = 当前事件.伤害量 × 1.5
```

监听普通移动后，不能改为所有位置改变。增伤在造成伤害前消费，之后即便被圣盾挡住也不退还；多段技能只增强首个实际进入该前置事件的伤害请求。保持现有 Rule 优先级，批量伤害中消费归属由统一派发顺序处理。

## 莫提斯：铁铲突击

基线：AP1、CP0、CD0、不限次数，正方向3格空地；穿过友军敌军、不穿不可通行地形，成功冲刺后批量普通4伤害。应用用户已确认的新位移契约：遇阻到最后合法落点，伤害对象来自实际经过路径。此两点覆盖基线预查询全部目标、要求抵达终点的旧写法，属于已授权规则规范迁移，不是行为完全相同的声明。

```text
Skill：铁铲突击
触发器：使用技能
行动点消耗：1
充能点消耗：0
冷却：0
每局使用次数：不限

code：
    新建【地格】变量【落点】 = 目标选择器(
        类型：地格，范围：3，中心：当前棋子.位置，
        筛选条件：{同行或同列：true，可行走：true，被占用：false}
    )
    新建【位移结果】变量【结果】 = 位移(
        棋子：当前棋子，起点：当前棋子.位置，终点：落点，
        敌军可通过性：true，友军可通过性：true，
        不可通行地格可通过性：false，中间地格是否经过：true
    )
    如果 结果.成功 == false：
        结束
    新建【元组<棋子>】变量【敌军】 = 筛选(
        容器：结果.经过棋子，条件：(棋子) => 棋子.阵营 != 当前棋子.阵营
    )
    造成伤害(目标：敌军，类型：普通，伤害量：4，伤害来源：当前棋子)
```

该直线单段路径不会重复经过同一棋子；目标中途失效由伤害入口处理。友军不受伤，但允许经过。实际位移失败不伤害；空路径敌军列表不阻止已发生的位移。

## 剑心：两招随机相邻落点（已确认补齐）

用户同意：忽略被传送棋子自身占用；选到原地跳过位移继续伤害，选到其他格但传送失败则结束。本次查询的占用排除不改变实际棋盘，传送失败不清空旧位置。两招不新增原地移动事件。

龙槌闪旧随机实现将四方向洗牌再找合法落点，新正文先用种子随机排序相对坐标，再按该顺序逐个查询；保持四方向洗牌的调用结构。天翔龙闪先收集合法候选再单次随机选择。查询越界/不可用的单格不产生有效引用，依赖它的追加语句跳过；不往候选中写空值。

## 暗夜造物与蝙蝠增援：用户纠正后的当前规格

最新用户决定覆盖基线的readyCharges累计：蝙蝠增援只有可用/不可用，不堆叠使用机会；使用限制由Skill体系承担，不用StatusTag或extension中的“可用次数”作为另一套额度。Skill定义声明限制，具体Skill实例保存运行资格；不能修改共享定义使同名其他实例同时解锁。额度不可用时按钮仍存在但不能发动，不通过删掉技能表示次数耗尽。费用、冷却与目标等其他限制仍分别校验，解锁不意味着无视这些限制。

基线原行为（仅保留差异证据）：初始有零强度可见计数状态，hitCount存进度，每3次正伤害readyCharges加1，最后一次使用会removeSkillById。新标准明确撤回此累计和增删技能方案，不把它当用户尚未决定的玩法。既有maxCharges是每局次数，不能简单把其设置为1来表达可反复解锁的一次资格；下文采用通用布尔使用资格的作者字段与定义配置，不引入角色专用字段。

伤害进度可存extension；用户原则认可变量驱动的额外显示，因此只保留“伤害进度”的显示需求，撤回“蝙蝠可用次数”计数显示。额外显示如何声明、按依赖变更通知的完整签名仍待整理；UI不能根据显示字符串自行决定可用性。

保留已核对的其他规则：每造成3次正伤害（排除自伤，不限敌方）触发解锁；蝙蝠增援AP1/CP0/CD1，选择正方向7格，穿友军/敌军/地形，敌方批量同时普通4伤害，合计实际伤害后正常治疗自身。空射线也消耗本次资格。资格消费在伤害前，不能在结尾再次覆盖伤害过程中重新获得的资格；伤害后计数与再解锁的细节须随以下边界确认。

### Cluster和资格声明

暗夜造物Cluster包含被动Skill、计数Rule和关联的蝙蝠增援Skill。蝙蝠Skill实例初始就存在但无资格，按钮禁用；计数Rule不反复获得/移除技能。同一技能组合的内部引用通过实际Cluster成员定位，不按棋子名称或技能字符串查找。同定义多实例只修改本Cluster的成员。

下列“使用资格”“初始值”“使用时消耗”“技能.使用资格”为已确认语义的规范化作者名称，不是现役字段名。资格为布尔；设true不增量计数，不清除冷却。引擎在有效释放正式提交时自动将资格置false，再执行效果；选择取消/释放失败不消耗。不在code末尾重复置false，避免覆盖效果中重新解锁的资格。上述提交位置是落实先消费后伤害的工程契约，具体运行阶段仍需统一实现。

```text
Skill：暗夜造物
类型：被动

Rule：暗夜造物·伤害计数
触发器：当前棋子.造成伤害后
code：
    如果 当前事件.目标 == 当前棋子：
        结束
    在【当前规则.extension】中新建【数值】变量【伤害进度】 = 0
    当前规则.extension.伤害进度 = 当前规则.extension.伤害进度 + 1
    当 当前规则.extension.伤害进度 >= 3：
        当前规则.extension.伤害进度 = 当前规则.extension.伤害进度 - 3
        遍历【当前规则.所属Cluster.技能列表】中的每一项【技能】：
            如果 技能.定义引用 == 蝙蝠增援定义：
                技能.使用资格 = true
```

蝙蝠增援定义是有类型的Skill定义引用，由编辑器选择，不是字符串。非正伤害不派发该伤害后事件，Rule无需重复写伤害量判断；对友方伤害也计数，只有自伤被排除。对每个实际受伤目标分别计数，不把多目标批次总计一次。伤害进度首次事件声明为0；如UI需在此前显示0，使用声明初始化或明确缺省显示，而不能把所有未声明变量都解释为0；显示绑定的完整初始化协议仍待工程整理。
