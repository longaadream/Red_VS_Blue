```text
        类型：元组<棋子>，方式：自动，中心：当前棋子.位置，
        范围：2，筛选条件：{关系：敌方}
    )

    遍历【敌军】中的每一项【目标】：
        附加状态(
            目标：目标，类型：冰冻，强度：1，
            持续时间：1，来源：当前棋子
        )
        附加规则(挂载对象：目标，规则：冰冻阻止移动，来源：当前棋子)
        附加规则(挂载对象：目标，规则：冰冻阻止技能，来源：当前棋子)
```

公共冻结Rule查询挂载对象仍具有冰冻才阻止对应事件；状态自然结束或驱散不隐式清除Rule。重复附加同一定义公共Rule不能让同一事件重复结算，具体共享挂载策略继续沿用统一生命周期契约。基线freeze-prevent辅助Skill的界面投影在实施时对齐，不凭本草案擅自删除现役显示信息。

```text

触发器：使用技能

code：
    新建【方向】变量【方向】 = 目标选择器(
        类型：方向，中心：当前棋子.位置，方向范围：正方向
    )
    新建【元组<棋子>】变量【敌军】 = 目标选择器(
        类型：元组<棋子>，方式：自动，
        中心：当前棋子.位置，方向：方向，形状：射线，范围：全图，
        筛选条件：{关系：敌方}，
        阻挡条件：{友军：true，敌军：false，阻挡弹射物地形：true}

    新建【棋子】变量【目标】 = 有序敌军[1]

    造成伤害(目标：目标，类型：普通，伤害量：2，伤害来源：当前棋子)
```
