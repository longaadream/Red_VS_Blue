# 类 Scratch 作者体系：语句接口目录

逐项用途、参数、结果、边界和示例见[作者语句使用手册](AUTHOR_STATEMENT_MANUAL.md)；快速检索与覆盖来源见[接口参考索引](AUTHOR_STATEMENT_REFERENCE.md)。本目录继续保留接口设计状态，不以说明书替代运行验收。

更新：2026-10-12。整理目前已讨论的作者语言接口，供积木编辑器设计与后续逐技能核对使用。**这是设计目录，不是现役引擎 API 或运行支持清单。**

依据：[公共接口规格](SKILL_MODULE_INTERFACES.md)、[实例类型](AUTHOR_INSTANCE_TYPES_DRAFT.md)、[设计记录](SKILL_MODULE_DESIGN_RECORD.md)。本文将分散条目按用途归并；未决项不因收录而变成已确认。历史草案与最新决定冲突时，以明确记录的最新决定为准。

标记：**确认**表示能力及所列契约已确认，不保证所有边界已定稿；**部分**表示能力已讨论，但完整签名、重载或结果仍待补齐。表中“未定”不是无返回值。`?` 表示可选参数；未列默认值的参数不擅自补默认值。

2026-10-12 最新作者边界：模块目录只提供原子操作和流程控制，不把回溯、飞雷神等组合能力发布为专用语句。extension 建议项按当前作用域筛选，但允许自定义对象、字段路径和类型；访问缺失字段不创建数据，也无需 fallback，该语句及其依赖无效，独立后续继续。高级选项不能成为重新暴露专用适配器的入口。

## 1. 积木组织建议

用户已认可结构化编辑方向：每条语句从模块列表选择，参数可以递归组合表达式；不要求 Scratch 积木外形，也不要求手打语法。采用行式语句、可点击参数与原位表达式编辑，复杂内容保持在同一编辑体系，支持按类型筛选、替换/复制子表达式和提取变量。数字、名称及说明可直接输入。以下分类用于组织接口，不新增战斗规则；既有作者代码作为同一结构的文字展示，具体控件尚未实现。

| 类别 | 作用 | 例子 | 连接限制 |
| --- | --- | --- | --- |
| 入口 | 建立一次执行上下文 | 使用技能；Rule 的死亡后触发器 | 位于执行段顶部，提供对应事件字段 |
| 执行语句 | 改变状态，或发起需要等待的交互 | 造成伤害、召唤、手动目标选择 | 顺序执行一次；有结果时保存到变量 |
| 值表达式 | 读取数据、运算、构造值 | 攻击力、距离、获取状态、映射取值 | 按类型嵌入输入槽；不得暗含战斗效果 |
| 布尔表达式 | 提供判断 | 相等、集合包含、比较 | 嵌入条件槽 |
| 控制结构 | 包含子语句 | 如果、遍历、while、结束 | 子语句保持顺序与作用域 |
| 定义与声明 | 配置可复用内容 | Skill、Rule、StatusTag、模板、结构体 | 属于内容定义，不混入战斗执行序列 |

**有返回值不等于纯表达式。** `结果 = 造成伤害(...)` 是执行语句；不能把造成伤害拖进费用公式，也不能因 UI 重绘再次执行。手动选择需要等待玩家；随机选择会推进种子随机序列，两者也不能用于纯费用预览。自动目标查询才是只读查询。

Rule 的“数值修正”是声明表达式，不是事件入口，不在费用预览时执行 Rule 的战斗 code。

## 2. 类型与变量

| 类型组 | 类型 | 关键约束 |
| --- | --- | --- |
| 基础值 | 数值、布尔、字符串 | 整数效果/字段由引擎向下取整，不要求每条作者语句写取整 |
| 场上引用 | 玩家、棋子、地格、区域 | 玩家归属与战斗阵营分开；敌友按阵营 |
| 内容定义 | 棋子定义/模板、手牌定义、状态定义、地形定义、标签引用、Skill/Rule/Cluster 定义引用 | 用类型明确的引用，不以显示名称字符串查找 |
| 运行实例 | 手牌、StatusTag（中文别名“状态”）、Skill、Rule、Cluster | 同名实例仍是不同对象；定义引用不能冒充实例 |
| 几何值 | 方向、坐标 `{x,y}` | 正方向为上、下、左、右；坐标可表示相对格偏移 |
| 结果结构 | 伤害结果、治疗结果、位移结果、路径查询结果 | 各自字段见下表，不统一虚构“成功”字段 |
| 泛型容器 | 集合<T>、元组<T>、映射<K,V> | Set 去重；元组是可重复、有序、可变长的 vector，首项为 `[1]`；Map 按键存值 |
| 自定义值 | 结构体、有类型函数表达式 | 结构体字段有类型；函数由受支持表达式构成，不是任意 JavaScript |

extension可以理解为实例附带的可扩展结构体：字段逐项声明类型，无须每个技能另造一个命名类型。命名结构体用于多处复用同一字段组合（例如元组中的任务记录），是组织和类型复用方式，不是每种复杂效果的新模块。extension保存数据，具体触发与结算仍由Rule/Skill的通用语句执行。

实例引用赋值保留身份；数值读取后存变量是当时的值。复制实例必须显式调用复制能力。构造一个含相同字段的结构体不能伪造引擎实例。

| 语句/表达式 | 输入与结果 | 状态与边界 |
| --- | --- | --- |
| `新建【T】变量【名称】 = 值` | 值必须兼容 T；建立局部变量 | 确认 |
| `变量 = 值` | 同类型赋值 | 确认；不能改变已声明类型 |
| `在【对象.extension】中新建【T】变量【名称】 = 初值` | 建立持久字段 | 确认；同名同类型重复声明不重置已有值 |
| `对象.extension.名称 = 值` | 写入已声明字段 | 确认；extension 不会提前自动留位置 |
| `对象.字段` | 返回字段的声明类型 | 确认；是否可写由字段契约决定 |
| `对象.字段 = 值` | 权威字段写入 | 部分；不是任意对象属性均可写，见第 10 节 |
| `结构体构造` | 按声明字段构造类型值 | 确认；精确编辑器控件待设计 |

extension 的总体目标是支持各种类型及完整类型值；各类值的身份、复制、保存及生命周期仍须落实，不能据此宣称每个基础值都已有可持久写入的实例身份。

## 3. 运算、容器与控制

| 接口 | 参数 / 返回 | 分类与边界 |
| --- | --- | --- |
| 算术、比较、逻辑 | 数值运算；`== != < <= > >=`；与/或/非 | 值/布尔；除零等错误边界待完整规格 |
| 条件取值 | 条件、成立值、不成立值 → 同一兼容类型 | 值；用于费用等纯表达式 |
| `距离(a,b)` | 棋子或地格 → 数值 | 值；非法位置按引用失效处理，具体距离口径须与规则对齐 |
| `筛选` | 容器、`(项:T)=>布尔` → 筛选后容器 | 值；保持 Set/元组类别，查询结果是快照 |
| `排序` | 容器、依据函数、升/降 → 元组<T> | 值；元组同值保留原顺序；Set 同值枚举须可回放 |
| `排序` 比较器重载 | 容器、`(a:T,b:T)=>数值` → 元组<T> | 确认支持有类型函数；比较结果细则待完整定义 |
| `随机排序` | 集合<T>或元组<T> → 元组<T> | 随机求值；使用引擎种子，保留元组重复项 |
| `随机选择` | 容器 → T 或无效值 | 随机求值；空容器不抽取，非空抽取一次；多项重载未定 |
| `获取前若干项` | 元组、数量 → 元组<T> | 值；Set 须先排序/随机排序；负数/越界待定 |
| `获取长度` | 元组/集合/映射 → 数值 | 值；分别计算项数/唯一成员数/键数 |
| `元组[n]` / `映射[键]` | 返回 T / V 或无效值 | 值；元组从 1 开始；Set 没有位置索引 |
| `加入集合` / `移除集合元素` | 集合、元素 | 容器写入；增加重复元素不增加数量，删除缺失成员不报错 |
| `容器包含元素`（旧称集合包含元素） | 集合<T>或元组<T>、元素:T → 布尔 | 纯查询；引用元素按身份相等，不修改容器或引入顺序 |
| `追加元组` | 元组、元素 | 容器写入；尾部追加，可重复 |
| 元组插入/删除 | 按 vector 能力维护 | 部分；完整签名未统一，不按同名内容批量删除不同实例 |
| `映射[键] = 值` | 映射、键、值 | 容器写入；相同键覆盖对应值 |
| `映射包含键` / `删除映射项` | 映射、键 → 布尔 / 未定 | 查询/写入；删除缺失键不报错 |
| `如果…否则…` | 布尔条件、两个语句段 | 控制；条件依赖无效引用时不能悄悄当成 false |
| `遍历【容器】中的每一项【变量】` | 类型明确的容器与子语句 | 控制；直接遍历原容器时新增项可继续访问，删除当前项不跳过下一项 |
| `当【条件】成立时循环` | 布尔条件、子语句 | 控制；引擎次数上限原则确认，具体上限和超限处理未定 |
| 跳出/继续循环 | 当前循环 | 控制；具体文字形式待统一 |
| `结束` / 裸 `return` | 当前入口 | 主动技能/手牌默认成功结束；Rule仅结束本次响应；循环内也退出入口 |
| `返回 使用失败(原因)` | 使用结果：失败；原因字符串 | 技能/手牌在提交前拒绝，不消耗资源、冷却或次数，不弃牌；旧技能释放失败是历史别名 |
| `返回 使用成功` | 使用结果：成功 | 立即结束技能/手牌正文，正常消费与冷却、次数、弃牌各提交一次；不要求实际产生效果 |
| `阻止当前事件` | 当前可阻止事件 | 不自动结束 Rule，后续语句继续；不能取消已确定死亡 |

不新增通用“同时结算”控制块。逐条/逐项默认顺序执行；批量伤害的同时语义属于伤害接口自身。

## 4. 查询与玩家选择

统一入口：`目标选择器(类型，筛选条件，范围?，最小距离?，方式?，可见玩家?，候选集合?，允许取消?)`。

| 输入 | 已确认内容 | 未决边界 |
| --- | --- | --- |
| 类型 | 棋子、地格、手牌、手牌定义、方向及指定容器形状 | 不能将单个地格写成元组<地格> |
| 筛选条件 | 敌友阵营、所属玩家、状态、标签、地格可行走/被占用、区域、行列等结构化条件 | 按具体查询类型提供字段，不接受任意源码 |
| 范围/中心 | 数值范围；地格中心；方向、射线；相对坐标元组 | 各形状默认值、部分距离区间参数仍待统一 |
| 方式 | 手动交互或自动查询 | 手动选择需等待；自动查询不可暗含手动弹窗 |
| 候选集合 | 集合<T>或元组<T> | 返回候选的原类型引用，定义选择不变成实例 |
| 可见玩家 | 可选集合<玩家> | 控制过程、结果表现和日志；精确权限协议待落地 |
| 忽略占用棋子 | 本次传送被移动棋子的集合，当前确认单个自身 | 仅用于本次占用校验，不提前清空实际棋盘；批量配对仍待定 |
| 允许取消 | 默认 false，允许的被动入口显式 true | 主动技能提交前退出准备不等于空放成功 |

返回值按选择类型为单值或明确容器类型，不能由 UI 随意决定。手牌选择使用实际手牌区交互。正方向选择显示四个方向；相对范围编辑使用格子坐标系、原点与受影响格，保存为元组<坐标>。

射线的友军、敌军、阻挡弹道地形分别配置阻挡条件。只查询首个阻挡点之前的候选；阻挡点本身是候选棋子时包含它再停止。`blocksProjectile` 与不可行走不是同一字段。

| 其他查询/交互 | 接口与结果 | 状态 |
| --- | --- | --- |
| 选项选择器 | 选项映射（显示标签 → 有类型值）→ 所选值 | 确认；不要把显示字符串当业务身份；其他完整参数待统一 |
| 获取状态 | 目标：棋子或玩家、类型：状态定义 → 元组<StatusTag> | 确认；稳定创建顺序，无该状态返回空元组 |
| 获取状态强度 | 目标：棋子、类型：状态定义 → 数值 | 确认无状态为 0；多个独立实例如何聚合未定 |
| 获取下一位玩家 | 参照：玩家、筛选条件? → 玩家或无效引用 | 确认；按当前回合顺序，不返回参照本人 |
| 查询路径 | 棋子、起点、方向、范围（数值或全图）、三类可通过性 → 路径查询结果 | 确认；只预测，不触发移动或伤害 |

## 5. 战斗效果

| 接口 | 输入 | 返回与关键契约 |
| --- | --- | --- |
| 造成伤害 | 目标：棋子/元组<棋子>/集合<棋子>；类型：普通/真实；伤害量：数值；伤害来源：棋子/玩家/手牌实例 | 单个伤害结果或元组<伤害结果>；批量同时出伤；多目标不同伤害量的单次请求未定 |
| 消灭 | 目标：棋子；来源?：棋子/玩家/手牌实例 | 进入正常死亡，不走伤害；有来源归属来源，无来源不授予击杀奖励；返回值未定 |
| 恢复生命 | 目标：棋子/元组<棋子>；数值；来源：棋子/玩家 | 治疗结果或同序元组<治疗结果>；正常治疗必须经过此模块 |
| 调整资源 | 玩家；资源：行动点/充能点；变化量；允许超过上限?=false | 布尔；扣除不足则 false、不扣成负数；增加且受上限限制时布尔语义待补 |
| 附加状态 | 目标；类型：状态定义；强度；持续时间：数值/永久；来源?；extension?；可见玩家?；显示配置? | 单目标返回 StatusTag；批量历史 Set 返回与后续容器规范需统一 |
| 移除状态 | 状态实例；或目标棋子+状态定义 | 普通移除只处理可见状态；按类型移除的多实例数量规则未定 |
| 附加规则 | 挂载对象：棋子/玩家/手牌实例；规则定义；来源? | Rule 实例；同挂载对象+同定义去重，返回已有实例并保留 extension |
| 移除规则 | Rule 实例；另有目标+规则定义重载 | 不终止该 Rule 已开始的当前执行；共享任务不能因单项完成被误删 |

伤害来源棋子死亡后整条伤害语句失效，不默认归其所属玩家。需要独立持续的延迟伤害在创建时直接保存玩家来源；诅咒、天照、黑棺已按此修改。手牌实例来源与执行入口的 Skill/Rule/手牌实例引用分别记录。

StatusTag 与 Rule 独立。状态来源可不填；不同来源不合并。同来源或双方无来源且extension内容相同时：持续时间相同加强度，强度相同加持续时间，两者相同都加，两者都不同则分开。声明不叠加的状态忽略新状态。强度就是层数，没有统一总强度上限。所属玩家回合结束自动减少持续时间，创建当回合不计；可见与可驱散统一。

## 6. 空间、召唤与显示

| 接口 | 输入 / 返回 | 确认范围与缺口 |
| --- | --- | --- |
| 普通移动 | 棋子、行动点消耗、允许取消?=false → 结果未定 | 引擎提供点按和拖动路径交互，逐格结算；作者不再手动实现普通移动选路 |
| 位移 | 棋子、起点、终点、敌军可通过性、友军可通过性、不可通行地格可通过性、中间地格是否经过 → 位移结果 | 遇阻停最后合法落点；成功与发生位移分开，合法原地成功但不派发位置事件；不自动判整次技能失败 |
| 召唤：模板创建 | 技能内声明的模板/定义/复制副本、位置、所属玩家、显示配置? → 棋子或失败无效值 | 默认召唤物；完整模板字段及批量签名待补 |
| 召唤：原实例入场 | 离场原棋子实例、位置 → 原棋子或失败无效值 | 保留身份；原核心/召唤物身份按已确认案例保留 |
| 出局 | 棋子实例 | 保留可引用实例，不等于死亡；完整结果与生命周期待补 |
| 设置棋子显示 | 棋子实例、具体字段显示配置 | 能力确认，完整字段表待补；省略字段不特殊化 |
| 创建区域 | 地格：元组<地格> → 区域 | 规范化草案；不占据落点、不隐式改变地形 |
| 移除区域 | 区域实例 | 清理该区域及其显示；不自动移除独立 Rule |
| 设置区域显示 | 区域、tileEffect 配置 | 已确认对接现有 tileEffect；不另建显示状态源 |
| 复制手牌到手牌区 | 手牌实例、接收玩家；本例不使用返回值 | 确认：新身份、保留当前数值/extension/附加Rule、可变数据独立、外部引用保留；事件与满手待运行验证 |
| 复制实例 / 应用实例信息 | 原实例 → 副本；副本应用至指定棋子 | 能力确认；深复制、extension、结果及全字段边界仍待补 |
| 设置上场顺序 | 棋子、n | 插入第 n 位，1 为首位；越界及同时插入待定 |

召唤首次呈现前应用显示配置，避免先暴露真实外观再伪装。显示快照保留召唤时数值，不持续追踪原棋子。规则引用外部定义，分身只是召唤物，不提供“分身专属模块”。

tileEffect 显示字段：类型、图标?、背景色?、边框阴影?、所属玩家?、图标位置?（四角）。所属玩家是归属信息，不等于可见权限；坐标与稳定身份由引擎投影产生。

复制/应用不能绕过空间权威入口直接写坐标；恢复信息不派发正常治疗/获得技能等事件。历史位置需要单独合法位移；位置恢复失败不阻止其他已约定信息恢复。批量位移配对采用移动列表，宿主转移相互占用依赖由传送层处理；不相关项目失败传播仍按实际场景核对。

## 7. 手牌与 Cluster

| 接口 | 输入 / 返回 | 状态与边界 |
| --- | --- | --- |
| 获得手牌 | 玩家、手牌定义、extension?：有类型字段结构体 → 新手牌实例或失败无效引用 | 创建时初始化每张实例的 extension；可直接附加Rule；手牌上限 10，满手直接放入弃牌区并返回新实例 |
| 弃置手牌 | 指定手牌实例 → 返回未定 | 进入弃牌区，不视为使用；事件细节待定 |
| 添加标签 / 移除标签 | 目标：手牌实例；标签引用 | 只改该实例，不同时修改同名牌；移除不存在标签的行为待定 |
| 获得技能 | 目标棋子、Cluster 定义 → 返回待定 | 按 Cluster 安装其 Skill/Rule；返回 Cluster 实例尚未最终确认 |
| 移除技能 | Cluster 实例 | 按 Cluster 操作；成员与共享 Rule 的清理、重复获得政策待补 |

手牌使用后默认进入弃牌区，特殊说明除外；不需要每张牌重复写弃置语句。不存在“抽牌”这一默认模块。Cluster 是可视化操作单位，内部主动/被动 Skill 与 Rule 都可编辑，StatusTag 定义引用不等于自动安装关联 Rule。

## 8. 结果结构与上下文

| 类型/上下文 | 已确认字段 | 限制 |
| --- | --- | --- |
| 伤害结果 | 实际伤害量：数值；是否击杀：布尔 | 实际伤害只计直接生命扣减，不含吸收、溢出；未确认通用成功字段 |
| 治疗结果 | 实际恢复量：数值 | 被阻止为 0；无效目标不是合法的 0 结果 |
| 位移结果 | 成功：布尔；发生位移：布尔；经过地格：元组<地格>；经过棋子：元组<棋子>；首个阻挡棋子：棋子或空 | 记录实际路径，不用预测路径替代 |
| 路径查询结果 | 最后合法落点；首个阻挡棋子（可为空）；经过地格；经过棋子 | 预测结果；阻挡棋子不计入可通过棋子；不能保证执行时仍合法 |
| 当前回合 | 编号：数值；玩家：玩家 | 只读；全局玩家回合序号，不是阵营轮数 |
| 当前事件 | 按触发器提供棋子、伤害来源、执行来源、位置、伤害量、局部变量等 | 必须使用事件专属结构，不能让每个事件都读取所有字段 |
| 当前规则 | 当前 Rule 实例及其 extension、可用来源引用 | 不提供隐式“关联状态”；状态需查询后存变量 |

首个阻挡棋子在路径查询中是预测结果；用户随后确认位移结果也提供执行中实际阻挡者，两者不得混用。

## 9. 入口与 Rule 声明

| 入口族 | 已讨论入口 | 权限与边界 |
| --- | --- | --- |
| 开局/回合 | 游戏开始时；所属玩家回合开始/结束；敌方回合结束 | 中局获得 Cluster 不补发游戏开始事件 |
| 使用 | 使用本技能；使用技能前/后；使用手牌前；成功使用手牌后 | 使用前可改已声明局部变量；准备/提交阶段衔接尚待实现设计 |
| 目标指定 | 被指定为目标前 | 逐目标处理，不以使用技能前替代；改写次数上限 16，转移后用新的候选规则 |
| 伤害 | 造成伤害前；受到伤害前；伤害应用前；造成/受到伤害后 | 造成伤害前先于受到伤害前；after 数值只读；before 可按契约改伤害量 |
| 死亡/击杀/离场 | 死亡前；死亡后；击杀后；棋子级离场后 | 死亡前不是复活窗口；死亡后已经提交离场；出局不冒充击杀 |
| 空间/召唤 | 普通移动入口；位置改变；召唤后 | 普通移动与位置改变分开；逐格位置事件，具体事件载荷/部分提交时点待对齐 |
| 状态 | 状态移除等已用入口 | 自然耗尽与主动驱散须保留区别，精确载荷待补 |

范围：全场、己方（同阵营）、本玩家、当前棋子。不能用“同一所属玩家”代替己方。事件对象、Rule 来源、挂载对象是不同概念。

伤害前 Rule 返回后若伤害量 <= 0，引擎停止该目标的伤害事件，不派发对应伤害后；不停止技能中独立的后续效果，不回滚已消耗状态。正常防御计算后的最少 1 点不覆盖这种主动归零/阻挡。

已确认数值修正写法：

```text
Rule：普通移动费用修正
数值修正：
    字段：当前棋子.普通移动.行动点消耗
    表达式：如果 条件 则 0 否则 原值
```

`原值` 是此前优先级修正后的值；沿用既有 Rule 优先级。预览、资源检查、提交共用求值，提交前重算，依赖变化时通知 UI，不轮询。**当前只确认普通移动费用这一应用范围**，不自动推广到冷却等任意字段。

## 10. 可写字段与引擎责任

| 写入口 | 当前明确许可 | 不可顺带推导 |
| --- | --- | --- |
| `状态.强度 = 数值` | 权威更新，<=0 自然耗尽，独立 Rule 保留 | 不等于持续时间等任意字段可写 |
| `Skill实例.当前冷却 = 数值` | 改具体实例并通知 UI | 不能写定义引用；无需另建设置冷却模块 |
| `棋子.所属玩家 = 玩家` | 经权威归属变更 | 阵营迁移政策及其他字段须按各自契约，不裸改对象 |
| `区域.地格 = 元组<地格>` | 保留区域身份并更新地格投影 | 不原地改容器绕过入口；不伪造位置改变事件 |
| `地格.地形 = 地形定义` | 更新地形通行/弹道数据，附着效果保留 | 不清掉 tileEffect |
| `当前事件.局部变量.名称 = 值` | 使用前写回已声明同类型变量 | 尚未声明则整条语句跳过，不自动创建或填 0 |
| `当前事件.伤害量 = 数值` | 有权限的 before 阶段 | after 阶段只读 |

其他属性增减已有技能案例，但这里不把未审定字段扩成“所有字段任意写”。棋子坐标、实例身份、技能列表等不能通过普通赋值绕过专用权威操作。

引擎共同负责：无效引用的依赖语句跳过；真实程序错误诊断；种子随机；整数化；权威生命周期；日志、动画、UI 投影；选择等待与恢复；费用提交；循环保护。作者无需为每个无效目标手写 fallback。跳过无效语句不等于吞掉程序错误，也不应导致交互卡死。

来源类型仍是原棋子/玩家，不采用此前扩展任务来源的提议。任务关联是普通extension字段，不产生StatusTag与Rule自动绑定。省略extension按定义声明初始化；比较的是最终内容，不是调用参数是否省略。直接修改现有extension不追溯自动合并既有状态。容器、循环引用的可保存编码与比较实现仍待工程验证，不能用JSON字符串化比较替代实例身份。

## 语句故障隔离与不得卡死（2026-10-12 用户最新确认）

这是跨模块引擎的强制设计目标，尚不表示所有运行路径已实现。运行时某条语句出现问题，必须终止该条语句、记录错误并跳过，继续执行与其无依赖的后续语句，不能让对局永久停在异常、选择或表现等待中。

- 缺失目标、失效引用、异常或无法完成的操作不能制造一个伪造的成功结果。该条结果标为无效；读取它的依赖语句同样跳过，独立语句照常执行。不得把无效值隐式当成0、false或另一个同名实例。
- 跳过不是吞掉异常：记录回合/阶段、执行实体、命令、语句/模块位置、错误原因、关键状态及随机种子（相关时），供界面提示和回放定位；不要为同一错误无限弹窗或无限重试。
- 错误语句不得遗留半提交的资源、棋子占用、锁或等待标记。正常模块应通过权威校验与提交边界维护不变量。已经成功结算的前序效果保留，不为恢复执行而重放；本条“跳过”不授权整个技能回滚或再次扣费。
- 循环、递归及事件链必须有有限的执行保护；超过保护上限退出对应执行结构并记录原因，后续独立流程可继续。具体上限仍沿用已确认配置，未定数值不在此擅自设置。
- 玩家选择等待、动画等待及异步模块要区分正常等待与异常悬挂。正常等待玩家输入不是语句故障；目标消失、候选失效、取消或等待异常应按接口完成/取消/失效规则恢复调度，不能遗留永久pending。动画失败不得锁死规则执行。无需作者为每条语句编写fallback。
- 合法的显式`返回 使用失败`、`返回 使用成功`或结束语句仍按其契约终止相应执行范围，不因容错规则而被忽略；编辑阶段已发现的结构/类型错误仍显示诊断，不把非法内容冒充有效内容保存执行。

必测：坏语句后的独立伤害/治疗仍执行；依赖坏返回值的语句跳过；循环超限可退出；选择目标离场/候选耗尽和动画异常能释放等待；故障不重复扣费、不重放效果、不污染占用；同种子同输入的故障路径可复现。按模块提供实现与回放证据后才能声称本原则已落地。
