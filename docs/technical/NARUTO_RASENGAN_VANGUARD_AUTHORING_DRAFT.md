## 螺旋手里剑

```text
Cluster：螺旋手里剑
成员：螺旋手里剑Skill
引用定义：沉默、沉默阻止技能

Skill：螺旋手里剑
触发器：使用技能
行动点消耗：2
充能点消耗：0
冷却：2
每局使用次数：不限
code：
    新建【棋子】变量【目标】 = 目标选择器(
        类型：棋子，范围：2，筛选条件：{关系：敌方}
    )
    新建【数值】变量【伤害量】 = 当前棋子.攻击力 × 2
    造成伤害(目标：目标，类型：普通，伤害量：伤害量，伤害来源：当前棋子)
    附加状态(目标：目标，类型：沉默，强度：1，持续时间：1)
    附加规则(挂载对象：目标，规则：沉默阻止技能)

Rule：沉默阻止技能
挂载对象：棋子
触发器：当前棋子.使用技能前
code：
    如果 获取长度(容器：获取状态(目标：当前棋子，类型：沉默)) > 0：
        阻止当前事件
```

沉默引用通用定义与独立Rule，不创建鸣人专属状态。可见即可驱散，按普通叠加处理，创建回合不递减。Rule去重且不随状态自动删除，状态不存在时不阻止技能。

沉默不依赖伤害成功：blocked但目标仍有效时仍附加；目标被杀死/离场则后两句按失效引用规则跳过，不读死者生命、不写fallback、不改成整次技能释放失败。准备时没有合法敌人仍按目标选择规则拒绝；效果阶段目标失效不追溯退款。范围默认最小距离1，敌友按阵营，普通伤害统一入口负责防御和取整。

## 率先出阵

```text
Cluster：率先出阵
成员：率先出阵被动Skill、率先出阵Rule

Rule：率先出阵
挂载对象：棋子
触发器：游戏开始时
code：
    设置上场顺序(棋子：当前棋子，n：1)
```

被动不增加主动按钮，不产生行动点/充能消耗、冷却或每局主动使用次数。开局Rule先于最终部署顺序确定执行；当前棋子指阵容中已创建的该实例，不要求先站到棋盘上。这里只修改顺序，不直接召唤、修改坐标或强制把别人挤出棋盘。n沿已确认从1开始的插入位置；通用多实例同位插入顺序与越界策略仍是工程接口细化项，不为鸣人新建专用排序器。
