冰冻采用同一公共StatusTag定义，强度1、持续1、可见且可驱散，按普通叠加及创建回合不计时长规则。存在该状态即限制主动普通移动/使用技能；不监听位置改变来阻止传送，不引入可行动标签。Rule独立挂载并按宿主+定义去重，状态移除后查询为空自然无作用。旧隐藏freeze-prevent仅转发这两项检查，新Cluster引用公共Rule而不生成重复检查的技能按钮。

用户已明确伤害blocked仍冰冻，撤回基线damageResult.success依赖；死亡目标使附加状态/Rule语句失效。不是先阻止伤害再退还技能费用。

```text

    新建【元组<棋子>】变量【周围敌军】 = 目标选择器(
```

## 灵魂汲取

```text
Skill：灵魂汲取
触发器：使用技能
行动点消耗：4
充能点消耗：0
冷却：2
每局使用次数：不限
code：
    新建【元组<棋子>】变量【敌军】 = 目标选择器(
        类型：元组<棋子>，方式：自动，范围：全图，筛选条件：{关系：敌方}
    )
    如果 获取长度(容器：敌军) == 0：
        返回 使用失败("没有存活的敌方棋子")
    新建【元组<棋子>】变量【有序敌军】 = 排序(
        容器：敌军，依据：(棋子) => 棋子.当前生命值，顺序：升序
    )
    新建【棋子】变量【目标】 = 有序敌军[1]
    新建【数值】变量【最大生命快照】 = 目标.最大生命值
    新建【数值】变量【波及伤害】 = 最大值(1, 最大生命快照 × 0.3)
    造成伤害(目标：目标，类型：真实，伤害量：999，伤害来源：当前棋子)
    新建【元组<棋子>】变量【剩余敌军】 = 目标选择器(
        类型：元组<棋子>，方式：自动，范围：全图，筛选条件：{关系：敌方}
    )
    造成伤害(目标：剩余敌军，类型：普通，伤害量：波及伤害，伤害来源：当前棋子)
```

稳定排序保留相同生命目标的原查询顺序，等价于旧reduce仅在严格更低时替换，不随机挑同血目标。首击是999真实伤害而非强制死亡，可被阻止；原目标若仍存活，会进入第二次全图查询并再次受波及。波及输入取首击前最大生命快照，不读取已死亡对象；0.3倍率与最少1在最终整数结算保持基线，不是按实际首击伤害计算。空剩余列表无效果，首击后不因无目标而返回失败。
