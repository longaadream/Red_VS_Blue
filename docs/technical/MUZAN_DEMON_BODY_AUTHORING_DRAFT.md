# 无惨之躯作者代码

基线muzan-demon-body及rule-muzan-damage-reduction：AP1、CP0、CD3、每局不限。按已确认统一位移、真实经过路径、通用定身和独立减伤Rule组合，不新增无惨专用位移模块。此为完整作者草案，未修改运行引擎。

```text
技能：无惨之躯
触发器：使用技能
行动点消耗：1
充能点消耗：0
冷却：3
每局使用次数：不限

code：
    新建【地格】变量【终点】 = 目标选择器(
        类型：地格，范围：6，
        筛选条件：{
            可行走：true，被占用：false，
            同行或同列：true，排除当前位置：true
        }
    )
    新建【位移结果】变量【结果】 = 位移(
        棋子：当前棋子，起点：当前棋子.位置，终点：终点，
        敌军可通过性：true，友军可通过性：true，
        不可通行地格可通过性：false，中间地格是否经过：true
    )
    如果 结果.成功 == false：
        结束
    如果 当前棋子.当前生命值 <= 0：
        结束

    新建【元组<棋子>】变量【敌军】 = 筛选(
        容器：结果.经过棋子，条件：(棋子) => 棋子.阵营 != 当前棋子.阵营
    )
    新建【集合<棋子>】变量【已结算】 = {}
    新建【数值】变量【伤害量】 = 当前棋子.攻击力 × 0.75
    遍历【敌军】中的每一项【目标】：
        如果 集合包含元素(集合：已结算，元素：目标)：
            继续下一次
        加入集合(集合：已结算，元素：目标)
        造成伤害(
            目标：目标，类型：普通，伤害量：伤害量，伤害来源：当前棋子
        )
        如果 目标具有【定身】状态 == false：
            附加规则(挂载对象：目标，规则：定身Rule，来源：当前棋子)
        附加状态(
            目标：目标，类型：定身，强度：1，持续时间：1，来源：当前棋子
        )

    如果 当前棋子.当前生命值 <= 0：
        结束
    如果 当前棋子具有【无惨之躯减伤】状态 == false：
        附加规则(挂载对象：当前棋子，规则：无惨之躯减伤Rule，来源：当前棋子)
    附加状态(
        目标：当前棋子，类型：无惨之躯减伤，
        强度：1，持续时间：1，来源：当前棋子
    )
```

```text
Rule：无惨之躯减伤
触发器：当前棋子.受到伤害前

code：
    如果 当前棋子具有【无惨之躯减伤】状态：
        当前事件.伤害量 = 当前事件.伤害量 × 0.5
    否则：
        移除规则(规则：当前规则)
```

定身使用千鸟已确认的共享定义/Rule，仅阻止普通移动；不因无惨之躯另起专属状态名。状态与Rule分别添加，显示定义可见即可驱散。减伤只判断状态存在，不因叠加强度再乘一次50%；不把层数自动解释成额外减伤倍率。整数伤害取整与正伤害最少1在引擎统一处理。

伤害量在完成位移后读取并固定，目标按实际经过顺序逐个结算，不以旧预测路径造成伤害。每个目标至多一次，受伤被挡但仍存活时仍定身；死亡/失效后状态和Rule附加语句失效。已经经过但随后移动走的棋子仍属于真实经过事实，不按终点时棋盘重新猜路径。位移过程中自身死亡则不进入后续伤害和减伤。

统一位移停最后合法落点，包括原目标无法抵达但部分位移成功的情况；覆盖基线trace必须抵达终点否则前置失败的策略，这是已批准公共政策，不新增技能fallback或资源返还。敌友可通过，不可通行地格不可通过；合法落脚仍由引擎验证。普通移动事件与位置改变/路径接触事件继续分开，沿途接触逐格处理。

定身与减伤按正常状态叠加、所属玩家回合末减少且创建回合不计。重复Rule安装/旧状态消失而Rule未清理的边界与千鸟一致，公共安装策略待实施核对，不靠relatedRules自动关联状态生命周期。基线状态旧剩余时间字段映射应遵守已确认作者计时，不另造专用计时器。
