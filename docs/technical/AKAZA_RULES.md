# 猗窝座（RED-217）

暗方（evil），生命16、攻击4、防御0、移动5；内容 ID `dark-akaza`。

| 技能 | 费用 | 规则 |
| --- | --- | --- |
| 先手斗气 | 被动 | 对当前满生命值敌军造成的伤害提高50%。每个目标在本次命中前独立判断，在防御和护盾前应用增伤。 |
| 破坏杀·乱式 | AP1 / CD1 | 选择敌军（1），造成1倍伤害；本回合自己已对该敌人造成实际生命伤害时，改为1.5倍，只有一次伤害结算。 |
| 破坏杀·灭式 | AP2 / CD2 | 选择一个正方向，对该方向4格内全部敌军造成伤害：距离1格1.25倍，2格1倍，3或4格0.5倍。 |
| 瞬步 | AP0 / CD3 | 选择自身中心7×7内本局曾被自己伤害过的存活敌军，传送至其正方向相邻的合法空格；成功传送后永久攻击力+1，可叠加。 |

猗窝座实际造成正的生命伤害后，通过 afterDamageDealt 给目标添加隐藏永久 statusTag，记录来源实例 sourceId 和 lastDamageTurn。完全护盾吸收或抵挡不添加。多只猗窝座的标记分别保存，不互相借用。乱式在本次命中前检查该来源标记的回合编号；瞬步只要求存在该来源的本局标记。两者均不扫描伤害日志。

灭式是方向范围伤害，不是弹射物，不受友军或墙体遮挡；友军不受伤。目标按距离顺序处理。倍率使用现有伤害取整约定，先计算技能基础伤害，再应用先手斗气和目标防御等修正。

瞬步的7×7指 Chebyshev 距离不超过3，包括角落。目标仍需为存活敌人，且有合法相邻落点。取消、被阻止、无法实际移动时不增加攻击；不消耗充能，不会直接伤害选中的敌人。

复用现有逐目标 `beforeDamageTaken`、`afterDamageDealt`、状态、统一位移与属性增量接口。满血增伤规则按伤害来源匹配被动持有者、按每个受击目标判断。技能关键词不添加普通叙述词。

声明式选取补充通用可选字段 `requiredTargetStatusFromSource`（要求目标指定状态来自施法者）和 `excludeSourceLanding`（合法邻格不忽略施法者占位）。供候选高亮、提交校验和 AI 共用，不新增伤害历史接口。新增字段后需重建各入口引擎。
