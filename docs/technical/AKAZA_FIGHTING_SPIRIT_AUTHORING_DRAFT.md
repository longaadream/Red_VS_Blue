# 先手斗气作者代码

基线akaza-fighting-spirit与rule-akaza-fighting-spirit；被动Cluster包含规则，无手动使用入口。基线规则在beforeDamageTaken阶段改写入伤量，草案保留该阶段，不擅自提前到造成伤害前。设计草案，未实施。

```text
被动技能：先手斗气

Rule：
    触发器：全场.受到伤害前

    如果 当前事件.伤害来源 != 来源：
        结束

    如果 当前事件.目标.阵营 == 来源.阵营：
        结束

    如果 当前事件.目标.当前生命值 != 当前事件.目标.最大生命值：
        结束

    当前事件.伤害量 = 当前事件.伤害量 × 1.5
```

来源指规则来源猗窝座实例，伤害来源指本次实际来源；不混用旧上下文反向命名的sourcePiece/targetPiece。是否正伤害由引擎派发入口判别，不在Rule重复写伤害量<=0过滤。状态/Rule优先级继续按基线影响此加成与阻挡的先后；不因简化草案改写原规则优先级。无新模块需求，运行与日志验证待实施。
