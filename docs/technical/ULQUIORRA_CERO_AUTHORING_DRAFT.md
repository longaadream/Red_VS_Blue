# 乌尔奇奥拉：虚闪与黑虚闪作者代码

核查origin/main技能定义。虚闪为初始技能，黑虚闪为归刃授予技能；两者AP1、CP0、不限次数，虚闪CD0、黑虚闪CD1。原magical统一为已确认普通伤害，不继续区分法术/物理。只是完整作者草案，未修改运行引擎。

```text
技能：虚闪
触发器：使用技能
行动点消耗：1
充能点消耗：0
冷却：0
每局使用次数：不限

code：
    新建【棋子】变量【目标】 = 目标选择器(
        类型：棋子，范围：4，筛选条件：{关系：敌方}
    )
    新建【数值】变量【数值】 = 当前棋子.攻击力 × 0.5
    造成伤害(目标：目标，类型：普通，伤害量：数值，伤害来源：当前棋子)
```

```text
技能：黑虚闪
触发器：使用技能
行动点消耗：1
充能点消耗：0
冷却：1
每局使用次数：不限

code：
    如果 获取状态强度(目标：当前棋子，类型：归刃) == 0：
        返回 技能释放失败
    新建【棋子】变量【目标】 = 目标选择器(
        类型：棋子，范围：2，筛选条件：{关系：敌方}
    )
    如果 目标.攻击力 >= 当前棋子.攻击力：
        返回 技能释放失败
    新建【数值】变量【数值】 = 当前棋子.攻击力 × 2
    造成伤害(目标：目标，类型：普通，伤害量：数值，伤害来源：当前棋子)
```

黑虚闪基线availability要求有归刃；灵压由通用前置条件表达，拒绝发生在效果与费用提交前，不在Rule里读skillId字符串。目标失效沿引擎语句无效规则，攻击小数由引擎向下取整。缺省CP由基线缺失chargeCost且通用默认0核对；授予时不同时擅自发动。
