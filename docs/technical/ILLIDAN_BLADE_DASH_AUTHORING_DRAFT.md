# 战刃挥刺作者草案

作者设计，未接入运行引擎。基线illidan-blade-dash：行动点2、充能点0、冷却1、每局次数不限。最新决定统一遇阻停在最后合法落点；位移结果提供实际经过地格与实际经过棋子元组，不使用预查询路径冒充执行结果。

```text
技能：战刃挥刺
触发器：使用技能
行动点消耗：2
充能点消耗：0
冷却：1
每局使用次数：不限

code：
    新建【地格】变量【终点】 = 目标选择器(
        类型：地格，范围：6，
        筛选条件：{
            可行走：true，被占用：false，
            同行或同列：true，排除当前位置：true
        }
    )

    新建【位移结果】变量【路径】 = 位移(
        棋子：当前棋子，起点：当前棋子.位置，终点：终点，
        敌军可通过性：true，友军可通过性：false，
        不可通行地格可通过性：false，中间地格是否经过：true
    )

    新建【元组<棋子>】变量【敌军】 = 筛选(
        容器：路径.经过棋子，
        条件：(棋子) => 棋子.阵营 != 当前棋子.阵营
    )

    造成伤害(
        目标：敌军，类型：普通，
        伤害量：当前棋子.攻击力，伤害来源：当前棋子
    )
```

伤害对目标集合同时结算。没有实际经过敌军时不产生路径伤害，不另写位移失败fallback。选择器的同行/同列等条件采用结构化筛选；字段最终命名待实现时与统一编辑器对齐。

待工程对齐：实际经过集合的路径事件与落脚回退边界、集合中重复遭遇同一实例的处理、第一步不可通过时的准备阶段拒绝及提示。确认返回字段不表示上述所有边界已验证；基线requireTraversableFirstStep交互约束须在实施时保留或另行明确变更。当前未修改技能数据、描述、动画或日志。
