# 作者语句使用手册

更新：2026-10-14。本文是面向效果编辑器作者的中文使用手册，配套[作者语句接口参考索引](AUTHOR_STATEMENT_REFERENCE.md)。它把[作者语句接口目录](AUTHOR_BLOCK_INTERFACE_CATALOG.md)中的 105 个数据条目逐项展开（不计表头）；目录、[技能与手牌模块接口](SKILL_MODULE_INTERFACES.md)和[作者运行实例类型草案](AUTHOR_INSTANCE_TYPES_DRAFT.md)仍是契约来源。

## 先读这几条

本文描述的是作者语言的设计契约。**设计过的接口不等于当前运行时已经完整支持**：目前应把每项标记为“设计-确认”“设计-部分”或“设计-待定”来理解；除工作台实际注册的模块外，不能在游戏中假定它已经可拖入或已经能结算。Cluster 初始化、实体 extension、稳定实例引用和结构化代码块已经有定向运行入口与测试证据（见下表及“运行接入补充”），其余作者目录仍在逐项迁移；旧角色代码也不能反向扩大契约。

最新明确决定优先于历史草案。参数默认值尚未在契约中明确时不要自行假定；这不等于参数必填，是否可省略要看该接口的明确说明。“未定”表示契约未冻结，不表示返回空值或可以自行选择。编辑器应在保存/编译前拒绝非法类型、缺少必需连接和契约错误并给出诊断；进入运行后的语句问题则按最新引擎目标记录上下文后跳过，独立后续继续，不能让游戏卡死，也不能把错误静默吞掉。

本文的伪代码是可读的有类型积木预览，不是要求作者手写的 JavaScript/TypeScript：在编辑器中从模块列表添加行，在蓝色参数芯片中选择字面量、变量或嵌套表达式。每段示例只展示一个用法；复杂技能仍由这些行按顺序组合。

### 当前工作台怎样开始

2026-10-14 验收修正：新增变量操作统一为以下三种句式；底层按棋子、玩家或全局拆分的读写接口留给编译器，不再作为多个新增语句入口。接口注册总数不等于作者菜单项数。

| 作者操作 | 句式与示例 |
| --- | --- |
| 新建局部变量 | 新建【数值】变量【伤害量】＝【当前棋子.攻击力 * 1.5】 |
| 声明扩展变量 | 在【当前玩家】的扩展中新建【数值】变量【计数】＝【0】 |
| 赋值 | 【当前玩家.扩展变量.计数】＝【当前玩家.扩展变量.计数 + 1】 |

字段读取、四则、比较和逻辑运算写在表达式中。选择器返回值须先保存为作者指定的名称，后续再引用；“目标”不隐式表示最近一次选择。统一声明中的类型、名称和初值可以先作为草稿一起编辑，再应用。中文输入法选字时不触发编辑器补全、提交或退出。

扩展声明的对象不限于棋子、玩家或全局：手牌、技能、规则、状态、能力组和地格效果的具体实例均有各自的扩展。保存实例到局部变量后仍按该实例读写，不能按同名定义批量修改。例如，在选中的手牌上声明 `倍率` 再赋值，只影响那一张牌；效果必须显式读取该变量才会改变数值。

不要把维伦与泰兰德的强化混同。已商定的维伦预言强化归属手牌实例，由该牌的规则在使用前改写本次局部数值，永久保留；泰兰德月神赐福归属玩家，玩家扩展保存倍率，由玩家规则在下一次圣光牌使用前改写本次局部数值、成功使用后消费。详见各自作者草案，通用扩展测试不代表这两项技能全部已迁移验收。

2026-10-14 补充确认：能力组是实现一项完整主动或被动能力所需的技能、规则、状态、卡牌与扩展声明的集合；一个棋子可有多个能力组。按底层类型汇总一个棋子的全部成员，不等于已完成逐能力分组。共用卡牌或状态定义可以在多组引用，定义引用不等同于获得能力时立即附加该状态或生成手牌。

描述动态插值已接入，例如 `造成 {当前手牌.扩展变量.伤害量} 点真实伤害。`。描述编辑提供“插入表达式”，在光标位置插入占位符，支持中文字段、扩展变量、索引、算术与逻辑表达式；渲染使用同一作者表达式解析器，只读求值，不消耗赐福、不触发规则、不执行随机或效果函数。具体显示链路和状态更新验证见本批验收记录，静态文本保存不能替代动态运行验证。

占位符支持半角 `{…}` 与全角 `｛…｝`。数值结果保留小数；需要整数显示时写 `{向下取整(当前手牌.扩展变量.伤害量 * 1.5)}`。布尔值显示“是/否”；缺失字段显示“未赋值”，并提供描述诊断。元组索引从 1 开始；结构与映射按实际键访问。描述当前登记的纯函数为加减乘除、余数、幂、向下取整、绝对值、最小值和最大值，尚不支持任意作者函数、随机、距离或容器查询调用。描述更新沿用战局快照与界面更新入口，不增设轮询。

图文操作见[开发者工作台使用说明](../../electron-editor/ui/developer-guide.html)。旧资源已有读写节点仍可打开编辑，底层编译器继续检查实际宿主的可写字段；只读字段与棋盘坐标不能借赋值绕过游戏效果。

按当前工作台的可观察路径操作：

1. 从 **棋子** 列表进入一个棋子；默认会进入技能编辑面板。需要编辑卡牌、Rule 或其他内容时，从关联入口进入对应内容页。内部路由名不属于作者接口，不需要记忆。
2. 在语句编辑区点击“添加语句”，从模块列表选择类别和模块。参数显示为蓝色芯片；点击芯片打开类型匹配的表达式编辑器，不能把显示文字当作实例 ID。
3. 编辑器顶部的“保存”是当前内容的保存入口。保存前修正类型错误或未完成的语句；资源包使用当前**已保存**内容，不会自动把未保存草稿当作接受结果。
4. “生成资源包”读取当前保存内容和图片。当前界面展示资源包流程，但“已保存”与“已接受/通过验收”仍是两件事；不能把生成按钮当作运行时发布或人工验收。
5. 技能图标槽目前不是作者语句契约的一部分；不要因为界面没有 skill icon 就在代码里伪造图标字段。状态的 `visibleStatus` 表现层可以读取已提供的 `iconPath` 资源路径，这是显示数据，不是状态身份或规则触发条件；状态导航使用当前新增的状态入口。

设计目录中的模块可能尚未出现在模块列表，或只在训练/预览路径出现。看到“设计-确认”时仍需检查当前编辑器是否注册、当前引擎是否实现，并在验证记录中分开写“设计通过”和“运行通过”。

## 通用字段、元组和扩展写回（2026-10-13）

最新作者输入使用下列统一句式。下表旧模块名称是底层兼容接口名称，不代表需要在作者界面分别添加“读取字段”“读取变量”等步骤。

```text
新建【数值】变量【amount】 = 当前棋子.攻击力 * 1.5
amount = amount + 2
对 目标 造成 amount 点 普通 伤害，来源为 当前棋子
```

变量名可以使用英文或中文，表达式保留手动输入。输入框的联想跟随光标，Tab 确认候选；右侧展开栏只是同一参数的较大编辑空间。空参数和比较式的空右值以灰字提示预期类型；右键或 Shift+F10 查看变量类型与字段。提示不是代码，界面不会伪造运行时数值。

每条有返回值的语句可展开“保存返回值”，给结果命名，后面直接使用该名字。局部变量每次读取当前值；普通计算结果保存计算当时的值。大括号构造元组，元组从 1 开始并保留重复项。`坐标(x,y)` 构造坐标；坐标字段为 `.x`、`.y`。

伤害与治疗不再要求作者区分单体和批量。`目标={A,B}`、`数值=3` 表示每个目标使用 3；`数值={3,5}` 表示逐项对应。长度不匹配时整条语句无效，不截断或循环复用。失效目标保留结果序号；同一目标重复出现时按元组顺序分别结算。来源可为棋子、玩家或具体手牌实例；“当前手牌”是正在执行的那张实例，不能用卡牌名称代替。

棋子来源在实际派发时必须仍是原来的在场存活实例。反应效果排队后来源死亡、离场或被同编号的新对象替换，对应效果跳过并记录诊断，独立后续继续。逐项数值元组的前一项若触发反击导致来源失效，剩余项返回 `skipped: "source-unavailable"`，已经结算的项目保留。作者无需加存活检查，也不会自动改用所属玩家作为来源。

这条规则适用于尚未开始结算的延迟来源。若本次结算已经通过 `来源捕获` 取得棋子实例，后续的“读取捕获来源字段 / 写入捕获来源字段”仍针对同一个已认证对象；对象在同一结算中离场不会改成另一个棋子，也不会丢失这次已开始的同步结算。不要把这种已捕获来源写入延伸成延迟伤害的存活豁免。

新模板召唤接受 `templateId、name、maxHp、currentHp、attack、defense、moveRange、ownerPlayerId、faction、isCore、skills、rules、statusTags、extension`；可省略当前生命、所属玩家、阵营、核心和空列表，默认满血、沿用来源归属、召唤物身份。显示选项使用同名字段，例如 `{name:"鸣人",currentHp:100,maxHp:100}`；它在召唤事件后的第一份公开显示前安装，不会先显示真实召唤物再更换。后续仍可使用“设置棋子显示”。

原实例回场必须引用离场时绑定的同一个实例；缺失绑定不会制造替代棋子。回场保留核心身份、归属、阵营、冷却、次数、状态和扩展变量，可明确设置回场生命。新召唤和回场均经权威生命周期提交，不能直接写棋子坐标。此通用宿主已有定向运行测试，旧召唤内容的作者图迁移仍在继续。

已声明扩展值可以直接写 `当前玩家.extension.奖励`。自定义外部扩展根可以手动输入；未存在时按无效依赖跳过。已知结构中拼错字段会立即报告，不猜成一个新字段。反应事件里排队的伤害/治疗还未结算时，只提供排队标记；实际结果续接正在接入，不可提前读取伪造的伤害或击杀结果。

同类值共用接口，不按角色或每种值类型新增模块。例如比较关系写为 `目标.阵营 == 当前棋子.阵营`，数量使用“获取长度”，取第一项使用 `[1]`；当玩法确实要找符合条件的第一项时，使用“查找”，而不是先把整个集合排序。查询没有匹配可以返回空值，失效引用则只让相关语句跳过；这两种情况不同。

“获得技能”和“移除技能”可以填入棋子或玩家，持有者类型随输入确定。技能使用内容库的定义引用；它和“当前技能”实例不同，不能拿定义引用修改实例的冷却或次数。例如：`为 所属玩家 添加技能 暴风雪伤害`。实例字段仍通过具体实例编辑。

伤害可以额外指定“击杀归属”，省略或空值时沿用伤害来源的正常归属。此选项只决定击杀收益，不替换伤害来源或事件身份。例如：`对 当前棋子 造成 999 点真实伤害，来源为 当前棋子，击杀归属于 对方玩家`。归属玩家失效时，整条伤害语句在结算前拒绝，不留下部分效果。

清理离场对象留下的记录时，可以用“查询战场与墓地记录标识”，逐项调用“移除记录中的规则”。该操作只清理已有规则记录，不使墓地棋子恢复行动，也不会生成一个新棋子。普通在场能力的获得、失去仍使用正常规则生命周期接口。

字段赋值会根据所选字段确定输入类型。例如 `当前棋子.生命上限 = 当前棋子.生命上限 + 5` 填数值，`状态.名称 = "标记"` 填文本，`状态.是否可见 = true` 填布尔值；不需要再选一次字段类型。生命字段写入不能绕过死亡、复活或治疗结算：要造成伤害、恢复生命、召唤或复活时，使用对应的权威效果语句。生命上限不得降到当前生命以下，非法写入记录诊断并跳过，独立后续继续。

已保存棋子记录的表现标记 `showFreezeEffect` 也是布尔字段，使用统一的 `piece.write-field` 已保存范围赋值；不能用当前棋子范围写入这个保存字段。字段类型由所选字段自动推断，旧的数值保存字段仍按数值输入。正式规则执行中读取时间使用只读的 `本次执行时间`，它来自本次执行绑定的确定性宿主时钟，可用于稳定标识和回放，不直接读取全局真实时钟。

状态字段写入作用于选中的具体实例。同名状态有多个实例时，修改一个不会自动修改其余实例；实例身份字段不能赋值。只有显式遍历并写入，才会修改多个状态。

“从模板创建卡牌”接受卡牌模板、卡牌标识和名称；名称、标识、说明、扩展初值和省略字段都可以引用表达式。它返回一个有类型的卡牌定义引用，可以保存在本次执行变量或扩展字段，再交给“加入手牌”。例如先创建 `新卡 = 从模板创建卡牌(护甲模板, 标识表达式, 名称表达式)`，再为所属玩家加入 `新卡`；生成定义和获得一个手牌实例是两个独立步骤，每次获得仍经过手牌容量与获得事件流程。

选项选择默认在取消时结束当前入口；需要“取消这一项但继续后续”时，可填写同返回类型的“取消后继续并返回”。例如飞雷神选择返回 `"yes"` 或 `"no"`，取消值设为 `"no"`，取消就按不触发处理；未填写时不会猜一个选项。这个设置与“上一步”导航不同，单选及多选都保留各自的返回类型。

多次收集日志或目标时，使用一个元组变量并显式赋值，例如 `日志列表 = 拼接(日志列表, {新日志})`。后续读取变量会得到最新列表；之前保存的长度或其他计算结果仍保持当时的值，不会跟着变量变化。

| 语句 | 用途 | 例子 |
| --- | --- | --- |
| 读取字段 | 从实例或记录取得某个有类型的值 | `伤害量 = 当前棋子.攻击力 × 1.5` |
| 比较值 | 比较同类型的值或实例身份 | `目标.阵营 != 当前棋子.阵营` |
| 构造单项元组 | 把一个值作为元组的一项，保留元素类型 | `路径 = {原棋子标识}` |
| 拼接元组 | 返回按顺序连接的新元组，保留重复项 | `完整路径 = 路径 + {"turns"}` |
| 反转元组 | 返回相反顺序的新元组，不改变原值 | `从最新到最早 = 反转(动作记录)` |
| 读取记录字段 | 按一个完整字段名读取有类型的副本，可使用动态键 | `区域 = 区域记录[原棋子标识]` |
| 删除记录字段 | 产生不含指定键的新记录；需显式写回才会改变对局 | `剩余区域 = 从区域记录副本删除 原棋子标识` |
| 排序 | 用逐项表达式生成排序依据，返回新元组；相等时保持原顺序 | `棋子列表按 每项.生命值 升序排列` |
| 随机选取 | 使用对局种子选择一项，空元组不消耗随机数 | `目标 = 从敌方列表随机选择一项` |
| 声明扩展变量 | 未声明时初始化；同类型已有值保留 | `在【玩家.extension】中新建【数值】变量【累计值】 = 0` |
| 读取扩展变量 | 获取指定类型的值或副本，支持自定义字段路径 | `记录 = 读取 全局.extension.区域记录` |
| 写入扩展变量 | 校验后显式提交，不自动新建缺失变量 | `全局.extension.区域记录[原棋子标识].turns = 剩余回合 - 1` |
| 声明本次执行变量 | 保存这次执行中的有类型值，可在分支和循环中更新 | `新建【数值】变量【总伤害】 = 0` |
| 读取本次执行变量 | 取得变量当前的值，保留声明类型 | `本次伤害 = 读取 总伤害` |
| 写入本次执行变量 | 更新同类型的值，非法写入不覆盖原值 | `总伤害 = 总伤害 + 伤害结果.实际伤害量` |

读取结构化扩展值后，改变副本不会改变对局，必须调用写入语句。根字段后端保留旧内容的存储位置；路径也可以使用文本元组，例如 `{"piece.a", "turns"}`，其中 `piece.a` 是一个完整键。字段缺失、类型错误时由引擎记录问题并跳过相关语句，作者不用额外包一层“存在才执行”。

本次执行变量支持与 extension 相同的值类型。它只在这次技能、规则或选择续接的执行中有效；需要跨回合或跨选择步骤保存时使用对应对象的 extension。声明语句的变量结果可以命名，再从后续蓝色参数的变量列表引用；读出的结构值是副本，更新时需使用写入语句。

可以先声明变量，再在不同分支赋值。尚未赋值就读取时，这条读取及依赖它的语句失效，独立后续继续。Skill、Status、Rule、Card、Cluster 和 tile-effect 等具体实例引用在明确进入 extension、挂起或存档边界时保存稳定身份；JSON/挂起恢复按该身份查找，已移除或失效的引用直接失效，不按数组位置或同名实例重定位。当前执行变量和只服务于本次调用的 opaque 句柄仍不能序列化到 extension，也不能跨执行复用。

上述接口已有注册和定向运行测试。全部旧内容的同类替换与最新工作台操作仍在验收，不能将本节理解为全目录已完成。

## 记号、身份与执行边界

`棋子`、`手牌`、`状态`、`Skill`、`Rule`、`Cluster` 是具体运行实例的引用；同名实例仍然不同。`棋子定义`、`手牌定义`、`状态定义`、`Cluster 定义` 是配置引用，不能当成实例使用。实例引用赋值保留身份，数值赋值保存读取当时的值。只有显式的复制接口创建副本，构造相同字段的结构体不能伪造引擎实例。

纯表达式只读取、计算或构造值，不能造成伤害、随机抽取、玩家等待或属性写入。`造成伤害`等语句即使有返回值仍是有副作用的执行语句；不能拖进费用公式，也不能因预览或重绘重复执行。随机操作使用可注入、可记录的种子流；手动选择会等待玩家；自动查询只读。

失效引用使依赖它的整条语句失效，独立后续语句继续；这不是异常处理，也不是把错误当成 `false`。事件前阶段按字段契约可以写，后事件结果只读；后事件 Rule 仍可调用正常效果。棋子坐标、身份、技能列表等必须通过专用权威入口更新，不能用任意字段赋值绕过生命周期。

不要为普通操作额外编写“读取棋子存活 → 如果存活才执行”。需要存活棋子的模块会在引擎内部检查；对象失效后，其依赖语句跳过，独立的玩家级效果仍继续。例如飞雷神直接判断棋子阵营关系并选择后续，作者不再重复检查水门、标记者或攻击来源的生命值。只有技能设计本身需要“存活时做 A、死亡时做 B”这样的不同效果，才显式使用存活条件。该规则不禁止死亡事件读取合法的历史信息。

字段读取和基础运算已经能表达的含义，应直接组合。例如敌我关系用 `当前棋子.阵营 == 目标.阵营`、`当前棋子.阵营 != 目标.阵营`；是否为本玩家用 `目标.所属玩家 == 当前玩家`。不另外添加“判断敌我”“玩家是否为队友”模块。工作台中的阵营是战斗队伍身份，2v2 的同队不同玩家具有相同值；它不等于角色内容的善恶分类。

在比较语句的左右参数中选择字段表达式即可，不必先创建单独的读取语句或填写内部阵营标识。字段不存在、棋子失效时由引擎处理，作者无需补一个存在性判断。需要复用计算结果时，仍可将它存入变量。

**最新运行容错目标（设计已确认，尚未全面落实）：** 运行中的错误语句、依赖无效结果的语句都记录错误并跳过，不能阻断独立后续；循环达到上限或挂起路径出现异常时退出当前路径并释放等待，不把正常等待玩家误报为错误。已经成功的治疗、费用、快照或其他效果不得因后续失败而重放或回滚。编辑器的类型/契约拒绝和运行时的容错跳过是两层行为，不能用后者替代前者的诊断。

## A. 组织、类型、变量与 extension

### 组织积木

<a id="stmt-org-entry"></a><a id="stmt-org-effect"></a><a id="stmt-org-value"></a><a id="stmt-org-bool"></a><a id="stmt-org-control"></a><a id="stmt-org-definition"></a>
<a id="stmt-org-category"></a>
#### 入口、执行语句、值表达式、布尔表达式、控制结构、定义与声明

**用途：** 这是六类编辑器积木的组织入口；它们是目录中的一个分类条目。入口建立事件上下文；执行语句按顺序改变状态或等待交互；值/布尔表达式嵌入输入槽；控制结构包含子语句；定义与声明配置可复用内容。

**签名/结果：** 不是单一运行时函数。入口位于执行段顶部；执行语句可以有结果；表达式按声明类型输出；控制结构拥有局部作用域；定义项保存 Skill、Rule、StatusTag、模板或结构体定义。

**边界：** 分类不新增战斗规则，也不保证每类已经在 UI 注册。

**例：** 在“使用技能”入口下放“目标选择器”（可能等待玩家的执行/交互语句），把“距离(…)”放进“数值表达式”芯片，把“目标.当前生命值 > 0”放进“布尔表达式”芯片，最后放“返回使用成功”（控制结果）。

### 类型

<a id="stmt-type-base"></a>
#### 基础值：数值、布尔、字符串

**用途：** 表达计算量、判断和显示文字。数值允许小数；整数属性写入或效果结算由引擎向下取整；整数分半使用 `n / 2` 的除法阶段取整约定。

**签名/结果：** `数值`、`布尔`、`字符串`；字符串可以保存到变量、extension 和容器，也可以由显示模板重新求值。

**边界：** 字符串不能代替实例、定义、标签或区域引用；未冻结的除零及混合精度边界不要自行补规则。

**例：** `新建【数值】变量【一半】 = 当前棋子.攻击力 / 2`。

<a id="stmt-type-board"></a>
#### 场上引用：玩家、棋子、地格、区域

**用途：** 指向场上的具体对象。所属玩家用于控制和资源；敌友关系按战斗阵营判断，两者不能混用。

**签名/结果：** `玩家`、`棋子`、`地格`、`区域` 引用；引用可以进入查询、效果和 extension。

**边界：** 无效或离场实例不能执行要求在场的动作；保存引用不等于获得写坐标权限。

**例：** `新建【棋子】变量【目标】 = 目标选择器(类型：棋子，筛选条件：{关系：敌方})`。

<a id="stmt-type-definition"></a>
#### 内容定义引用：模板、手牌、状态、地形、标签、Skill/Rule/Cluster 定义

**用途：** 指向可复用的内容配置，供创建实例、筛选或安装使用。

**签名/结果：** `棋子定义/模板`、`手牌定义`、`状态定义`、`地形定义`、`标签引用`、`Skill/Rule/Cluster 定义引用`。

**边界：** 定义引用不是运行实例；不得用显示名称字符串查找对象，也不能以定义引用直接移除某个实例。

**例：** `获得手牌(玩家：当前玩家，手牌定义：圣光惩击)` 使用定义创建一张新牌。

<a id="stmt-type-instance"></a>
#### 运行实例：手牌、StatusTag、Skill、Rule、Cluster

**用途：** 代表一次实际获得、附加或运行中的对象，可保存身份、来源、extension 和生命周期数据。

**签名/结果：** `StatusTag`（中文界面可写“状态”）、`Skill`、`Rule`、`Cluster`、`手牌` 实例引用。Skill 有当前冷却/次数等字段；Rule 有挂载对象/来源；Cluster 有 Skill/Rule 成员。

**边界：** 同定义多实例互相独立；StatusTag 不自动安装 Rule；Skill/Rule 单实例操作不等于 Cluster 整组操作。

**例：** `新建【状态】变量【盾】 = 获取状态(目标：当前棋子，类型：圣盾)[1]` 保存的是某一份状态实例。

<a id="stmt-type-geometry"></a>
#### 几何值：方向与坐标

**用途：** 表达朝向和相对格偏移。

**签名/结果：** `方向` 支持上、下、左、右；`坐标` 为 `{x,y}` 二维整数值，可组成 `元组<坐标>`。

**边界：** 坐标不是地格实例；方向不包含距离、落点或目标棋子。空间选择器的最小距离默认 1，包含中心必须显式写 0。

**例：** `新建【方向】变量【朝向】 = 目标选择器(类型：方向，中心：当前地格，方向范围：正方向)`。

<a id="stmt-type-result"></a>
#### 结果结构：伤害、治疗、位移、路径查询结果

**用途：** 保存权威入口返回的事实，供后续条件和日志使用。

**签名/结果：** `伤害结果`、`治疗结果`、`位移结果`、`路径查询结果` 各自有独立字段；不能假定都有通用 `成功` 字段。

**边界：** 结果结构不是再次执行效果的指令；未确认字段不能自行增加。

**例：** `新建【伤害结果】变量【结果】 = 造成伤害(...)`，随后读 `结果.实际伤害量`。

<a id="stmt-type-container"></a>
#### 泛型容器：集合、元组、映射

**用途：** 组织多个同类型值。`集合<T>` 是去重 Set；`元组<T>` 是有序、可重复、可增删的 vector；`映射<K,V>` 按键取值。

**签名/结果：** `集合<T>`、`元组<T>`、`映射<K,V>`；元组索引从 1 开始，Set 没有位置索引。

**边界：** 不用 Set 内部顺序表达玩法顺序；需要前 n 项或路径顺序先得到元组。实例包含判断按身份比较，不能按显示名称去重。

**例：** `新建【元组<棋子>】变量【路径目标】 = 排序(容器：候选，依据：距离(当前棋子，项)，顺序：升序)`。

<a id="stmt-type-custom"></a>
#### 自定义值：结构体与有类型函数表达式

**用途：** 用带类型字段的结构体保存任务记录，用有类型函数作为筛选/排序的纯计算回调。

**签名/结果：** `结构体{字段:类型}`；函数形如 `(项:T) => 布尔` 或 `(a:T,b:T) => 数值`。代码块是结构化程序值，不是任意 JavaScript。

**边界：** 函数回调不能执行效果、等待交互或写属性；结构体中保存的实例引用仍按身份和有效性规则处理。

**例：** `筛选(容器：目标，条件：(项：棋子) => 项.当前生命值 > 0)`。

### 变量与 extension

**2026-10-12 编辑方式确认：** extension 候选列表只建议当前上下文已声明的字段，但这不是访问限制。作者可以自定义指定对象、变量名称、字段路径和预期类型，引用其他入口可能创建的数据。读取和赋值均不自动创建字段；不存在或类型不符时语句无效，依赖其结果的语句跳过，独立后续继续。无需添加存在性判断或 fallback。只有明确的声明语句负责创建变量。

例如，自定义读取 `当前玩家.extension.延迟任务.伤害量`，指定数值类型，把结果连接到伤害语句。没有该字段时，该伤害语句无效；独立的后续治疗仍照常结算。编辑器应提供类型选择控件，不要求手写接口表达式。

<a id="stmt-var-local-new"></a>
#### `新建【T】变量【名称】 = 值`

**用途：** 声明本次入口的局部变量并保存表达式结果。

**签名/结果：** 输入类型 `T` 和兼容值；结果是局部变量引用。局部变量不自动持久化。

**边界/权限：** 类型必须兼容；声明未完成或依赖失效时整条语句失效，不填 0 或 `false`。

**例：** `新建【数值】变量【伤害】 = 当前棋子.攻击力 × 1.5`。

<a id="stmt-var-assign"></a>
#### `变量 = 值`

**用途：** 更新已有变量。

**签名/结果：** 同类型变量与兼容表达式；无业务返回值。

**边界/权限：** 不能借赋值改变已声明类型；赋值实例引用保留身份，数值保存当前值。

**例：** `伤害 = 伤害 + 2`。

<a id="stmt-var-extension-declare"></a>
#### `在【对象.extension】中新建【T】变量【名称】 = 初值`

**用途：** 在实例附带的持久结构体中声明一个字段。

**签名/结果：** 宿主实例、字段类型 `T`、名称和初值；字段写入宿主 extension。

**边界：** 同名同类型重复声明复用旧值且不重置；同名异类型是契约错误；extension 不自动预留字段。

**例：** `在【当前玩家.extension】中新建【映射<棋子,数值>】变量【记录】 = {}`。

<a id="stmt-var-extension-write"></a>
#### `对象.extension.名称 = 值`

**用途：** 写入已经声明的持久字段。

**签名/结果：** 宿主实例、已声明字段、同类型值；无额外返回值。

**边界/权限：** 未声明字段不自动创建；可变容器要按实例复制契约处理，不共享不应共享的数据。

**例：** `当前玩家.extension.记录[目标] = 当前回合.编号`。

<a id="stmt-field-read"></a>
#### `对象.字段`

**用途：** 读取对象的声明字段，用作值或后续参数。

**签名/结果：** 对象引用 → 字段声明类型。

**边界/权限：** 字段是否可写由各字段契约决定；读取失效对象会使依赖语句失效，不能从显示名推导字段。

**例：** `新建【数值】变量【费用】 = 当前事件.伤害量`。

<a id="stmt-field-write"></a>
#### `对象.字段 = 值`

**用途：** 通过字段专用的权威写入口更新允许写入的字段。

**签名/结果：** 对象字段与兼容值；返回值依字段契约，未统一。

**边界/权限：** 不是任意对象属性写入；坐标、身份、技能列表等不能借此绕过专用生命周期。明确允许的字段见本手册“可写字段”。

**例：** `当前事件.伤害量 = 当前事件.伤害量 / 2`（仅在有权限的伤害前阶段）。

<a id="stmt-struct-constructor"></a>
#### 结构体构造

**用途：** 按声明字段构造一个普通类型值，适合任务记录、映射值和代码块参数。

**签名/结果：** `结构体{字段1:T1,...}` 的字段值 → 该结构体值。

**边界：** 结构体值不伪造棋子、Rule 或其他引擎实例身份；精确编辑器控件仍待设计。

**例：** `新建【任务】变量【记录】 = {目标：目标，剩余回合：2}`。

## B. 运算、容器与控制

<a id="stmt-expr-arithmetic"></a>
### 算术、比较、逻辑

**用途：** 计算数值并产生布尔判断。

**签名/结果：** 数值运算；`== != < <= > >=`；与、或、非。返回数值或布尔。

**边界/权限：** 纯表达式，不改状态、不等待、不推进随机；除零等错误边界仍待完整规格。整数效果/字段最终由引擎向下取整。

**例：** `如果 当前棋子.攻击力 > 10 且 当前棋子.当前生命值 > 0： ...`。

<a id="stmt-expr-conditional"></a>
### 条件取值

**用途：** 在两个兼容类型值之间选择，不执行分支副作用。

**签名/结果：** `条件取值(条件，成立值，不成立值) → 同一兼容类型`。

**边界/权限：** 纯表达式；两个值不能靠隐式字符串转换或不同实例定义硬凑类型。

**例：** `新建【数值】变量【费用】 = 条件取值(当前棋子.当前生命值 > 0，1，0)`。

<a id="stmt-expr-distance"></a>
### `距离(a,b)`

**用途：** 读取棋子或地格之间的距离，用于筛选、排序和费用计算。

**签名/结果：** `距离(棋子或地格，棋子或地格) → 数值`。

**边界/权限：** 纯查询；非法位置/失效引用不应被当作任意距离，具体距离口径须与对应规则对齐。

**例：** `排序(容器：敌人，依据：(项：棋子) => 距离(当前棋子，项)，顺序：升序)`。

<a id="stmt-expr-filter"></a>
### `筛选`

**用途：** 以有类型 lambda 保留满足条件的容器成员。

**签名/结果：** `筛选(容器：集合<T>或元组<T>，条件：(项:T)=>布尔) → 同类别容器`；查询结果是快照。

**边界/权限：** 纯查询，lambda 只能计算值；Set 保持唯一，元组保持顺序和重复项。

**例：** `敌人 = 筛选(候选，(项：棋子) => 项.当前生命值 > 0)`。

<a id="stmt-expr-sort-key"></a>
### `排序`（依据值）

**用途：** 把容器按一个纯计算出的排序值整理为有序序列。

**签名/结果：** `排序(容器：集合<T>或元组<T>，依据：(项:T)=>排序值，顺序：升序或降序) → 元组<T>`。

**边界/权限：** 必须接收新元组；元组同值保持原顺序，Set 同值枚举须可回放。排序函数不能写状态。

**例：** `最近 = 排序(敌人，依据：(项：棋子) => 距离(当前棋子，项)，顺序：升序)`。

<a id="stmt-expr-sort-comparator"></a>
### `排序`（比较器重载）

**用途：** 用两项比较函数排序，表达多字段或复杂次序。

**签名/结果：** `排序(容器，比较：(a:T,b:T)=>数值) → 元组<T>`；比较结果细则仍待完整定义。

**边界/权限：** 已确认支持有类型函数；比较器仍必须纯计算，不能调用伤害、随机选择或交互。

**例：** `顺序 = 排序(目标，比较：(a：棋子,b：棋子) => a.攻击力 - b.攻击力)`。

<a id="stmt-expr-random-sort"></a>
### `随机排序`

**用途：** 产生一个可遍历的随机顺序。

**签名/结果：** `随机排序(集合<T>或元组<T>) → 元组<T>`；使用引擎种子随机流，保留元组重复项。

**边界/权限：** 是随机求值，不是纯费用预览；Set 初始枚举必须稳定可回放，具体随机消耗仍待工程对齐。

**例：** `轮询顺序 = 随机排序(自己的目标)`。

<a id="stmt-expr-random-select"></a>
### `随机选择`

**用途：** 从容器抽取一个成员。

**签名/结果：** `随机选择(元组<T>或集合<T>) → T或无效值`；单项重载在非空容器抽取一次，空容器返回无效值。带数量重载尚未冻结。

**边界/权限：** 使用种子流；元组重复项保留权重；无效结果使依赖语句失效，不自动补默认成员。

**例：** `随机目标 = 随机选择(敌人)`。

<a id="stmt-expr-take"></a>
### `获取前若干项`

**用途：** 截取有序序列的前 n 项。

**签名/结果：** `获取前若干项(元组<T>，数量：数值) → 元组<T>`。

**边界/权限：** Set 没有玩法顺序，先排序或随机排序；负数和越界政策仍待定。

**例：** `前三个 = 获取前若干项(最近，数量：3)`。

<a id="stmt-expr-length"></a>
### `获取长度`

**用途：** 统计容器数量。

**签名/结果：** `获取长度(元组<T>或集合<T>或映射<K,V>) → 数值`；元组按项计数，集合按唯一成员计数，映射按键计数。

**边界/权限：** 纯查询，不把 Set 的内部顺序转成玩法顺序。

**例：** `如果 获取长度(容器：护盾) > 0： ...`。

<a id="stmt-expr-index-map-read"></a>
### `元组[n]` / `映射[键]`

**用途：** 读取有序元组的项或映射中的值。

**签名/结果：** `元组[n] → T`；`映射[键] → V`；缺失/越界返回无效值；元组 `[1]` 是第一项。

**边界/权限：** Set 不支持位置索引；映射缺键不会自动插入默认值。

**例：** `首个护盾 = 获取状态(...)[1]`。

<a id="stmt-expr-set-mut"></a>
### `加入集合` / `移除集合元素`

**用途：** 改变 Set 的成员。

**签名/结果：** `加入集合(集合<T>，元素:T)`、`移除集合元素(集合<T>，元素:T)`；无业务返回值。

**边界/权限：** 重复加入不增加数量；移除缺失成员不报错；容器是状态数据，不能把它写成普通查询。

**例：** `加入集合(已处理，目标)`。

<a id="stmt-expr-contains"></a>
### `容器包含元素`（旧称“集合包含元素”）

**用途：** 判断集合或元组是否含有指定成员。

**签名/结果：** `容器包含元素(集合<T>或元组<T>，元素:T) → 布尔`。

**边界/权限：** 纯查询；引用按实例身份比较，不改变顺序或容器内容。旧名称只是同义写法。

**例：** `如果 容器包含元素(保存的目标，当前事件.目标)： ...`。

<a id="stmt-expr-tuple-append"></a>
### `追加元组`

**用途：** 向有序元组尾部加入一项。

**签名/结果：** `追加元组(元组<T>，元素:T)`；保留重复项。

**边界/权限：** 与 Set 加入不同，不去重；顺序是数据的一部分。

**例：** `追加元组(路径，当前地格)`。

<a id="stmt-expr-tuple-edit"></a>
### 元组插入/删除

**用途：** 按 vector 语义在指定位置插入或删除元组项。

**签名/结果：** 具体插入/删除签名尚未统一；结果应保持元组类型、顺序和重复项。

**边界/权限：** 不按显示名称批量删除不同实例；越界行为待定，不能假定自动补齐。

**例：** `在第 2 项插入【目标】`（使用当前编辑器提供的位置控件；不要手写未冻结函数名）。

<a id="stmt-expr-map-write"></a>
### `映射[键] = 值`

**用途：** 新增或覆盖映射键对应的值。

**签名/结果：** `映射<K,V>[键:K] = 值:V`；同键覆盖对应值。

**边界/权限：** 键和值必须符合声明类型；不要把对象名称字符串当作实例键。

**例：** `记录[当前事件.目标] = 当前回合.编号`。

<a id="stmt-expr-map-management"></a>
### `映射包含键` / `删除映射项`

**用途：** 查询映射是否有键，或移除键和值。

**签名/结果：** `映射包含键(映射，键) → 布尔`；`删除映射项(映射，键)` 的返回值未定。

**边界/权限：** 删除缺失键不报错；删除是写入，包含是纯查询。

**例：** `如果 映射包含键(记录，目标)：删除映射项(记录，目标)`。

<a id="stmt-control-if"></a>
### `如果…否则…`

**用途：** 按布尔条件选择一个语句段。

**签名/结果：** `如果(条件：布尔，成立段，否定段)`；无值返回。

**边界/权限：** 无效引用不能悄悄变成 `false` 分支；段内语句仍按顺序和作用域执行。

**例：** `如果 伤害结果.实际伤害量 > 0：附加状态(目标，燃烧，1，1)；否则：结束`。

<a id="stmt-control-foreach"></a>
### `遍历【容器】中的每一项【变量】`

**用途：** 对集合或元组逐项执行语句。

**签名/结果：** `遍历(容器<T>，项变量:T，子语句段)`；空容器不进入循环。

**边界/权限：** Set 唯一、元组保序且可重复；直接遍历原容器时新增项可继续访问，删除当前项不跳过随后项；循环受引擎次数上限保护，具体上限待定。

**例：** `遍历【目标】中的每一项【目标】：造成伤害(目标：目标，...)`。

<a id="stmt-control-while"></a>
### `当【条件】成立时循环`

**用途：** 在每次循环体开始前重新判断布尔条件。

**签名/结果：** `当(条件：布尔，子语句段)`；条件不成立时不进入或停止。

**边界/权限：** 仅接受已登记模块和控制结构；次数上限原则已确认，数值和超限处置待定。

**例：** `当 获取长度(待处理) > 0 时循环：处理待处理[1]；删除映射项(待处理，...)`。

<a id="stmt-control-break-continue"></a>
### 跳出/继续循环

**用途：** `跳出循环` 结束当前最内层循环；`继续下一次` 跳过剩余体并进入下一项或重新判断 while。

**签名/结果：** 只在循环体内有效；无返回值。

**边界/权限：** 不等于 `结束`；嵌套作用域和预算由引擎处理，具体编辑器文字可能调整。

**例：** `遍历目标：如果 目标.当前生命值 <= 0：继续下一次`。

<a id="stmt-control-return"></a>
### `结束` / 裸 `return`

**用途：** 退出当前 Skill、手牌或 Rule 入口。

**签名/结果：** 主动技能/手牌入口默认使用成功；Rule 只完成本次响应；循环或条件内也退出整个入口。

**边界/权限：** 已结算效果保留；不自动阻止外层事件、不退款、不取消其他 Rule。

**例：** `如果 没有目标：结束`（若在主动入口，仍需确保准备阶段没有把取消误当空放）。

<a id="stmt-control-fail"></a>
### `返回 使用失败(原因)`

**用途：** 在主动 Skill/手牌提交前拒绝本次使用并给出字符串原因。

**签名/结果：** `返回 使用失败(原因：字符串)` → 使用失败；不适用于 Rule 入口。

**边界/权限：** 不消费费用、冷却、次数、资格或手牌去向；不能先造成效果再返回失败要求回滚。历史“技能释放失败”是同义旧写法。

**例：** `如果 目标为空：返回 使用失败("没有合法目标")`。

<a id="stmt-control-success"></a>
### `返回 使用成功`

**用途：** 结束主动 Skill/手牌正文并明确成功提交结果。

**签名/结果：** `返回 使用成功` → 成功；正常费用、冷却、次数、资格与手牌去向各提交一次。

成功结果文案是可选项，默认留空，也可按需填写；返回成功不要求添加说明。失败时填写原因。结果文案与独立的战斗事件日志分开，留空不会删除伤害、治疗等事实记录。

**边界/权限：** 不要求实际造成伤害或移动；已提交后的效果不能再改成失败或退款。

**例：** `造成伤害(...)
返回 使用成功`。

<a id="stmt-control-block"></a>
### `阻止当前事件`

**用途：** 在当前事件允许阻止的阶段阻挡事件继续结算。

**签名/结果：** 无普通返回值；权限由事件类型决定。

**边界/权限：** 不自动结束 Rule，后续语句仍继续；不能取消已确定的死亡；伤害前使伤害量归零时不派发对应伤害后事件。

**例：** `受到伤害前：移除状态(圣盾)；阻止当前事件；结束`。

## C. 选择器与几何

统一选择器形态是 `目标选择器(类型，筛选条件，范围？，最小距离？，方式？，可见玩家？，候选集合？，允许取消？)`；参数行本身也是目录条目，下面逐项说明。

<a id="stmt-selector-type"></a>
### 选择器参数：类型

**用途：** 决定选择对象的类型和返回形状。

**签名/结果：** 支持棋子、地格、手牌、手牌定义、方向、`StatusTag` 以及显式 `元组<T>`/`集合<T>`；返回单值或声明的容器类型。选择具体状态时可写 `目标选择器(类型：StatusTag，所属对象：棋子，筛选条件：{可见：true}) → StatusTag或空引用`。

**边界：** 单个地格不能写成 `元组<地格>` 来冒充另一种返回形状；定义选择不会变成实例。StatusTag 选择返回具体状态实例，同名不同来源分别存在；不可见状态不进入候选。

**例：** `目标选择器(类型：StatusTag，所属对象：当前棋子，筛选条件：{可见：true}，允许取消：true)`。

<a id="stmt-selector-filter"></a>
### 选择器参数：筛选条件

**用途：** 用结构化字段限制敌友、所属玩家、状态、标签、可行走/占用、区域、行列等。

**签名/结果：** `筛选条件` 是与目标类型匹配的结构化值，不接受任意源码字符串。

**边界：** 敌友按战斗阵营；“本玩家”才按所属玩家。射线筛选不改变阻挡判断。

**例：** `筛选条件：{关系：敌方，具有状态：燃烧，地格可行走：true}`。

<a id="stmt-selector-range"></a>
### 选择器参数：范围/中心

**用途：** 指定空间中心、最大距离、方向、射线或相对坐标/形状。

**签名/结果：** `范围` 是数值或全图；中心是地格/棋子可读位置；形状可使用方向、射线或相对 `元组<坐标>` 等结构。

**边界：** 最小距离默认 1，边界包含；包括中心必须显式最小距离 0。一般形状默认值和部分区间仍待定。

**例：** `目标选择器(类型：棋子，中心：当前棋子，范围：3，最小距离：0)`。

<a id="stmt-selector-mode"></a>
### 选择器参数：方式

**用途：** 选择手动交互或自动查询。

**签名/结果：** `方式：手动` 会等待玩家并返回确认项；`方式：自动` 只读计算候选并返回类型化值。

**边界：** 自动查询不能弹出手动窗口；手动选择不适合费用预览；等待恢复后必须重新验证上下文。

**例：** `目标选择器(类型：棋子，方式：自动，筛选条件：{关系：敌方})`。

<a id="stmt-selector-candidates"></a>
### 选择器参数：候选集合

**用途：** 把选择限制在作者显式提供的集合或元组中。

**签名/结果：** `候选集合：集合<T>或元组<T>`；返回原类型引用。

**边界：** 不能把手牌定义选择误写成已有手牌实例选择；候选中的引用若失效，依赖语句按失效规则处理。

**例：** `候选牌 = 目标选择器(类型：手牌定义，候选集合：圣光牌定义元组)`。

<a id="stmt-selector-visible"></a>
### 选择器参数：可见玩家

**用途：** 限制选择过程、结果、高亮、提示和日志的查看者。

**签名/结果：** `可见玩家：集合<玩家>`；省略时沿用正常公开表现。

**边界/权限：** 可见权限不等于所属玩家或战斗阵营；仅隐藏高亮而公开日志不符合该契约。

**例：** `可见玩家：集合{当前玩家}`，用于只让持有者看到真实目标。

<a id="stmt-selector-ignore-occupant"></a>
### 选择器参数：忽略占用棋子

**用途：** 在本次传送/批量位移合法性查询中，声明本次要移动的棋子可暂时不作为阻挡占用。

**签名/结果：** 当前确认的形状是被移动棋子的集合（目前确认单个自身）；只影响本次校验。

**边界：** 不提前清空实际棋盘、不改变真实占用；批量配对仍待完整契约。

**例：** `忽略占用棋子：集合{当前棋子}`。

<a id="stmt-selector-cancel"></a>
### 选择器参数：允许取消

**用途：** 显式声明交互是否允许取消。

**签名/结果：** `允许取消：布尔`；省略默认 `false`。

**边界：** 主动技能提交前退出准备是不使用，不是空放成功；Rule 不因被动入口自动继承取消权。对允许取消的 StatusTag 选择，取消或没有可见候选返回空，不弹空菜单；依赖空引用的移除语句跳过，独立后续继续。等待期间实例失效不替换成同名状态。已提交的效果中恢复选择时，从选择处继续，不重放已完成的治疗、扣费或快照。

**例：** `目标选择器(类型：StatusTag，所属对象：当前棋子，筛选条件：{可见：true}，允许取消：true)`。

<a id="stmt-selector-option"></a>
### 选项选择器

**用途：** 让玩家从带显示标签的业务值中选择一项。

**签名/结果：** `选项选择器(选项：映射<字符串,T>) → T`；返回有类型值，不返回显示标签作为身份。

**边界：** 完整交互参数仍待统一；取消仍按入口/选择器显式配置。

**例：** `选择 = 选项选择器({"左翼":左翼目标，"右翼":右翼目标})`。

<a id="stmt-selector-status-list"></a>
### `获取状态`

**用途：** 读取目标身上某个状态定义的实际实例。

**签名/结果：** `获取状态(目标：棋子或玩家，类型：状态定义) → 元组<StatusTag>`，按稳定创建顺序；无状态返回空元组。

**边界：** 返回状态实例而不是定义；状态与 Rule 独立；引用身份可用于精确移除。

**例：** `盾 = 获取状态(目标：当前棋子，类型：圣盾)`。

<a id="stmt-selector-status-strength"></a>
### `获取状态强度`

**用途：** 读取目标棋子某状态的强度/层数。

**签名/结果：** `获取状态强度(目标：棋子，类型：状态定义) → 数值`；无状态确认返回 0。

**边界：** 多个独立实例如何聚合仍待定；不能把所有状态强度解释成抵挡次数。

**例：** `层数 = 获取状态强度(目标：当前棋子，类型：强化)`。

<a id="stmt-selector-next-player"></a>
### `获取下一位玩家`

**用途：** 按当前回合顺序找到参照玩家之后的第一名符合条件的玩家。

**签名/结果：** `获取下一位玩家(参照：玩家，筛选条件？) → 玩家或无效引用`；省略筛选条件表示顺序上的下一位，不返回参照本人。

**边界：** 关系条件按战斗阵营；无符合对象返回无效引用；出局玩家及参照不在顺序中的处理仍待生命周期对齐。

**例：** `敌方玩家 = 获取下一位玩家(参照：当前玩家，筛选条件：{关系：敌方})`。

<a id="stmt-selector-path"></a>
### `查询路径`

**用途：** 预测从棋子/起点沿方向的可通过路径，不执行移动。

**签名/结果：** `查询路径(棋子，起点，方向，范围或全图，敌军可通过性，友军可通过性，不可通行地格可通过性) → 路径查询结果`。

**边界：** 结果含最后合法落点、首个阻挡棋子、经过地格和经过棋子；不触发移动/伤害，执行时仍可能因状态变化而不同。

**例：** `预测 = 查询路径(当前棋子，当前地格，朝向，范围：5，敌军可通过性：false，友军可通过性：false，不可通行地格可通过性：false)`。

<a id="section-effects"></a>
## D. 伤害、治疗、消灭、状态与 Rule

<a id="stmt-effect-damage"></a>
### `造成伤害`

**用途：** 经权威伤害流水线对一个或多个棋子造成普通或真实伤害。

**签名/结果：** `造成伤害(目标：棋子/元组<棋子>/集合<棋子>，类型：普通或真实，伤害量：数值，伤害来源：棋子/玩家/手牌实例) → 伤害结果或元组<伤害结果>`。批量集合同时出伤；实际伤害量只计直接扣血，是否击杀表示本次伤害导致死亡。

**边界/权限：** 真实伤害仍受圣盾等状态规则影响；正伤害正常防御后至少 1，主动 Rule 将伤害量归零则该目标伤害事件停止。棋子来源已死亡时整条语句失效，不自动回退到所属玩家；延迟效果要在创建时保存玩家来源。

**例：** `结果 = 造成伤害(目标：敌人，类型：普通，伤害量：当前棋子.攻击力，伤害来源：当前棋子)`。

`author.effect.damage@2` 还可以填写中文参数“归属方式”。默认“沿用当前归属”时，宿主按当前技能、卡牌或 Rule 上下文取得标识；选择“无技能归属”时显式把 `undefined` 交给同一条权威伤害流水线，事件和日志不会凭空补一个当前内容标识。参数中的空文本技能标识仍是空文本，不会被当成省略。默认方式在句子中折起，选择无技能归属后显示为“归属方式为 无技能归属”。

已捕获来源的延迟/同步伤害继续使用同一个认证句柄和批量 host 调用；历史语句省略第五个参数时保留宿主的当前上下文回退，只有明确选择“无技能归属”才传递清除策略。已捕获对象在本次已经开始的结算中离场，仍按原对象完成该次同步写入；这不改变尚未开始结算的存活来源校验。

旧内容中的 `effect.damage-without-skill-id` 和 `effect.damage-pieces-unattributed` 会分别展开为这条公共语句；前者继续提供原来的 `结果/成功/实际伤害` 字段，后者继续提供原始结算结果。旧图中的物理/真实类型可直接迁移；未匹配的历史类型保留兼容入口，不在迁移时偷偷改成普通伤害。

<a id="stmt-effect-eliminate"></a>
### `消灭`

**用途：** 不经过伤害，直接让棋子进入正常死亡流程。

**签名/结果：** `消灭(目标：棋子，来源？：棋子/玩家/手牌实例)`；当前只确认单目标，返回值未定。

**边界/权限：** 不受防御、圣盾或伤害免疫阻止；正常派发死亡前/后并处理掉落和胜负。来源省略时不授予击杀奖励；重复死亡由权威流程拒绝。

**例：** `消灭(目标：濒死目标，来源：当前玩家)`。

<a id="stmt-effect-heal"></a>
### `恢复生命`

**用途：** 经正常治疗流水线恢复棋子生命。

**签名/结果：** `恢复生命(目标：棋子，数值：数值，来源：棋子或玩家) → 治疗结果`；元组目标返回同序 `元组<治疗结果>`。

**边界/权限：** 不超过最大生命；被阻止或没有恢复返回实际恢复量 0；无效目标不是合法的 0 结果。

**例：** `治疗 = 恢复生命(目标：友军，数值：3，来源：当前棋子)`。

<a id="stmt-effect-resource"></a>
### `调整资源`

**用途：** 按增量调整玩家的行动点或充能点。

**签名/结果：** `调整资源(玩家：玩家，资源：行动点或充能点，变化量：数值，允许超过上限：布尔=false) → 布尔`。

**边界/权限：** 扣除不足返回 `false` 且不扣成负数；`允许超过上限` 省略或 false 遵守上限，true 允许本次增加超过上限；增加受上限限制时的完整布尔语义仍待补。

**例：** `成功 = 调整资源(玩家：当前玩家，资源：行动点，变化量：-1)`。

<a id="stmt-effect-add-status"></a>
### `附加状态`

**用途：** 创建或按状态合并规则附加 StatusTag 实例。

**签名/结果：** `附加状态(目标，类型：状态定义，强度：数值，持续时间：数值或永久，来源？，extension？，可见玩家？，显示配置？) → 单目标 StatusTag`；棋子集合/玩家批量实例的完整返回形状仍待定。

**边界/权限：** extension 先按类型初始化再判断合并；同状态、来源相同/均无且 extension 内容相同才有合并资格。可见与可驱散统一；不同来源不合并；创建当回合不减少持续时间。显示配置在首次显示前生效，`iconPath` 是当前显示层可读取的图片路径，不改变状态身份。

**例：** `燃烧 = 附加状态(目标：敌人，类型：燃烧，强度：1，持续时间：2，来源：当前棋子，显示配置：{iconPath："images/burn.png"})`。

<a id="stmt-effect-remove-status"></a>
### `移除状态`

**用途：** 按状态实例，或按棋子+状态定义，走正常状态移除生命周期。

**签名/结果：** `移除状态(状态实例)` 或 `移除状态(目标棋子，状态定义)`；按类型移除的多实例数量和返回值仍待定。

**边界/权限：** 普通移除只处理可见状态；自然耗尽、主动驱散、强度耗尽的原因必须区分；移除后的只读快照不能恢复旧实例或执行旧对象操作。

**例：** `移除状态(状态：获取状态(目标：当前棋子，类型：圣盾)[1])`。

<a id="stmt-effect-add-rule"></a>
### `附加规则`

**用途：** 把 Rule 定义挂载到棋子、玩家或手牌实例，并取得 Rule 实例。

**签名/结果：** `附加规则(挂载对象：棋子/玩家/手牌实例，规则：Rule 定义引用，来源？) → Rule 类型`。

**边界/权限：** 同挂载对象+同定义天生去重；重复调用返回已有实例，不重置 extension/来源，不注册第二份监听。Rule 与 StatusTag 不自动绑定。

**例：** `规则 = 附加规则(挂载对象：当前玩家，规则：回合结束诅咒结算，来源：当前手牌)`。

<a id="stmt-effect-remove-rule"></a>
### `移除规则`

**用途：** 移除指定 Rule 实例，或使用目标+定义重载定位它。

**签名/结果：** `移除规则(Rule 实例)`；另有目标+Rule 定义重载。

**边界/权限：** 不终止已经开始的当前执行；共享任务不能因一个任务完成就删除仍需处理的共享 Rule。

**例：** `移除规则(当前规则)`。

<a id="section-spatial"></a>
## E. 移动、召唤、快照与显示

<a id="stmt-spatial-move"></a>
### `普通移动`

**用途：** 调用引擎统一的点按/拖动普通移动交互，逐格经权威规则结算。

**签名/结果：** `普通移动(棋子：棋子，行动点消耗：数值，允许取消？=false) → 结果未定`。

**边界/权限：** 作者不自行写路径选择、落点或逐格移动；引擎处理等待、确认、取消和防重复。免费移动可写消耗 0，并显式写 `允许取消:true`；结果字段尚未冻结。

**例：** `普通移动(棋子：移动者，行动点消耗：0，允许取消：true)`。

**公共查询句式：** 需要展示或组合普通移动落点时使用 `按宿主普通移动规则查询(棋子)`，返回合法地格元组；移动范围、地形、阻挡和落脚校验均由权威宿主处理，作者不重算几何。

<a id="stmt-spatial-displace"></a>
### `位移`

**用途：** 把一个棋子或批量移动列表提交到权威位置系统。

**签名/结果：** 单项：`位移(棋子，起点，终点，敌军可通过性，友军可通过性，不可通行地格可通过性，中间地格是否经过) → 位移结果`；批量：移动列表 `元组<结构体{棋子,起点,终点}>` → 同序 `元组<位移结果>`。

**边界/权限：** 遇阻停最后合法落点；`成功` 与 `发生位移` 分开，原地合法成功但不发位置事件。经过地格/棋子记录实际路径；不直接改坐标。换位占用由传送层维护，不增加“必须全成功”参数。

**作者公共句式：** 普通作者使用 `按路径策略提交位移(棋子，目标地格，位移方式，地形策略，可穿越友方，可穿越敌方，屏蔽地形类型)`；位移方式可选 `传送(teleport)`、`冲刺(dash)`、`拉拽(pull)`，地形策略可选 `可通行(walkable)`、`弹道(projectile)`、`任意(any)`。无路径策略的单项传送、步行、推动或拉拽使用 `统一单棋子位移`；两枚棋子换位使用 `原子交换棋子位置`，其方式标识为 `swap`。括号中的英文是图中稳定标识，编辑器显示中文标签；这些句式都由权威位置提交器结算，作者不写棋子坐标。

**例：** `结果 = 位移(当前棋子，起点，终点，敌军可通过性：false，友军可通过性：false，不可通行地格可通过性：false，中间地格是否经过：true)`。

<a id="stmt-spatial-summon-template"></a>
### `召唤：模板创建`

**用途：** 按技能声明的模板/定义/复制副本创建一个新棋子实例。

**签名/结果：** `召唤(模板或定义，位置：地格，所属玩家：玩家，显示配置？) → 棋子或失败无效值`。

**边界/权限：** 默认创建召唤物；首次显示前应用显示配置；完整模板字段、批量签名和失败契约待补。必须走生命周期入口，不能写坐标。

**例：** `分身 = 召唤(模板：影分身模板，位置：落点，所属玩家：当前玩家，显示配置：伪装快照)`。

<a id="stmt-spatial-summon-existing"></a>
### `召唤：原实例入场`

**用途：** 让一个已离场/出局的原棋子实例重新入场，保留身份。

**签名/结果：** `召唤(棋子：已有离场实例，位置：地格，入场初始化？) → 原棋子或失败无效值`；已确认可显式提供 `{当前生命值:数值}` 入场初始化。

**边界/权限：** 不创建同名后备棋子，不复制身份；满血入场不派发普通治疗事件；失败不改原实例生命。

**例：** `回场 = 召唤(棋子：死亡记录.原实例，位置：落点，入场初始化：{当前生命值：死亡记录.最大生命值})`。

<a id="stmt-spatial-eliminate"></a>
### `出局`

**用途：** 让棋子离场但保留可引用实例，供后续恢复/召回。

**签名/结果：** `出局(棋子实例)`；完整返回值、持续时间和冷却推进仍待补。

**边界/权限：** 不等于死亡，不能执行要求在场的行动；不能直接改坐标或借出局改变胜负语义。

**例：** `出局(当前棋子)`，随后把该实例保存进玩家 extension。

<a id="stmt-spatial-piece-display"></a>
### `设置棋子显示`

**用途：** 为具体棋子实例设置逐字段显示覆盖。

**签名/结果：** `设置棋子显示(棋子实例，显示配置字段)`；返回值未定。

**边界/权限：** 只影响投影、动画、面板和日志显示；省略字段不特殊化；不能改变真实技能、状态、移动力或胜负身份。

**例：** `设置棋子显示(分身，{名称：本体名称，iconPath：本体图标路径})`。

<a id="stmt-spatial-create-zone"></a>
### `创建区域`

**用途：** 把一组地格登记为可引用区域。

**签名/结果：** `创建区域(地格：元组<地格>) → 区域`。

**边界：** 区域不占据落点、不隐式改变地形；形状由地格元组计算，不注册角色专属区域模块。

**例：** `区域 = 创建区域(地格：中心及八邻格)`。

<a id="stmt-spatial-remove-zone"></a>
### `移除区域`

**用途：** 清理区域实例及其显示。

**签名/结果：** `移除区域(区域实例)`；返回值未定。

**边界：** 不自动删除独立 Rule 或其他引用；按实例身份移除，不能按坐标误删别人的区域。

**例：** `移除区域(当前玩家.extension.锚点[1])`。

<a id="stmt-spatial-zone-display"></a>
### `设置区域显示`

**用途：** 用现有 `tileEffect` 投影设置区域的地格显示。

**签名/结果：** `设置区域显示(区域，tileEffect 配置)`；字段包括 `tileType`、可选 `icon`、`bgColor`、`boxShadow`、`ownerPlayerId`、`iconPosition`。

**边界：** 归属信息不等于可见权限；不建立第二套显示状态源，不直接决定伤害或触发器。

**例：** `设置区域显示(区域，{tileType："burning", icon："images/burn.png", iconPosition："topLeft"})`。

<a id="stmt-spatial-copy-card"></a>
### `复制手牌到手牌区`

**用途：** 从一个具体手牌实例复制出新身份并放入接收玩家手牌区。

**签名/结果：** `复制手牌到手牌区(手牌：手牌实例，玩家：玩家)`；当前示例不依赖返回值。

**边界：** 保留定义、标签、当前可复制数值、extension 和附加 Rule；可变数据与 Rule 实例独立，外部引用保留原对象。满手、事件和运行复制细节仍需验证。

**例：** `复制手牌到手牌区(手牌：诅咒牌，玩家：当前玩家)`。

<a id="stmt-spatial-copy-apply"></a>
### `复制实例 / 应用实例信息`

**用途：** 复制一个独立数据副本，或把保存信息应用到目标棋子。

**签名/结果：** `复制实例(实例：棋子实例) → 棋子数据副本`；`应用实例信息(来源实例，目标棋子)`；返回值和失败边界仍待补。

**边界：** 副本不自动召唤、不占格、不进入胜负；应用不伪造治疗、状态增删或获得技能事件。历史位置单独走位移；不能替换目标身份或直接写坐标。

**例：** `快照 = 复制实例(实例：当前棋子)`，再将 `应用实例信息(快照，目标棋子)` 用于回溯。

<a id="stmt-spatial-order"></a>
### `设置上场顺序`

**用途：** 调整棋子初始化/上场列表中的插入位置。

**签名/结果：** `设置上场顺序(棋子，n)`；`n=1` 是首位。

**边界：** 越界及同时插入细节待定；游戏开始时 Rule 必须早于最终初始部署顺序确定。

**例：** `设置上场顺序(当前棋子，1)`。

<a id="section-cards"></a>
## F. 手牌、区域、Cluster 与实例结果

<a id="stmt-card-gain"></a>
### `获得手牌`

**用途：** 按手牌定义创建一张独立手牌实例。

**签名/结果：** `获得手牌(玩家：玩家，手牌定义：手牌定义引用，extension？：有类型结构体) → 手牌实例或失败无效引用`。

**边界：** extension 在获得后事件前初始化；手牌上限 10，满手时新牌直接进入弃牌区但仍返回新实例；失败不返回同名旧牌。

**例：** `新牌 = 获得手牌(玩家：当前玩家，手牌定义：诅咒，extension：{伤害量：4})`。

<a id="stmt-card-discard"></a>
### `弃置手牌`

**用途：** 把指定手牌实例送入弃牌区。

**签名/结果：** `弃置手牌(手牌实例) → 返回值未定`。

**边界：** 弃置不视为使用；手牌使用后的默认去向是弃牌区，特殊内容才显式改变；事件细节待定。

**例：** `弃置手牌(当前手牌)`。

<a id="stmt-card-tags"></a>
### `添加标签` / `移除标签`

**用途：** 修改一张具体手牌实例的标签。

**签名/结果：** `添加标签(目标：手牌实例，标签：标签引用)`；`移除标签(目标：手牌实例，标签：标签引用)`。

**边界：** 不改同名牌；删除不存在标签的行为仍待定；标签不代替实例/定义身份。

**例：** `添加标签(目标：当前手牌，标签：预言强化)`。

<a id="stmt-card-gain-cluster"></a>
### `获得能力组（Cluster）`

**用途：** 按能力组定义为棋子安装其 Skill 和 Rule 成员，并取得这一次获得的能力组实例。

**签名/结果：** `获得能力组(目标：棋子，定义：能力组定义) → 能力组实例`。运行时对应 `clusters.acquire(pieceId, definition)`；实例含定义 `id`、独立 `instanceId`、Skill/Rule 成员和可选 extension，并记录所属棋子。

**边界：** 同一棋子按定义 `id` 重复获得时返回已有实例，不重置成员、来源或 extension。每个直接 Skill/Rule 的初始化能力组独立记录；只有已实际安装且由定义明确列出的成员才会被采用，玩家级 Rule 不会自动装到棋子。能力组安装前会校验全部成员，宿主安装失败会恢复成员和原实例身份；不会自动安装静态 Piece Cluster 目录。

**例：** `新建【能力组】变量【能力组】 = 获得能力组(目标：当前棋子，定义：圣盾 Cluster)`。

<a id="stmt-card-remove-cluster"></a>
### `移除能力组`

**用途：** 按 Cluster 实例移除该次获得的专属成员。

**签名/结果：** `移除能力组(能力组：能力组实例) → 布尔`；运行时对应 `clusters.remove(group)`，按能力组实例身份定位所属棋子。

**边界：** 只移除该能力组拥有且已没有其他能力组共享的 Skill/Rule；能力组之间共享的成员直到最后一个拥有者移除才清理。能力组获得前已经存在、或被独立宿主标记保护的成员会保留；不能用定义引用替代能力组实例。

**例：** `移除能力组(能力组：能力组)`。

<a id="stmt-result-damage"></a>
### 伤害结果

**用途：** 描述单目标伤害结算事实。

**签名/结果：** 字段 `实际伤害量：数值`、`是否击杀：布尔`；批量结果按目标对应为元组。

**边界：** 实际伤害只计直接扣血，不含护盾吸收和溢出；`是否击杀`不是普通离场；未确认通用成功字段。

**例：** `如果 结果.是否击杀：获得击杀后的奖励`。

<a id="stmt-result-heal"></a>
### 治疗结果

**用途：** 描述一次恢复生命的实际事实。

**签名/结果：** 字段 `实际恢复量：数值`；被阻止/无恢复可为 0。

**边界：** 无效目标不伪装成合法 0 结果；不含后续反应治疗或伤害。

**例：** `治疗量 = 治疗结果.实际恢复量`。

<a id="stmt-result-displacement"></a>
### 位移结果

**用途：** 读取权威位移提交的实际路径和两个成功事实。

**签名/结果：** 字段 `成功：布尔`、`发生位移：布尔`、`经过地格：元组<地格>`、`经过棋子：元组<棋子>`、`首个阻挡棋子：棋子或空`。

**边界：** 预测路径不能代替实际路径；合法原地可成功但不发生位移，也不发位置事件；遇阻停止在最后合法落点。

**例：** `如果 结果.发生位移：消耗“移动后一次”资格`。

<a id="stmt-result-path"></a>
### 路径查询结果

**用途：** 保存查询时的预测路径。

**签名/结果：** 字段 `最后合法落点`、`首个阻挡棋子`、`经过地格`、`经过棋子`。

**边界：** 阻挡棋子不计入可通过棋子；结果不提交移动，执行时不保证仍合法。

**例：** `落点 = 预测.最后合法落点`（之后仍须再次走权威位移）。

<a id="stmt-context-turn"></a>
### 当前回合

**用途：** 读取全局回合顺序事实。

**签名/结果：** `当前回合.编号：数值`、`当前回合.玩家：玩家`；只读。

**边界：** 编号每次切换到下一玩家回合递增，不是阵营轮数或某玩家行动次数；作者不能写入或自行维护全局计数。

**例：** `当前玩家.extension.上次伤害回合 = 当前回合.编号`。

<a id="stmt-context-event"></a>
### 当前事件

**用途：** 读取当前触发器提供的事件专属字段。

**签名/结果：** 按触发器提供棋子、伤害来源、执行来源、位置、伤害量、局部变量等字段；没有统一的全字段对象。

**边界/权限：** 前事件字段按权限可写，后事件结果只读；尚未声明的局部变量写入跳过整条语句；事件元数据不能伪造身份。

**例：** `当前事件.伤害量 = 当前事件.伤害量 / 2` 仅能放在有权限的伤害前阶段。

<a id="stmt-context-rule"></a>
### 当前规则

**用途：** 读取正在响应的 Rule 实例、extension 和可用来源引用。

**签名/结果：** `当前规则：Rule`，字段按 Rule 类型可读；没有隐式关联状态。

**边界/权限：** 需要状态时必须显式 `获取状态` 后保存变量；Rule 去重不能被当前规则引用绕过。

**例：** `当前规则.extension.已使用回合 = 当前回合.编号`。

## G. 入口与事件声明

下列是 Rule/Skill 的入口族。它们不是另一个隐藏效果模块；作者在对应入口下放普通语句。事件字段和完整载荷仍按触发器逐类实施。

<a id="stmt-entry-turn"></a>
### 开局/回合入口

**用途：** 响应游戏开始、所属玩家回合开始/结束或敌方回合结束。

**签名/结果：** 入口事件提供对应玩家/回合字段；Rule 执行完本次响应即结束。

**边界：** 中局获得 Cluster 不补发游戏开始事件；创建当回合的状态不在该回合结束时减少持续时间。

**例：** `入口：所属玩家回合结束 → 遍历任务并处理每项延迟效果`。

<a id="stmt-entry-use"></a>
### 使用入口

**用途：** 响应使用本技能、技能前/后、手牌前或成功使用手牌后。

**签名/结果：** 使用前可以写已声明局部变量；准备选择/纯计算通过后，费用、资格、冷却和去向先提交一次，再执行效果 code。

**边界：** 提交前失败不消费；提交后不能退款或改报失败；成功不要求产生实际效果。

**例：** `入口：使用本技能 → 选择目标 → 返回使用成功`。

<a id="stmt-entry-target"></a>
### 目标指定入口

**用途：** 在逐目标指定前响应并按契约改写目标。

**签名/结果：** 当前事件提供发起棋子、目标、实际 Skill 和预留地格等字段；前阶段可按权限改写目标。

**边界：** 不是“使用技能前”的替代；改写预算上限 16，转移后按新候选规则验证，不重新套原筛选器。

**例：** `入口：被指定为目标前 → 如果目标在预留地格：当前事件.目标 = 备选目标`。

<a id="stmt-entry-damage"></a>
### 伤害入口

**用途：** 响应造成伤害前、受到伤害前、伤害应用前、造成/受到伤害后。

**签名/结果：** 造成伤害前先于受到伤害前；前阶段可按字段契约修正；后事件读取只读结果。伤害量归零/被阻挡时不派发对应伤害后。

**边界：** 后事件只读结果，不禁止 Rule 再调用治疗/状态等正常效果；代受使用 `当前事件.承受者 = 棋子实例` 的专用权威字段，不能任意改所有事件目标。

**例：** `入口：伤害应用前 → 若为致命伤害则阻止当前事件`。

<a id="stmt-entry-death"></a>
### 死亡、击杀、离场入口

**用途：** 响应死亡前、死亡后、击杀后或棋子级离场后。

**签名/结果：** 死亡前处于死亡流程但尚未离场；死亡后已提交离场与墓地；离场不等于击杀。

**边界：** 死亡前不是复活窗口，不能取消死亡或治疗回存活；死亡后可召唤新实例。出局不冒充击杀。

**例：** `入口：死亡后 → 召唤(模板：骷髅，位置：当前事件.位置，所属玩家：当前玩家)`。

<a id="stmt-entry-spatial"></a>
### 空间/召唤入口

**用途：** 响应普通移动入口、逐格位置改变或召唤后。

**签名/结果：** 普通移动与位置改变是不同事件；移动后结果使用实际路径/发生位移字段。

**边界：** 普通移动提交、逐格事件及部分提交时点仍按运行实现对齐；作者不直接写坐标。

**例：** `入口：召唤后 → 设置棋子显示(新棋子，显示配置)`。

<a id="stmt-entry-status"></a>
### 状态入口

**用途：** 响应状态移除等状态生命周期事件。

**签名/结果：** 状态移除后提供只读状态快照和移除原因；自然耗尽、主动驱散、强度耗尽需可区分。

**边界：** 快照不能恢复失效状态或修改已删除实例；精确载荷和运行快照生成仍待补。

**例：** `入口：状态移除后 → 如果 当前事件.移除原因 == 持续时间耗尽：清理任务记录`。

## H. 明确允许的字段写入

<a id="stmt-write-status-strength"></a>
### `状态.强度 = 数值`

**用途：** 更新一个实际 StatusTag 实例的强度。

**签名/结果：** `状态实例.强度 = 数值表达式`；强度 `<=0` 进入自然耗尽，独立 Rule 保留。

**边界/权限：** 不因此获得写持续时间或其他任意字段的权限；不移除重加、不重部署 Rule。

**例：** `强化.强度 = 强化.强度 + 1`。

<a id="stmt-write-skill-cooldown"></a>
### `Skill实例.当前冷却 = 数值`

**用途：** 直接更新某个 Skill 运行实例的冷却。

**签名/结果：** `Skill实例.当前冷却 = 数值表达式`；引擎校验并通知 UI。

**边界/权限：** 只能写实际 Skill 实例，不能写定义；不重置使用次数；提交前默认冷却与效果中作者写入不互相覆盖。

**例：** `当前技能.当前冷却 = 3`。

<a id="stmt-write-owner"></a>
### `棋子.所属玩家 = 玩家`

**用途：** 通过权威归属变更更新控制者/所属玩家。

**签名/结果：** `棋子实例.所属玩家 = 玩家引用`；具体返回值未定。

**边界：** 不自动决定战斗阵营迁移、不裸改对象；资源、手牌和 Rule 归属按各自契约处理。

**例：** `当前棋子.所属玩家 = 新玩家`。

<a id="stmt-write-zone-cells"></a>
### `区域.地格 = 元组<地格>`

**用途：** 保留区域身份并通过区域入口更新其地格投影。

**签名/结果：** `区域实例.地格 = 元组<地格>`；返回值未定。

**边界：** 不能原地改容器绕过入口，不伪造棋子位置改变事件；显示需重新投影。

**例：** `当前区域.地格 = 新地格`。

<a id="stmt-write-terrain"></a>
### `地格.地形 = 地形定义`

**用途：** 更新地格的通行和弹道属性。

**签名/结果：** `地格.地形 = 地形定义引用`；附着 `tileEffect` 保留。

**边界：** `walkable` 与 `blocksProjectile` 是不同事实；不能借换地形清掉显示覆盖或状态。

**例：** `落点.地形 = 沼泽地形`。

<a id="stmt-write-event-local"></a>
### `当前事件.局部变量.名称 = 值`

**用途：** 在使用前阶段回写已声明的同类型局部变量。

**签名/结果：** `当前事件.局部变量.名称 = 同类型值`；无效/未声明字段使整条写入跳过。

**边界：** 不自动创建变量、不填 0；后事件结果只读。

**例：** `当前事件.局部变量.倍率 = 当前事件.局部变量.倍率 + 0.5`。

<a id="stmt-write-event-damage"></a>
### `当前事件.伤害量 = 数值`

**用途：** 在有权限的伤害前阶段修改即将结算的伤害量。

**签名/结果：** `当前事件.伤害量 = 数值表达式`；后事件只读。

**边界：** 必须由阶段/类型校验；归零会停止该目标伤害事件，但不撤销技能其他独立效果，也不回滚已消费的状态。

**例：** `当前事件.伤害量 = 当前事件.伤害量 / 2`。

```text
入口：受到伤害前
```

## 设计、编辑器、引擎的三层核对

### 2026-10-13 运行接入补充

本批已接入的能力组操作为：让【棋子】获得【能力组定义】、读取【棋子.能力组】、移除【能力组实例】。定义包含 `id`、`skills`、`rules` 和可选 `extension`；获得结果包含实例身份及所属棋子。重复获得同一定义不会重置原实例。移除一个能力组，只移除它独自提供的 Skill/Rule，保留其他能力组和独立添加仍在提供的成员。安装失败会恢复成员及其原实例身份。

主动技能中可以直接引用 `当前技能`，读取 `当前技能.冷却`、`当前技能.剩余次数`、`当前技能.等级`、`当前技能.所属棋子`；可修改前三个运行字段。该引用指向正在执行的实际技能实例，不是内容库定义；实例失效时语句失效，不会改到另一个同名实例。Rule 也有按挂载对象和稳定 `instanceId` 的当前实例入口；Status、Card、Cluster 和 tile-effect 使用同一套精确实例 extension 边界。当前执行变量仍是执行期值，不能把 opaque 句柄当作可持久化对象。

坐标元组参数可点击“绘制相对范围”，点选格子，再指定原点。编辑器按点选顺序保存 `{坐标(x,y), ...}`；原点不会自动加入结果。已有范围含变量或计算时，仍通过表达式修改，绘图不会覆盖动态项。

代码块已具有数据结构验证、显式参数绑定、编译和运行调用入口：保存语句图和参数签名，不保存 JavaScript 函数；返回值按声明类型检查，嵌套调用共享递归/总调用数预算。普通选择可以沿用 pending 宿主，但反应队列的 settled result continuation 仍未实现；不能把这项能力扩大为所有手牌代码片段或完整编辑器嵌套创建都已迁移。

### 容器表达式与代码块返回值

元组写成 `{1, 2, 2}`，保留重复项和顺序；下标从 `1` 开始。`集合({1, 2, 2})` 得到两个元素。`映射({1, 2}, {"天照", "冰冻"})` 按两个元组逐项建立键值关系，数值键 `1` 和文本键 `"1"` 是不同的键。

```text
新建【集合<数值>】变量【seen】 = 集合({1, 2, 2})
新建【布尔】变量【found】 = seen.包含(2)
seen = seen.加入(3)
新建【映射<数值, 文本>】变量【names】 = 映射({1, 2}, {"天照", "冰冻"})
新建【文本】变量【name】 = names[1]
names = names.写入(2, "定身")
```

集合提供 `包含`、`加入`、`移除`、`数量`、`转元组`；映射提供 `包含键`、`读取`、`写入`、`移除`、`键列表`、`值列表`、`数量`。成员写法和函数写法都支持，例如 `seen.包含(2)` 与 `包含(seen, 2)`。修改容器的函数返回新容器，须赋值给变量才替换原值。读取不存在的键使当前语句无效，不自动生成值；独立后续语句继续。空集合或空映射需要当前位置提供元素类型。

“执行代码块”的参数必须符合该代码块声明的签名；调用处选择的返回类型也会校验，不能将文本结果当成数值。代码块仍使用相同原子语句编译，调用深度和总调用数有上限。真实 Electron flat smoke 在隔离临时项目中从空白卡牌入口完成了选择、结构化代码块、手牌 extension、目标、伤害和治疗的组合，并保存后重开；13/13 个场景通过（其中空白卡牌组合为一个明确夹具），证据见 [`sentence-flat-ui-smoke.json`](../../docs/qa/RED-252-flat-sentence/sentence-flat-ui-smoke.json)。这只证明该路径和覆盖到的图形可编辑，不扩展为任意卡牌、任意嵌套图或 105 个设计条目均已迁移；反应队列的 settled result continuation 仍未实现。

写完一段内容后分别核对：

- **设计层：** 该条目是否在[参考索引](AUTHOR_STATEMENT_REFERENCE.md)中，签名、默认和待定边界是否与最新[公共接口规格](SKILL_MODULE_INTERFACES.md)一致。
- **编辑器层：** 当前模块列表是否能选择；蓝色芯片是否能提供所需类型；保存后是否能重新打开。目录收录不代表 picker 已注册。
- **引擎层：** 用固定状态/种子/命令回放检查费用、事件、身份、位置和结果；“保存”或“资源包生成”不等于运行结算或人工接受。最新目标是记录运行错误后跳过问题语句、继续独立后续并退出异常循环/挂起路径；正常等待玩家不算错误，已成功效果不得重放。该容错目标尚未全面落实，验证时要把“错误已记录且游戏未卡死”作为独立检查项。

相关实例和技能草案可从[作者草案索引](AUTHORING_DRAFT_INDEX.md)进入；其中“待运行验证”“待实现”应原样保留，不得改写成“已支持”。


### 使用映射作为选项（运行接口 v3）

技能开头的无条件目标选择会进入引擎释放前的目标准备，因此目标校验和被指定为目标的规则可以复用同一声明。读取字段、运算不会执行来生成候选；副作用、条件分支之后的选择保留在实际执行到该处时交互。明确配置的既有目标约束仍优先使用，不需要作者再写距离、存活或占用的重复检查。

在现有技能中修改目标语句的范围，会同步能明确对应的选区声明和说明模板。例如影分身的 `5` 改成 `6` 后，保存的目标范围、对应说明、预览和游戏候选都使用 `6`。原有选项和额外位置限制保持不变。若自定义说明无法安全对应，编辑器保留原文并提醒检查；不会替换说明里所有相同数字。只修改伤害等其他效果，不会擅自修正旧选区声明。

“选择选项值”接受 `映射<文本, T>`：键显示给玩家，值是选中后返回的数据。例如 `映射({"触发", "不触发"}, {true, false})` 的单选结果是布尔值。键保留插入顺序，即使显示文字是 `"10"`、`"2"` 也不按数字重新排序。不同文字可以对应相同值。

最少与最多统一约束数量：恰好选一项就是最少 1、最多 1。单选返回 T，多选返回 `元组<T>`，保留点击顺序与重复值。返回形式或选项值类型改变时，编辑器应同步推导返回类型；不把容器的内部字段展示为选项。旧 v2 结构体选项保持兼容读取。

### 延迟伤害与动态卡牌

反应事件中的共同伤害也使用「造成伤害」。如果来源和目标都是本次执行保留的实例引用，伤害进入当前事件的结算队列，避免在正在处理伤害时重入。返回值的 `queued` 只表示已入队，不能当作已造成伤害或已击杀；结算后的结果须由相应事件读取。保留引用只在本次执行内有效，不能自己用普通结构体伪造或带到另一次执行。

清理保留实例的规则时，目标直接使用该实例引用。即使原棋子已离场，也只清理原对象，不重新按编号寻找其他棋子；后来出现的同编号对象不会受到影响。无效引用会产生诊断，依赖该引用的语句跳过，独立后续照常。

独立延迟伤害在创建时保存玩家引用。例如诅咒卡保存 `卡牌.extension.sourcePlayerId`，之后施法棋子死亡或改变归属也不改变该玩家。黑棺第一段仍由施法棋子造成，延迟段读取状态创建时保存的玩家。没有保存的来源时，该伤害语句及依赖其返回值的语句失效，其他独立清理继续；不从墓地棋子、当前目标或其他友军补出来源。

创建动态卡牌使用通用模板操作，可绑定数据字段与扩展变量。允许绑定伤害量、倍率、行动点/充能消耗、范围、标签和触发器；可省略样本标记、图片、效果标签、目标文字和关键词。代码及作者图只能来自已验证模板，不能通过数据字段覆盖。扩展变量仍限制为 64KB，完整模板另按 16MB 校验，避免生成代码被当成扩展变量误拒绝。

### 状态实例与通用选择的兼容组合

棋子和玩家的状态都可以按实例读取，重复类型或重复旧标识不会合并。读取到的实例可以保存为本次执行变量并访问 extension；在显式进入 extension、挂起或 JSON 边界时，状态使用 owner 和稳定 `instanceId` 持久化，Skill、Rule、Card、Cluster 和 tile-effect 也按各自实例身份恢复。移除其中一个不会误删另一实例；旧引用在实例被移除或替换后失效，不按数组索引重定位。生命周期移除仍使用状态宿主并检查唯一标识，直接记录清理不触发移除事件。旧玩家记录清理即使没有匹配项，也保留原来的空状态数组存储行为。

固定二选一、可取消二选一和文本多选现在共用选择宿主。它们的选项由普通记录和元组组成，保留标签、说明、顺序、指定玩家与取消值；作者新建选择仍使用上文的映射与最少/最多参数，不必编写选择协议。传送的“是否实际改变位置”从位移结果的变化元组读取，不再需要专用传送模块。

能力使用记录通过棋子字段赋值和元组拼接实现。状态位置刷新与旧关联规则字段更新通过筛选状态实例、修改字段实现，原来的首个匹配行为不变。更新旧关联规则字段只改变记录，规则安装与卸载仍是独立语句，不建立 StatusTag 与 Rule 的强制绑定。

### 声明召唤

“召唤”提供新建棋子、原实例回场和“使用当前内容声明”三种方式。前两种在句中填写棋子及落点；声明方式只填写来源和落点，模板、储存位置及允许数量在当前内容的“内容召唤声明”中编辑。声明属于整份内容，嵌套代码块不另建一份。

例如恶魔召唤（5）先保留支付伤害的友军引用，再对该友军造成伤害，最后用保留引用和选择的地格提交声明召唤。这里的来源是承担代价的友军，储存实例或默认模板才是将要召唤的棋子。来源因代价死亡时，声明队列仍按原规则结算；作者无需额外检查存活或补写替代分支。按玩家储存的原实例、使用后的储存清理和满血回场均由既有召唤生命周期负责。

声明方式返回 `queued` 和 `queueCount`，只表示入队结果及队列返回数量，不表示召唤已经结算成功。需要处理召唤后的棋子时使用相应召唤事件。旧版召唤语句继续读取；新写内容使用同一个“召唤”入口。

内容召唤声明在编辑器保存前使用与运行时相同的封闭解析器校验。必填模板标识、显示名称或其他字段为空时，草稿会保留以便修复，但保存会被阻止，磁盘上的已保存内容不变；修复后再保存才会更新声明。

### 资源包与普通目录

资源包包含运行所需定义，但并非每个定义都属于普通卡牌或技能目录。组合护甲的六种模板用于生成实际手牌，保留在资源包中而不登记到普通 cards/manifest.json；历史技能 grimmjow-gran-rey-cero 保留兼容读取，也不重新进入普通技能目录。工作台只允许 content-discovery-policy.ts 明确登记的这些例外及初始化直接加载的幸运币规则；新建的未知未登记内容仍会阻止接受修改。不要通过扩大普通目录来修复资源包校验，否则会改变内容发现范围。
