# 施法范围预览

1.0.10 的范围选择器同时展示两类信息：淡蓝色地格表示施法的几何范围，原有高亮表示允许选择的目标。范围内的障碍物、友军或空格不会因此变为合法目标。

`prepareAction` 和 pending 会话由权威目标模块生成 `rangeCells`；页面只传递坐标，不复制距离和方向规则。无明确有限范围或无有效起点时，不猜测范围。pending 的范围坐标只发送给选择拥有者。

范围与候选分别经过视图模型进入渲染器。合法目标格不叠加淡蓝色填充，保持原有识别效果；取消、切换选择和退出历史时沿现有高亮生命周期清理。点击和拖动仍使用原来的合法候选集合。

验证包括范围与候选差异、正方向和地图边界、pending 投影隐私、渲染层清理，以及真实训练页面的可视检查。
