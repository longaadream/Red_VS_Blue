## 验收流程

1. 打开管理器，从官方内容复制出普通内容项目文件夹，或新建空白项目。
2. 外部 AI/文本工具修改角色 JSON、贴图及技能代码；管理器刷新可见并校验。非法 JSON 显示具体文件/位置，不能覆盖源文件。
3. 一键加载到客户端测试，实际执行修改后的技能；目标选择/取消及失败无半提交行为有效。
4. 导出完整社区包，在另一内容安装中导入，不要求 GitHub 登录；一次只启用一套内容。
5. 切换或回退内容；失败激活恢复旧版本。有活动对局时给出明确提示。
6. 官方发布需要作者明确确认；本地未发布改动不进入玩家检查更新结果。
