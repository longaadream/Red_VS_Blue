# 瞬步作者草案

设计草案，未实施。基线aizen-shunpo：行动点1、充能点0、冷却1、每局次数不限。灵压要求主要目标攻击力低于施法者。落点距该敌人不超过2，需可行走且空置。基线只有位移成功后才给行动点。

```text
技能：瞬步
触发器：使用技能
行动点消耗：1
充能点消耗：0
冷却：1
每局使用次数：不限

code：
    新建【棋子】变量【目标】 = 目标选择器(
        类型：棋子，范围：5，筛选条件：{关系：敌方}
    )

    如果 目标.攻击力 >= 当前棋子.攻击力：
        返回 构造行动结果(
            成功：false，提示：目标攻击力必须低于施法者
        )

    新建【地格】变量【落点】 = 目标选择器(
        类型：地格，中心：目标.位置，范围：2，
        筛选条件：{可行走：true，被占用：false}
    )

    新建【位移结果】变量【结果】 = 位移(
        棋子：当前棋子，起点：当前棋子.位置，终点：落点，
        敌军可通过性：false，友军可通过性：false，
        不可通行地格可通过性：false，中间地格是否经过：false
    )

    如果 结果.成功：
        调整资源(
            玩家：当前棋子.所属玩家，资源：行动点，
            变化量：2，允许超过上限：true
        )
```

用户已确认调整资源支持允许超过上限参数，默认为false；瞬步显式true，保留基线直接增加2行动点的行为。上述为新标准作者代码，尚未接入运行引擎，不新增临时行动点独立资源池。

基线传送成功判定表达的是奖励条件，不是技能自写目标失效或来源死亡fallback。后续编辑器应呈现“位移成功后获得2行动点”。
