    )
    新建【元组<棋子>】变量【敌军】 = 目标选择器(
        类型：元组<棋子>，方式：自动，中心：当前棋子.位置,

    )
    新建【元组<棋子>】变量【有序敌军】 = 排序(
        容器：敌军，依据：(敌人) => 距离(当前棋子,敌人)，顺序：升序
    )
    新建【棋子】变量【目标】 = 有序敌军[1]
    新建【映射<数值,数值>】变量【倍率】 = {1:2，2:1.5，3:1，4:0.5}

友军与阻挡弹射物地形截断射线，首个敌军本身包含在命中候选中并截断后续。没有敌军时索引无效，依赖目标的计算/伤害跳过，释放默认成功；不写fallback。整数伤害由引擎向下取整。日志应保留友方阻挡、地形阻挡、未命中、实际伤害等基线结果，未来需公共射线查询事实/表现适配，当前作者查询返回元组不伪造阻挡原因字段。新四箭头方向UI依此前已确认方向选择器合同实施，不宣称与旧地格点击界面已经一致。

## 超级霰弹

```text
Skill：超级霰弹
触发器：使用技能
行动点消耗：0
充能点消耗：2
冷却：2
每局使用次数：2

code：
    新建【方向】变量【方向】 = 目标选择器(
        类型：方向，中心：当前棋子.位置，方向范围：正方向
    )
    新建【地格】变量【原点】 = 当前棋子.位置
    新建【元组<地格>】变量【射线地格】 = 目标选择器(
        类型：元组<地格>，方式：自动，中心：原点,
        方向：方向，形状：射线，范围：4，筛选条件：{}
    )
    遍历【射线地格】中的每一项【地格】：
        如果 地格.地形 == 地形定义引用(墙) 或 地格.地形 == 地形定义引用(掩体)：
            地格.地形 = 地形定义引用(普通地板)

    新建【映射<数值,数值>】变量【倍率】 = {1:4，2:2，3:1.5，4:1}
    遍历【射线地格】中的每一项【地格】：
        新建【元组<棋子>】变量【敌军】 = 目标选择器(
            类型：元组<棋子>，方式：自动，中心：地格,
            范围：0，筛选条件：{关系：敌方}
        )
        新建【数值】变量【距离值】 = 距离(原点,地格)
        遍历【敌军】中的每一项【敌人】：
            造成伤害(
                目标：敌人，类型：普通，伤害量：当前棋子.攻击力 × 倍率[距离值],
                伤害来源：当前棋子
            )
```

射线地格按距离近到远遍历，地图边界裁切；先处理整条射线的墙/掩体，再逐地格查询当时的敌军并逐个伤害。不是同时伤害，不提前快照所有敌军而改变反应中移动到后续地格的行为。倍率是固定射线地格距离；作者已在破墙前保存地格原点，避免来源被反应移动后距离变化导致倍率错位；公共查询顺序/原点值保存及权威执行挂起恢复需工程核对。基线在循环中读取source.attack，保留逐目标当前攻击读取。破坏数量和命中数量日志来自权威记录，不由UI重算；地格附着效果保留，其他地形不改。空方向仍成功。没有击退效果。

## 止血绷带：正常治疗，已确认

基线Rule监听afterDamageTaken：实际正伤害后，棋子仍活着且当前HP<=6、spentPassives中尚未登记才响应；先登记每局使用，再直接令currentHp=min(maxHp,currentHp+4)，创建永久可见已触发状态。旧直接生命写入没有调用治疗权威流程。用户明确此效果本来就是正常治疗，不能跳过治疗模块；最新规范以恢复生命权威模块修正旧实现，不保留旧绕过行为。

以下为已确认的正常治疗作者方案；治疗阻挡及前后事件沿公共恢复生命模块，不引入直接生命赋值接口：

```text
Cluster：止血绷带
成员：止血绷带被动Skill、止血绷带Rule

Rule：止血绷带
触发器：当前棋子.受到伤害后
code：
    在【当前棋子.extension】中新建【布尔】变量【绷带已使用】 = false
    如果 当前棋子.当前生命值 <= 0 或 当前棋子.当前生命值 > 6：
        结束
    如果 当前棋子.extension.绷带已使用：
        结束
    当前棋子.extension.绷带已使用 = true
    恢复生命(目标：当前棋子，数值：4，来源：当前棋子)
    附加状态(目标：当前棋子，类型：止血绷带已触发，强度：1，持续时间：永久)
```

标记可见/可驱散，使用次数保存在extension，驱散显示标记不返还次数；被动Rule重复挂载自然去重，不以角色名判断。正常治疗受阻不回退已记录的使用次数，沿本次先消耗再治疗的方案；新局实例extension重新初始化，不靠可驱散状态承担每局次数。致命伤HP0不回复，不取消死亡。禁疗是需要明确的验收场景。
