## 类型与引用

| 类型 | 含义 |
| --- | --- |
| 数值 | 允许小数运算；整数属性写入或效果结算由引擎向下取整；整数分半n/2见最新算术约定 |
| 布尔 | true / false |
| 字符串 | 显示文字；支持变量、extension字段及泛型容器，不代替对象引用 |
| 玩家 | 玩家引用 |
| 棋子 | 某个具体棋子实例的引用，不是棋子模板 |
| 地格 | 棋盘位置引用；地形字段保存地形定义引用 |
| 地形定义 | 一种地形的定义引用，含可行走/弹射物可通过等属性 |
| 区域 | 一组地格组成的区域引用 |
| 棋子定义 / 棋子模板 | 初始定义或供召唤创建实例的模板；具体结构继续补充 |
| 手牌定义 | 某种手牌的模板，例如圣光惩击 |
| 手牌 | 某一张具体手牌的实例引用 |
| 状态 | 某个具体状态实例的引用 |
| 伤害结果 | 某次对单个目标造成伤害的结果 |
| 治疗结果 | 本次对单个目标恢复生命的结果，提供实际恢复量 |
| Skill | 内部实际技能实例，包含当前冷却、次数及extension |
| Rule | 独立规则实例，包含来源、挂载对象及extension |
| Cluster | 汇聚Skill、Rule及相关定义的技能组合；获得/移除以组合实例为单位 |
| 方向 | 朝向；正方向选择支持上、下、左、右 |
| 位移结果 | 权威位移提交结果；完整字段仍待商定 |
| 结构体 | 由具名、带类型字段组成的复杂类型；支持作者声明，字段可为实例引用或容器 |
| 坐标 | 二维整数坐标值；相对范围中表示偏移，字段x、y，不是地格实例 |
| 映射<T1,T2> | 按T1类型键查询T2类型值，不按集合位置取项 |
| 集合<T> | 对应Set；同类型元素不可重复，不提供位置下标，不用其内部遍历次序表达玩法顺序 |
| 元组<T> | 按用户命名对应C++ vector；有序、可重复、可增删、可按位置索引的同类型序列，不是固定异构tuple |

每张手牌都有独立实例身份。两张同名、同定义的牌不是同一个对象。选择手牌、添加标签、附加 Rule、强化数值或修改显示时，只作用于传入的实例；不能按名称或定义 ID 批量修改其他同名牌。对集合操作则以显式传入的实例集合为准。

引用与数值不同：棋子、手牌等变量保存引用；数值赋值保存当时的计算值。来源失活不等于所有历史记录不可读，死亡事件仍可提供死亡位置、所属玩家和初始定义。

### 旧草案容器迁移规则：最新确认

用户明确此前按列表使用的集合改用元组，而非强制去重。旧技能中的目标列表、手牌列表、编队/落点、实际经过路径、Skill/Rule成员列表和允许重复的数值记录使用元组；只有明确需要唯一成员语义的地方使用Set。查看者权限集合保持集合<玩家>。元组[1]为第一项。

排序、随机排序、筛选和长度等通用操作使用容器参数以同时支持元组与集合；筛选保留输入容器种类，不能默默去重。目标选择器显式声明元组<T>时返回有序列表，显式声明集合<T>时返回Set。查询同一棋子不会凭空生成重复项，但元组本身允许保存重复实例。效果模块对重复目标的结算次数不因容器改名擅自改变，需要在相应规则案例中明确。

## 通用执行契约

- 使用 `当前棋子.攻击力` 等属性访问语法，支持字面量、变量、表达式、嵌套调用。
- 失效目标使依赖它的整条语句无效；独立后续语句继续。不要求内容写目标存活 fallback。
- 使用前 Rule 引用尚未声明的局部变量时，跳过整条语句；不自动创建变量，不替代为0，不产生部分写入。
- `结束` / 裸 `return` 退出当前技能、手牌或Rule入口；在主动使用入口按默认成功结束，在Rule内只结束该次响应。位于循环或条件内也退出入口，不只是退出循环。已经结算的效果保留，详见返回结果契约。
- `阻止当前事件` 不等于结束当前 Rule；后续合法语句仍执行。
- 非法类型、契约错误和运行异常不是正常目标失效，不能通过跳过语句吞掉。
- 随机操作统一使用引擎可注入、可记录的种子随机流。
- 整数写入/结算自动向下取整；小数倍率保留中间值，整数分半n/2按最新约定在除法阶段向下取整；作者无需显式写取整。

## 循环结构

用户明确要求将集合遍历（for/foreach）和条件循环（while）纳入统一作者框架；它们是控制结构，不是棋子、技能或伤害专用效果模块。当前确认需要支持两种结构，以下语法为讨论草案，运行代码未改。

### 集合遍历（for/foreach）

```text
遍历【集合】中的每一项【局部变量】：
    语句
```

输入为 `集合<T>`，循环项保留T类型，可以是棋子、手牌、状态、数值等。命运庇护中的“对每个棋子”必须用此结构明确表达，不作为隐藏的批量效果。集合保证元素唯一，元组保留顺序与重复项；遍历两者均保留元素类型及实例身份。空容器不执行循环体。需要明确结算顺序时先转换/排序为元组。用户已确认动态遍历：循环中新增元素继续检查，删除当前元素不漏掉随后元素。具体游标与嵌套作用域由运行实现保证，未实施。

### 条件循环（while）

```text
当【布尔条件】成立时循环：
    语句
```

每次执行循环体前重新计算条件，条件不成立时不进入/停止该循环；循环体允许由已登记模块和其他控制结构组成，不接受任意脚本回调。条件使用失效引用时的完整语义仍须商定。用户已确认引擎设置循环次数上限，适用于while及动态遍历；具体数值、计数范围和超限处置待确认，不设未经确认的次数或静默截断。

### 待讨论的循环控制

用户已确认 `跳出循环`（break，只退出当前最内层循环）及 `继续下一次`（continue，跳过当前循环体剩余语句后进入下一次遍历/重新判断while条件）。已确认的 `结束` 为return，结束整个本次Skill/Rule执行，不等同于break。具体嵌套作用域及执行预算仍待补充，未实施。

## 变量与 extension

### 局部变量

```text
新建【T】变量【名称】 = 表达式
名称 = 表达式
```

声明建立类型；赋值必须符合类型。局部变量不自动持久化为 extension。

用户补充确认：extension 支持保存所有作者数据类型，不限于数值；包括泛型集合。可能重叠的数据可以按其类型存为集合，例如允许同值的多份数值保存为 `元组<数值>`。这不取消先声明再写入的要求，也不自动把棋子引用转为数值 ID；来源和目标的保存接口另行讨论。

### 持久变量

```text
在【当前玩家.extension】中新建【数值】变量【Multiplier】
当前玩家.extension.Multiplier = 1.5
删除变量（位置：当前玩家.extension，名称：Multiplier）
```

extension 必须先声明变量，再存值，不自动分配未声明字段。用户最新明确要求每一个类型均提供 extension，替代此前仅限玩家/全局及后续只扩展棋子/Rule/StatusTag的限制。支持全部作者类型及泛型集合，不排除手牌或Skill类型；不因此新增本次释放的全局状态来源。月神赐福倍率仍存玩家 extension。数值等值类型的extension身份、复制与持久化语义尚待实际案例确定，不能把统一接口直接解释为给共享数值字面量自动建立全局可变对象。

用户要求暂不继续讨论当前尚未涉及的来源/目标专用能力，改用所属实例的 extension 保存内容需要的数据，例如庇护状态的来源棋子。实例与定义数据不能混为一份，同名效果不应互相覆盖；具体复制、离场/移除后的保存、清理和序列化细节待逐技能确认。当前只记录设计，未改运行代码。

持久字段重复声明已确认：第一次新建时按声明类型创建并初始化；再次声明同名同类型字段复用已有值，不重新执行初始值赋值；同名但类型不一致报契约错误，不覆盖。真正重置通过显式赋值表达。用于多次伤害/多次施放安全声明玩家extension映射，防止清空整局记录；用户已认可这条规则；仅作用于持久extension字段，局部变量仍按每次执行建立。未实施。

删除变量的调用写法已在月神赐福消耗 Rule 中确认。持久字段同类型重复声明复用已有值，类型冲突报错；缺失字段删除的详细行为仍待对齐。

## 查询与集合模块

### 目标选择器

```text
目标选择器（类型，筛选条件，范围？，最小距离？，方式？，可见玩家？） → T、元组<T>或集合<T>
```

| 参数 | 已确认的含义 |
| --- | --- |
| 类型 | 棋子、地格、手牌及元组<T>/集合<T>等目标类型；实例与定义必须区分 |
| 筛选条件 | 结构化字段，不能藏在任意源码字符串中 |
| 范围 | 棋子/地格空间查询的最大距离，例如5；采用该选择器声明的距离算法 |
| 最小距离 | 可选数值，默认1；与最大距离组成包含边界的区间，需要包含中心时显式设0 |
| 方式 | 支持手动选择和自动查询；已确认示例使用“自动” |
| 可见玩家 | 可选集合<玩家>；限制选择过程及结果的表现、提示和日志，省略正常公开 |

已讨论的筛选字段：关系为友方/敌方；地格可行走、被占用；具有/不具有状态；手牌所属玩家、所在区域、标签包含/不包含。圣光预言仍限定现有三种普通圣光手牌，不能因标签迁移自动扩大候选池。

用户已确认目标选择器可选参数可见玩家：集合<玩家>，限制选择过程及结果的表现与日志查看者，包括高亮和提示；省略时沿用正常公开选择。镜花水月仅指定蓝染所属玩家，不自动对同阵营队友开放；权威规则仍获得真实结果。权限须覆盖全部表现入口，不能只隐藏高亮却公开日志。该接口尚未实施，不因状态接口已有同名参数自动生效。

选择器不包含排序参数。手牌选择返回独立实例引用，现有秘密选择与查看者权限必须保留。数量范围与取消协议的完整参数结构尚待补充。

征讨号令引出的已确认扩展：可选 `候选集合：元组<T>或集合<T>` 参数，将选择限制为显式提供的集合。该技能输入元组<手牌定义>，返回单个手牌定义，再创建新的手牌实例；不混同于选择已有手牌。用户已确认该参数、技能主体及展示候选牌供点击的交互方向，未实施。

用户确认统一取消规则：交互入口默认不允许取消；需要取消的入口显式声明 `允许取消：true`。不在Rule触发器上统一授予其所有后续交互取消权限，不因是被动技能就默认允许取消。入口省略此参数等同false；具体取消后如何继续由对应流程契约明确，不将取消混同于非法目标。

圣光大远征讨论中的修订：主动技能尚未提交施放时的目标选择属于准备阶段，不必逐项写允许取消，退出准备等于未施放；不能没有有效目标就空放。该准备阶段退出不等同于取消已经触发的被动或已进入效果流程的交互；后者仍按入口显式声明。尚未按新框架实施。

### 射线目标选择的阻挡条件：已确认

用户已确认在自动射线选择器增加结构化阻挡条件：友军、敌军、阻挡弹射物地形（布尔）。从中心沿方向查询，只返回首个阻挡点之前的候选棋子；若阻挡点本身是候选棋子，包含它后停止。筛选关系不改变阻挡判断，不能先滤掉友军再错误穿过它。射线查询不是实际位移，不触发移动/位置改变事件；排序继续使用独立排序模块。

### 排序

```text
排序（容器：集合<T>或元组<T>，依据：(元素:T)=>排序值，顺序：升序或降序） → 元组<T>
排序（容器：集合<T>或元组<T>，比较：(a:T,b:T)=>数值） → 元组<T>
```

有序结果必须用新元组变量接收，不能赋回Set变量。元组输入同值保留原顺序；Set输入的同值顺序需要统一且可回放的实现，不假设玩家选取顺序。显式命名函数参数，类型从输入容器推导，查询函数只计算值不执行效果。

### 随机排序

```text
随机排序（容器：集合<T>或元组<T>） → 元组<T>
```

随机排序输出有序元组，保留输入各项及数量，元组输入的重复项不会被自动去重。统一使用引擎种子随机流。Set输入须先建立可重放的初始枚举次序，不能依赖不受控的容器内部次序；具体算法与随机流消耗仍待工程对齐，不修改现有随机算法。

### 获取集合前若干项

```text
获取前若干项（元组：元组<T>，数量：数值） → 元组<T>
```

只对有序元组取前若干项，保留顺序及重复项。Set没有玩法意义上的“前n项”，先排序/洗牌为元组。越界与负数量政策继续按原待定项对齐，不静默补足落点。

### 集合基本操作：按已确认Set规范

```text
加入集合（集合：集合<T>，元素：T）
集合包含元素（集合：集合<T>，元素：T） → 布尔
移除集合元素（集合：集合<T>，元素：T）
```

按用户授权的正常Set处理，重复元素不新增，包含操作查询成员，删除缺失成员不做操作；不视为向有序列表尾部追加。元组的追加/插入/删除按vector类操作维护。本次使用追加元组（元组：元组<T>，元素：T），向尾部加入一项，保留重复值；不新增技能专用容器操作。不能把两张同名但身份不同的手牌当作重复元素。

### 获取集合项

```text
元组变量[n] → T 或无效值
映射变量[键] → 对应值或无效值
```

Set不支持位置索引，先转换/排序为元组。元组按位置取项，映射按键取值，缺失不能自动插入默认值；保留已确认无效值使依赖语句跳过的规则。用户已确认元组下标从1开始，[1]表示第一项；采用vector的有序可重复功能，不采用C++的0起始编号。

### 获取长度

```text
获取长度（容器：元组<T>或集合<T>或映射<K,V>） → 数值
```

返回容器项数；元组重复项逐项计数，集合计唯一元素数，映射计键数。与元素类型无关。用于统计全场圣盾棋子等，不新增专属计数模块。

### 随机选择

```text
随机选择（容器：元组<T>或集合<T>） → T或无效值
随机选择（集合：集合<T>，数量：数值） // 数量重载完整契约仍待定
```

用户已确认单项重载：省略数量直接返回一个元素，空容器返回无效值，使依赖语句失效；使用引擎种子流，不要求先随机排序整个容器。元组按位置均匀取项（重复项保留权重），Set需有稳定可回放枚举次序。按炎灵基线非空随机下标一次抽取对齐，避免迁移为全洗牌改变随机流消耗；具体实现验证仍未执行。

带数量重载的返回单项或容器、是否允许重复等尚未确认；月神赐福数量1历史写法不据本次自动定稿。用户只确认单项取值，不将旧数量参数解释为自动支持批量有放回抽样。

## 伤害与恢复

### 造成伤害

```text
造成伤害（目标，类型，伤害量，伤害来源）
```

| 参数 | 类型与行为 |
| --- | --- |
| 目标 | 棋子、元组<棋子>或集合<棋子> |
| 类型 | 普通 / 真实；不提供物理、法术或毒素类别 |

## 整数分半直接使用算术：最新确认

## 语句故障隔离与不得卡死（2026-10-12 用户最新确认）

这是跨模块引擎的强制设计目标，尚不表示所有运行路径已实现。运行时某条语句出现问题，必须终止该条语句、记录错误并跳过，继续执行与其无依赖的后续语句，不能让对局永久停在异常、选择或表现等待中。

- 缺失目标、失效引用、异常或无法完成的操作不能制造一个伪造的成功结果。该条结果标为无效；读取它的依赖语句同样跳过，独立语句照常执行。不得把无效值隐式当成0、false或另一个同名实例。
- 跳过不是吞掉异常：记录回合/阶段、执行实体、命令、语句/模块位置、错误原因、关键状态及随机种子（相关时），供界面提示和回放定位；不要为同一错误无限弹窗或无限重试。
- 错误语句不得遗留半提交的资源、棋子占用、锁或等待标记。正常模块应通过权威校验与提交边界维护不变量。已经成功结算的前序效果保留，不为恢复执行而重放；本条“跳过”不授权整个技能回滚或再次扣费。
- 循环、递归及事件链必须有有限的执行保护；超过保护上限退出对应执行结构并记录原因，后续独立流程可继续。具体上限仍沿用已确认配置，未定数值不在此擅自设置。
- 玩家选择等待、动画等待及异步模块要区分正常等待与异常悬挂。正常等待玩家输入不是语句故障；目标消失、候选失效、取消或等待异常应按接口完成/取消/失效规则恢复调度，不能遗留永久pending。动画失败不得锁死规则执行。无需作者为每条语句编写fallback。
- 合法的显式`返回 使用失败`、`返回 使用成功`或结束语句仍按其契约终止相应执行范围，不因容错规则而被忽略；编辑阶段已发现的结构/类型错误仍显示诊断，不把非法内容冒充有效内容保存执行。

必测：坏语句后的独立伤害/治疗仍执行；依赖坏返回值的语句跳过；循环超限可退出；选择目标离场/候选耗尽和动画异常能释放等待；故障不重复扣费、不重放效果、不污染占用；同种子同输入的故障路径可复现。按模块提供实现与回放证据后才能声称本原则已落地。
