# 教程对手 AI

关联：RED-228；基础合同：`docs/technical/AI_ENVIRONMENT.md`、`docs/technical/PVP_PRACTICE.md`。

教程自由练习使用 `lib/game/tutorial-ai.ts::planTutorialAiAction`。它固定组合现有
`practiceEnvironment`、公开状态评价器 `evaluateZeroStageState` 和短程搜索，不创建新的规则、随机源或
私有状态投影。调用方每次只提交 `nextAction`，权威结算后再用最新状态重新规划。

默认搜索配置为深度 3、beam 6、每次决策 128 个节点、每回合 896 个节点和每回合最多 24 个已接受的普通操作。
教程主线程的测量预算为普通决策 250ms、部署决策 500ms、每回合 2500ms。这些时间是搜索边界上的测量值，
不是可抢占的硬实时承诺；单个不可中断的规则模拟可能超过边界。

运行时使用课程定义的 `rootSeed`，并在可用时与 `getBattleRootSeed` 交叉核对。搜索续接、累计节点和累计耗时只
跨同一实际回合和当前玩家保留；行动计数在权威提交成功后才增加。待处理选择暂时交给人类时不重置同一回合的预算，
回合切换才开始新的预算。

教程仍按教学脚本播放开场示范。进入自由练习后，对手每次只播放一个已规划行动，并在播放期间检查权威状态和输入拥有者；
状态过期时丢弃该行动并重新规划。规划失败、没有行动或权威拒绝选定行动会显示明确的中断状态，不静默退回旧 AI。

回退方式是移除 RED228 的适配器和教程运行时接入，保留最新依赖的规则及预演源码，再重建匹配的生成引擎；不涉及存档、规则数值、
卡牌或其他 AI 模式，不应撤销依赖同步或整目录覆盖资源。
