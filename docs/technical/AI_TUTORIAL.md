# 教程对手 AI

RED-230 新增 `tactical-intuition` 标准对局样板，首页同时提供目标教学与直接 AI 实战入口。双方八枚预设棋子保持模板正常生命，标准渐进部署使用权威部署状态；玩家增援选择不由教程 AI 代选。`practice=1` 只关闭该课目标引导，不改变规则、生命或部署流程。

新课从自主阶段开始，使用下述 RED-228 规划器。目标教学反馈来自已接受操作的实际前后状态，不另外计算伤害或未来威胁。旧课开场示范保持原行为。退出与重开必须使旧的异步对手操作失效，重开保留当前入口模式。

关联：RED-228、RED-232；基础合同：`docs/technical/AI_ENVIRONMENT.md`、`docs/technical/PVP_PRACTICE.md`。

教程自由练习使用 `lib/game/tutorial-ai.ts::planTutorialAiAction`。它固定组合现有
`practiceEnvironment`、公开状态评价器 `evaluateZeroStageState` 和短程搜索，不创建新的规则、随机源或
私有状态投影。调用方每次只提交 `nextAction`，权威结算后再用最新状态重新规划。

默认搜索配置为深度 3、beam 6、每次决策 128 个节点、每回合 896 个节点和每回合最多 24 个已接受的普通操作。
RED-232 将自由对局搜索移入独立的现有练习 Worker 实例，使用 `tutorial-plan` 请求，正式权威结算和预演保持原入口。
Worker 使用现有资源加载与版本校验，不借用练习对局的 session 状态。普通决策的测量预算为 250ms、部署决策 500ms、每回合 2500ms。这些时间是搜索边界上的测量值，
不是可抢占的硬实时承诺；单个不可中断的规则模拟可能超过边界。

普通教程搜索申请至多十二个根候选的基本比较，包含结束回合以及可用技能、卡牌和移动候选，避免软决策截止只留下结束回合。
此比较可超过单次软时间，但不放宽累计回合时间、节点或动作上限；耗尽的继承预算仍停止搜索。`overDecisionBudget` 和
`overTurnBudget` 如实报告超界。普通练习的默认搜索顺序与预算保持不变，无收益动作仍可正常结束回合。

运行时使用课程定义的 `rootSeed`，并在可用时与 `getBattleRootSeed` 交叉核对。搜索续接、累计节点和累计耗时只
跨同一实际回合和当前玩家保留；行动计数在权威提交成功后才增加。待处理选择暂时交给人类时不重置同一回合的预算，
回合切换才开始新的预算。

教程仍按教学脚本播放开场示范。进入自由练习后，对手每次只播放一个已规划行动，并在播放期间检查权威状态和输入拥有者；
状态过期时丢弃该行动并重新规划。退出与重开销毁旧搜索实例并拒绝待决请求。规划失败、没有行动或权威拒绝选定行动会显示明确的中断状态，不静默退回旧 AI 或主线程搜索。

教程本地 PUT 直接交由 canonical runner 执行隔离复制，保留正式随机游标、审计与回放，不再先复制完整状态一次。
非教程训练入口保持原复制边界。可选 `tutorialPerf=1` 仅用于本地验收测量，不改变游戏规则或搜索结果。

棋盘普通重绘后可在下一帧恢复同一局面、选中角色、技能与目标的已请求公开预演，继续使用原预演控制器的缓存和不可预演提示。
取消、指针离开、换技能、局面或目标版本变化、退出与历史查看使旧请求失效，不能恢复过期预演。这项显示生命周期修复不改变技能释放或合法目标规则。

RED-234 补上目标技能在视角变化后的预演恢复：渲染器只记录未按下的鼠标位置，视角变化后更新摄像机矩阵并重新命中当前地格；即使仍是同格，也重新发出悬停意图。页面只恢复当前命中的合法目标，离开、按下、取消、无命中或销毁后不沿用旧地格。无目标技能仍走原悬停恢复，既有历史和权威版本护栏不变。此为确认的视角生命周期修复，不代表所有冰霜箭偶发问题已复现。

教程 onAiDecisionResult 额外提供 score、两类预算超界标记、复制的 continuation 和根候选诊断。根候选按评估/拒绝优先保留最多64条，只包含ID、原因、分数与拒绝码；完整遗漏/阻挡/重复数量另行计数。页面只在既有 tutorialPerf=1 的最多20条性能记录中保存这些信息，不新增普通玩家调试界面或搜索状态。它用于区分部署后预算耗尽与真实比较后的结束决策；RED-234 未更改AI预算或评分，用户的开局只部署便结束仍未得到精确复现与修复结论。

候选验证服务可通过显式 `RVB_QA_REPLAY_STATE` 从工作树 `output/` 内的 JSON 回放状态提供本地诊断端点；默认关闭，仅监听 loopback。
页面还须同时启用 `tutorialPerf=1&qaReplay=1`，恢复完整权威元数据后继续走正式教程入口。此为后期回放恢复验收，不是普通产品入口或存档读取功能。

RED-232 回退应撤销该任务的搜索桥接、Worker 消息和提交优化，再重建配套网页/Worker 引擎，保留 RED-230 教程与 RED-231 预演。

回退方式是移除 RED228 的适配器和教程运行时接入，保留最新依赖的规则及预演源码，再重建匹配的生成引擎；不涉及存档、规则数值、
卡牌或其他 AI 模式，不应撤销依赖同步或整目录覆盖资源。
