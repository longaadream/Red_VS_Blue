# 眼棱作者代码草案

基线illidan-eye-beam已核对，实际伤害量字段语义用户已确认。作者草案，未实施。

```text
技能：眼棱
触发器：使用技能
行动点消耗：1
充能点消耗：0
冷却：3
每局使用次数：不限

code：
    新建【棋子类型】变量【目标】 =
        目标选择器(类型：棋子，范围：4，筛选条件：{敌方：true})
    新建【数值类型】变量【伤害量】 = 当前棋子.攻击力
    新建【伤害结果类型】变量【结果】 =
        造成伤害(目标：目标，类型：普通，伤害量：伤害量，伤害来源：当前棋子)
    恢复生命(目标：当前棋子，数值：结果.实际伤害量，来源：当前棋子)
```

恢复量按该伤害权威返回事实计算，不在after反应后重新读取目标HP来反算。完全阻挡恢复0，不将0治疗当作释放失败，不要求作者另写是否成功判断。若释放者已失效，恢复语句自动失效。
