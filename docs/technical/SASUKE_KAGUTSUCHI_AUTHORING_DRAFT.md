# 加具土命作者代码

基线sasuke-kagutsuchi。用户已确认强度就是层数，本次附加最多4层、总强度不限。此文是完整主动技能组合草案，不代表天照所有Rule或运行迁移已经完成；共享地格登记由天照铺设流程维护。

```text
技能：加具土命
触发器：使用技能
行动点消耗：1
充能点消耗：0
冷却：1
每局使用次数：不限

code：
    新建【棋子】变量【目标】 = 目标选择器(
        类型：棋子，范围：99，筛选条件：{}
    )
    新建【玩家】变量【伤害玩家】 = 当前棋子.所属玩家
    新建【地格】变量【中心】 = 目标.位置
    新建【集合<地格>】变量【全局.extension.天照地格】 = {}
    新建【映射<地格,区域>】变量【全局.extension.天照区域】 = {}
    新建【映射<地格,棋子>】变量【全局.extension.天照来源】 = {}
    新建【映射<地格,玩家>】变量【全局.extension.天照伤害玩家】 = {}

    新建【集合<地格>】变量【消耗地格】 = 筛选(
        容器：全局.extension.天照地格，
        条件：(地格) => 距离(地格, 中心) <= 4
    )
    新建【数值】变量【消耗数量】 = 获取长度(容器：消耗地格)
    新建【数值】变量【附加强度】 = 2
    如果 消耗数量 == 1：
        附加强度 = 3
    如果 消耗数量 >= 2：
        附加强度 = 4

    遍历【消耗地格】中的每一项【地格】：
        新建【区域】变量【区域】 = 全局.extension.天照区域[地格]
        移除集合元素(集合：全局.extension.天照地格，元素：地格)
        删除映射项(映射：全局.extension.天照来源，键：地格)
        删除映射项(映射：全局.extension.天照伤害玩家，键：地格)
        删除映射项(映射：全局.extension.天照区域，键：地格)
        移除区域(区域：区域)

    新建【StatusTag】变量【灼烧】 = 附加状态(
        目标：目标，类型：天照灼烧，
        强度：附加强度，持续时间：永久，来源：当前棋子
    )
    在【灼烧.extension】中新建【玩家】变量【伤害玩家】 = 伤害玩家
```

范围99保留基线选择参数，可选任意阵营棋子，不擅自换成仅敌方。中心在消耗前保存为地格；查询曼哈顿4格内全部天照，不按铺设来源或所属玩家筛选。消耗0/1/至少2格时分别附加2/3/4强度，但无论多少格都全部消耗，不能只移除两个格子。新附加状态使用来源分组后的普通叠加：同来源叠加，不同来源保留独立实例。不先移除旧状态，也不手算旧强度。

全局extension中的集合与映射为同一场战斗现有全局扩展存储，不新建外部单例或第二份战斗状态。天照地格作为Set唯一登记；天照区域按每格独立单格区域投影，映射由天照之炎/因陀罗之矢铺设阶段创建并维护；天照来源保留首次铺设棋子。相同地格键必须引用地图同一规范地格，不因临时坐标对象生成不同键。首次声明初始化、重复声明复用，不能在每次技能使用时清空天照。

这些共享字段是作者组合的存储约定，不是新增技能专属原子模块。铺设必须保证Set与三个映射一致；缺映射是数据不变量错误，不按普通目标失效静默掩盖。先清登记再移除区域，移除只清该区域tileEffect，不改变原地图地形属性。只消费地格区域，棋子身上已经附着的灼烧完全保留；消耗后天照伤害Rule仍应结算已有灼烧，不因为地格为空移除伤害Rule。

来源参数显式使用当前棋子，来源与已有状态相同时按普通规则叠加；不同时新增独立状态，不覆盖其他来源。基线历史来源字段不统一；新规范用原棋子引用区分叠加来源，并在灼烧extension中直接保存玩家伤害来源。两者不混用；玩家伤害及击杀不归到原棋子，其差异须在迁移中验证。目标在消耗后的独立反应中失效时，状态附加跳过，已消耗地格不回滚，遵循通用失效语句政策。

已批准差异：原代码min(4,旧层数+本次层数)的总强度钳制撤销。本次只有附加量最多4，目标原有同来源6强度且本次附加4时得到10强度；不同来源则保留6与4两个状态实例；永久状态合并保持永久。状态栏显示强度为层数，回合伤害Rule按2×强度计算；已获批准的普通状态叠加和逐格接触不得被旧stacks逻辑再次重复执行。
