## 完整作者代码

```text
Cluster：自燃
成员：自燃被动Skill、自燃·拒愈、自燃·灵力消耗、自燃·压制

Rule：自燃·拒愈
触发器：当前棋子.受到治疗前
code：
    阻止当前事件

Rule：自燃·灵力消耗
触发器：当前棋子.造成伤害后
code：
    如果 当前事件.目标 == 当前棋子：
        结束
    如果 当前事件.执行来源.定义引用 == Rule定义引用(炎灵燃地·踏入)：
        结束
    如果 当前事件.执行来源.定义引用 == Rule定义引用(炎灵燃地·回合结算)：
        结束

    在【当前棋子.extension】中新建【数值】变量【自燃余量】 = 0
    新建【数值】变量【总累计】 = 当前棋子.extension.自燃余量 + 当前事件.伤害量
    当前棋子.extension.自燃余量 = 总累计 % 5

    如果 总累计 >= 5：
        造成伤害(
            目标：当前棋子，类型：真实，
            伤害量：总累计 / 5，伤害来源：当前棋子
        )

Rule：自燃·压制
触发器：当前棋子.造成伤害前
code：
    如果 当前事件.目标 == 当前棋子：
        结束
    在【当前棋子.extension】中新建【数值】变量【压制回合号】 = -1
    如果 当前棋子.extension.压制回合号 == 当前回合.编号：
        结束

    当前棋子.extension.压制回合号 = 当前回合.编号
    遍历【当前事件.目标.技能列表】中的每一项【技能】：
        技能.当前冷却 = 最大值(技能.当前冷却，1)
```

同名同类型extension重复声明复用已存值，不在每个事件清0；初次声明初始化，复制/偷取时共享持有棋子字段的具体计数携带不擅自扩展。自燃内部数字不再用强度可归零的StatusTag，避免自动耗尽删除历史；旧余量和压制标记不可见，不新增状态栏显示。基线原压制标记按全局回合编号记录，本方案同一玩家回合编号内最多一次，下一玩家回合即可再触发。

伤害后当前事件.伤害量为该目标实际生命扣减，排除吸收/溢出。自伤排除目标==当前棋子，燃地排除类型化Rule定义，不用字符串；普通其他对外直接伤害均可累计。%为通用数值余数运算，5为正整数，无负数余数政策扩展。总累计/5可保留小数，造成伤害权威整数结算向下取整，作者不显式floor。一次跨多个5保留基线合成同一伤害请求：余量3+伤害10=13，余量变3，一次自伤2；不改成两次伤害1从而改变盾/反应触发次数。伤害前Rule改写仍可正常改变这一次自伤。

自燃自伤在当前伤后响应完成后的调度继续按权威效果链执行，不能把内容队列改为抢先递归造成相邻Rule差异。强度自动耗尽规则不影响这些数值extension变量，Skill冷却直接赋值仍经过权威写入与通知。

压制先记录回合再修改目标各内部Skill。对自己伤害不占次数；目标无Skill仍占次数。后续伤害被圣盾等阻止不返还本回合压制记录，先前已改的冷却保留。遍历Skill实例列表，不改共享技能定义，不增加新Skill/Rule。未知或失效引用沿统一契约，类型错误不吞掉。
