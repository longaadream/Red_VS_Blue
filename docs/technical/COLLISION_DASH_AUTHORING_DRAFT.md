# 火箭重拳与旋转冲刺：实际碰撞作者草案

固定基线`082166c6b803b2e838bce5f0f6824c5bbc714dd6`。用户确认位移返回实际首个阻挡棋子，包括贴身受阻；下列代码覆盖原预测目标方案。仅作者规范，未修改运行代码。

## 火箭重拳：rocket-punch

```text
Skill：火箭重拳
触发器：使用技能
行动点消耗：2
充能点消耗：0
冷却：1
每局使用次数：不限
code：
    新建【方向】变量【方向】 = 目标选择器(
        类型：方向，中心：当前棋子.位置，方向范围：正方向
    )
    新建【地格】变量【起点】 = 当前棋子.位置
    新建【元组<地格>】变量【方向地格】 = 目标选择器(
        类型：元组<地格>，方式：自动，中心：起点，形状：射线，方向：方向，
        范围：5，最小距离：0，筛选条件：{},
        阻挡条件：{友军：false，敌军：false，阻挡弹道地形：false}
    )
    新建【元组<地格>】变量【由远到近】 = 排序(
        容器：方向地格，依据：(地格) => 距离(起点, 地格)，顺序：降序
    )
    新建【位移结果】变量【结果】 = 位移(
        棋子：当前棋子，起点：起点，终点：由远到近[1]，
        友军可通过性：false，敌军可通过性：false，
        不可通行地格可通过性：false，中间地格是否经过：true
    )
    如果 结果.首个阻挡棋子.阵营 != 当前棋子.阵营：
        造成伤害(目标：结果.首个阻挡棋子，类型：普通，
            伤害量：当前棋子.攻击力 × 2.5，伤害来源：当前棋子)
```

射线只给出本方向最远尝试终点，不要求地格可行走或空置；沿途是否可通过完全交给位移的三个布尔参数。最小距离0包含起点，向地图外侧选择时不生成非法地格。中间地图空洞依位移权威检查停止，不跨过缺失地格。终点在第5格则不会打第6格棋子。

友军也阻挡但不受伤；墙/洞等不可行走格阻挡但返回空棋子。贴身敌人使发生位移为false，仍可直接受到伤害；不得写“没有移动就结束”。纯事件拦截没有棋子碰撞则不出伤。倍数运算由引擎自动向下取整，使用碰撞结算后当前攻击力。

## 旋转冲刺：sonic-spin-dash

Cluster初始化展开[动能共享依赖](SONIC_MOMENTUM_AUTHORING_DRAFT.md)中的声明与Rule部署，并把本Cluster实际旋转冲刺Skill加入消费动能技能和更新动能技能两个Set。这些是普通作者语句，不按角色硬编码。

```text
Cluster：旋转冲刺
初始化声明区：
    展开动能公共依赖初始化语句
    加入集合(集合：当前棋子.extension.消费动能技能，元素：本Cluster.旋转冲刺)
    加入集合(集合：当前棋子.extension.更新动能技能，元素：本Cluster.旋转冲刺)

Skill：旋转冲刺
触发器：使用技能
行动点消耗：1
充能点消耗：0
冷却：2
每局使用次数：不限
code：
    新建【方向】变量【方向】 = 目标选择器(
        类型：方向，中心：当前棋子.位置，方向范围：正方向
    )
    新建【数值】变量【原动能】 = 当前棋子.extension.动能
    新建【数值】变量【范围】 = 如果 原动能 >= 5 则 7 否则 5
    新建【地格】变量【起点】 = 当前棋子.位置
    新建【元组<地格>】变量【方向地格】 = 目标选择器(
        类型：元组<地格>，方式：自动，中心：起点，形状：射线，方向：方向，
        范围：范围，最小距离：0，筛选条件：{},
        阻挡条件：{友军：false，敌军：false，阻挡弹道地形：false}
    )
    新建【元组<地格>】变量【由远到近】 = 排序(
        容器：方向地格，依据：(地格) => 距离(起点, 地格)，顺序：降序
    )
    新建【位移结果】变量【结果】 = 位移(
        棋子：当前棋子，起点：起点，终点：由远到近[1]，
        友军可通过性：true，敌军可通过性：false，
        不可通行地格可通过性：false，中间地格是否经过：true
    )
    如果 结果.首个阻挡棋子.阵营 != 当前棋子.阵营：
        造成伤害(目标：结果.首个阻挡棋子，类型：普通，
            伤害量：当前棋子.攻击力 × 1.5，伤害来源：当前棋子)
        如果 原动能 >= 7：
            附加状态(目标：结果.首个阻挡棋子，类型：沉默，强度：1，持续时间：1)
            附加规则(挂载对象：结果.首个阻挡棋子，规则：沉默阻止技能)
    新建【数值】变量【本次动能】 = 获取长度(容器：结果.经过地格)
    如果 获取长度(容器：获取状态(目标：当前棋子，类型：保留动能)) > 0：
        当前棋子.extension.动能 = 原动能 + 本次动能
    否则：
        当前棋子.extension.动能 = 本次动能
```

友军允许经过但不能作为落点，敌军阻挡；途中地形仅看walkable，不重加地形名称白名单。范围和沉默资格使用原动能快照；普通命中被盾阻止也可附沉默，目标死亡则相关语句失效。沉默调用共享限制Rule，不是技能专属控制机制。

本次实际经过地格不含起点，累计成功走过的路程；动能写入发生在伤害及其反应后。是否保留在写入时查询标记；保留时使用基线原动能快照加步数，否则以步数替换。使用后公共消费Rule识别更新动能Skill，不再次清空。贴身无步数仍执行碰撞；没有碰撞的零步合法结果写0或保留原动能。失效请求没有结果时，依赖结果的写入跳过，不能当成合法0步。
