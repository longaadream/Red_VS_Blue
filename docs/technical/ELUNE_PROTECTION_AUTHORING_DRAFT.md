# 艾露恩的守护：完整作者草案

固定基线`082166c6b803b2e838bce5f0f6824c5bbc714dd6`，核对elune-protection、rule-elune-protection及rule-elune-protection-player。玩家级共享已确认，完整作者主体转A；不修改运行代码。

已确认：被动Cluster包含召唤后授予Rule；召唤时向所属玩家授予永久可见守护，已持有不重复授予。玩家级防护Rule独立存在，泰兰德离场后仍有效。防护在友方棋子伤害应用前，比较防御/吸收后最终伤害与当前生命；非致命不消耗。致命时先消费守护、阻止当前伤害，再正常调用恢复生命5，治疗来源为玩家；不能直接写生命，也不是取消死亡。被阻止后不触发实际受伤后；消灭不属于伤害，不受此守护保护。

不采用旧草案的“当前状态”隐式绑定：Rule应查询挂载玩家的实际守护StatusTag，再移除实际实例；Rule与状态不自动关联。默认不叠加/已有不授予保证单玩家一次资格，不增加角色ID硬编码或棋子死亡清理。

用户确认每个玩家独立持有一份，均可保护同阵营棋子；2v2两个玩家各有一份即总共两次。一个玩家的多个泰兰德仍共享该玩家的一份，不叠加。描述应明确“所属玩家持有一次，可保护友方棋子”，避免“全队共享一次”误导为阵营去重。

```text
Cluster：艾露恩的守护
成员：艾露恩的守护被动Skill、守护授予Rule
引用定义：艾露恩守护StatusTag、守护防护Rule

Rule：守护授予
挂载对象：棋子
触发器：当前棋子.召唤后
code：
    新建【玩家】变量【玩家】 = 当前棋子.所属玩家

挂载对象：玩家
触发器：友方棋子.伤害应用前
优先级：-100
code：
    新建【元组<StatusTag>】变量【守护们】 = 获取状态(目标：当前玩家，类型：艾露恩守护)
```

玩家Rule中的当前玩家是挂载玩家，不是当前回合玩家或伤害来源玩家；友方上下文按该玩家阵营过滤。非正伤害由引擎提前结束。守护声明不叠加，重复附加忽略新状态。Rule独立去重，不随状态消费删除；泰兰德死亡不撤销玩家已取得的守护。消耗后再次召唤可以重新授予，不增加终身一次标记。

同次伤害按统一优先级顺序响应，被第一份守护阻挡即停止后续伤害监听，不能再消费队友那一份；同优先级使用引擎既定排序/种子规则，不为泰兰德另定顺序。阻止事件不结束正在执行的这条Rule，因此仍调用正常治疗。消费状态产生的反应和治疗事件须沿统一调度，不能重复响应原伤害。
