# ADR-0035：桌边便笺与桌面窗口偏好独立于战斗状态

- 状态：已接受，候选实现等待 RED-241 人工验收
- 日期：2026-10-08
- 授权：用户已确认交接计划，并明确要求按计划实现。

## 决策

桌边便笺属于房间内交流，采用独立 Colyseus 消息类型。它需要房间身份认证、稳定参战身份的 3000ms 冷却、请求去重与授权收件人；不需要也不能消费战斗命令、authority version、战斗随机数或持久化 journal。服务端进程内保存有界冷却/请求缓存，原生断线重连不清空；房间销毁后清理，不承诺服务器重启后保留便笺。

Electron 默认全屏属于游戏主窗口的本机偏好，采用独立带版本文件，不能写入游戏存档或改动 admin/editor 窗口。只有现有可信 game renderer 的有限 boolean IPC 与 F11 可以显式切换；不存在 Electron bridge 的调试页面隐藏入口。

背景、资源转盘、沙漏、角色签与提示纸条只消费既有投影。部署落位影像仅是位置提示，规则执行仍由原部署命令完成。预演继续复用继承候选的隔离规则运行与隐私边界。

## 取舍与回退

便笺不进入战斗回放，因此回放只还原战斗。旧服务端不声明支持时客户端禁发并给出可读状态。独立窗口文件缺失或损坏时回退默认全屏并记录异常；不破坏原配置。

社交、桌面偏好、UI 材质可分别撤销，保留此前已验证的移动与技能预演。详细接口见 [RED241_TABLETOP_UI](../technical/RED241_TABLETOP_UI.md)。不自动合并或发布。
