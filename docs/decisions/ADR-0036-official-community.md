# ADR-0036：官方账号好友与社区公告板

状态：已接受，候选等待验收
日期：2026-10-08
任务：RED-242

## 背景

玩家默认停留在离线入口，约人需要开发者逐个联系。用户批准增加好友、公告板和一次可关闭的启动登录提示。

## 决策

复用官方账号与同源官方服务，在独立社交表持久化好友关系、申请、屏蔽和公告板内容。账号由服务端会话认证，不采信请求中自报的作者或玩家身份；不公开邮箱。在线状态来自有过期时间的认证心跳，不由网卡状态或本机缓存宣称连接成功。社交内容不进入 BattleState、随机、journal 或排位计分。

官方公告复用既有可信管理入口；玩家纯文本帖和回复有界分页、限频、作者删除及可信管理员隐藏。首版邀请复制原房间码，进入房间仍经既有联机权限校验，不新增自动入房能力。

首页突出在线社区。有效会话自动连接；未登录时同次客户端启动首次到首页提示一次，明确允许继续离线。主进程向游戏窗口传入公开随机启动标记，preload仅提供只读访问；该标记不是登录凭据，不增加可写IPC，返回首页或刷新不重新提示。进程重启标记变化；断网不阻断离线玩法。

## 取舍

不另建账号系统或修改战斗状态。首版不提供私聊、群组、图片上传和外部推送；人数少时先围绕好友及约桌交流组织社区。

## 验证与回退

双账号关系及内容流程、权限、并发申请、屏蔽、心跳过期、真实PostgreSQL持久化及官方服务重启、启动/返回首页/断网行为及原联机回归；独立审查。撤销入口与服务接入，保留新增表，旧账号和战斗数据继续可用。不自行合并或发布。
