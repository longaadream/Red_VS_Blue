# ADR-0034：统一位置提交与路径接触（RED-209）

状态：用户于2026-09-14批准实施。基线 main / be664e65cfb47b46019c0f045d9784c7dcd65b51。

一个公共位置提交器处理单体与整组位移；落点被占用、预留、限制或路径失效是正常取消，不能产生半组提交。重复身份和非法参数是契约错误。路径查询只产生事实，最终提交重新验证。

beforeMove/afterMove专指普通走格，定身只限制走格。beforePiecePositionChange/afterPiecePositionChange适用于全部棋盘位移；afterPiecePathContact提供实际接触格（不含起点，含终点，同次去重）。传送/换位只有落点；冲刺和走格有真实路径。死亡、部署与召唤保留生命周期。

修订ADR-0028的收集时机：所有成功位移在真实经过格和终点收集结晶，归移动棋子所属玩家；原地、取消不收集。沿用天照的提交后路径事实结算，不引入逐格可中断移动。整组先提交坐标，再统一收集/记账，随后发送充能与接触事件，防止先发生的反应改变同组收集。普通移动先扣AP再结算接触。旧afterMove中的地格订阅迁到接触事件，普通移动计数保持。

预留由宿主上下文授权，双尾飞行只能消费本次飞行预留。精确回溯不搜索替代格；复杂伤害/召唤组合保留各自生命周期。联合空间提交不引入新的EffectBatch种类，仍遵守ADR-0022。

鸣人分身和回溯的必要复合效果完成前，宿主可延迟接触反应；每次成功位置提交仍立即冻结拾取并记账。嵌套复合效果遵守父级延迟，连续多次位移保留每次接触事实；只在棋子仍位于对应终点时派发落点效果，路径接触不因后续移动丢失。该宿主机制不向技能作者开放任意跳过接触的选项。

范围：引擎空间/触发/位移/拾取与运行时入口、现役内容、语言词典、相关演出、测试与生成引擎。风险High。不得升级依赖、改伤害/费用数值、新增角色或发布。配套回退代码、内容与浏览器引擎，不删除用户数据。

验收：空间不变量、定身/禁锢、换位/编队、预留、路径穿越差异、沿途拾取与原地排除、地格去重、pending/重放、现役迁移清单、Node/browser一致性及独立审查。相关Linear合同RED-209已记录。
