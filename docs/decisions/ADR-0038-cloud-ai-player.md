# ADR-0038：独立云端 AI 玩家与可见信息隔离推演

状态：方案已获项目负责人批准，实现等待验收
日期：2026-10-09
关联任务：RED-249，RED-83

## 背景

现有即时收益剪枝会放弃需要连续投入的卡牌路线。完整离线 AIEnvironment 可以通过正式规则搜索目标，但线上玩家快照不是完整权威状态。ADR-0023 对普通客户端的只读预检限制也不允许预测伤害和触发链。

## 决策

项目负责人在 RED-249 对应聊天明确批准仅用于独立 AI 进程的例外：使用自己的手牌、公开棋盘和公开规则进行隔离推演，不读取对手手牌或服务器真实随机状态，每次只提交一步，收到权威状态后重新搜索。

- 例外只适用于 `lib/ai-bot/` 的独立 Node 进程；不接入普通浏览器、Electron 玩家 UI、Web Worker 或默认人机策略。
- 离线求解器接受明确授权的完整离线状态和种子。线上策略必须先生成字段白名单的影子状态；不得直接把玩家快照强制当作完整权威状态。
- 网络快照携带的种子、运行时游标、任意 extensions、私有库存、隐藏状态及执行代码均不能进入线上推演。静态技能和规则仅使用本地可信内容，服务器 Profile 必须与本地版本匹配。
- 影子状态中的伤害、随机事件、触发链和终局均是假设。缺失的隐藏信息或 pending continuation 不得通过服务器泄漏字段补齐；需要公开选择时逐步提交并由服务器结算。
- 每个真实动作使用新命令 ID 和最新 authorityVersion；同一命令的回执查询保持原 ID。任何未明确结算的命令都会暂停后续行动，不能以新 ID 重发。
- 重连通过原生 SDK 恢复原会话，重新同步权威快照，并先澄清未完成命令。服务器拒绝或新版本会覆盖旧计划。
- 不新增账号认证规则或放宽权限；使用现有官方登录和匹配接口。生产账号、部署、长期运行及实战强度不属于本次准备验证。

## 搜索边界

通用目标搜索不以即时正分为扩展条件。它搜索同一玩家同一回合内的路线，设置节点、深度及时间预算，并区分找到路线、完整搜索未找到、预算耗尽和输入错误。预算上限导致的不完整搜索不能证明无解。

五次召唤回归使用真实卡牌及完整离线实例，9 AP 足以验证五个连续动作。线上剩余 AP、未知动态规则和对手干扰可能让整条路线不可执行；必须重新规划，不能据此宣称具有全局最优策略或稳定胜率。

## 验证及回退

验证正式规则的五动作卡链、输入/全局规则隔离、隐私白名单、预算边界和原生回执/恢复流程。Cloud 与官方服实际运行另外记录，不能用本地测试代签。

新增入口不改变服务端或现有 UI，关闭独立机器人进程或撤销 RED-249 即可回退，无存档、数据库或协议迁移。
