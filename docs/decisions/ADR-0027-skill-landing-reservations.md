# ADR-0027：技能落点、动作内保留格与无落点收束

- 状态：已接受
- 任务：RED-174
- 日期：2026-09-02

## 背景

技能位移不一定遵守普通移动的直线路径和阻挡规则，但角色成功落地后仍必须位于可行走、未被其他存活角色占用的唯一地格。若只在整次结算结束后扫描重叠并抛错，已经进入 pending 的动作可能无法收束，也无法说明哪一个技能应让出落点。

## 决策

1. 规则层共享三种落点语义：精确落点只接受指定格；附近落点按技能给出的确定顺序选择首个合法格；编队落点只有在能一次分配完整且互不重复的阵型时才返回结果。三者都检查可行走地形、存活角色占用和动作内保留格。
2. 具有 `requireUnoccupied` 的已选地格在技能的 `beforeSkillUse`、技能本体和 `afterSkillUsed` 反应链中成为动作内保留格。反应技能不得把该格作为自己的落点；pending 重放保留同一组格子。
3. 合法目标查询尽早排除必然没有落点的目标，例如伊利丹不能把被占用格选作冲刺终点，剑心不能选择四周没有合法落点的敌人。技能本体仍在写入坐标前按当前权威状态复核，失效时只取消该技能效果。
4. 固定候选的 pending 若候选数量不足最低选择数，不创建空选择器，直接收束当前效果并继续外层事务。这样大远征等完整编队无法成立时不会留下无法回答的 pending。
5. 不增加结算末尾的全局重叠扫描或异常。回溯、暗影步等精确回到历史格的效果在目标格失效时清理自身记录并取消；不会寻找替代格。

## 结果

- 伊利丹可穿过并伤害敌人，但只在空格停下。
- 葛力姆乔与水门的反应移动不会抢占原技能已经选定的空落点。
- 剑心、水门等附近传送优先使用现有合法格；无合法格时不移动、不造成后续伤害。
- 圣光大远征只提交完整阵型；无完整阵型时不会产生空 pending 或部分移动。
- 相同状态、seed 与命令序列保持相同候选顺序和最终落点。

## 未采用方案

- 结算后发现重叠再抛错：定位太晚，可能使 pending 或外层动作无法完成。
- 所有技能位移强制复用普通移动：会错误引入直线路径、移动距离和途经阻挡语义。
- 精确回溯自动寻找附近替代格：会改变技能承诺，并可能产生不可预期的资源与站位结果。

## 验证与回退

- 固定 seed 覆盖伊利丹占用终点、葛力姆乔保留格、蓝染瞬步与水门前置触发竞态，以及 Node/浏览器运行时一致性。
- 单元测试覆盖精确、附近和编队分配；角色测试覆盖剑心、水门、大远征、回溯、暗影步和黑色月牙天冲的失效落点。
- 回退时整体回退 RED-174 的规则、数据、测试与浏览器引擎产物；没有存档、依赖、经济或随机算法迁移。
