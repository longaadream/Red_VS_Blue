# ADR-0001：部署阶段公开双方站位

> RED-138 取代说明：本文的公开站位、单枚重投与双方锁定只适用于 `legacy-reroll-v1` 和缺少 mode 的历史状态；新建对局默认的私有三选一渐进式部署见 [ADR-0024](./ADR-0024-progressive-reserve-deployment.md)。

状态：已接受
日期：2026-08-13
关联任务：RED-25

## 背景

Demo v0.1 核心对局合同原先规定部署重投阶段中每名玩家仅可查看己方站位。项目负责人已确认该规则应调整为双方均可查看全部站位。这会影响部署阶段的信息公开方式及对应验收场景，因此需要保留独立决策记录。

## 决策

在部署重投阶段，每名玩家均可查看双方站位。每名玩家仍最多可重投 1 枚核心棋子，也可以全部保留。双方锁定后同时确认部署结果；阶段时限仍为 45 秒。

## 备选方案

- 仅显示己方站位：不采用；已由项目负责人确认改为公开双方站位。
- 逐枚或逐次揭示对方重投结果：不采用；本次决策不引入额外的揭示步骤。

## 影响

- 更新核心对局合同第 5 节、核心循环、Demo 范围及 AC-04。
- 后续部署 UI、服务端状态同步和测试任务应以双方可见站位为依据。
- 不改变出生规则、重投次数、锁定流程或阶段时限。

## 验证方式

在 legacy 部署阶段，任一玩家可观察到双方全部初始站位；每方不能重投超过 1 枚；双方锁定后部署结果同时确认。新建对局验收改见[核心对局合同 §5](../product/DEMO_V0_1_CORE_MATCH_CONTRACT.md#5-渐进式预备区部署)及 AC-03、AC-04。

## 回退方式

如需恢复隐藏对方站位，创建新的 ADR 取代本记录，并同步修订合同、验收场景和相关实现任务。
