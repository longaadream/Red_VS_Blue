# ADR-0033：受信发行者的 JSON 脚本资源包

- 状态：已接受（用户 2026-09-10 明确要求保留 JSON 代码并支持打包发布）
- 任务：RED-202；本地合同见 `docs/qa/RED-202-IDE/PACK-PUBLISH-TASK.md`
- 范围：仅取代 ADR-0018 中外部资源包一律禁止脚本的规则；其他开放包、身份、PVE、哈希和激活合同保持有效。

## 背景

现有全部技能与规则包含 JSON 内代码。仅允许编辑却拒绝打包无法交付资源更新；为每个数字增加读取层也不是用户选择的工作流。

## 决策

增加 `authoring` 校验策略，供编辑器原包导入/导出。保留脚本文本且验证归档、路径、内容哈希和已有签名，但禁止联网资格和 smoke 执行。它不作为玩家安装策略。

外部运行时仅在签名验证成功且 keyId 命中宿主配置时放行脚本。名单来自应用安装目录的 `config/content-script-publishers.json`，不来自包或活动 Profile。未签名 local-dev 和社区渠道仍不接受可执行内容。开发模式允许无签名仅作用于无签名包；有签名包始终按外部包验证。

编辑器与客户端打包携带同一公钥 ID 名单，发行私钥仅留在编辑器用户目录。发布协调器在每次上传（含缓存重试）前验证包和身份一致性。所有检查通过后才创建/更新 GitHub Release。

已安装脚本 Profile 在启动、激活、读取验证快照、回滚时，从持久化原始包及补丁链重新验证签名和当前名单，并对比最终 Profile 身份。稳定版本失效时沿用已有启动恢复，退回随客户端分发的 Base；不继续运行被撤销信任的脚本。

## 影响与边界

用户明确点击「打开训练营」后，编辑器允许已接受 authoring 内容在独立浏览器沙箱预览。准备过程仍只验证并复制字节，不在 utility/main 进程执行用户代码，也不改玩家安装策略。训练页面与引擎来自编辑器程序目录，候选只能供 JSON 和已校验图片；缺失 JSON 不回退旧数据。独立临时 session 无 preload/Node/权限，禁止外部请求、窗口、下载；WebRTC 非代理 UDP 禁用，TCP 强制经过本地拒绝代理。临时打包目录在准备成功/失败后清理，关闭窗口释放会话。该入口只验证本地训练，不赋予联机或发布资格。

旧客户端需一次升级。此后兼容现有 helper/API 的 JSON 改动只发资源包；新增宿主能力仍需客户端更新。签名不提供沙箱，陌生作者不能自行签名获得执行资格。游戏客户端主进程及玩法规则实现不在本次修改范围内。

备选数值参数层、独立 JS 作者文件未采用：用户选择现有 JSON 与内置 IDE。资源自动下载/发现不在本次范围，保留手动导入和既有候选、激活、回滚流程。
