# ADR-0032：状态与地格效果的显式表现批次

2026-09-08，用户在动作动画验收中批准：地格效果、状态的批量添加和移除可入队，并在渲染时整批应用。基线为 main / b8a26a90fc591b61fef9fa33db4e679fb75eb33b，已刷新。

## 边界

本决策扩展表现层的同时播放白名单，不改变 ADR-0022 的四类权威 EffectBatch，也不推迟、合并或重新排序状态生命周期触发。风险 Medium；不修改随机、数值、存档、网络命令或部署。本轮范围为游戏表现记录接口、技能内容中的显式批次声明、浏览器表现与相关测试。

`context.presentationQueue.push(kind, apply)` 接受 `statusAdded`、`statusRemoved`、`tileEffectAdded`、`tileEffectRemoved`。这是内容执行中的同步表现作用域：FIFO drain 每次 push；同一个队列在 drain 中再次 push 的工作追加到尾部。回调不返回规则结果，不可异步。未知类型在执行回调之前失败。它不是 EffectChain 的通用规则 writer。

```js
context.presentationQueue.push('statusRemoved', function () {
  targets.forEach(function (target) {
    removeStatusEffectById(target.instanceId, statusId);
  });
});
```

只读记录器在作用域前后及现有规则边界采样。匹配声明类型的事实带同一 `batchId`；其他类型仍独立。被动消费者不继承调用者的批次。播放队列只合并同一根动作中连续、同类型、同显式批次的事件；插入伤害、移动或有实际效果的被动后必须分段。一个技能中的多次 push 不会合成一个批次。

## 渲染与恢复

状态变更和地格效果都从播放前模型开始，每个 batch 完整应用到临时模型后调用一次 renderer.update，不暴露部分目标已更新的中间模型。地格事实携带安全的标识、类型、坐标和图标，保留同一动作内先添加后移除的效果，不依赖最终快照猜测中间结果。无显式标识的地格效果使用类型、位置、来源作为稳定身份，避免数组删除引发后续格子的伪增删。

无批次的旧内容保持顺序播放。略过和清空队列仍收束到权威最终模型。记录不写入 BattleState；pending 试算与失败记录不发布，局部回滚也恢复地格采样及批次计数。

当前主动技能入口提供队列，接入天照之炎、因陀罗之矢、加具土命、赐福、混沌控制。其他内容需在明确连续批量变化处主动声明；不通过解析代码或仅按类型推断同时性。

## 验证与回退

验证四类批次同帧显示、不同批次与生命周期反应隔离、先增后删、稳定地格身份、真实天照九格、状态/hash 中立，以及剑心三段和葛力姆乔连锁回归。类型检查、定向静态检查、浏览器构建和独立审查随本任务执行。回退本次队列声明、采样和渲染接线即可；不需要迁移战斗状态。
