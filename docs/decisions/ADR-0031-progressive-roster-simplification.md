# ADR-0031：渐进部署角色简化

状态：按用户批准方案实施，待验收；任务 RED-189。
基线：main / e7d47cd1b3598237e04752cc77306264babf1deb。

## 决策

- 鸣人增加可见被动“率先出阵”。模板 `progressiveDeployment.openingVanguardPriority` 控制先锋候选池，不依赖角色 ID；有优先棋子时只在优先池使用原命名种子流抽取。出生格、召唤事件、随机调用次数以及非优先阵容行为不变。未来多个优先模板按同样种子规则选一枚。
- 模板 `playerRules` 在初始化时按所有者和规则 ID 去重加载。古尔丹授予玩家级裂魂，预备区、上场和死亡不影响规则存续；每枚正式死亡（含双方召唤物）授予一张灵魂残片。双方各有古尔丹时各自获得。强制移除不触发死亡收集。规则缺失时初始化失败。
- 带土仅保留神威·转移和原神威·时空间。前者 1 AP、冷却 3，先选择自身 7 格内其他存活友军，再选择自身 7 格内空可行走地格，立即传送。禁锢、无法行动及预留落点不可选。取消或非法命令不消费资源；不触发普通移动的结晶收集或免费首移消费。
- 末日铁拳移除手炮与格挡，火箭重拳伤害倍率从 200% 提高为 250%；路径、费用、冷却和撼地猛击保持现行规则。

## 边界与代价

保留旧技能、旧裂魂规则文件供既有引用与历史数据使用，当前模板不再挂载。未迁移正在进行中的旧对局，改动在新局初始化生效。通用传送第三参数只扩展当前可信主技能上下文；目标权限由声明式 targeting 与技能校验负责。目标步骤 `forbiddenTileEffectTypes` 保持候选与提交一致。

本任务不实施关键词体系重构。传送、冲刺及效果复用继续讨论，不增加触发时机关键词。

## 验证与回退

测试与限制见 [RED-189 QA](../qa/RED-189-progressive-roster.md)。回退本任务的数据、引擎、测试和文档变更即可恢复新局旧行为；无存档版本修改。不得将既有 lint 或 AI 准入失败视作通过，未经批准不合并或发布。

## 用户追加：仙人模式

移除打坐期间的一次免伤，保留原打坐限制、倒计时、分身加速以及完成后3 AP和1 CP奖励。旧免伤规则定义保留历史兼容，新释放不再挂载。
