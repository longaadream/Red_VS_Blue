# ADR-0037：玩家资料、已结束对局摘要与官方回放

状态：实施候选，RED-244；2026-10-08 用户已批准 High 方案，未合并/发布。

## 问题

账号已有认证、排位与好友关系，但缺少统一档案、可编辑头像昵称以及可读战绩。直接公开权威数据库战报会暴露非展示字段；从当前规则重算旧回放也无法保证历史事实。

## 决定

- 复用官方账号与会话。昵称仍写入 `official_accounts.name`，头像保存在独立版本化 `official_player_profiles`；只允许本人认证修改及服务器棋子目录 ID，无上传。
- 登录玩家可读取明确白名单的卡片、档案、已结束对局摘要。摘要只使用真实锁定阵容，常用阵容按完整八棋子组合统计。旧记录缺失资料明确为空，不拼造阵容。
- 角色统计只采用已实际开局且落盘终局的官方结算记录，按服务器资源身份隔离；分子、分母在同一个只读 REPEATABLE READ 事务内取得。
- 回放先验证参赛者及终局权限，再读现有 PostgreSQL 验证报告。导出沿用 Trace v2；journal 模式只复原报告中已有的权威记录帧，不执行技能/卡牌代码。保留大小、脱敏、完整性检查与局外查看门禁，不公开原始 receipts/checkpoint 容器。
- 好友邀请独立表、五分钟过期、每分钟五条上限、删除好友/任一方向屏蔽后失效。邀请只携带同一服务器内的目标主机/房间标识，不是入房凭据，客户端继续执行已有资源校验与签名加入流程。
- 页面共用档案弹窗。历史名称保留当局记录；头像可使用当前头像。账号或服务器变化使旧请求结果失效。头像查询缓存并合并请求，避免战斗重绘触发网络风暴。

## 不改变的边界

不修改游戏规则、Elo 计算、随机算法、既有存档、journal 与 Trace 格式。没有头像上传、私聊或新的全局身份来源。完成实现不代表人工产品体验已验收。

## 回退

关闭新增接口和入口或回退本任务提交，保留新增资料与邀请表。旧账号、排位和回放文件继续采用原协议，毋须反向迁移。
