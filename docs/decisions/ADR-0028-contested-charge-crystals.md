# ADR-0028：以公共永久地格效果表达可争夺充能结晶

## 状态

已接受；RED-185 按已批准的产品合同实现。

## 日期与基线

- 日期：2026-09-05。
- Linear：RED-185。
- `base_branch`：`main`。
- `base_sha`：`41748fbea0111f6e3ead4237e3beef000d22b6d4`。
- 继承决策：ADR-0004、ADR-0010、ADR-0011、ADR-0012、ADR-0016、ADR-0022。

## 背景

旧规则在 DeathBatch 墓地提交后直接给击杀方增加通用 CP。这无法表达对手争夺、跨动作留场、多枚同格拾取，也把死亡结算与真正的资源获得时机混为一体。现有权威状态已经用 `battle.extensions.tileEffects` 表达可见、可持久化、可投影的棋盘效果。

## 决策

1. 最终进入墓地的正式核心棋子（`isCore=true` 且非 `noKillCharge`）在冻结的死亡坐标生成一枚 `tileType: "charge-crystal"` 的中立公共地格效果。复活、普通召唤物和强制移除不生成。
2. 结晶 ID 由 DeathBatch ID 与死亡棋子稳定 ID 构成；多个结晶可以占据同一格并独立进入状态 hash、快照、重连、回放、AI v2 观察和展示事件。
3. 结晶没有回合期限。只有成功的普通 `move` 在最终落点执行收集；同格全部结晶原子移除，移动方队伍按数量获得 CP，并派发一次合计数量的 `afterChargeGained`。
4. 部署、召唤、原地站立、传送及其他强制位移不收集。收集不增加普通移动自身的 AP 费用。
5. 通用击杀不再立即加 CP。霜之哀伤保留内容级即时奖励，但由 +2 调整为 +1；若受害者为正式核心，仍生成通用结晶。

## 理由

复用公共 `tileEffects` 可避免建立第二套棋盘实体、网络投影与回放协议。把收集点放在权威普通移动 reducer 中，使“只有普通移动”成为结构约束，而不是由每个召唤或位移技能分别排除；DeathBatch 只负责死亡资格和稳定落点，资源触发发生在真正拾取时。

## 兼容与回退

- 旧存档没有 `charge-crystal` 时行为自然为空；未知地格效果继续由既有投影容忍。
- 若回退 RED-185，需同时恢复旧通用击杀充能和霜之哀伤 +2，并移除结晶生成、移动收集、展示元数据及教程步骤，不能只隐藏 UI。

## 验证

- 正式死亡、复活与排除项测试；双方争夺、持久存在、同格多枚与普通移动费用测试。
- Frostmourne +1 且仍掉落测试。
- 状态 hash/公开投影/AI 观察、TypeScript、静态检查和固定 seed 自博弈验证。
