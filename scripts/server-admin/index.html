连接服务器

沿用本机 known_hosts 验证服务器身份；私钥不会上传。排位需先完成邮件和数据库配置。

版本与资源

上传包含资源和引擎的完整构建目录，先校验，再启用。

启用会停服并备份数据库，再切换版本。回退时填写上方版本列表中的旧版本名称。切换失败会尝试恢复旧版。

连接原服务器指挥台

保留账号、对局、SMTP、赛季、公告、备份恢复和审计功能。服务端必须先启动原指挥台；端口和令牌来自其本机管理地址，不是玩家服务端口。

手动连接（通常无需填写）

凭据仅保留在当前管理进程内存，通过 SSH 访问服务器回环地址。自动读取服务器受限目录中的管理地址，不需要开放管理端口。
