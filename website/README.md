# 官网展示与基础音效预览

本次将官网由更新记录主导改成游戏介绍、真实截图、角色展示与下载入口；Wiki 暂不实施。按最新反馈删除训练营准备展示、挑衅口号和重复介绍，主要说明 PVP / PVE、LAN / 服务器。战斗展示采用 GitHub README 的 `docs/media/feature.png`：真实千鸟突进/命中分镜，原生伤害字放大，速度线为宣传加工；完整界面来自 `docs/media/battle.png`。不把拼贴图称为原始录像。

四张原创 SVG 涂鸦位于 `assets/doodle-*.svg`，使用不规则线条与纸片布局。`motion.js` 通过 IntersectionObserver 触发一次性出现效果，用 requestAnimationFrame 合并滚动事件，仅移动可见插画，偏移最多 16px；无 JavaScript 仍能阅读全部内容，系统减少动态效果设置会关闭动画，页面恢复时重新注册观察器。不拦截滚动或要求用户等待动画。

## 构建与预览

在仓库根目录运行：

```powershell
node scripts/build-official-site.mjs
node scripts/preview-official-site.mjs
```

输出为 `output/official-site-preview`，预览地址 `http://127.0.0.1:4188/`。构建需要已验收的 `output/release-019-content/source` 快照，缺失时明确失败，不回退到旧数据。图鉴展示该快照的资源 1.0.4，明确标为候选；公开下载仍沿用 `website/release.json` 中的客户端 0.1.7 / 资源 1.0.2。正式发布新的资源时须同时更新构建快照、图鉴标签、发布清单、HTML 兜底链接和资源发布页链接。

游戏内 `pieces.html` 与官网生成器共用 `data/pages/js/gallery-content.js`：排除 PVE 专用模式及旧版 pve- 模板，保留兼容 PVP/PVE 的普通角色。本次 36 位。官网从同一资源快照读取基础技能、可解锁技能与解锁来源、关键词的短/长解释、相关卡牌的图像/消耗/效果，不导出规则代码。搜索同时覆盖关键词和关联卡牌；生成遇到缺失定义直接报错。

资源手动下载导向已核验的 GitHub 资源发布页，避免 COS 对象当前的 text/plain 响应头导致浏览器打开二进制文本。Windows / Android COS 地址保持不变。

## 音效

`data/pages/js/battle-audio.js` 提供原创 Web Audio 合成音效：伤害、治疗、移动、传送；通过战斗表现阶段触发，不更改规则。单个动作内同类范围效果合并；重复播放阶段去重；跳过动画不补响。音量设置保存在本机，默认 45%，支持静音；首次输入前不自动发声，后台页面抑制新声音，声部上限为 12。

试听页 `/sound-preview.html`。构建脚本从游戏代码复制音效模块，避免维护两份实现。
