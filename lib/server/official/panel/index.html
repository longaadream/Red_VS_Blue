备份与恢复

先开启维护并等待比赛结束。备份和恢复会短暂停止玩家服务，完成后保持维护状态。备份包含账号、战绩及数据库中的对局记录，不包含 SMTP 配置。

恢复会将数据回到备份时间，恢复前自动备份当前数据。仅支持原 Windows 用户、本机同版本数据库备份。旧数据副本会保留在服务器数据目录，不自动删除。
